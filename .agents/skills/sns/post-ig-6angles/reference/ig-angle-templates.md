# Instagram 6切り口テンプレート集

X 版（rules §2-0 template + §2-8 相性表）と同じ 6 切り口を Instagram 向けに最適化。
違いは (1) キャプション 300-600 字、(2) ハッシュタグ 8-12 個、(3) URL なし→「プロフィールから」CTA、
(4) **カルーセルのスライドコピーが必要**。

---

## カルーセルの共通構造

```
Slide 1: 表紙（切り口フック + ランキング名）  ← 3秒で止まらせる
Slide 2-4: 本体（切り口別の中身、下記参照）
Slide 5: データ補足 / 地図（コロプレス or 簡易棒グラフ）
Slide 最終: 出典 + 保存CTA + プロフィール誘導
```

キャプションは Slide 1 の中身を軸に書く。スライド全体の要約ではなく「Slide 1 だけ見た人にも刺さる」文面にする。

## 共通 NG パターン（Instagram 版）

| NG | 理由 |
|---|---|
| キャプションにクリッカブル URL を入れる | Instagram は caption のリンクがクリックできない（プロフィールから誘導） |
| ハッシュタグ 15 個超え | スパム判定リスク、エンゲージメント低下 |
| スライドコピーが長すぎる（1枚 20 字超） | 1スライドは「一目で読める量」に制限 |
| 数値の推測・捏造 | `evidence-based-judgment.md` 違反 |
| 「のはず」「おそらく」等の推測語 | 同上 |
| 保存 CTA がない | 保存率がアルゴリズムに直結 |
| 「プロフィールから」誘導がない | Instagram の唯一の外部リンク経路 |
