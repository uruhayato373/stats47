## 推奨アクション

1. **最優先 = 候補1（一票の格差／議員定数）**: 6/4 に高市首相が「衆院比例45減」を自民に指示し、はてブ economics で 198+105+66 users と最ホット。stats47 に `prefectural-assembly-members`（都道府県議会議員数）・`voter-list-registrants`（選挙人名簿登録者数）があり、人口/有権者あたり議員数＝「一票の格差」を 47 都道府県で可視化できる。**未カバーの新規テーマ × 時事性最高 × データ保有**の三拍子。タイトルは curiosity gap で「あなたの一票は何分の一か／鳥取と東京で◯倍」型に。
2. **次点 = 候補2（出産費用）**: はてブ life「出産に金すら出さない男」238 users＋「妊婦健診・出産費用の値上がり」が話題、出生数最低ニュースとも連動。既存の出生率記事（fertility-rate / fertility-fiscal-nexus / birth-death-gap）とは別軸の **「出産費用＝出産入院料消費支出額の県差」** で差別化。`maternity-hospital-consumption-expenditure` で直接書ける。
3. **候補3（認知症死亡率）**: 「認知症 治療可能に・新薬」報道（健康トピック）。`dementia-death-rate` が直接あり未カバー。新薬時代に「どの県で認知症死亡率が高いか」は需要あり。
4. **候補4（原発建て替え 14基）**: 経産省が 2050 年代までに最大14基建て替え目標。`nuclear-power-plant-count`＋`electricity-generation-capacity` で「発電を担う県と消費する県の偏り」を可視化可。立地自治体の論点と接続。
5. **候補7（乳用牛）は brushup**: GSC で「乳用牛 都道府県 ランキング」が 758 impressions（クイズ流入「中国地方5県のうち乳用牛が…」）。**既存記事 `dairy-cattle-hokkaido-monopoly` に流入中**なので新規不要 → 中国地方5県比較セクションを追記する brushup でクイズ需要を取り込む。

- **トレンド概要**: 2026-06-04、高市首相が自民幹事長に「衆院比例代表 45 削減」を指示。議員定数削減論が再燃。はてブ economics で複数エントリ（198 / 105 / 66 / 9 users）、Yahoo 国内「衆院定数は比例45削減 首相指示」。
- **注目度**: はてブ合計 ~370 users（economics 上位）＋ Yahoo トピックス掲載
- **分類カテゴリ**: administrativefinancial（行財政）
- **ヒットソース数**: 2 / 6（hatena, yahoo）
- **タイミング**: 定数削減＝「一票の重み」の地域差が直接の論点。今まさに議論の俎上。

#### 使えるデータ
| データ | ソース | ranking_key | 備考 |

#### 記事の切り口（案）

## メモ

- **過密テーマ（新規不要・brushup 検討）**: 出生率本体（fertility-rate-prefecture-gap / fertility-fiscal-nexus / birth-death-gap-decline で 6 記事級）、東京一極集中（population-migration-tokyo-concentration）、ガソリン価格。2025 国勢調査速報（東京圏 30.1%／東北 6.2%減・秋田ワースト＝note WebSearch で確認）は既存記事への 2025 反映で対応。
- **データなしで離脱（★☆☆）**: クマ被害（鳥獣被害データ未整備）、はしか・RSウイルス（県別感染症データ薄い）、富山空港改名（空港乗降客の県別データなし）。e-Stat 追加が要るため `--deep` 指定時の補完候補。
- **競合動向（note）**: 「未来予測ラボ（data_analyst_jp）」が持続可能性スコア・消滅リスク・格差変動スコア・老後コスト等を多指標分析で量産中。stats47 は単一指標 × curiosity gap × Web 送客で差別化（[感情喚起の煽り合戦に入らない](feedback_sns_growth_emotion_themes)）。
