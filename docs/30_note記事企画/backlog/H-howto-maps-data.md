# H シリーズ × 操作手順（地図・データの使い方）— note 記事候補

## 概要

GIS の専門家ではなく、**自分のデータや公的統計を地図・Excel・レポートで使いたい一般の人**に向けた操作手順の連載。
無料で公開し（収益化戦略 §3.3「note は無料が基本」）、末尾から stats47 のダウンロード（CSV / KML / GeoJSON）へつなぐ。

### なぜこの連載か（2026-10-17 実測）

- note の「【保存版】GoogleマップでKMLファイルを利用する方法」（2025-12-05 公開）は通算の閲覧 3,226 で note 286 本中 2 位、
  直近 28 日（2026-09-07〜10-04）も閲覧 377。note 内の表示は 10 回しかなく、読者は note の外（検索）から来ている。
  出典: `data/note/dashboard/2021-05-01_2026-09-11_*.json`・`2026-09-07_2026-10-04_*.json`（`pageViews` と `impressions`）
- note 全体でも、閲覧が note 内の表示の 5 倍を超える 11 本が全閲覧 7,048 の 55% を占める。note は検索の受け皿として働いている
- KML 記事の末尾から案内している有料の GIS 分析記事（洪水×人口・地価×人口など）は 28 日の閲覧が 1〜5。
  読者が求めるのは分析ではなく「地図にデータを載せる操作」で、目的が合っていない
- stats47 のサイト側でも「e-stat 使い方」が 28 日で表示 49・平均 9 位、「gis 土地利用」28・「gis 鉄道」26 の表示がある
  （`data/gsc/snapshots/2026-W41/queries.csv`）。サイトは GIS 系で 20〜37 位と弱いので、受け皿は note に置く
- サイトのダウンロードは 3 週で 194 → 414 回（28 日）に増え、用途の最多は「学習」（`data/ga4/snapshots/2026-W41/`）

**仮説**: 検索で探される操作手順の記事を増やすと、note の閲覧が増え、末尾から stats47 のダウンロードへの流入が増える。
需要の証拠は KML 記事 1 本の実績だけなので、1 本ずつ出して閲覧と送客を測る。
