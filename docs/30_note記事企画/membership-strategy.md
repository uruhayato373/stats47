# note メンバーシップ収益化戦略

> AI を制作エンジンに据えた前提でのメンバーシップ事業設計。
> 既存 note戦略.md (無料記事による送客ファネル) と並行・補完する有料収益化ライン。

## なぜ今やるか — AI 前提で経済構造が変わる

従来想定 (人間制作前提):
- 記事 1 本 = 3〜5 日 (取材・図表・執筆)
- 月産 4〜8 本が限界、固定費としての人件費が大きい
- 損益分岐 = ¥1000 × 100〜300 人 → 集客が事前条件

AI 前提 (Claude Code + 既存資産):
- 記事 1 本 = 半日 (人間は企画・確認、AI が実装)
- 月産 10〜20 本可能、限界費用 ≒ 0
- 固定費: **Claude Pro ¥15,000 / 月**
- 損益分岐: ¥1000 × **15 人** (note 手数料込みで実質 17〜19 人)
- 100 人達成で **月¥85,000+ の純利益**

**結論**: 「audience がない段階で memberhip は早い」という慣習論は AI 前提では成立しない。
固定費が極端に低いので、20 人取れた瞬間に黒字化、その後は完全レバレッジ。

## 3 段階ロールアウト

| Stage | 期間 | 形態 | 価格 | 目標 |
|---|---|---|---|---|
| **1. 単発有料記事** | 2026-06 〜 2026-08 | note 単記事 | ¥500-1000 | 月3〜5本、合計 30 部 / 月 売れたら次段階 |

Stage 1 は需要検証フェーズ。「動画 + 解説 + データ + プロセス公開」の単発記事で、買い手が誰か (個人・自治体・研究者・エンジニア) を把握する。

## 訴求の核 (差別化)

「Claude が作った」は手法であって価値ではない。買い手が払う理由を 4 つに分けて設計:

| 価値類型 | 例 | 想定買い手 |
|---|---|---|
| **物語の深さ** | 「自殺率の半世紀 — 1998年の急増と平成大不況」 | 一般読者・ジャーナリスト |
| **データの希少性** | 「過疎×医療×教育のクロス分析、47県半世紀分」 | 研究者・自治体職員 |
| **意思決定支援** | 「リモートワーカー向け47県スコア」 | 移住検討者 |
| **舞台裏 (How-to)** | 「Claude Code + e-Stat で47県時系列動画を1日で作る (全スクリプト公開)」 | エンジニア・データ職 |

特に **舞台裏シリーズ** はリピート率高 + 単価¥1500 設定可能 + エンジニア層は決済ハードル低い → 高 ARPU。

## 技術的注記 (note 動画埋め込み)

| 方法 | 可否 | 用途 |
|---|---|---|
| YouTube URL 貼付 | ✅ 推奨 | URL 1 行で自動展開、最も信頼性高い |
| Vimeo 埋め込み | ✅ | ¥7,000/年〜、Private で有料壁内に閉じ込められる |
| GIF アップロード | ✅ | 短いループ (5-10秒) を本文に挟む |
| MP4 直接アップ | ❌ | note 非対応 |

実運用パターン:
- 動画自体は **YouTube public** で外に出して誘導役にする
- **解説 + 出典データ + プロセス** を有料壁の中に置く
- YouTube 再生数も独立 KPI として計測可能 (YT Analytics + GA4)

## KPI 設計
