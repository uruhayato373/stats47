# 東京一極集中はいつ始まった？──人口前年度比で読む47都道府県の50年史

## 【無料部分】

### 動画 (1分11秒)

> `https://www.youtube.com/watch?v=3O4v9iVgntE`

47都道府県の人口前年度比 (5年中央移動平均) を 1976〜2024 年で色付けしたコロプレス地図のアニメーションです。**増加 = 青／減少 = 赤** で、各年の各県が「人口を増やしているか／減らしているか」が一目で分かります。

### 3 つの驚き

この動画を 49 年分通しで見て分かることは、次の 3 つです。

1. **「東京一極集中」は1980年代にはまだ存在しない。むしろ周辺県 (神奈川・千葉・埼玉・愛知) のほうが東京より青かった**
2. **1994 年、東京自身も人口減少県だった (-0.14%/年)**。平成不況の傷は中央にも届いていた
3. **東京一極集中の本当のピークは 2006 年 (+0.93%/年)**。意外と最近の現象

「いつ東京は地方を吸い上げ始めたのか？」── この問いの答えは、データを 49 年分連続で見ないと出てきません。本記事では、動画の 4 つの時代区分を、データと歴史的事象を重ねながら解説します。

### 第 1 幕: 高度成長の余韻 (1976〜1990)

1976 年から始まる動画の最初の 15 年間、青く塗られているのは **「東京を取り囲む県」** です。神奈川 (1976-1990 年平均 +1.4%/年)、千葉 (+1.6%)、埼玉 (+1.5%)、愛知 (+1.0%)、大阪 (+0.7%)。一方の東京は +0.4%/年 程度で、地方並みの増加率に留まっています。

この時代は **郊外化 (suburbanization) の最盛期** でした。都心の住宅は地価高騰で手が出ず、若い世帯は神奈川・千葉・埼玉のニュータウンに住宅を求めた。東京駅から 30 分以内に通勤できる横浜・千葉・大宮が爆発的に人口を増やします。

地方でも、**沖縄が突出して青く** 描かれます (1983 年ピーク +1.28%/年)。1972 年の本土復帰から 11 年、米軍関連や本土からの移住、出生率の高さで、47 都道府県中ぶっちぎりの増加率を維持しました。

このフレーズで覚えてください: **「1980 年代の東京は『一極集中』ではなく『中心地化』だった」**。中心地が大きくなる代わりに、周辺県と一緒に成長していた。

### 第 2 幕: 平成不況と東京自身の減少 (1991〜2003)

バブル崩壊 (1991) から 10 年、地図全体が薄くなっていきます。神奈川・千葉・埼玉の濃い青は色を失い、地方は薄い赤に染まり始める。

**そして 1994 年、東京自身も赤く塗られます (-0.14%/年)**。

これは多くの人が知らない事実です。「東京は常に人口を吸い上げてきた」という直感は、実は誤りで、平成不況の真っ只中、東京 23 区は若年層の流入が止まり、自然減 (出生 < 死亡) と社会減 (転入 < 転出) のダブルパンチで一時的にマイナス成長になっています。

この時期、青い色を保っているのは沖縄と神奈川だけ。

**1995 年 1 月 17 日、阪神大震災**。兵庫県は復興期に大量の人口流出を経験します (動画では兵庫が一時的に深い赤に)。被災住民は大阪・京都だけでなく、関東圏に大量に移住しました。

### 第 3 幕: 都心回帰と東京一極のピーク (2004〜2014)

2004 年から、東京がはっきりと青くなり始めます。**2006 年、東京の前年度比は +0.93%/年 (5年MA) でピーク**。

何が起きていたか:
- **都心マンションブーム**: バブル崩壊で更地になった都心の地価がボトムを打ち、不動産デベロッパーが大量の超高層マンションを供給。汐留、品川、豊洲、新宿西口
- **小泉構造改革 (2001-2006)**: 規制緩和で都心の容積率が引き上げられ、再開発が加速
- **団塊ジュニア世代の流入**: 1990 年代に進学・就職で上京した世代が、結婚・出産期に都心に定着

この時期、**周辺県 (神奈川・千葉・埼玉) の青も維持されます**。しかし注目すべきは、**東京の青のほうが濃くなった** こと。1980 年代までは「東京 < 神奈川」だった増加率が、2000 年代後半に逆転します。

**2008 年 9 月、リーマンショック**。経済停滞は明らかですが、地図はあまり変わりません。雇用が東京に集中する構造はむしろ強化され、失業した地方は「次の仕事を求めて東京へ」のパターンを加速させます。

**2011 年 3 月 11 日、東日本大震災**。福島・宮城・岩手の三県は深い赤に。

### 第 4 幕: 「東京 vs それ以外」の確立 (2015〜2024)

2015 年以降、地図は明確に二極化します。**東京 (+0.4〜0.7%/年) と、それ以外のほぼすべての県** という構図。

特に印象的なのは、**長年青く塗られていた神奈川・千葉も淡くなる** こと。2010 年代後半、これら周辺県も人口増加が止まり始め、東京一極集中は「東京 23 区一極集中」に純化していきます。

**2020 年、コロナ**。リモートワーク普及で「地方移住ブーム」が話題になりましたが、データを見るとブームは限定的でした。一時的に東京 23 区から周辺県への転出が増えましたが、2022 年以降は再び東京流入に戻っています。

**2024 年現在**:
- 東京: +0.4〜0.7%/年 (依然増加)
- Tokyo 周辺 (神奈川・埼玉・千葉): ほぼ 0 (横ばい)
- 地方の大半: -0.5 〜 -1.5%/年 (深刻な減少)
- 最大の減少県: **高知 -1.38%/年**
- 北海道: -0.91%/年
- 沖縄: ついに -0.05%/年 (1972 年以来の減少県化)

## 「もう一つの東京一極集中」

東京以外で青く描かれ続けた数少ない例外:

- **千葉県 浦安市・流山市** (動画では県単位)
- **神奈川県 川崎市**
- **滋賀県** (関西版郊外化、京都・大阪からの流入)
- **福岡県** (九州唯一の継続増加県、九州各県からの吸い上げ)

つまり「地方の中の小東京」が日本各地に発生しています。福岡が九州内で果たしている役割は、東京が日本全体で果たしている役割と相似形です。

## なぜ「半世紀」で見る必要があるのか

メディアでよく見る「東京一極集中グラフ」は 5〜10 年程度のスパンが多いです。しかしそれだと:

- **「1980 年代までは違った」という事実が見えない**
- 「いつ始まったのか」の答えが出せない
- バブル崩壊・平成不況・リーマン・震災・コロナの **時代と人口動態の対応関係** が見えない

50 年分の連続データを地図で見て初めて、「東京一極集中」は **2000 年代後半の比較的新しい現象** であり、**周辺県の失速とセット** で進行していることが分かります。

## 制作プロセス (Claude Code × e-Stat × Remotion)

本記事と動画は、**Claude Code を制作エンジンとして** 半日で完成しました。プロセスを公開します。

1. **データ取得** (10 分)
   - e-Stat API から「推計人口」の 50 年分一括取得
   - スクリプト: `.claude/scripts/estat/backfill-stats-prefecture.cjs`
   - 「`cdTimeFrom` を使わず全年度取得 → メモリでフィルタ」が e-Stat キャッシュ規約

2. **YoY 加工** (5 分)
   - 各県の前年度比 P(t)/P(t-1) を算出
   - 5年中央移動平均で平滑化 (端は窓を切詰め)
   - 全期間 maxAbs を計算 (配色 domain 用)
   - スクリプト: `.claude/scripts/web/build-yoy-timeseries.cjs`

3. **動画生成** (Remotion, 2 時間)
   - d3-geo + interpolateRdBu で コロプレス
   - フレーム同期型アニメーション (1.2 秒/年)
   - intro テロップで計算方法を可視化
   - レンダー時間: ~3 分 (1920×1080 / 30fps / 2010 frame)

4. **note 記事執筆** (3 時間)
   - 動画を見ながら 4 幕構成で骨子化
   - 各時代の歴史的事象とデータを対応
   - Claude (会話で本記事を共同執筆)

合計 **6 時間程度**。同種記事を量産するための制作スクリプトはすべてオープンソースなので、興味ある方は GitHub リポジトリでご確認ください。
