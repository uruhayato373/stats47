## D-1: 医師不足県は自殺率も高いのか？相関を半世紀で見る

### メタ
- 価格: ¥800
- ビジュアル: 2 つの YoY コロプレス並列表示 + scatter (47点、年別アニメ)
- ターゲット: 政策研究者、ジャーナリスト、医療関係者
- 想定字数: 5500

### 「直感に反する事実」フック
- 一般的な思い込み: 医師が少ない県 → 心療内科にもアクセス困難 → 自殺率高い
- **実データ: 相関は意外と弱い (r = -0.3 程度)**
- 秋田は医師数全国 19 位 (中位) なのに自殺率全国 1 位
- 高知は医師数全国 1 位なのに自殺率全国 4 位

### 構成
1. 47 県の医師数 vs 自殺率の scatter (2023 年)
2. 1975-2023 で相関係数の推移
3. 「医師数では説明できない」上下県の深掘り (秋田・高知・島根 etc)
4. 別の説明変数: 雇用率、農林漁業従事者比率、独居高齢者率
5. **本当に効くのは「コミュニティ強度」と「就労機会」** — その証拠
6. 政策への示唆 (相談窓口だけでは不十分)

## D-2: 過疎地ほど出生率が高い逆説 — 都市の罠を可視化

### メタ
- 価格: ¥800
- 想定字数: 5500

### 「直感に反する事実」フック
- 一般的な思い込み: 経済力ある都市の方が結婚・出産しやすい
- **実データ: 出生率は東京最下位 (1.08)、沖縄 1 位 (1.60)、明確な逆相関**
- 経済力が高いほど出生率が低い (世界的傾向と同じ)

### 構成
1. 47 県の人口密度 vs 出生率 scatter
2. 県民所得 vs 出生率 scatter
3. 過疎県でなぜ出生率が高いのか
   - 住宅費安い、3世代同居率高い、コミュニティ強い
4. 都市の罠: なぜ経済力があると出生率が下がるか
   - 住宅費・教育費・機会費用
5. 例外: 福岡県 (都会だが出生率高め)、何が違うか
6. 政策への示唆: お金より住宅と社会保障

## D-3: 観光客が多い県は地元住民は幸せか？

### メタ
- 価格: ¥600
- 想定字数: 4500

### 「直感に反する事実」フック
- 一般的な思い込み: 観光客増 = 経済潤う = 地元住民幸せ
- **実データ: 京都、伊勢などはオーバーツーリズムで地元満足度低下**
- 一方、北海道、長野などは観光と地元生活が共存

### 構成
1. 47 県の外国人宿泊客数 vs 地元住民満足度 (内閣府調査)
2. 物価上昇、家賃上昇、混雑との関係
3. オーバーツーリズム化県 (京都、大阪、沖縄) と適応県 (北海道、長野) の比較
4. 観光収益の地元配分率の問題
5. 政策示唆: ホテル税、住民優先施策

## D-4: 製造業が強い県は子育てしやすい？

### メタ
- 価格: ¥600
- 想定字数: 4500

### 「直感に反する事実」フック
- 一般的な思い込み: 製造業好調 = 雇用安定 = 子育てしやすい
- **実データ: 微妙。愛知・三重は出生率中位、栃木はやや低い**
- 「製造業」の中身が変わったから、一律ではない

### 構成
1. 製造業出荷額シェア vs 出生率
2. 自動車製造県 (愛知・栃木・神奈川) と電機製造県 (三重・福岡) の違い
3. 製造業雇用の女性比率の問題
4. シフトワーク・夜勤と子育ての両立難
5. 政策示唆: 製造業誘致だけでは子育て改善せず

## D-5: 人口減少が止まらないのに地価が上がる県

### メタ
- 価格: ¥800
- 想定字数: 5000

### 「直感に反する事実」フック
- 一般的な思い込み: 人口減 → 需要減 → 地価下落
- **実データ: 福岡・沖縄・札幌は人口減 (or 横ばい) でも地価上昇**
- 北海道全体は人口減でも、札幌市は地価上昇

### 構成
1. 47 県の人口増減率 vs 地価変動率 scatter
2. 例外県の分析: 福岡 (アジア接続)、沖縄 (リゾート開発)、札幌 (北海道集中)
3. 「県内集中」の構造: 県全体は減でも県庁所在地は増
4. 投資マネー・インバウンドマネーの効果
5. 政策示唆: 県単位ではなく市町村単位での施策必要
