## 地方財政テーマの SNS コンテンツ案

### Compare（2地域比較）— `/preview-remotion --type comparison`

**方針**: 対決ペアと指標テーマを独立管理し、ペア × テーマの組み合わせで動画を量産する。各テーマ5指標を順に比較し、勝敗を積み上げる60〜90秒のショート動画。

#### 指標テーマ

| # | テーマ名 | 訴求 | 指標 |
|---|---|---|---|
| T-1 | 財政比較 | 「財政的に強いのはどっち？」 | 財政力指数 / 経常収支比率 / 実質公債費比率 / 将来負担比率 / 地方税割合 |
| T-2 | 公務員になるなら？ | 「待遇がいいのはどっち？」 | 平均給与月額 / ボーナス / 退職金 / ラスパイレス指数 / 時間外手当 |
| T-3 | 税金の使い方対決 | 「住民にお金を使ってるのは？」 | 1人当たり歳出 / 1人当たり教育費 / 1人当たり民生費 / 人件費割合 / 民生費割合 |
| T-4 | 知事と警察官の給料 | 「トップの給料が高いのは？」 | 知事の給料 / 警察官給与 / 平均給与月額 / ボーナス / 退職金 |
| T-5 | 借金ヤバいのはどっち？ | 「将来の負担が大きいのは？」 | 将来負担比率 / 実質公債費比率 / 経常収支比率 / 民生費割合 / 財政力指数 |

#### 対決ペア

| # | 対決 | コンセプト | 注目ポイント |
|---|---|---|---|
| CMP-1 | 東京都 vs 大阪府 | 2大都市対決 | 知事給料で大阪が逆転（東京50%カット） |
| CMP-2 | 東京都 vs 島根県 | 最強 vs 最弱 | 財政力5倍差。でも実質収支比率は島根が上 |
| CMP-3 | 北海道 vs 沖縄県 | 北と南の端 | 北海道だけ実質公債費比率18%超え |
| CMP-4 | 神奈川県 vs 埼玉県 | 首都圏ライバル | 人口規模が近いのにどこで差がつく？ |
| CMP-5 | 愛知県 vs 大阪府 | 製造業 vs 商業 | 財政力は愛知が上、歳出構造は大きく異なる |
| CMP-6 | 兵庫県 vs 福岡県 | 地方中核対決 | 兵庫の将来負担比率313%の衝撃 |
| CMP-7 | 石川県 vs 富山県 | 隣県対決 | 能登地震で石川の時間外手当が全国1位 |

### Correlation（相関散布図）— `/preview-remotion --type correlation`

2指標の関係性を散布図で見せる。

| # | X軸 | Y軸 | 仮説 |
|---|---|---|---|
| COR-1 | 財政力指数 | 地方税割合 | 財政力が高い県は自力で稼いでいるか |
| COR-2 | 人件費割合 | 経常収支比率 | 人件費が財政硬直化の主因か |
| COR-3 | 1人当たり教育費 | 大学進学率 | 教育投資は進学率に影響するか |
| COR-4 | 財政力指数 | 実質収支比率 | 財政力が高い県ほど黒字か（島根県の逆転も注目） |
| COR-5 | ラスパイレス指数 | 財政力指数 | 財政が豊かな県ほど公務員給与は高いのか |
| COR-6 | 平均給与月額 | 平均年齢 | 年齢が高い県ほど給与も高いのか |
| COR-7 | 知事給料 | 財政力指数 | 財政が豊かな県ほど知事の給料は高いのか |
