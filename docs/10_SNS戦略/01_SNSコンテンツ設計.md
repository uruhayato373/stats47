# SNSコンテンツ設計

SNS展開における戦略・テーマ選定・投稿設計を定義する。

> **⚠️ 実行規約の正典は `.claude/rules/sns-content-standards.md` (2026-07〜)。** 本ファイルは背景・思考整理用の
> 読み物で、頻度・雛形・チャネル方針が食い違う場合は rules 側が優先。
>
> **現行チャネル方針 (2026-08-23 更新)**: Instagram = 主力 / X = 自動化・瞬発 / note = 衛星 / YouTube =
> **通常動画3本・6週間の限定 pilot (EXP-006)**。通常動画をマスターにして Instagram Reels / X へ派生する。
> TikTok は撤退恒久。旧「全PF同時投稿（YouTube Shorts / TikTok）・週3-5投稿」の量産モデルは廃止した。

## 0. 設計方針

### 0.0 競合状況 (2026-07 更新)

| 競合 | 状況 | 示唆 |
|---|---|---|
| **@riskmap.jp** (日本リスクマップ) | **IG 約 20K フォロワー**・34 投稿・週次動画更新。当初は治安/心霊系だったが「**47都道府県の統計・ランキングを動画で紹介**」へ framing を寄せてきた (2026-07 実測) | stats47 の主戦場に接近。少数精鋭 (34 投稿で 20K) = **1 本の質と保存率**が効く。煽り追随はせず信頼性×網羅性×Web送客で差別化 |
| **todo-ran / uub** | Web の指標網羅 (1,501 / 1,843 vs stats47 ~533) | Web は守り。SNS は「1 本で刺す」感情設計で勝負 |

- 定点観測は `/competitor-scan` で継続 (テーマ別名乗りで取りこぼしを防ぐ)。
- 参照 memory: `project_competitor_riskmap_jp` / `feedback_sns_competitor_search` / `project_competitor_indicator_benchmark`。

### 0.1 原則

1. **マスターを先に作る** — YouTube の6〜12分通常動画を一次コンテンツとし、主張と出典を保った2〜4本の短尺を Instagram / X へ派生する。各PFを別々に量産しない
2. **テーマは人間の感情から逆算する** — 「数字の格差が大きい=面白い」ではない。金・ステータス・地元愛/自虐・子育ての不安など、人が反応する欲望・コンプレックスから逆算してデータを当てはめる
3. **AI をフル活用し、人間は判断と改善に集中する** — キャプション執筆・テーマ選定・トレンド分析を AI に任せ、人間は「何を投稿しないか」の判断とエンゲージメント分析に注力する
4. **6切り口で物語的深度を持たせる** — shock/versus/question/paradox（エンゲージメントメカニクス層）に加え、結論/理由/体験/反論/数字/ハウツーの **6切り口**でトレンドに乗せた量産を実施。X は `/post-x-6angles`、Instagram は `/post-ig-6angles` が主力（2026-06〜）

### 0.2 YouTube pilot のフェーズ設計

| フェーズ | 期間 | やること | やらないこと |
|---|---|---|---|
| **Phase 1: 3型を制作・公開** | 6週間 | 財布/逆説、意思決定支援、地域雑学の通常動画を各1本。1本から Reels / X を各2〜4本派生 | Shorts-first、47県分割、投稿自動化 |
| **Phase 2: 判定** | 3本目の14日後 | 視聴維持、送客、派生投稿、制作工数を EXP-006 へ記録し継続/修正/再撤退を決める | 結果前の専任agent・OAuth復活 |

### 0.3 判定基準（EXP-006）

各動画は公開14日後、pilot 全体は3本目の14日後に判定する。YouTube Studio の詳細な維持率を読む最低サンプルとして100再生を用いる。

| 判定 | 条件 | アクション |
|---|---|---|
| **継続候補** | 3本完了、2/3本が100再生以上、対象動画の30秒維持率中央値50%以上、平均視聴率35%以上、YouTube UTM engaged sessions 合計10以上 | 通常動画の継続と、計測/投稿自動化の必要性を別途審査 |
| **修正継続** | 反応は基準未達だが、特定の1型または派生投稿が直近28日中央値を上回る | 勝った型だけ2本追加。構成・尺・サムネを1変数ずつ変更 |
| **早期停止** | 最初の2本が各14日で100再生未満かつ30秒維持率30%未満、出典欠陥、または3巡後も制作12時間超/本 | 3本目を停止または再設計。SEO/IG/Xへ集中 |

## 1. AI 活用設計

### 1.1 YouTube マスター1本のワークフロー

```
1. EXP-006 の brief からランキング / ブログ / テーマを横断し、使用 metric・survey・provenance を固定する
2. article-writer が6〜12分の構成・台本・出典表を作り、人間が主張と事実を承認する
3. chart-author が必要な図表素材を作る。Remotion は図表・地図・短いアニメーション素材にだけ使う
4. NLE でナレーション、映像、図表、字幕を編集し、通常動画 master を完成させる
5. 人間が最終視聴し YouTube Studio へ手動投稿。UTM付き stats47 URL と出典を説明欄へ置く
6. master のタイムコードから Reels / X を各2〜4本切り出し、posts.json で親子関係を記録する
7. 公開14日後に Studio と GA4 を計測し、EXP-006 を更新する
```

### 1.2 AI が担う領域 vs 人間がやるべきこと

| 工程 | AI | 人間 |
|---|---|---|
| テーマ選定 | 感情トリガーに基づくテーマ候補提案（スコア付き） | 候補から選択。ボツの理由をフィードバック |
| キャプション執筆 | PF別にフック・本文・CTAを3パターン生成 | 微調整。トーンの最終確認 |
| 画像テキスト | サムネイル上のテキスト・煽りコピーを生成 | 品位チェック。炎上リスク判断 |
| エンゲージメント分析 | インプレッション・RT・引用の傾向を要約 | 勝ちパターンの言語化 |
| コメント返信 | 返信ドラフトを生成 | 最終確認して送信。炎上時は人間が判断 |
| **投稿しない判断** | — | **量より質。死にコンテンツを出さない勇気** |

### 1.3 動画制作方針（通常動画マスター型）

- **編集動画が主、図表生成は従**: NLE で物語・ナレーション・映像・図表を編集する。Remotion は再利用可能な図表素材に限定する
- **1動画1問い**: 冒頭30秒で問いと意外性を示し、定義→比較→理由→限界→結論の順に進める。ランキングの読み上げだけにしない
- **出典を画面と説明欄の両方へ**: metric、年次、単位、統計調査、stats47 の根拠 URL を提示する。ランキング・ブログ・テーマの関連導線を説明欄にまとめる
- **派生は再編集する**: 縦に切るだけでなく、各短尺が単独で理解できるようフック・字幕・CTAを付け直す。元動画の `parent_post_id` と `source_timecode` を台帳へ残す

### 1.4 スキル体系

| スキル | 用途 |
|---|---|
| **`/post-x-6angles`** | **X 用 6切り口量産**（scout→media→writer→reviewer→scheduler の5フェーズ、トレンド連動）★主力 |
| **`/post-ig-6angles`** | **Instagram 用 6切り口量産**（カルーセル or リール判定付き、スライドコピー生成）★主力 |
| `/post-x` | X 向けテキスト+画像を生成。domain / template パラメータで全データドメイン対応 |
| `/post-instagram` | Instagram Graph API 経由で即時投稿（`/post-ig-6angles` 生成物の配信に使う） |
| `/post-note` | note.com 有料記事を作成（無料部+有料部） |
| `/render-sns-stills` | Remotion で図表・地図・短いアニメーション素材を生成。YouTube master の編集器ではない |
| `/nsm-experiment` | EXP-006 の基準・進捗・結果を管理。pilot 成功までは YouTube 専用 skill を新設しない |

## 2. テーマ選定戦略

### 2.1 感情トリガー分類

データの格差や統計的な面白さではなく、**人間の感情を動かすか**で選定する。

| 感情トリガー | テーマ例 | なぜ反応されるか |
|---|---|---|
| **財布・生活不安** | 「年収が高いのに貯金ゼロの県」 | 自分の生活に直結。保存・共有動機が強い |
| **地元愛・自虐** | 「実は全国1位の〇〇県」 | 地元民が反応。引用RTでマウント合戦 |
| **子育て・教育不安** | 「教育費と学力が比例しない県」 | 親世代の切実な関心。DM共有されやすい |
| **格差への怒り** | 「東京vs地方の医療格差」 | 社会的な議論を呼ぶ。引用RTが増える |
| **意外性・裏切り** | 「米消費量1位は新潟じゃない」 | 常識を裏切る。「マジで？」でシェア |

### 2.2 データドメイン × テンプレ型マトリクス

投稿コンテンツは **データドメイン**（素材）と **テンプレ型**（表現）の組み合わせで構成する。

| | 衝撃事実型 | 対決型 | 問いかけ型 | 逆説・警告型 |
|---|---|---|---|---|
| **ranking** | 「〇〇1位は意外な△△県」 | 「1位 vs 47位」 | 「あなたの県は何位？」 | 「〇〇なのに△△が低い県」 |
| **compare** | 「東京と大阪、意外な差」 | 「東京 vs 大阪 5番勝負」 | 「あなたはどっち派？」 | 「勝っているはずが負けている」 |
| **correlation** | 「所得と自殺率の衝撃的関係」 | 「相関する2指標の逆転県」 | 「なぜ〇〇と△△が連動する？」 | 「〇〇が高いほど△△が悪化する」 |

テンプレ型の詳細定義（構造・フック例・適合ドメイン）は各 `/post-*` スキル内の「テンプレート定義」セクションを参照。

### 2.3 Tier 設計

| Tier | 選定基準 | 投稿頻度 | データドメイン | テンプレ型 |
|---|---|---|---|---|
| **Tier 1** | 財布・人生に直結 + 意外性あり | 週2回 | correlation, ranking | 衝撃事実型, 逆説・警告型 |
| **Tier 2** | 地元愛・対決 + 議論を呼ぶ | 週1回 | compare, ranking | 対決型 |
| **Tier 3** | 雑学・豆知識として面白い | 週1回 | ranking | 問いかけ型 |

## 3. X（Twitter）投稿設計

### 3.1 投稿フォーマット

| 要素 | 仕様 |
|---|---|
| テキスト長 | 〜200字。事実凝縮型「ニュース速報」的 |
| 画像 | 1〜4枚。1200 × 675 px（16:9） |
| ハッシュタグ | 0〜2個。トレンド参加時のみ |
| CTA | 「引用で感想を」「RTで拡散」 |
| リンク | URL 直貼り（サイト誘導） |
| アルゴリズム重視指標 | リポスト → 引用RT → 返信 |

### 3.2 画像設計

| 要素 | 仕様 |
|---|---|
| サイズ | 1200 × 675 px（16:9） |
| テキスト | 4語以内。太字サンセリフ（Noto Sans JP Black） |
| 配色 | ダーク背景 + ヒートMAP配色（青→赤）+ 白テキスト |
| MAP | 左にヒートMAP日本地図、右に偏差値・数字を大きく |
| ファイル | JPG/PNG、5MB以下（モバイル） |

### 3.3 投稿カレンダー

週3回、曜日を固定:

| 曜日 | データドメイン | テンプレ型 | Tier |
|---|---|---|---|
| 火 | correlation / ranking | 衝撃事実型 / 逆説・警告型 | Tier 1 |
| 木 | compare | 対決型 | Tier 2 |
| 土 | ranking | 問いかけ型 | Tier 3 |
