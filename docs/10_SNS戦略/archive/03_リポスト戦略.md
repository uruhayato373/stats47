# リポスト戦略 — 公務員・自治体層への露出強化

stats47jp の X アカウントから、都道府県・市町村公式 + 関連省庁の投稿を引用リポストして、公務員層へのリーチを強化する。**自動 follow / like / reply は TOS 違反のため絶対に行わない。** リポストのみ、半自動 (人間承認) で運用。

## ゴール

| KPI | 3 ヶ月後 (2026-08-25) |
|---|---|
| stats47jp フォロワー (X) | +500 (公務員系) |
| ターゲット公式アカウントからの逆 RT | +20 件 |
| `/ports` 系ページの X 経由訪問 | +1,000 セッション/月 |

## ターゲット (75 件)

リスト: `docs/10_SNS戦略/repost-targets.csv`

| 区分 | 件数 | 優先度 A の例 |
|---|---|---|
| 都道府県公式 | 47 | 北海道・東京都・愛知県・大阪府・福岡県・沖縄県 (港湾・物流相性高い県) |
| 政令市・主要市 | 18 | 横浜市・名古屋市・大阪市・神戸市・北九州市・福岡市 |
| 関連省庁 | 6 | 国土交通省・総務省統計局・内閣府地方創生 |

| **合計** | **75** | |

**注意:** CSV 内の handle は `verified=verify` 状態。**公開前に必ず X 上で実在を確認**してから運用開始。リブランディングで handle が変わるため、四半期に 1 回 verify ステップを実施。

## 運用ルール

### 頻度

- **1 日 3 件、月 90 件** (75 ターゲット全員に月 1 回以上接触)
- 時刻分散:
  - 07:30 (公務員出勤前のタイムラインチェック)
  - 12:15 (ランチ休憩)
  - 19:30 (帰宅後)

### リポスト判断基準

**引用リポストする** ✅:
- 統計データ・ランキング・人口・地方経済の発表
- 港湾・物流・交通・観光の数字発表
- 地方創生・自治体 DX・オープンデータ関連の公式情報
- 災害復興データ (人口推移、産業動向)

**リポストしない** ❌:
- 単純な広報 (イベント告知、求人) — 統計性低い
- 政治的発言・選挙関連
- 災害発生時の緊急情報 (拡散誤情報リスク)
- 医療誤情報につながる可能性のあるもの
- 純粋な観光広告 (data 性なし)

### リポスト形式

**引用リポスト + 1 行コメント**:

```
@aichi_kouhou 愛知県のデータも 👉
名古屋港の海上貨物量は全国 1 位 (1.58億トン)、輸出 4,306万トンで全国 23% を占めます。
詳細: stats47.jp/ports/23003
[引用元投稿]
```

ポイント:
- 公式アカウントを @ で言及 (通知が飛ぶ → 認知)
- stats47 のデータで「価値追加」
- URL は `/ports/[portCode]` などの該当データへ直リンク (UTM 推奨)

### NG パターン

- 単純 RT (コメントなし) — 価値ゼロ、bot 判定リスク
- ハッシュタグ大量 (5 個以下に抑える)
- 連続 3 投稿以上で同じ県をリポスト (片寄り、bot 判定)
- 1 時間以内に 5 件以上 (rate limit と spam 判定)

## TOS リスク管理

### やってはいけないこと

| アクション | 理由 |
|---|---|
| 自動 follow / unfollow | X 自動化規約違反、ban リスク |
| 自動 like (mass) | spam 判定 |
| 自動 reply (mass) | spam 判定 |
| 同じ文面で複数投稿 | 重複検知、shadowban |
| ハッシュタグ大量 (6 個以上) | spam 判定 |
| 連続 5 投稿/時 以上 | rate limit + spam 判定 |

### 安全策

- リポストは **常に引用リポスト + 1 行コメント** (単純 RT は使わない)
- 1 時間に 1 件まで (3 件/日 × 8 時間スパン)
- 同じターゲットを 24 時間内に複数リポストしない (CSV で `last_repost_date` 管理)
- コメント文面は metric / 県ごとに variation (テンプレ NG)
