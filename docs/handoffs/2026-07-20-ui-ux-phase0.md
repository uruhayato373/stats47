- **search/about**: 機能的で画像不要。about に pipeline 図なし。

以下は上記を要約したコード裏取り所見:

1. **ヘッダーに「都道府県 (/areas)」が無い** — PC 一次ナビは ランキング/統計ブログ/テーマ▾+検索のみ (`HeaderClient.tsx` NAV_ITEMS)。`/areas` は home hero ボタンとモバイル drawer だけ。

3. **blog 記事 header は text-only・関連記事レールも画像なし** — 記事固有 visual なし (`blog/[slug]/page.tsx`)。
4. **home hero が hero SSOT 外の直書き** — `app/page.tsx:146-201` inline。`HeroBanner`/`page-heroes.ts` はテーマ/カテゴリ専用。
5. **dark は OS 追従せずトグル (data-theme) 駆動** — `prefers-color-scheme: dark` でページは light のまま。バグではないが SSOT 明示が要る。

## P0-5 (OGP/metadata 整合監査→是正) — 実施済 (2026-07-20・未 deploy)

**監査**: 本番 stats47.jp を Googlebot UA で全 route family 走査 (og:image URL + HTTP + canonical + robots)。
**発見した実欠陥**: 一部ページの og:image が **ランタイム `opengraph-image.tsx` route を参照し Cloudflare Worker で HTTP 500**
(next/og の ImageResponse が Worker で例外 = ogp-image-standards §3 課題0)。SNS/Slack/LINE カードが無画像になる。
`twitter:image` は root default の `/og-image.jpg` で全ページ生きていたため、**og:image だけ壊れていた**。

| ページ | 症状 | 是正 |
|---|---|---|
| `/blog` (一覧) | og:image=`/opengraph-image` 500 | 静的 `/og-image.jpg` を明示 (generateOGMetadata) |
| `/blog/tags` | 同上 500 | 同上 |
| `/about` | og:image 欠落 | openGraph.images に `/og-image.jpg` |
| `/privacy` | 500 (terms は正常=兄弟不整合) | openGraph.images に `/og-image.jpg` |
| `/areas/*/cities/*` | 親 area の runtime opengraph-image 500 | 親県の静的 R2 OGP (`ogpImageKeys.area`) |
| `/areas/*/cities/*/[categoryKey]` | 同上 500 | 同上 |

- 正常だった (静的/prerender で 200): home・ranking hub/detail (R2 ogp.png)・blog detail (R2)・category(+compare)・themes list/detail (theme opengraph-image は**ビルド時 prerender** で 200)・areas list/detail (R2)・survey list/detail・terms・areas/[code]/[themeSlug]。`/search` は noindex 正常。`/tag/*` は 301。
- **検証**: tsc exit 0。localhost `/blog` で og:image が `/og-image.jpg` に変わり `opengraph-image` 参照が消えたことを実測 (他5ページは同一機構+tsc+静的ターゲットは本番 200 既知)。
- **未 deploy** (batched)。本番 200 化はデプロイ後に Googlebot UA 実測で確認する。
- **systemic follow-up (課題0 清掃)**: root `app/opengraph-image.tsx` と `areas/[areaCode]/opengraph-image.tsx` の**ランタイム route が残存し Worker で 500**。今回のページは参照を外したが、**将来 og:image 未指定の新ページが再び 500 に落ちる**。恒久対策 = これらランタイム route を静的化 or 削除 (ogp-image-standards §3/§5)。別 P0/清掃タスクとして起票推奨。
