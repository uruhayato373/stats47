# DB 管理ツール（drizzle-kit studio）

> **⚠️ 完全DBレス (doc 19) によりデータ管理経路としては superseded。**
> SSOT は **git TS (設定・運用エンティティ) + R2 (観測値)** であり、ローカル SQLite は
> **再生成可能な使い捨てビルドキャッシュ**。studio でビルドキャッシュを直接編集しても再生成で消えるため、
> **データ「管理」には使わない**（編集は git TS 定義 → 生成スクリプトで R2）。
> studio は **ビルドキャッシュの中身を閲覧/デバッグする read 用途のみ**有効。
> 下記の `indicators` / `ranking_items` 等のテーブル例も Phase 6 で廃止済みで現存しない。

admin アプリ廃止後、ローカル SQLite (使い捨てビルドキャッシュ) の **閲覧・デバッグ**には `drizzle-kit studio` を使える。
**編集による正典データ管理はできない** (git TS が SSOT)。

## 起動方法

```bash
npm run db:studio
```

ブラウザで `https://local.drizzle.studio` が開く。

## できること

| 機能 | 説明 |
|---|---|
| テーブル一覧 | 全テーブルのスキーマ（カラム名・型・PK・NOT NULL）を表示 |
| レコード閲覧 | ページネーション付きでレコードを一覧表示 |
| フィルタリング | カラム値での絞り込み（例: `is_active = true`） |
| ソート | 任意のカラムで昇順・降順ソート |
| レコード編集 | セルをクリックして値を直接編集・保存 |
| レコード追加・削除 | GUI でレコードの追加・削除が可能 |
| SQL 実行 | 任意の SQL クエリを直接実行（SELECT / UPDATE / DELETE 等） |
| リレーション表示 | 外部キーで関連するレコードを表示 |

## 主な用途（旧 admin 機能の代替）

### ランキング項目管理（旧 `/ranking/items`）

```sql
-- 都道府県ランキングの一覧（有効のみ）
SELECT ranking_key, title, unit, is_active, is_featured
FROM indicators
WHERE area_type = 'prefecture' AND is_active = 1
ORDER BY category_id, title;

-- is_active のトグル
UPDATE ranking_items SET is_active = 0 WHERE ranking_key = 'xxx';

-- 項目数の確認
SELECT area_type, COUNT(*) as total,
       SUM(is_active) as active, SUM(is_featured) as featured
FROM indicators GROUP BY area_type;
```

### カテゴリ管理（旧 `/categories`）

```sql
SELECT * FROM categories ORDER BY display_order;
```

### 広告管理（旧 `/affiliate-ads`）

```sql
SELECT * FROM affiliate_ads ORDER BY created_at DESC;
```

## 注意事項

- drizzle-kit studio はローカル SQLite ビルドキャッシュのみを操作する（閲覧/デバッグ用途）
- **正典データの編集は git TS 定義** → 生成スクリプトで R2 に反映する（ビルドキャッシュ直接編集は再生成で消える）
- 本番反映は `/sync-snapshots` 等で R2 snapshot を再生成（永続/リモート D1 は廃止、2026-04-29 解約済み）
- バッチ処理（地域プロファイル・相関分析）は R2 観測値を入力にエフェメラル計算 → R2
