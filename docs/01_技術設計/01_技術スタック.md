### データ可視化

### その他
- **MiniSearch** - クライアントサイド検索

- **Sonner** - トースト通知
- **KaTeX** - 数式レンダリング

## バックエンド

### API・認証
- **Next.js API Routes** - サーバーサイドAPI
- **JWT** - カスタム認証

### データ層 (完全DBレス → `19_完全DBレス設計.md`)
- **Cloudflare R2** - 観測値・配信 snapshot の SSOT。**本番アプリが読む唯一のデータソース**
- **git TS** - 設定・運用エンティティの SSOT (`packages/data-configs/` 他)
- **Drizzle ORM / schema** - 型ソース + テスト基盤 + エフェメラル集計の temp table 型 (永続 D1 なし)
- **Better SQLite3** - 使い捨てビルドキャッシュ / エフェメラル集計エンジン (`:memory:` / DuckDB)。SSOT ではない
- ※ 永続/リモート Cloudflare D1 は廃止 (本番 binding なし、実行時 query = 0)

### ストレージ
- **Cloudflare R2** - オブジェクトストレージ (本番配信 + 観測値 SSOT)

### 外部API
- **e-Stat API** - 政府統計データ
- **Google Gemini API** - AI機能（video）

## 技術選定の原則

1. **型安全性** - TypeScriptによる開発時エラー防止
2. **パフォーマンス** - エッジコンピューティングとCDN活用
3. **低コスト** - Cloudflare無料枠の最大活用
4. **開発効率** - モダンな開発体験とツール
5. **保守性** - シンプルで理解しやすい構成
