# システムアーキテクチャ

> **データ層の正典は [`19_完全DBレス設計.md`](./19_完全DBレス設計.md)。**
> SSOT は **git TS (設定・運用エンティティ) + R2 (観測値・配信) の二つだけ**。永続/リモート D1 は廃止。
> 本番アプリは R2 snapshot のみ読む。

## 概要

stats47 は、Next.js 15 の App Router を使用したフルスタック Web アプリケーション。地域統計データの可視化とランキング表示を提供し、SSG/ISR/CSR を使い分ける。ホスティングは Cloudflare Workers (OpenNext)。

## レンダリング戦略

| データ特性 | 方式 | 適用例 |
|---|---|---|
| 静的・共有可能・SEO 対象 | SSG (`generateStaticParams`) | ranking 詳細、カテゴリ、テーマ、areas |
| 更新が緩やかな一覧 | ISR | ブログ一覧等 |
| ユーザー操作依存 | CSR (Client Component) | 絞り込み、地図インタラクション、比較 UI |

- デフォルトは Server Component。`useState` / `useEffect` / イベントハンドラがある場合のみ `"use client"`。
- **layout (またはその配下の Server Component) で `cookies()` / `headers()` を呼ぶと SSG が崩れる** →
  `.claude/rules/nextjs-ssg-preservation.md` 必読。

## データフロー (完全DBレス)

```
[git TS 定義 (設定・運用 SSOT)] ──生成スクリプト──▶ [R2 app/<domain>/...]
[e-Stat / MLIT API]            ──/page-data-batch──▶ [R2 app/stats/<metric>/*.json]
[R2 観測値]                    ──エフェメラル計算──▶ [R2 派生 snapshot (profile / 相関)]
                                                      ↓ fetchFromR2AsJson
                                            [Server Component → Page]
```

- 本番アプリは DB を一切 query しない (`getDrizzle()` 実行時 query = 0、Phase F 2026-05-30)。
- R2 書き込みは CI / クラウド専用 (`.claude/rules/r2-storage-design.md`)。
- 主要エンティティの SSOT 別分類は doc 19 §3 の決定表を参照。

## 動的ダッシュボードシステム (page_components)

テーマ / エリア / ランキング各ページのチャート構成は `page_components` で宣言的に管理する。

- **定義 (SSOT)**: git TS `apps/web/scripts/data/page-components/<pageType>/<key>.json`
  - pageType: `theme` / `area-category` / `area` / `ranking` / `city-category`
- **生成**: `apps/web/scripts/export-page-components-snapshot.ts` で R2 `app/page-components/all.json` を直接生成
  (横断整合性はビルド時に検証)
- **配置の判定基準**: `11_area-vs-theme責務分離.md`
- ダッシュボード追加はレコード追加のみ (コード変更ゼロ)

## キャッシュ階層

| 層 | 用途 | 実装 |
|---|---|---|
| CDN/Edge (Cloudflare) | 静的アセット + ページ配信 | Cache-Control。410 は 7 日キャッシュ (`/purge-cdn` で消去) |
| R2 snapshot | ビルド済みページデータ | 再生成 = `/sync-snapshots` (CI) |
| e-Stat API キャッシュ | API レスポンス再利用 | R2 (キーは statsDataId + cat。年度・地域でキャッシュ分断しない → `.claude/rules/estat-api.md`) |

## バンドル・パフォーマンス最適化

- **Dynamic Import**: 重い可視化 (Leaflet / D3 大型チャート) は `next/dynamic` で遅延ロード
- **TopoJSON**: GeoJSON より 30-80% 軽量。47 都道府県レベルは SVG レンダリング
- **コンテナクエリ**: ダッシュボードカードグリッドは `@sm:`/`@md:`/`@lg:` (右レール有無で本文幅が可変のため) → `.claude/rules/ui-components.md`
- 計測: PSI 日次 (`psi-audit-daily.yml`)、改善ルールは `.claude/rules/evidence-based-judgment.md` (LCP は要素特定が先)
