# プロジェクト構造

## モノレポ構成

```
stats47/
├── apps/
│   ├── web/             # メインの Next.js アプリ (App Router)
│   ├── remotion/        # 動画・SNS 静止画生成 (Remotion)
│   └── ges/             # Google Earth Studio 47都道府県旋回動画
├── packages/            # 共有パッケージ
├── docs/                # ドキュメント
└── scripts/             # ユーティリティスクリプト (scheduled/ = launchd wrapper)
```

## packages/

| パッケージ | 役割 |
|---|---|
| `data-configs` | **metric 定義の SSOT** (`src/metrics/<key>.ts`) + validate lint |
| `stats-r2` | R2 観測値 (`app/stats/*`) の reader / 型 |
| `database` | Drizzle schema (型ソース)・テスト基盤・使い捨てビルドキャッシュ操作 (永続 D1 なし) |
| `visualization` | D3 チャート・地図コンポーネント (React) |
| `r2-storage` | Cloudflare R2 ストレージ抽象化・push/pull スクリプト |
| `estat-api` | e-Stat API ラッパー・データ変換 |
| `ranking` | ランキングアルゴリズム・データ処理 |
| `area` | 地域コード型定義・都道府県/市区町村マスタ |
| `area-profile` | 地域プロフィール (強み/弱み) 集計 |
| `category` | カテゴリデータサービス |
| `correlation` | 相関分析ロジック |
| `migration-flow` | 人口移動フロー集計 |
| `station-passengers` | 駅別乗降客数 |
| `ai-content` | AI コンテンツ生成 |
| `gis` | GIS ツール (国土数値情報パイプライン・TopoJSON) |
| `svg-builder` | SVG チャート生成 (ブログ・SNS 用) |
| `components` | 共有 UI コンポーネント (shadcn/Radix UI) |
| `types` | 共有 TypeScript 型定義 (indicator-sets = テーマ SSOT 含む) |
| `utils` | 汎用ユーティリティ |
| `logger` | ロギングユーティリティ |

## apps/web の構造

```
apps/web/src/
├── app/           # App Router ルート定義
├── features/      # 機能別モジュール（主要なコード配置先）
├── components/    # 共有コンポーネント (organisms/molecules)
├── hooks/         # カスタムフック
├── lib/           # ユーティリティ (analytics, metadata, structured-data 等)
├── store/         # 状態管理 (Jotai)
├── config/        # 設定
├── constants/     # 定数
├── types/         # 型定義
├── providers/     # React Provider
└── middleware.ts
```

### ルート構造

```
app/
├── page.tsx                           # トップページ
├── ranking/[rankingKey]/              # ランキング詳細 (主力 SEO 面)
├── category/[categoryKey]/            # カテゴリ別一覧 (+ /compare)
├── themes/[themeSlug]/                # テーマダッシュボード
├── areas/[areaCode]/                  # 県プロフィール (+ /[themeSlug] / /cities/[cityCode])
├── survey/[surveyKey]/                # 調査別一覧
├── blog/[slug]/ + tag/[tagKey]/       # ブログ記事・タグ
├── search/                            # 検索
└── about / privacy / terms            # 静的ページ
```

URL 体系・301/410・canonical の正典は [URL 構造](./15_URL構造.md)。

### features/

機能ごとにモジュールを分割。各 feature は以下のサブディレクトリを持つ。

```
features/{name}/
├── actions/       # Server Actions
├── components/    # UI コンポーネント
├── services/      # データ取得・変換ロジック
├── adapters/      # データ変換アダプター
├── types/         # 型定義
├── utils/         # ユーティリティ
├── hooks/         # フック
└── lib/           # 内部ライブラリ
```

全 feature が全サブディレクトリを持つわけではない。feature 一覧は [DDDドメイン分類](./04_DDDドメイン分類.md) を参照。

### components/

共有 UI コンポーネント。レイアウト系が中心。

```
components/
├── organisms/     # Header, Footer, Sidebar, PageHeader, MobileNavigation
└── molecules/     # ShareButtons, BreadcrumbStructuredDataScript, DatasetStructuredDataScript
```
