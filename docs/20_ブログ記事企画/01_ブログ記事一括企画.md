# ブログ記事企画管理

## 方針

- 3つのアプローチ（カテゴリ / トレンド / アフィリエイト）で企画を生成
- 企画確定後、記事を執筆・公開したらそのエントリを削除（ライフサイクルルール）
- `/update-blog-plan` で定期的に本ファイルを最新化

## 現状サマリー

- 公開済み記事: **約197件**（2026-05-30 更新 / R2 `app/blog` 実測）
- 原稿完成（未公開）: **0件**（`docs/21_ブログ記事原稿` は空 = 取り残しなし）
- 企画 backlog: `backlog/` にカテゴリ別アイデア + `backlog/phase-2-authority/articles/` 31件（着手状況は各ファイルの `status` 参照）
- バッチ1-2（14カテゴリ×5=70本）全公開済み。バッチ3（construction/laborwage/socialsecurity）も公開多数（下記内訳）

### カテゴリ起点（/plan-blog-articles）

各カテゴリの指標を網羅的に調査し、5本ずつ企画を生成する。

- バッチ1（7カテゴリ × 5本 = 35本）: **全件公開済み**
- バッチ2（7カテゴリ × 5本 = 35本）: **全35本公開済み（2026-03-09）**
