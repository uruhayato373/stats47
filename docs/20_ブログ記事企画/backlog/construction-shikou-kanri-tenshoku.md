# 土木施工管理技士（1級・2級）ガイド × 建設転職アフィリエイト — 記事企画 + 競合分析

> 目的: 1級/2級土木施工管理技士のガイド記事を増やし、建設業向け転職アフィリエイトの表示・成約を増やす。
> 前提テーゼ（2026-05-29 収益化レビュー）: **「YMYL助言サイトでなく、YMYL隣接のデータ供給サイトとして戦う」**。資格ガイドの正面勝負はレッドオーシャンなので、stats47 の堀（都道府県データ）で差別化する。

---

## 1. 競合分析（2026-05-29 調査）

### SERP を支配しているのは「資格スクール」と「転職会社の自社メディア」

`2級土木施工管理技士 難易度 / 勉強法 / 合格率` の検索結果上位は次の2タイプで占有:

| タイプ | 代表サイト | 収益モデル | E-E-A-T |
|---|---|---|---|
| 資格スクール | アガルート / 日建学院 / SAT / ユーキャン | 自社講座販売 | 講座実績で圧倒的 |
| 転職会社の自社メディア | 施工管理求人.com（レクリー）/ ベスキャリ建設 / ワット・コンサルティング / ビーバーズ / Mivoo | 自社転職サービス送客 | 厚労省許可番号・実績 |

`1級土木施工管理技士 求人` 等の**取引クエリ**は、マイナビ転職 / doda / リクナビNEXT / リクルートエージェント / 施工管理転職ナビ（ビルメンナビ）の**求人DB**が占有。

### 競合記事の典型構造（精査: 施工管理求人.com の2級ガイド）

- H2 8個（資格とは → メリット → 合格率・難易度 → 試験内容 → 日程・受験資格 → 勉強法 → 転職エージェント紹介 → FAQ）
- 文字数 **8,000–10,000字**
- CTA **6–7回**（中盤〜下部に集中、自社転職サービス＋関連記事）
- **都道府県別データは一切使っていない**（全国一律の試験情報のみ）

### 結論: 正面勝負の勝ち目と、空いている白地

- ❌ **「難易度・合格率・勉強法」の正面 SEO は不利**。stats47 は資格スクール／転職会社に E-E-A-T で勝てない（合格実績・求人DBがない）。
- ✅ **誰もやっていない白地 = 都道府県別データ**。「建設業の賃金・求人倍率・人手不足・高齢化が県でどう違うか × 施工管理技士の市場価値」は、stats47 の e-Stat データで**唯一の差別化軸**になる。競合は全国一律情報しか持たない。

## 2. 記事戦略: 2階層クラスタ

正面勝負の資格ガイドだけ増やしても埋もれる。**データ記事（堀・集客）→ 資格ガイド（網羅性・回遊）→ 転職/講座CTA** のクラスタで設計する。

### Tier A — データブリッジ記事（stats47 の堀・最優先）

competitor が持たない県別データで集客し、転職アフィリエイトへ橋渡し。すべて既存指標で作れる（下記「使用データ」参照）。

| slug | 想定タイトル（curiosity gap） | 使用データ | アフィ | 優先 |
|---|---|---|---|---|
| construction-wage-prefecture-ranking | 建設業の年収は県で◯◯万円違う｜大工・電気工事士・建築士の都道府県ランキング | carpenter / electrician / architect-annual-income | 転職 | **S** |
| construction-job-opening-ratio-pref | 建設業の人手不足が深刻な県ランキング｜有効求人倍率で見る「売り手市場」 | active-job-opening-ratio + construction-industry-count | 転職 | **S** |
| construction-worker-aging-value | 建設業の高齢化が進む県と、1級土木施工管理技士の希少価値 | construction-worker-aging（建設業従業者高齢化）| 転職 | A |

### Tier B — 資格ガイド記事（網羅性・トピッククラスタ・回遊）

competitor 構造を踏襲しつつ、**各記事に「県別年収/求人データ」セクションを1つ織り込む**ことで差別化。資格取得意欲の読者には「通信講座」アフィリエイトも併置（転職とは別 intent）。

| slug | 想定タイトル | 主CTA | 優先 |
|---|---|---|---|
| 2kyu-doboku-shikou-kanri-gaiyou | 2級土木施工管理技士とは｜難易度・合格率・勉強時間を県別年収データ付きで解説 | 講座＋転職 | A |
| 1kyu-doboku-shikou-kanri-gaiyou | 1級土木施工管理技士の難易度と年収メリット｜2級との差を県別データで | 講座＋転職 | A |
| 1kyu-2kyu-doboku-chigai | 1級と2級土木施工管理技士の違い｜できる仕事・年収・転職市場価値 | 転職 | A |
| doboku-shikou-kanri-juken-shikaku | 受験資格・試験日程・申込み（最新の制度改正に対応） | 講座 | B |
| doboku-shikou-kanri-benkyou | 2級土木の勉強法・必要時間｜独学 vs 通信講座の費用対効果 | 講座 | B |
| doboku-shikou-kanri-nenshu-tenshoku | 土木施工管理技士の年収を上げる転職｜県別賃金から見る「移動で得する県」 | 転職 | A |

## 3. アフィリエイト拡張提案（★技術的に重要な前提あり）

### 前提となる技術課題（着手前に必ず修正）

1. **カテゴリ紐付けのミスマッチ**: `affiliate-category.ts` で `"construction": "housing"`。つまり**「建設」カテゴリの記事には引越しアフィリエイト（引越し侍）が出る**。施工管理転職記事で転職アフィリエイトを出すには:
   - 記事タグを **labor 系（`employment` / `labor-market` / `wages`）** にする（`TAG_AFFILIATE_MAP` で labor に変換される）、または
   - `TAG_AFFILIATE_MAP` に建設転職用タグ（例 `construction-job` → `labor`）を**追加**する。
   - ※ ブログ記事は `TAG_AFFILIATE_MAP`（タグベース）で出し分くため、`construction` categoryKey の housing 紐付けは触らず、**記事タグ設計で labor を当てる**のが外科的。

2. **建設特化 転職ASPの追加**: 現在の labor アフィリエイトは リクルートエージェント / doda の汎用のみ。建設業読者の CVR を上げるため、建設特化サービスを A8.net / 他ASPで探索して追加する。

### 追加候補（要 A8.net / ASP 提携審査・単価は要確認）

| サービス | 特徴 | 想定成果地点 |
|---|---|---|
| 施工管理求人ナビ（クイック） | 建設特化・年収UP実績訴求 | 無料登録/面談 |
| ビーバーズエージェント | 建設特化・WLB/週休2日訴求 | 無料登録/面談 |
| セコカンNEXT / 俺の夢 / GATEN職 | 建設・施工管理特化 | 無料登録 |
| リクルートエージェント / doda（既存） | 汎用大手・件数多い | 無料登録 |
| **資格スクール（別intent）**: SAT / アガルート / ユーキャン 土木講座 | 「勉強法」記事の読者向け | 講座申込（高単価・高CVR） |

> 単価・提携可否は実測前の推定。`evidence-based-judgment.md` に従い、提携確定後に本欄を上書きする。
> 登録手順: `/register-affiliate-banner` スキル（D1 `affiliate_ads` への INSERT、ローカルMacで実施）。

## 4. 使用データ（既存指標で充足）

| 指標 | metric key | 用途 |
|---|---|---|
| 建設業職種の県別年収 | `carpenter-annual-income` / `electrician-annual-income` / `architect-annual-income` | 年収ランキング・移動で得する県 |
| 有効求人倍率 | `active-job-opening-ratio` | 人手不足・売り手市場 |
| 建設業事業所数 | `construction-industry-count` | 市場規模・求人母数 |
| 建設投資・工事種別 | `construction-contract-*`（road / river / port-airport 等） | 県別の建設需要の質 |
| 高卒求人倍率 | `high-school-new-graduates-job-opening-ratio` | 若手不足の補強 |

→ 新規 e-Stat 取得はほぼ不要。既存 R2 snapshot で Tier A 記事を即着手できる。

## 5. 想定効果と検証（実証ベース）

- **集客**: 「建設業 年収 都道府県」「建設 求人倍率 ランキング」は競合不在の情報クエリ → 着地しやすい（仮説）。検証: 投下4週後 GSC impressions ≥ 100/週。
- **収益**: 転職無料登録は成果地点が低く CVR が比較的高い（仮説）。検証: GA4 `affiliate_click`（labor）と A8 成果レポートで実測。
- **成功基準（8週後）**: Tier A 3本＋Tier B 2本投下 → labor affiliate_click ≥ 10/週。
- **撤退基準**: 8週で click 0 継続 → タグ紐付け（前提課題1）が効いているか再確認 → CTA配置見直し。
