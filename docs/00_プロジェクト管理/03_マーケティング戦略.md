## 概要

Stats47 のユーザー獲得戦略。**Two-track + 意思決定レイヤ** とする (2026-07-07 STP 分析で S2 を明示昇格):

- **Track A (ペルソナ 1, 雑学エンタメ層)**: プログラマティック SEO（自動生成ランキングページ 2,000+）と SNS。PV・AdSense **基盤として維持** — ただし AI 直答に最も侵食されやすいセグメントのため、成長をここに依存しない
- **Track A+ (生活意思決定層, S2)** ★2026-07-07 昇格: 移住・引越し・子育て環境・転職年収の**比較検討層**。AI 耐性中 × アフィリ収益性高 × 競合弱 (とどラン/uub は意思決定支援 UI を持たない)。ブログ型ポートフォリオ (D2 食品/F 市区町村/G 移動フロー、[`15_ブログSEO拡充戦略.md`](../02_実装計画/15_ブログSEO拡充戦略.md)) とアフィリ意図軸 (housing/mobility/labor) が実行面
- **Track B (ペルソナ 3, 行政・自治体関係者)**: 公務員 × AI 活用記事 (note + ブログ)、内部リンク強化、公務員系タグページの index 復活。出典・年次・定義の正確性が必須のため **AI 耐性が最も高い**濃いニッチ

手動コンテンツ量産は行わない。Track B も「月 1-2 本の高品質記事」上限とする。

> **SNS戦略**の詳細は [SNSコンテンツ設計](../10_SNS戦略/01_SNSコンテンツ設計.md) を参照。

### ビジョン

**「統計データで日本を理解する、みんなのプラットフォーム」**

### ポジショニング・ステートメント (2026-07-07 制定)

> **「公的統計を、最速で、市区町村まで、見やすく。」**
> — 出典明示の一次加工データを、公的リリースから最短で、都道府県の一段深くまで、誰でも読める形にする。

各語の対競合の裏付け ([STP 分析 §5](../04_レビュー/2026-07-07-stp-analysis.md)):
- **最速** = とどランの更新遅延の逆張り (差別化第 1 軸)
- **市区町村まで** = 知覚マップの空白 (とどラン/statja は都道府県中心、uub は市区町村を持つが体験が古い)。決算カード・移動フロー・GIS が既存資産
- **見やすく** = uub / e-Stat の体験の逆張り (差別化第 2 軸)
- **公的統計・出典明示** = riskmap.jp (SNS 感情煽り) / AI 生成コンテンツとの信頼性差別化

SNS プロフィール・OGP・サイト説明文・note 導線の文言はこのステートメントに揃える。

### 段階目標

6ヶ月後のMAUを一発で設定せず、実測データで補正しながら段階的に目標を引き上げる。

| 時点 | 目標 | 検証ポイント |
|------|------|------------|
| **1ヶ月目** | プログラマティックSEOで100ページ公開 | Search Consoleでインデックス率・表示回数・平均掲載順位を計測 |
| **2ヶ月目** | 実測データで「1ページあたり月間流入数」を算出 | この数字 × 500ページで6ヶ月後のMAUを再試算。初期仮説（平均Vol.200×CTR10%）の検証 |
| **3ヶ月目** | 再試算した目標値でKPIを再設定 | 仮説が外れていた場合、テンプレート改善 or キーワード戦略の見直し |
| **6ヶ月目** | 再試算ベースのMAU目標 | — |

## Phase 1 でやらないこと

| やらないこと | 理由 |
|---|---|
| B2B マーケティング全般 | 問い合わせが月3件を超えるまで不要 |
| ブログ記事の量産・外注 | 品質管理コストが高い。月0〜数本を上限とし品質に全振り |
| 教育コンテンツの体系的整備 | 検索ボリュームが小さく、PV への寄与が限定的 |
| 手動コンテンツカレンダー | 週3本・月10本のノルマは1人運営で持続不可能 |

## 競合分析と差別化戦略

市場に存在する既存プレイヤーを分析し、Stats47が勝てる領域を明確にします。

### 1. 競合分析マップ (2026-07-07 刷新)

| 競合 | 特徴・規模 | 弱点 | stats47 との関係 |
| :--- | :--- | :--- | :--- |
| **とどラン** (todo-ran.com) | 1,501 ランキング・相関/偏差値・書籍化ブランド・10年超の被リンク | データ更新の遅れ・UI が古い | S1 (雑学) の最大競合。指標数はほぼ並んだ (stats47 約 2,200 config) が被リンクで劣後 |
| **uub.jp/pdr + rnk** | 263 テーマ / 1,843 データセット・市区町村ランキングも保有・老舗 | テキスト主体 UI・可視化なし | 市区町村粒度で唯一被る競合 |
| **統計リアル** (statja.com) | 新興・更新頻度高 (2026-05 更新確認) | 規模・ブランド未確立 | 同型の後発。動向監視のみ |
| **e-Stat ランキング / 統計ダッシュボード / RESAS** | 官製・信頼性最強・約 6,000 系列 | UX 複雑・SEO 弱・「調べ方を知っている人」専用 | 競合というより**上流データ源**。「e-Stat より速く辿り着ける」が価値 |
| **@riskmap.jp** (IG/TikTok 専業) | 20K フォロワー・週次動画・「統計×ランキング」名乗りに接近中 | Web サイト無し = 検索資産ゼロ・出典明示なし | SNS 面の直接競合。感情煽り路線には追随しない |
| **ChatGPT / AI Overviews** | 単一事実クエリを SERP 上で直答 | 市区町村粒度・最新年次・出典の正確性が弱い | **非対称競合** (下記「AI 検索環境の構造変化」) |

> 旧マップ (GO TOKYO / 枚方つーしん) は市場定義が観光・ローカル情報に寄っており廃止。定点観測は `/competitor-scan` (月次) と memory (`project_competitor_indicator_benchmark` / `project_competitor_riskmap_jp`)。

### 1.5 AI 検索環境の構造変化 (2026-07 時点)

- SERP の約 58% に AI Overviews が表示され、informational クエリのオーガニック流入は 30-40% 減 (出典: [thestacc.com](https://thestacc.com/blog/google-ai-overview-statistics/) / [velacore.au](https://velacore.au/traffic-lost-to-google-ai-overviews/)、アクセス 2026-07-07)
- 「うどん消費量 1位はどこ?」型の**単一事実クエリ (Track A の主流入) は AI が直答して終わる**リスクが構造化した
- 一方 **AI Overviews に引用されたブランドはオーガニッククリック +35%** ([quickseo.ai](https://quickseo.ai/blog/google-ai-overviews-statistics-2026-60-data-points-every-seo-should-know)、アクセス 2026-07-07)

**方針: 「AI に引用される一次加工ソース」ポジションを取る。** 出典・年次・定義の明示 (metric config の note/description)・構造化データ・安定 URL は既に引用適性が高い。実行レバーは [`16_月間100万PVロードマップ.md`](../02_実装計画/16_月間100万PVロードマップ.md) §4 ③、定点観測は改善バックログ STP-AI-WATCH-01。

### 2. 差別化戦略

エンジニア1人で技術力によって構築できる参入障壁にフォーカスする。コンテンツ量産の人海戦術には引きずり込まれない。

**差別化の第1軸: 更新速度**
- 公的統計のリリースから24時間以内にランキングページを自動更新する
- とどランの最大の弱点「データ更新の遅れ」で圧倒的な差を作る
- データパイプラインの自動化がエンジニアの技術力で直接構築可能な参入障壁

**差別化の第2軸: UI体験**
- モバイルファーストで、ランキングをスワイプで比較・フィルタリングできるインタラクティブUI
- とどランの「UIがモダンではない」という弱点を突く

**相関分析はおまけ機能**
- 作ること自体は否定しないが、差別化の主軸にはしない
- N=47の統計的限界を考慮し、SNSで話題にする程度の位置づけに留める

## コンテンツ戦略

### プログラマティックSEO（Phase 1 の主軸）

- ランキングページ 500+ を自動生成し、検索流入の面を取る
- 地域プロファイル 47ページ
- 相関分析ページ（おまけ。差別化の主軸ではない）
- すべてのページに一次ソースへのリンクを付与し、信頼性を担保

### ブログ記事

- 月0〜数本を上限とする。バズを狙える確信があるネタ、またはトレンド連動テーマのみ
- 品質に全振りし、1本で最大の検索流入を目指す
- テーマ選定・執筆は `/draft-from-trend`（metric→R2直執筆）・`/discover-trends` 等のスキルでAI支援
- 記事カテゴリや月間本数のノルマは設けない

## 編集ガイドライン（ランキングの倫理）

データを扱うメディアとしての信頼性を維持するため、以下のルールをすべてのコンテンツに適用する。

### 1. 相関表現のルール
- **「相関がある」と「因果関係がある」は明確に区別する**。相関分析の結果は「〜と相関がある」「〜と関連がみられる」と表現し、「〜が原因で」「〜のおかげで」等の因果表現は使用しない
- 相関係数を提示する場合は、サンプルサイズ（N=47）の限界にも言及する
- 疑似相関の可能性がある場合は「第三の変数の影響も考えられる」旨を注記する

### 2. ワーストランキングの扱い
- 犯罪率・離婚率・生活保護率など、地域スティグマにつながりうる指標は**「ワースト」という表現を避ける**
- 構造的要因（都市化度・高齢化率・統計の取り方の違い等）を必ず補足し、数値の一面的な解釈を防ぐ
- タイトルで煽る表現（「最悪の県」「ダメな県」等）は禁止

### 3. 出典・データソースの明記
- すべてのランキング・統計データに**一次ソースへのリンクを付与**する
- データの調査年・調査主体・調査方法を明記する
- 複数年のデータを比較する場合、調査方法の変更があれば注記する
