# 収益化戦略（SSOT）

## 0. 本文書の位置づけ

Stats47 の**収益モデル、チャネル配分、広告・アフィリエイトの配置判断、収益ゲートの唯一の真実源**。
トラフィック成長は [`03_マーケティング戦略.md`](./03_マーケティング戦略.md)、施策の status・期日・担当は
[`.claude/todo/`](../todo/todo-standards.md)、実装規約は `.claude/rules/` と各 analytics skill を優先する。

本書には変動する在庫数、週次実測、完了済み工程、モデル別担当を固定しない。現在値は `.claude/state/metrics/` と
広告 state、当月の重点は [`monthly.md`](../todo/monthly.md) から読む。

## 1. 目的と North Star Metric

目的は、無料の公的統計可視化を維持しながら、運営費と継続改善の工数を回収できる状態を作ること。
短期的な売上最大化のために、統計の解釈、公平性、表示速度、読者体験を犠牲にしない。

**North Star Metric（NSM）は週次収益**とする。

```text
週次収益 = AdSense 確定額 + アフィリエイト発生額 + 商品の実売額
```

PV は収益の先行指標であって NSM ではない。主な先行指標は次のとおり。

| 領域 | 先行指標 | 主な参照先 |
|---|---|---|
| 集客 | GSC finalized7d clicks、GA4 Japan-only PV | search-growth / `.claude/state/metrics/` |
| AdSense | earnings、page RPM、imp RPM、viewability、広告カバレッジ | adsense-improvement |
| アフィリエイト | `affiliate_impression`、`affiliate_click`、CTR、CV、EPC、発生額 | affiliate-improvement / ASP 管理画面 |
| 商品 | 無料需要、pilot 購入数、返金、制作・運用工数 | product skill / 販売台帳 |
| 地域意思決定 | 比較・地図操作・データDL等を含む地域意思決定セッション | GA4 / business-plan state |

重複する rolling 28d の差を WoW と呼ばない。検索の期間契約は
[`weekly-cycle-contract.md`](../../.claude/skills/analytics/search-growth/reference/weekly-cycle-contract.md)、
効果判定は [`evidence-based-judgment.md`](../../.claude/rules/evidence-based-judgment.md) に従う。

## 2. 戦略の中心

**2026-08-16 のオーナー判断により、AdSense は全ページで一時停止する。** 低い収益に対して
広告表示、外部スクリプト、空き枠が読者体験へ与える機会費用を見直すためで、停止中はアフィリエイトと
商品需要の検証へ集中する。過去の AdSense 実績は、再開判断の比較材料として保持する。

停止中の収益は次の二層で作る。

1. **高意図だけ深く収益化する** — 年収・移住・住宅・教育など意思決定に近い文脈に限り、一致するアフィリエイトを置く
2. **需要が確認できたものを商品化する** — 無料需要を確認してから、単一の低単価 pilot で実売を検証する

広告枠数や商品数を増やすこと自体は成果ではない。**計測できること、文脈が一致すること、実売が確認できること**を
横展開の条件にする。

### stats47 2.0 の5収益レイヤー

実行順は、既存集客を維持しつつ、商用意図、知識・データ販売、継続課金、法人へ価値を積み上げる。後段ほど需要ゲートを厳しくする。

| レイヤー | 無料価値 | 収益 | 開始条件 |
|---|---|---|---|
| 集客 | ランキング・テーマ・地域分析・地図 | 既存流入、将来の広告再評価 | 品質を維持 |
| 商用意図 | 移住・住宅・旅行・仕事の比較 | 文脈一致Affiliate | 計測とcomplianceが稼働 |
| 知識・データ | 結論・方法概要・出典 | note、加工データ、レポート | 無料需要と利用条件を確認 |
| 継続課金 | 更新・保存・高度DL | Membership / Pro | 同種依頼と支払意思が反復 |
| 法人 | 公開ケース | 診断・PoC・ライセンス | 具体相談が月3件等の需要ゲート |

週次収益は引き続きNSMである。事業計画の「地域意思決定セッション」は、ユーザー価値を早く検知する**先行指標**であり、NSMを置き換えない。M3/M6/M12の売上・アクセス値は予測ではなくGo/Pivot/Stop用の仮説として表示する。

### 優先順位

| 優先 | 収益レーン | 方針 |
|---:|---|---|
| 1 | 文脈一致アフィリエイト | 高意図ページだけに配置。計測稼働前・文脈不一致の一括展開は禁止 |
| 2 | note からの送客 | note を収益終点ではなく、広い検索意図から Stats47 の比較・収益面へ送る入口として使う |
| 3 | デジタル商品・データ商品 | 無料需要→単一の低単価 pilot→実売の順で検証。複数チャネルへ同時展開しない |
| 4 | AdSense | 全ページで一時停止。再開は停止後28日実測とオーナーの明示判断を条件とする |
| 5 | B2B・スポンサー・会員制 | 問い合わせ・購入需要を確認してから設計。先回りして重い基盤を作らない |

## 3. 収益レーン別方針

### 3.1 AdSense

#### 全面一時停止（2026-08-16 決定）

直近の確定7日実績を確認したうえで、オーナーは現在の週次収益より読者体験を優先し、
**AdSense のスクリプト、Auto ads、手動枠、fallback、広告用の空カード・予約高を全ページで停止する**と決定した。
アフィリエイト広告は停止対象に含めない。判断時の数値は `ADSENSE-PAUSE-01` の改善ログに保存する。

実装の全体スイッチは `apps/web/src/lib/google-adsense/constants.ts` の
`ADSENSE_DISPLAY_ENABLED`。停止中は環境変数が `true` でも配信せず、再開時もこの1箇所で制御する。
施策 status とデプロイ日は `ADSENSE-PAUSE-01` で追跡する。

これは効果確定ではない。デプロイ後28日間、AdSense減収を既知の機会費用として、Core Web Vitals、
engagement、アフィリエイトCTR、商品導線のクリックを比較する。過去の計測ではスクリプト停止による
LCP改善が確定していないため、速度や回遊の改善を実測前に主張しない。再開には実測とオーナーの明示判断を要する。

以下は再開を判断した場合に適用する配置原則と過去の根拠であり、停止判断より優先しない。

- モバイルの手置き枠は置かず Auto ads に任せる（2026-08-04 決定・下記）
- 配置前に高さを予約し、CLS とコンテンツ可読性を守る
- 低 viewability / 低 imp RPM の枠は、追加ではなく移設・形式変更・撤去を比較する
- 同一ページで複数施策を同時変更せず、14日・28日の判定窓を持つ
- クリックを誘導する文言、広告と本文を誤認させる表示、コンテンツより広告を先に見せる設計は禁止する

#### モバイルの手置き枠を撤去した根拠（2026-08-04・W31 実測）

placement 別の実測で、**手置き枠と Auto ads の RPM が 1 桁違う**ことが分かった。

| placement | 収益 | imp | RPM | viewability | requests | 充足 |
|---|---:|---:|---:|---:|---:|---:|
| AUTO_ADS Desktop | ¥73 | 681 | ¥107 | 86.3% | 2,734 | 60.0% |
| AUTO_ADS Mobile | ¥33 | 287 | ¥114 | 74.0% | 1,207 | 80.5% |
| MANUAL Desktop | ¥34 | 2,640 | ¥13 | 48.9% | 9,333 | 28.9% |
| **MANUAL Mobile** | **¥4** | 495 | **¥8** | **28.6%** | 2,037 | 25.7% |

モバイルの手置き枠は週 ¥4（全収益の 2.7%）のために 2,037 リクエストと 495 の描画を消費し、
表示できた分の 7 割が視認されていない。実ユーザー LCP は p75 = 2,476ms で閾値 2,500ms まで
24ms しか余裕がなく、モバイルが最も苦しい。**収益レーンの入れ替えではなく不良在庫の整理**として
撤去する（上記「低 viewability / 低 imp RPM の枠は撤去を比較する」の実行）。

デスクトップの手置き枠は週 ¥34（23%）あるため同じ理屈では切れない。枠単位の内訳
（unit_id ↔ コード側 slot_id）が要るが、その ad-units inventory は 2026-08-04 まで
**一度も取得に成功していなかった**（`fetch-adsense-snapshot.mjs` を同日修正）。inventory が
入ってから個別に判断する。

**未検証**: 手置き枠を外した領域に Auto ads がどう反応するかは測っていない。確実なのは
「週 ¥4 を失う」ことだけで、それ以外は撤去後の実測を待つ。画面が確定するまでは
baseline 自体がノイズなので、判定は UI が落ち着いてから行う。

実装・計測の正典は `apps/web/src/lib/google-adsense/`、
ビューポート方針は `apps/web/src/features/ads/constants/manual-ad-policy.ts`、
`.claude/skills/analytics/adsense-improvement/`、Google 管理画面の安全契約は
`.claude/scripts/google-admin/README.md`。

### 3.2 文脈一致アフィリエイト

広告は**ページ分類 → vertical → 広告**で解決し、在庫都合で無関係な商材を出さない。
vertical、提携状況、配置、計測の詳細は
[`affiliate-ads-standards.md`](../../.claude/rules/affiliate-ads-standards.md) が実装 SSOT。

| 読者の意図 | 主な vertical | 主な配置面 |
|---|---|---|
| 年収・仕事を比較したい | `labor` / `economy` | 年収・所得・求人 ranking / blog |
| 移住・地域を選びたい | `housing` / `furusato` | area、人口移動・住宅 blog |
| 住まい・移動手段を検討したい | `housing` / `mobility` | 地価・住宅・交通 ranking / blog |
| 教育・子育て環境を比べたい | `education` / `population` | 教育・子育て ranking / blog |

配置拡大は `affiliate_impression` と `affiliate_click` が page type / vertical / placement 別に取得でき、
ASP の発生額と照合できることが前提。クリックだけで効果を主張しない。

案件は報酬単価の高低ではなく、読者の行動段階に合わせて二層で運用する。

1. **探索レーン** — 無料閲覧・ダウンロード・アプリ・無料登録など、購入前の比較中でも実行できる案件。
   広い情報探索ページへ無差別に増やさず、文脈が一致する一つの導線として検証する。
2. **意思決定レーン** — 資料請求・見積もり・相談・購入など、具体的な意思決定を伴う案件。
   対象 ranking key または記事文脈を明示できる高意図ページだけに置く。

「無料」という表示だけで低負担と判定しない。個人情報、電話連絡、面談、支払いの有無を含む成果条件を
ASP の確認日付き情報から記録し、条件不明の案件は探索レーンへ自動採用しない。クリック報酬も、クリック数ではなく
確定収益まで取得できる場合だけ他方式と比較する。評価の主指標は**確定収益 / 1,000 viewable impression**、
補助指標は CTR、CVR、確定率、`affiliate_impression / pageview` とする。ASP の成果を広告単位へ結べない場合は
0円ではなく判定不能として扱う。機械契約と実装順は `.claude/rules/affiliate-ads-standards.md`、進捗は
`.claude/state/ads/affiliate-portfolio-latest.json` と
`.claude/state/ads/affiliate-pilot-readiness-latest.json` を正典とする。

運用の現在地は`.claude/state/ads/affiliate-portfolio-latest.json`、公開pilotの開始可否と観測判定は
`.claude/state/ads/affiliate-pilot-readiness-latest.json`を読む。週次自動化は観測・候補提示までで、ASP申請、
priority変更、勝者反映、push/deployを行わない。pilotは既存配信中の1案件・既存の1枠・ranking/blogの1ページに限定し、
必要click/impと最大期間内の実現可能性を開始前に計算する。CTRが高くても確定収益が成熟するまでは勝者としない。
readiness が `blocked` の間は公開pilotを進めず、再開するときだけ新しい期限付き改善カードを起票する。

AdSense停止中の第一段階は、新規ASP申請や在庫追加より先に、**既存在庫を文脈一致のまま
視認される位置へ配線すること**とする。在庫が10 verticalすべてを満たしている間は、停止した枠のうち
検索需要がある ranking と地域意図が明確な area の本文・右レールを優先する。バナーは画像だけを表示し、
PR見出し、説明、Card装飾は加えない。home や `other` から意図を推測して無関係な案件を出さず、
viewable impression の 50% × 1秒閾値も緩めない。評価は `affiliate_impression / pageview` と
placement別CTRを、デプロイ前後の重複しない期間で比較する。

### 3.3 note と外部送客

- note は問い・物語・統計の読み方を提供し、全都道府県データ、比較体験、CV 導線は Stats47 に残す
- 本文を Stats47 と重複させず、関連する ranking / area / blog へ自然に接続する
- 評価は note views ではなく、note→Stats47 流入と収益面到達で行う
- 投稿頻度・実行規約は [`sns-content-standards.md`](../../.claude/rules/sns-content-standards.md) と
  [`note戦略.md`](../30_note記事企画/note戦略.md) を優先する

### 3.4 商品・データ販売

公的統計そのものではなく、**整形、定義統一、更新、比較体験、テンプレート、業務時間短縮**に対して課金する。
基本のランキング・出典・比較データは無料で維持する。

進行条件は次の順序に固定する。

1. 無料コンテンツで需要を観測する
2. 1テーマ・1商品・1販売面の低単価 pilot を作る
3. 外部公開・価格設定・出品は人間が承認する
4. 実売と運用工数を確認する
5. 勝った商品だけ別チャネルへ展開する

無料需要を通らない商品、同文大量展開、AI 無審査公開、複数チャネル同時 pilot は禁止する。

#### Geo分析のコンテンツ・フライホイール

Geo/GIS作業は内部処理で終わらせず、1つのcanonical分析から次の面を同じR2 artifactで派生させる。
正典は `packages/data-configs/src/business-plan/geo-content-lifecycle.ts`、空間演算とlineageの品質契約は
[`geo-analysis-standards.md`](../../.claude/rules/geo-analysis-standards.md) とする。

| 面 | 無料・有料の境界 | 完了条件 |
|---|---|---|
| Geo canonical | 47県の結論、全県集計、方法、限界、manifest、県別途中データを無料閲覧 | 47県artifact・保存則・入力SHAがPASS |
| テーマ・area | 主題別・県別の読み口とcanonicalへの導線を無料提供 | 数値を独自複製せず同一artifactを参照 |
| ブログ・SNS | 発見と読み解きを無料提供し、canonicalへ着地 | Geo記事型の意味レビューと出典・近似条件を確認 |
| note・データ商品 | 再現手順、データ辞書、テンプレート、加工済みCSV/JSON、検証manifestを販売 | 無料結論を隠さず、同梱物のSHA・47件・利用条件を検証 |

初回の公開順は需要・差別化・商用意図・既存資産で固定し、各企画を28日ずつ評価する。

| 順 | Geo企画 | 収益上の役割 | 次へ進む条件 | 停止条件 |
|---:|---|---|---|---|
| 1 | 人口減でも地価が上がる20府県 | 商用意図の入口 | Geo・県別stage・データ導線を確認後、note 1面だけで商品pilot | 住宅購入推奨や府県平均と誤読される場合 |
| 2 | 2050年も洪水区域に人口は残る | 公共性・信頼の入口 | 方法・途中artifactまで読む行動を確認 | 地域の安全/危険判定として誤読される場合 |
| 3 | 駅近人口は2050年にどれだけ残るか | 移住・交通の意思決定支援 | 比較・県別閲覧・データ導線を確認 | 800m直線距離を徒歩到達圏と誤読される場合 |
| 4 | 2050年人口の基準線 | 3分析を束ねる証拠ハブ | Geo3本への回遊を確認 | 既存記事と検索意図が重複する場合はハブへ統合 |

収益値はまだ実測前の仮説である。単価・月次売上を確約せず、次の順で1つずつ検証する。

| 仮説 | 月次下限 | 基準 | 上限 | 検証ゲート |
|---|---:|---:|---:|---|
| Geo文脈アフィリエイト | 0円 | 9,000円 | 25,000円 | 住まい文脈のviewable impression・CTR・発生額 |
| Geo再現パック | 0円 | 5,960円 | 17,880円 | 1商品・1販売面で2〜6件の実売 |
| 個別地域レポート | 0円 | 20,000円 | 60,000円 | 具体的な有償相談が発生した場合だけ受注 |
| 法人利用ライセンス | 0円 | 30,000円 | 100,000円 | 問い合わせ月3件または用途が明確な相談 |
| 会員/API | 0円 | 0円 | 0円 | pilot実売と反復需要が出るまで実装しない |

1回のデータ取得・空間演算を複数面へ再利用するが、同じ本文の複製や47県の薄い記事量産はしない。
販売物は公的データの再販売ではなく、再現可能な加工・検証・業務時間短縮に対して対価を得る。

## 4. ページ種別ごとの責務

| ページ | 収益上の役割 | 方針 |
|---|---|---|
| `/ranking/[key]` | 検索集客の主面 | AdSense停止中。高意図指標だけ文脈アフィを追加 |
| `/blog/[slug]` | 検索集客と意思決定支援 | AdSense停止中。記事文脈に一致する少数アフィ |
| `/areas/[code]` | 地域比較ハブ | ふるさと納税・引越し等の地域意図を優先。計測前の枠拡大は禁止 |
| `/themes/[slug]` | 回遊・比較面 | 収益化より深掘り導線と体験品質を優先 |
| `/geo/[analysis]` | 空間横断分析のcanonical | 結論・全県集計・方法・途中データは無料。再現パックと加工済み成果物だけを商品化 |
| `/category/[key]` | ナビゲーション面 | 広告・アフィを増やさず、ranking への導線を優先 |
| home / 一覧 | 発見面 | AdSense停止中。主コンテンツを妨げない |

UI の具体仕様は統一レイアウトと広告コンポーネントを優先し、本書に見た目を重複定義しない。

## 5. 意思決定ゲートと実行順

旧P0〜P3の週番号ベース工程は廃止し、施策ごとに次のゲートを使う。

| Gate | 通過条件 | 未達時 |
|---|---|---|
| **計測** | page type / device / placement / vertical 別に表示・クリック・収益を追える | 新しい枠や商材を増やさず計測を復旧 |
| **AdSense再開** | 停止後28日のUX・回遊・代替収益と、停止直前の機会費用を比較し、オーナーが明示承認 | 停止を継続し、枠やスクリプトを戻さない |
| **アフィ横展開** | 事前定義した期間・母数で CTR / CV / EPC / 発生額を判定できる | 文脈・商材・配置を再検討し、一括展開しない |
| **トラフィック拡大** | [`03_マーケティング戦略.md`](./03_マーケティング戦略.md) の T1〜T4 ゲートに従う | 収益施策だけでページ供給を前倒ししない |
| **商品横展開** | 無料需要、単一 pilot の実売、許容できる制作・運用工数 | 商品数・販売チャネルを増やさない |
| **B2B基盤** | 問い合わせ月3件以上、または有償相談の具体的需要 | LP、決済、API基盤を先行実装しない |

実装順序は原則として以下。

1. 計測の正常性を確認する
2. AdSense停止後28日のUX・回遊・代替収益を比較する
3. 既存の高意図ページと note 導線を改善する
4. 年収・移住等の文脈で小さくアフィリエイト実験する
5. 勝った商材・配置だけ横展開する
6. 無料需要があるテーマだけ商品 pilot へ進める

## 6. チャネル配分

| チャネル | 収益戦略上の位置づけ |
|---|---|
| SEO / blog | 主力。ranking で広く集客し、blog で比較・意思決定を深める |
| Instagram / X | 送客と指名検索の補助。頻度・運用は SNS 実行規約に従う |
| note | 外部衛星と商品需要の検証面 |
| YouTube | **6週間・通常動画3本の限定 pilot**。収益化を目的に量産せず、視聴維持・指名/サイト送客・制作工数を EXP-006 で検証する |
| TikTok | **撤退済み。収益化を理由に再開しない** |

## 7. 検証規律

- 全領域の active WIP は **5以下**。停止中の AdSense 配置実験は **0件**とする
- 同一ページ・同一指標に複数変更を重ねず、何が効いたか分離できる状態を保つ
- effect 未確定の同系統へ新施策を積まない
- 想定値、根拠、判定日、取得コマンド、実測値が揃うまで `effect/full` 等を付けない
- rolling 28d 同士の差、bot 混入値、未登録 custom dimension をゲート判定に使わない
- 人間承認が必要な OAuth、管理画面設定、ASP申請、外部出品はTODOで追跡し、文書へ期限を重複記載しない

週次候補の収集・承認は search-growth / adsense-improvement / affiliate-improvement、
施策 status は [`improvements.md`](../todo/improvements.md) を正典とする。

## 8. 禁止事項と倫理

- 全 ranking へ同じアフィリエイト広告を置かない
- アフィリエイト未計測のまま枠・商材を拡大しない
- AdSense と複数アフィ施策を同時変更しない
- 47都道府県分の薄い記事・商品を一括生成しない
- note と Stats47 に同じ本文を複製しない
- 統計結果を商材・スポンサーに都合よく解釈しない
- 広告クリックを促す表現や視覚誘導を置かない
- 公的統計の基本閲覧を有料化しない
- 需要未検証の会員制、API、法人営業基盤を先に作らない
- 収益密度施策を飛ばして、PV や商品数だけを追わない
