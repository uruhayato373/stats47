## 評価サマリ

「ピアノ＝都会」という読者の直感を 2014年度の世帯正規化データで裏切る、curiosity gap が本文と一致した良質な単一指標深掘り記事 (アーキタイプ A + 時系列サブ章 C)。上位5+下位5 の SVG 1枚を軸に、内陸教育県クラスター・瀬戸内・大都市の世帯正規化/住宅事情・南九州沖縄の気候要因まで、図に対して 2,805字の厚い構造的解釈が付き、順位の読み上げに終わっていない。data JSON との数値突合 (27 件の順位・値・平均333台・2.1倍差) はすべて一致し、callout は記事固有の「読み違い防止」(湿度/防音/電子代替・世帯正規化の罠) として機能している。公開可能な読者価値があると判断する。残る論点は時系列章の出典裏付けと文体の単一の常体混入で、いずれも公開を止める致命ではない。

## 指摘

- [MAJOR] 発見2 の歴史的首位主張 (奈良1994/1999年度首位・栃木2004年度首位・群馬2009年度首位) が data/*.json (2014年度のみ) で裏付けられておらず、断定形で書かれている。source.json も year:2014 のみ参照。読者価値は高い章だが、検証不能な数値主張を事実として提示している点は factual exposure。修正案: (a) 過年度の e-Stat 値 (1000世帯あたり) を取得して `data/piano-ownership-timeseries.json` + 折れ線 SVG を追加し主張を接地させる、または (b) 取得しない場合は「総務省の過年度集計では」と出典を明示し、断定を緩める。C 視点 (時系列推移) を名乗るなら本来は折れ線 SVG が要る。
- [MINOR] 文体の常体混入が1箇所。L64「…首位の座は移り変わってきた。」は地の文だが常体終止 (gate の copula 検出では捕まらない動詞終止形)。同章の箇条書きは「後退しています/駆け上がりました/時期もありました」と ですます。修正案: 「…首位の座は移り変わってきました。」に統一。
- [MINOR] 発見1 で「神奈川（29位・321台）・千葉・埼玉の首都圏勢がそろって中位以下」とあるが、千葉28位(322)・埼玉25位(330) は東京22位(340) と僅差で、「そろって中位以下」はやや誇張気味。data 上は首都圏も全国平均(333)前後に密集する構図なので「平均前後に密集」と表現する方が正確。読者誤読を生むほどではないため MINOR。

## 判定理由

curiosity gap がデータと一致 (都会沈下は実データで裏付け済み)、図あたり解釈が厚く (2,805字/図、床350を大幅超)、図表重複・水増し・markdown表なし、callout は記事固有、内部リンク5・source-link は各図直下にインライン配置、数値27件すべて JSON と整合。MAJOR の時系列出典は読者価値を損なう水増しではなく「裏付け強化の余地」であり、断定表現の緩和か折れ線追加で解消できる範囲。MINOR 2件も局所修正で済む。意味品質②層として公開に足る読者価値があるため **PASS** とする (BLOCK 級なし)。MAJOR/MINOR は次回 brushup で接地・統一することを推奨。
