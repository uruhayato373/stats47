## 評価サマリ
「40年で約10分の1。それでもゼロにならない理由とは？」という curiosity gap は真正で、本文は第一種設置義務・災害輻輳耐性・僻地の最後の砦という3つの構造的理由を実体ある分析として届けており、水増しや図表重複はありません。callout 5個はいずれも記事固有の読み違い防止知識（第一種/第二種の区別、全国平均値と実台数の単位差、設置場所検索）で質が高く、ですます調も一貫しています。ただし (1) ランキング SVG の下位パネルが順位ラベルを反転（徳島=509個を「43位」と表示、本文の「最少の徳島=47位相当」と矛盾）、(2) アーキタイプ C の核である時系列の折れ線図が欠落し、激減カーブが prose 描写のみで図がない、(3) C 必須の「変化の地理的偏り」視点が姉妹記事へ全面委譲され本記事内では扱われない、の3点で REVISE とします。

## 指摘
- [BLOCK] data/public-phone-top-bottom.svg の下位パネルの順位ラベルが反転している。JSON では徳島=509個=rank47・福井=692個=rank43 だが、SVG は徳島に「43」福井に「47」を付与（値の小さい順に43→47を割当）。読者には「47位 福井692個・43位 徳島509個」と誤った順位が見え、本文「最少の徳島県は509個」と矛盾する。修正案: generate-article-charts の bottom-5 ラベル割当を rank 降順（最下位=最大番号47）に直して SVG を再生成する（article.md は変更不要）。
- [MAJOR] アーキタイプ C（時系列変化）の核心である「40年の激減カーブ」を可視化する折れ線 SVG が無い。1984→2024 の推移・2001〜2003 の急落・2010年代後半の下げ止まりは記事の主役だが prose 描写のみ。C のテンプレ②「折れ線 SVG で推移」が満たされていない。修正案: 全国推移の *-timeseries.json を data/ に追加し generateLineSvg で折れ線図を本文先頭の章（「40年で約10分の1」）直下に配置する。
- [MAJOR] C 必須視点「変化の地理的偏り（減少が均一でないことを示す）」が本記事内に存在しない。地域差は5箇所（line22/46/51/77/92）で姉妹記事に委譲されており、本記事は「どの県で速く減ったか」を一切扱わない。実質的に「全国時系列＋最新年スナップショット」に留まり C の時系列×地理の掛け合わせが欠ける。修正案: 姉妹記事との棲み分けは保ちつつ、本記事でも「減少率の地域差（例: 都市部は第二種が多く減少が急、僻地は第一種主体で減りにくい）」を1段落＋できれば減少率タイルマップで触れる。
- [MINOR] 2001→2003 の減少は実測 26.0%（14,482→10,705）だが、本文（line31）は「3割近く」、まとめ（line86）は「約3割」と表現。26% は「3割近く」としてはやや過大。修正案: 「2年で4分の1超（約26%）」など実数に忠実な表現に揃える。
- [MINOR] 姉妹記事 public-phone-count-gap への誘導が4回（line22/46/51/77）登場し冗長。回遊価値はあるが反復が多い。修正案: 図直下と末尾の2箇所程度に集約する。
- [MINOR] 時系列の数値（1984=19,894 / 2001=14,482 / 2003=10,705 / 2024=2,045）を裏付ける data ファイルが folder に無く検証できない。MAJOR の折れ線図追加（*-timeseries.json）と併せて出典データを接地すれば factual 追跡性も担保できる。

## 判定理由
読者価値・分析の厚み・文体・callout 品質・内部リンク密度は基準を満たし、決定的 gate（callout5/内部リンク7/charCount3475/prosePerChart3475/である調0/表0）も review.md 以外は全て pass。しかし SVG 下位パネルの順位ラベル反転は読者に見える明確な事実矛盾であり BLOCK 級。加えてアーキタイプ C を宣言しながら時系列折れ線図が無く「変化の地理的偏り」も扱わないため、型の必須分析視点が2点未充足。よって verdict: REVISE。article-writer 側で SVG 再生成（順位ラベル修正）＋折れ線図追加＋地理的偏りの1段落を施し、再 review で PASS に更新する。
