## 指摘

### 前回指摘の解消確認

- [解消: blocker] 品目数の開示漏れ — 本文に「（「他の生鮮肉」「他のパン」のように分類の残り物をまとめた残余品目を除く、以下同じ）」が追加され、生成スクリプトの `countsNote` が要求する開示条件を満たしました。実データ照合の結果、rows 総数 125 (json `rows` の要素数と一致)、残余品目 ("他の" 始まり) 14件、これを除いた category 別集計は「高く」12・「多く」25 で、本文の記述および json の `counts` フィールドと完全に一致します。「多く高く」「支出額大」の0件も残余品目を含めた全 125 行でも 0 で、「1つもありません」という断定は正しい記述です。
- [解消: major] callout の内容重複 — そば・うどん節末の `[!WARNING]` から「支出金額であって消費量ではない」という冒頭 `[!NOTE]` と重複していた記述が削除され、「日本そば・うどんの順位だけで大阪の粉もん文化の実態を測ることはできません」「麺類の消費が少ないことが粉もん人気の低さを意味するわけではない」という、40位という順位の読み違いを防ぐ論点固有の内容に絞られました。
- [解消: major] まとめへの未統合 — まとめに「支出額を数量×価格に分解すると、単価の高さで稼ぐ品目（たけのこ・かに等12品目）と購入量の多さで稼ぐ品目（酒類・牛肉等25品目）に分かれ、量も単価も両方高い品目は一つもない」が追加され、記事全体の結論として統合されました。代表品目の分類も実データと一致しています (たけのこ 価格指数169・かに 194 はいずれも「高く」、牛肉 数量指数137・チューハイ 154・ビール 122 はいずれも「多く」)。

### 残る指摘 (いずれも PASS を妨げない)

- [minor] 「125品目について…分解すると（…残余品目を除く、以下同じ）」という語順では、注記が 125 という母数そのものにも係るように読める余地があります。実際の 125 は残余品目14件を含む全対象で、除外が効くのは後続の12・25という内訳のみです。「125品目（残余品目を含む）を対象に分解すると、品目数の内訳は残余品目を除いて数えます」のように母数と内訳の係り先を分けると誤読の余地がなくなります。
- [minor] まとめの「酒類・牛肉等25品目」という代表例のうち、酒類はチューハイ・カクテル、発泡酒、ビールが「多く」に分類される一方で清酒は「高く」（数量指数63・価格指数123）に分類されます。「酒類」と一括りにすると清酒が反例になるため、「ビール類・牛肉等」のように限定するとより正確です。
