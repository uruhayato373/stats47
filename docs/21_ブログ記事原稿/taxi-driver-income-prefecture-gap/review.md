## 評価サマリ

職業別年収シリーズと同型のテンプレ記事だが、本記事固有の分析が明確に立っている。中核論旨は「タクシーは移動サービスを他地域へ運べない非貿易財なので、需要(乗客密度)の地域差がそのまま所得差に転写される」という構造で、大工記事が導いた「職人の供給希少性で地方が上位」とは逆向きの結論を、同じ賃金構造基本統計調査から正しく差別化して導いている。歩合給比率・実車率・1乗車単価・深夜割増・空港長距離乗車という、タクシー業界に固有の収益メカニズムを上位/下位の解釈に一貫して織り込んでおり、「順位の読み上げ」に終わっていない。archetype A の必須視点(なぜ上位/下位かを地理・産業構造で説明)を満たし、図あたりの解釈段落も厚い(上位段落は約350字、下位段落は約280字で構造解釈を伴う)。factual な数値(東京586・石川230.5・倍率2.54・42県・欠測5県)はすべて data JSON と整合。callout は記事固有(岡山4位の抽出変動 TIP / 北陸積雪の年変動 WARNING / 倍率算式 NOTE)で定型反復ではない。CTA は source-link 2本+カテゴリ誘導で過多ではない。curiosity gap タイトルは本文の中身(2.5倍差・大都市が高い理由)と一致し釣りではない。

## 指摘

- [minor] 「発見1」見出しは上位10と下位5を並べるとしながら、本文の下位列挙が「北陸・東北・南九州」と抽象化され、図(下位5の県名)と発見1の対比が一段薄い。下位5県名を発見1冒頭で再掲すると上位/下位の対称性が読者に伝わりやすい。
- [minor] 北海道7位の解釈が「発見1」内の `[仮説]` ブロックに置かれ、上位を論じた最初のH2(本文)とやや離れている。札幌都市需要+長距離観光乗車の仮説は上位解説に統合した方が論旨が連続する。
- [minor] 石川最下位を「新幹線延伸前のデータ」と触れているが、延伸後にタクシー賃金が上がる見込みかの一文(時系列の含意)があると読者価値が増す。本文の WARNING で年変動には触れているため必須ではない。

## 判定理由

blocker/major 級の実質欠陥なし。テンプレ流用の懸念に対し、タクシー業界の非貿易財性・歩合構造という固有の分析視点が明確に立っており、シリーズ他記事の使い回しではない読者価値がある。factual・archetype A 必須視点・callout 固有性・curiosity gap 真正性・CTA 適量をすべて満たす。残る指摘は構成の連続性に関する minor 3点のみで公開を妨げない。PASS。
