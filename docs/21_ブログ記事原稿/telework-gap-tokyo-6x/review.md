## 評価サマリ
テレワーク6倍格差を産業構造で説明し、副業率・転職率と重ねて「働き方の柔軟性格差」へ展開する着想は良く、ですます調も統一され図あたり601字と解釈の厚みも十分にあります。一方で frontmatter が `archetype: B`(相関・真因解明)を宣言しているのに、B 型の必須分析視点である「散布図 SVG で相関を可視化」と「相関≠因果」の明示が共に欠落しています。さらに本文・description の「10%未満の県は10県」がデータと食い違う(実際は20県)factual エラーがあり、この2点は公開前に是正が必要です。

## 指摘
- [BLOCK] factual エラー: 本文 L27「10%未満の県は10県にのぼり」と description L5「10%未満の県は10県」は誤り。`telework-rate-ranking.json` で 10%未満は **20県**(rank 28 長崎9.8〜rank 47 秋田6.4)。修正案: 「10%未満の県は20県にのぼり、全体の4割を超えます」等。description も同時に修正。
- [BLOCK] アーキタイプB の必須視点欠落(散布図): `archetype: B` を宣言しながら相関を**散布図 SVG で可視化していない**(現状はテレワーク率・副業率・転職率の3つを別々のランキング棒グラフで提示し、相関は散文のみ)。B 型は「テレワーク率 × 副業率」「テレワーク率 × 転職率」の散布図で県の分布を見せ、相関の強さ・外れ値(京都など)を視覚的に示すのが核。修正案: テレワーク率を横軸にした散布図 SVG を1〜2枚追加するか、宣言を `archetype: A` に変更し相関節を補足扱いに格下げする(どちらかで型と中身を一致させる)。
- [MAJOR] アーキタイプB の必須視点欠落(相関≠因果): 本文は「テレワークで通勤時間が浮けば副業に充てる時間も生まれやすくなる」「都市部では地理的制約が緩和されるため求人の選択肢が広がりやすく」と**因果的に読める表現**を重ねているが、相関≠因果の警告が `[!WARNING]` 等で明示されていない。3指標が高い県は「大都市圏」という共通の交絡(産業集積・人口規模)で同時に高くなるだけで、テレワークが副業・転職を直接押し上げる因果は本データから言えない。修正案: 「テレワーク率・副業率・転職率がいずれも大都市圏で高いのは共通の背景(産業構造・人口規模)による見かけの相関であり、テレワークが直接ほかを引き上げる因果関係を示すものではない」旨の `[!WARNING]` を相関節に追加。L59/L67 の因果断定トーンも「〜可能性があります」へ緩和済みだが、警告 callout で補強する。
- [MINOR] L53 と L82(まとめ)で「6倍以上/6.2倍」「上位は首都圏・大都市圏が独占」「下位は東北・四国・山陰」が冒頭・ランキング節・まとめで3回ほぼ同文で反復。まとめは findings 図と本文の両方で同じ点を繰り返しており、まとめ本文は「政策含意」に寄せて要約の重複を1回分削ると締まる。
- [MINOR] L31「上位は三大都市圏(東京・大阪・名古屋)」とあるが、ランキング上位5は東京・神奈川・千葉・埼玉・大阪で名古屋(愛知6位)は5位圏外。「三大都市圏とその周辺、特に首都圏」と表現を実データに合わせると正確。

## 判定理由
ですます調・図あたり字数(601)・内部リンク(3)・callout(3)・表禁止・SVG系譜などの機械フロアは quality-gate を通過しており、解釈の厚みも単なる順位読み上げを超えている。しかし (1) 「10県」の factual エラー、(2) archetype B 宣言に対する散布図の不在 の2点は読者価値・整合性に直結する致命的問題であり BLOCK。相関≠因果の明示欠落(MAJOR)も B 型記事として必須要件を満たさない。よって verdict: REVISE。散布図追加(または archetype 修正)+ factual 修正 + 相関≠因果 callout を反映後、再 review で PASS に更新する。
