## 評価サマリ

「数量×価格で分解する富山市の食卓」節は、既存の支出額ランキング（ぶり・いか・昆布・餅すべて1位）を単に繰り返すのではなく、47県庁所在市平均=100の数量指数・価格指数に分解することで「量で稼ぐ品目（いか239.3/97.5、ぶり211.3/109.7）」と「単価でも稼ぐ品目（昆布138.0/162.4、餅143.8/134.7）」という新しい読み方を提示できている。数値は `data/kakei-quantity-price.json` の該当行（squid・yellowtail・konbu・mochi）と完全一致し、「今回調べた家計調査の食料品目のうち富山でもっとも高い価格指数」という主張も全125行を確認した結果、昆布の162.4が最大値であることを実測で確認できた（捏造なし）。読み違い防止の3点（47県庁所在市平均=100であり全国値ではない／価格指数は品種・ブランドの違いを含む／富山市の二人以上世帯・2024年の値）は末尾の[!NOTE]にすべて明記されている。品目ごとの解釈（ぶり=嫁ぶり文化、いか=ホタルイカ、昆布=北前船交易、餅=米どころ文化）も各図の直後に具体的な段落で置かれており、図の羅列で終わっていない。callout は WARNING（支出額=消費量ではない）を新設の数量×価格節への伏線として自然に機能させており、定型の年次差caveatの使い回しには見えない。quality-gate.mjs は blocker 0 件（warning はprose文字数2141字・図あたり535字がやや目標未達、および katakana/kanji表記差によるsource-link誤検知のみ）。

## 指摘

- [minor] 「富山の食卓を貫くもの」節の「餅は米どころの伝統が支える。」（article.md 71行目）が動詞終止形の常体で終わっており、前後の「〜です。」「〜生まれています。」とですます調が混在している。修正案: 「餅は米どころの伝統が支えています。」に統一する。
- [minor] frontmatter の `archetype: E`（網羅ハブ・代表2-3指標で束ねる型）に対し、実際の本文は4品目それぞれの個別解釈に加え数量×価格分解という定量分析まで含み、D2（食品・家計消費）またはB（相関・真因解明）寄りの深さになっている。内容自体に問題はないが、archetype ラベルが実態と一致していないため、次回改稿時に `D2` への変更を検討してよい（読者影響なし、メタデータの整合性のみ）。
- [minor] `<source-link href="/ranking/konbu-consumption-expenditure">` と `<source-link href="/ranking/mochi-consumption-expenditure">` が quality-gate の offtopic-link warning で「本文にラベル文字列が出てこない」と検出されているが、実際は直後の段落で「昆布の消費支出額」「餅の消費支出額」と漢字表記で言及されており内容的には整合している（label側が「こんぶ」「もち」のかな表記のため lint が拾えていないだけ）。対応不要だが、将来 lint の日本語表記ゆれ対応を検討する際の参考情報として記録する。

## 判定理由

BLOCK 級の指摘は0件。数量×価格の新規節は支出額ランキングの言い換えではなく、量と単価という2軸に分解した独自の読み方を提示できており、読者価値のある追加コンテンツと判断できる。すべての数値がR2データ（家計調査由来のranking json + kakei-quantity-price.json）と一致し、「もっとも高い価格指数」という定量的主張も全品目を突合して裏取りできた。読み違い防止の3点（平均基準の性質・価格指数の限界・調査対象の属性）もcalloutに過不足なく含まれている。文体は動詞終止形の常体が1箇所混在するのみで、記事全体としてはですます調に統一されている。以上より、指摘は軽微な修正提案（MINOR）に留まり、公開品質として`PASS`と判定する。
