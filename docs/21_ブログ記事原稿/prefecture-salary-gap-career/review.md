アーキタイプ D(生活含意・対比)として設計されており、必須分析視点(内訳分解+読者の生活への含意)を満たしている。R2 の ground truth データ(software-engineer-rankings.json / salary-gap-by-job.json)と本文の全数値を突合したところ、京都608.4万・沖縄402.6万・格差1.51倍、システムコンサルタント2.65倍(秋田952.5/沖縄359.1)、タクシー運転手2.54倍、薬剤師1.52倍、介護職員1.33倍まで完全一致し、rank主張の捏造は無い。内部リンク5件(areas/26000, ranking/system-consultant-annual-income, category/laborwage, blog/care-worker-income-prefecture-gap 等)は全て実在ページへ200到達し、タイトルの1位値も本文の主張と一致している。今回の変更は既 live 記事への PR 表記追加(冒頭の全体PR宣言 + アフィリエイトバナー直前の「> ※PR：以下は転職エージェントのご紹介です。」)のみで、この2箇所は景表法対応として適切な位置に配置されている。callout は4個とも記事固有の内容(職種による母数のばらつき、県順位の読み方の注意、格差の大小で取るべき戦略が変わる示唆、無料の仕組みの説明)を持ち、全記事共通の定型文の反復ではない。
## 指摘
- [MINOR] 「まとめ」セクションの箇条書き5行(87-91行)がすべて動詞終止形の常体(「違う。」「効く。」「べき。」「狙える。」「変わる。」「構わない。」)で統一されており、本文他部分のですます調から浮いている。ですます調は本文全体の94%程度(101文中81文がです/ます/ました等終わり)で維持されているが、まとめブロックのみ意図的にせよ非意図的にせよ常体でまとまっており、文体の一貫性という観点で軽微な指摘とする。

## 判定理由
機械ゲートのblockerのうち「data/*.json無し」はローカルoutboxにdata/フォルダが同梱されていないための誤検知であり、R2上の実データで数値・SVG系譜とも実在・整合を確認済み。内部リンクは全件生存し、リンク先タイトルの数値も本文と一致している。PR表記2箇所は適切な位置にあり、アフィリエイトCTAは1件+TODOコメント(次の提携用の実務メモ)のみで過剰配置ではない。まとめブロックの文体ゆれとTODOコメント残置はいずれも読者体験を大きく損なわないMINOR事項であり、BLOCK/MAJORに該当する欠陥は無い。PR表記追加という差分の目的、および既存本文の読者価値(具体的な倍率データ+転職判断への翻訳)の両面から公開を妨げる要因は無いため PASS とする。
