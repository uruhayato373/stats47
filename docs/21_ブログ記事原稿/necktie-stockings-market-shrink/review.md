## 指摘

- [major] 県別断面の地域差を、標本変動を考慮せずに地域性として読んでいる（§まだネクタイを買っている県はどこか）。本文は「地域ごとの業種構成や冠婚葬祭の慣習の違いが影響している可能性があります」と述べますが、この記事自身が §値段はほとんど変わっていない で「分母となる購入数量がもともと1本未満と小さい品目では、年による変動が大きくなりやすい」と注意を促しています。同じ注意は県別断面にこそ強く当てはまります。記事の導出どおり1世帯の年間購入本数は2024年で0.1本前後、単価は3,370.8円なので、支出額は各都市サンプル内のごく少数の購入に左右され、1件の高額購入が都市平均を大きく動かします。滋賀6円（サンプル内でほぼ購入なし）と熊本1,265円の211倍という開きは、安定した地域差というより単年・低頻度・高単価品目の標本変動を多く含むと考えるのが自然です。修正案: 同節に「この値は都道府県庁所在市の単年サンプルで、購入頻度が極めて低い品目のため年による振れが大きく、順位は年ごとに入れ替わりやすい」旨の一文（または WARNING callout）を足す。地域差を主張として残すなら、複数年平均に置き換える。

- [major] 「0本」表示の理由を出典なしに家計調査の集計方法へ帰属している（§そもそも何回買っているのか の本文と NOTE callout）。「家計調査の年間購入数量は小数点以下を四捨五入して集計されるため、1本未満の年はすべて『0本』と表示されます」とありますが、丸めているのは本記事の集計スクリプトです。`.claude/scripts/blog/fetch-kakei-monthly.mjs` は年計を `Math.round(xs.reduce((a, b) => a + b, 0))` で整数に丸めます（`annual: "sum"`）。一方で単価の系列は同じ数量を丸めずに `sum(expenditure) / sum(quantity)` で割っており（`annual: "ratio"`）、2000年に3,764.2円という有限値が出ている以上、年計の生値は0ではない小数（0より大きく0.5未満）です。12か月の整数の合計が小数になることはないので、e-Stat 側の月次値が小数であることも確定します。読者が受け取る結論（購入頻度が極めて低いから0と表示される）自体は正しいため blocker とはしませんが、公開物が政府統計の集計方法について事実と異なる説明をしている状態です。修正案は2つ: (a) 主語を家計調査から外し「この図は年間本数を整数に丸めているため、1本を大きく下回る年は0本と表示されます」と書く。(b) より良い解決として、数量系列を小数2桁で再生成する。そうすればネクタイの系列に本来の減少（記事が本文で述べている約8割減）が現れ、この callout も本文の説明段落も不要になります。

- [minor] 帽子の2020年→2023年の記述が2箇所で重複しています。§支出はどこまで縮んだのか に「落ち込みが目立つのは2020年の61で…2023年には85.1まで回復しています」、§なぜ品目によって縮み方が違うのか に「帽子は2020年の落ち込み（指数61）から2023年に85.1まで戻しており」とあり、同じ2つの数値を同じ趣旨で繰り返しています。後者は前者を受けた解釈段落なので、数値の再掲をやめて「先に見た帽子の戻りの速さは」と受ける形にすると重複が消えます。

- [minor] archetype C が求める「変化の地理的偏り」は厳密には未達で、追加された地図は2024年単年の水準断面です。記事はこれを「上で見てきた全国の縮小トレンドとは別の視点です。各県の順位が24年間でどう動いたかまでは、このデータだけでは確認できません」と正しく開示しており、誠実な扱いなので許容範囲と判断しました。型としての「変化の不均一」は品目間比較（ネクタイ・ストッキング vs 帽子）が実質的に担っており、そちらは十分な厚みがあります。将来の更新で県別の時系列が取れるなら、2000年前後との順位変動を1枚足すと型の要件を正面から満たせます。

- [minor] 「九州・四国の一部の県が上位に集まる一方で、近畿・中部の一部の県は下位に偏っており」は、上位10県のうち九州・四国は3県（熊本・福岡・徳島）、下位10県には宮崎・愛媛も含まれます。「一部の」という限定が付いているので誤りではありませんが、「集まる」「偏る」はやや強い語です。上位3県が九州・四国であることを述べるに留めると、上の標本変動の注意とも整合します。

## 判定理由

blocker 0件のため verdict は PASS です。前回 REVISE の根拠だった2件の blocker は、いずれも指摘した箇所そのものが書き換えられ、実データと突き合わせて解消を確認しました。1件目（帽子2020年の水準）は `accessory-expenditure-index-timeseries.json` の帽子系列で61が全期間最小値であることを確認し、記述は自系列の最小と3品目間の相対順位を分けて書けています。2件目（月次の本数レンジ）は該当文が削除され、data JSON に存在しない数値は本文・callout のどこにも残っていません。

変更 hunk のスポットチェックでも新たな blocker は出ませんでした。追加された「支出指数18.8 ÷ 単価比0.895 ≒ 0.21」の導出は算術的に正しく（0.188 ÷ 0.8955 ＝ 0.2099）、記事の中心的主張と整合します。新設した県別セクションの数値・倍率・順位はすべて `necktie-stockings-market-shrink-map.json` と一致し、「都道府県庁所在市ベース」という前提も正しく開示されています。追加された地図 SVG は720×720、凡例は右下で「低い／高い」＋実数値スケール（6円／636円／1,265円）、左上に上位3県という現行のタイルマップ規格どおりで、意味的ラベルの誤用もありません。

読み違い防止の3点は満たしています。全国集計と県順位の違い・二人以上の世帯であることは冒頭の NOTE が明示し、新設した県別セクションも冒頭で「都道府県庁所在市ベース」と断ったうえで末尾に「全国の縮小トレンドとは別の視点」と付記しています。相関と因果は WARNING が担い、前回指摘した内部表記の `[仮説]` も外れました。ですます調は地の文で統一され、決定的 gate の である調 検出0件に加えて動詞終止形の常体混入も見当たりません（まとめの体言止め箇条書きは他の PASS 記事と同じ house convention です）。

残した major 2件は、どちらも公開済みの数値を誤らせるものではなく、読者が受け取る結論も正しいままです。ただし1件目は記事が自分で述べた注意（低頻度品目の分母の小ささ）を県別断面に適用し損ねたもの、2件目は丸めの主体を取り違えたもので、いずれも一文の追加・書き換えで解消できます。次回この記事に触れる際に対応してください。特に2件目は、数量系列を小数で再生成すれば callout も説明段落も不要になり、記事の中心的主張がそのまま図で見えるようになります。
