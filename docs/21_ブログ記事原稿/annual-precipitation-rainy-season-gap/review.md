## 評価サマリ

アーキタイプ B（相関・真因解明）として必要な三要素——降水量ランキング SVG・降水日数ランキング SVG・散布図 SVG——がそろっており、「量1位=日数1位ではない」という curiosity gap は本文で具体数値（静岡3753mm / 113日、富山182日）によって確かに裏付けられている。各 SVG の後に地形・気候メカニズムを踏み込んで説明する段落が置かれており（図あたり prose ~1,394字）、数値の読み上げではなく「なぜその値になるか」の構造説明が主体となっている点は強い。一方、内部リンク3本のうち `/areas/` ページへの誘導が0本で、上位・下位県（静岡・富山・岡山など）の area ページへの個別誘導が抜けている。散布図直後に [!WARNING] が挟まり「見かけの相関 vs 真因」の散文が Warning の後に来る構成は、読者が図→警告→解釈という順で読むことになり警告が解釈より前に立ちはだかるため若干読みにくい。いずれも公開を止めるには至らないが、修正すれば回遊性と読みやすさが向上する。

## 指摘

- [major] **内部リンクに `/areas/` ページが含まれていない。** 本文で静岡・富山・岡山・石川・宮城・北海道などの固有県名を多数参照しているが、`/areas/{prefCode}` への誘導が1本もない。例えば「静岡（3753.5mm）」初出時に `[静岡の都道府県データ](/areas/22000)` を付けると、county ページへの回遊起点となり内部リンク密度の強化にもなる。上位2〜3県（静岡・富山・岡山）に少なくとも1本ずつ追加することを推奨。

- [major] **散布図直後に [!WARNING] が挿入され、解釈段落が Warning の後に来る構成になっている。** 現状は「散布図 → [!WARNING] → 4タイプの説明段落」の順になっており、読者は図の意味を理解する前に「これは因果でない」という制限を先に受け取る。アーキタイプ B の正典テンプレ（「散布図 → 解釈段落 → [!WARNING]」）に沿い、まず4タイプの散文解釈を展開してから Warning を末尾に配置する方が読者の理解順序として自然。

- [minor] **[!WARNING] の「散布図は年によって大きく変動することに留意」という後半節が汎用的すぎる。** 前半（相関≠因果・集中豪雨型が量を底上げするメカニズムの違い）は記事固有で良い。後半「年によって変動」は気候系すべての記事に書けてしまう定型で情報価値が低い。代わりに「台風の接近本数が平年より多い/少ない年で静岡・南九州の順位が大きく入れ替わる」など、この記事で示したデータの具体的な変動要因に絞ると良い。

- [minor] **タイトルの curiosity gap が「だが」1語だけで成立している。** 「降水量トップは静岡だが雨の日数トップは富山」の構造は矛盾逆説型として機能しているが、検索上位で競合するタイトルと差別化するには「なぜ」「3.7倍格差」「量1位≠日数1位」のような明示的な gap 要素を加えるとクリック率がさらに伸びる余地がある（例：「降水量トップは静岡、なのに雨の日数トップは富山｜量と日数が逆転する梅雨の構造 (2024)」）。ただし現タイトルは NG パターンには該当せず即時修正は任意。

- [minor] **第4セクション「梅雨と『雨の質』が変える生活リスクと農業条件」は読者価値があるが、アーキタイプ B の正典テンプレ（⑤ 両 `/ranking/{key}` リンク＋誘導）で終わることが推奨されている。** 現状では第4セクションの末尾に `source-link` が無く、降水量・降水日数ランキングへの最終的な再訪問誘導がない。データ出典セクション直前に両ランキングへの `<source-link>` を1本追加するか、第4セクション末尾に `/category/landweather` 以外の `/ranking/{key}` リンクを追加することを推奨。

## 判定理由

BLOCK 級・major 級のうち公開を止める致命的指摘はなく、アーキタイプ B の必須三要素（2指標の上位5+下位5 SVG 対比・散布図・相関≠因果の明示）はすべて揃っている。prose 字数も3図で合計約4,183字（図あたり1,394字）で blocker 閾値（350字/図）を大きく上回る。major 指摘の `/areas/` リンク追加と Warning 配置順の修正は次の編集時に対応することを推奨するが、現状でも読者価値の実体は十分であるため PASS とする。
