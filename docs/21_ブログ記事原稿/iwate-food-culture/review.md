## 評価サマリ

追加された「数量×価格で分解する盛岡市の食卓」節は、冒頭3品目の支出額ランキング（順位の言い換え）とは異なる軸を持ち込んでおり、りんご・わかめの全国1位が「単価の高さ」ではなく「購入量の多さ」に支えられている、という支出額順位だけでは分からない発見を提示できている。数量指数・価格指数の値はいずれも `data/iwate-quantity-price-findings.json` および `kakei-quantity-price.json` の該当行と一致し、捏造は確認されなかった。読み違い防止に必要な3点（47県庁所在市平均=100であり全国値ではない／価格指数は品種・銘柄差を含む／対象は盛岡市二人以上世帯の値）はいずれも末尾のNOTEで明記されており、機械floor（quality-gate.mjs、`docs/21.../article.md` を直接指定した実行）も blocker 0 件で通過している。一方でcalloutが5個に達し（適量3-4個の上限を超過）、うち3個が「支出額≠消費量・自家消費/贈与」というほぼ同じ論点を繰り返しており、また「高く買う」区分の説明で総数6品目と述べた直後に代表4品目を「これにあたります」と閉じた言い方で書いているため、部分的な冗長・precisionの粗さがある。これらはMAJOR/MINORに留まり、公開を止めるBLOCK級の欠陥ではない。

## 指摘

- [major] callout が5個（適量3-4個・5個以上は過剰の基準に抵触）で、うち NOTE（L25「支出額であって消費量ではない」）・WARNING（L58「支出金額の調査であり消費量ではない…自家消費や贈与が支出額に表れにくい」）・TIP（L67「産地での自家消費・贈与が家計調査に表れにくい…買って食べるかもらって食べるか」）の3個が「支出額≠消費量／自家消費・贈与」という同じ論点をほぼ言い換えているだけで独立した情報量が薄い。修正案: WARNING と TIP（L67）を1個に統合する（WARNING側の「生産量順位とのずれ」＋TIP側の「買って食べる/もらって食べる」の視点を1つのcalloutにまとめれば、callout数を4個に減らしつつ内容は保てる）。
- [major] 「数量×価格で分解する盛岡市の食卓」節の3段落目で「盛岡市の125品目では…『高く買う』が6品目という内訳になっています」と述べた直後、その2段落後で「かれい…、柿…、すいか…、ワイン…の4品目がこれにあたります」と書いている。「の4品目がこれにあたります」は閉じた列挙表現（＝これで全部）に読めるため、直前で示した「6品目」という総数と矛盾して見える（実際は6品目中の代表4品目で、残る2品目〈メロン・かに〉が省かれている）。修正案: 「…の4品目が代表例です（ほかにメロン・かにも該当）」のように、代表選出であることを明示する。
- [minor] 冒頭2段落目「青森を上回るりんご、三陸のわかめ、そして盛岡の麺文化を映す中華めん。」と、「岩手の食卓を貫くもの」節の1文目「青森を上回るりんご、三陸わかめ、盛岡の麺文化を映す中華めん。」がほぼ同一文の繰り返しになっている。まとめ的な反復としては許容範囲だが、後者を別の言い回しに変えると冗長感が減る。
- [minor] `<source-link href="/ranking/chinese-noodles-consumption-expenditure">中華めん消費支出額ランキングをもっと見る</source-link>` のリンク文言・本文表記が「中華めん」（かな）だが、対象 ranking の正式 title は「中華麺消費支出額」（漢字）であるため、quality-gate.mjs の offtopic-link チェックが誤検知している（本文では「中華めん」を繰り返し論じており実際には主題のズレはない）。表記を統一する必要はないが、リンクラベルを正準タイトルに寄せる（または本文中に一度「中華麺」表記を入れる）と機械チェックの誤検知が解消する。
- [minor] 「柿やワインも数量は平均以下ながら単価は2〜3割高く」の柿は priceIndex 134.5（+34.5%）で「2〜3割」の上限をわずかに超えている（ワインは+23%で範囲内）。誤りというほどではないが「3割強」寄りの表現の方がより正確。

## 判定理由

BLOCK 級の指摘は0件。数量指数・価格指数の全ての引用値（りんご241/75、わかめ259/70、しじみ207/92、塩さけ207/88、かれい88/122、柿73/135、すいか43/201、ワイン70/123、豆腐117/112）およびカテゴリ件数（多く高く0・高く6・多く29・支出額大1）は `kakei-quantity-price.json` の counts フィールド（「他の〜」残余品目を除いた件数）と厳密に一致しており、数値の捏造・誤引用は確認できなかった。りんご・わかめ・中華めんの支出額ランキング（1位岩手9,262円/2位青森7,748円、1位岩手2,796円/2位長野2,428円、1位岩手6,598円/2位山形6,441円）も `data/*.json` と完全一致する。追加節は支出額ランキングの言い換えではなく「量で稼ぐ」「単価で稼ぐ」という新しい読み方を提示できており、47市平均=100・価格指数の品種差・盛岡市二人以上世帯という3つの読み違い防止情報もNOTEに明記済みである。callout過多と「4品目がこれにあたります」の precision の粗さはMAJOR指摘として次回改稿時の修正を推奨するが、読者に誤った数値・順位を伝えるものではなく、公開を差し止めるBLOCK要件には該当しないためPASSとする。
