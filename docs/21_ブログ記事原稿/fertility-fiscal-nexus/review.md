## 評価サマリ
タイトルの curiosity gap は真正で、本文は「財政が豊かなほど少子化が深刻」という逆説に正面から答えており、callout も記事固有の知識を足している(逆相関が東京1点に引っ張られる旨の相関≠因果 caveat、沖縄1位でも自然増ではない注意、住居費・人口移動へ誘導する TIP)。文章の論理も都市/北日本/九州沖縄の3タイプ分けや秋田の例外提示で厚みがある。しかし frontmatter で `archetype: B`(相関・真因解明)を宣言しているにもかかわらず、B 型の必須分析視点である「散布図 SVG で相関を可視化」が存在せず、対の指標である財政力指数のチャート・data JSON も無い。記事の中核主張(財政力×出生率の逆相関)が散文の断言のみで支えられ、視覚的証拠がゼロという構造的欠陥がある。図は出生率ランキング1枚だけで、4象限分類も箇条書きにとどまる。読者価値は文章としては高いが、宣言したアーキタイプの核心成果物が欠落しているため REVISE とする。

## 指摘
- [major] archetype:B の必須「散布図 SVG で相関を可視化」が無い。財政力指数(x軸)×出生率(y軸)の散布図/4象限 SVG を追加し、本文の「4象限で分類すると」の箇条書きを図に置換する。
- [major] 対の指標 財政力指数のランキング SVG と data JSON が不在。東京1.06/沖縄0.36/神奈川/愛知1.29/秋田 を本文で繰り返し引用するが視覚化されておらず、「×」比較の片側が見えない。財政力指数 上位5+下位5 SVG を追加する(B 型テンプレ②③相当)。
- [minor] 図が1枚のため記事の論点(逆相関)が prose 断言依存。上記2図の追加で図あたり解釈の厚みと B 型の章構成(指標A→指標B→散布図)が整い、説得力が増す。
- [minor] 住居費・通勤・保育費を「都市の構造」として列挙するが具体数値の裏取りが弱い(家賃3〜4倍は概数)。可能なら住居費/転入超過率の別指標を散布図補助線として引くと真因の説得力が上がる。

## 判定理由
読者価値(論理・callout・curiosity gap)は十分だが、frontmatter で宣言した archetype B の中核成果物=相関の可視化(散布図)と対指標(財政力指数)のチャートが両方欠落している。B 型を選んだ以上「相関を図で示す」ことが読者への約束であり、それを散文の断言だけで代替するのは構造的欠陥(major)。散布図 + 財政力指数 SVG の2図を追加し、4象限の箇条書きを図に置換すれば PASS。文章自体の修正は不要。
