- [MINOR] callout 3個はいずれも記事固有の内容（家計調査の世帯定義・都道府県庁所在市限定・都心部の実態が反映されにくい理由）であり、全記事共通の定型文には見えない。良好。ただし WARNING と TIP がいずれも「家計調査は都道府県庁所在市が対象」という同じ限界を角度を変えて2回説明しており、やや冗長。将来の brushup では一方を簡潔化する余地がある。
