「薬の富山」という読者の既存イメージを冒頭で裏切り（実際の化学工業出荷額1位は千葉、富山は17位）、curiosity gap を本文で誠実に回収する良質な archetype A 記事です。各 SVG 図の直後に「なぜ上位/下位か」の解釈段落（臨海コンビナートの立地論理／徳島の大塚グループ1社依存／薬都富山の比率高・絶対額中位という現在地）が厚く置かれ、図あたり prose 550字を満たします。絶対額と比率を別軸で扱い、最後に化学 vs 輸送の二大軸という構造把握まで踏み込んでおり、ランキング羅列で終わっていません。数値・順位は data/*.json と整合します。

## 指摘
- [MINOR] 「製造品出荷額の推移」セクション (L85-93) で全国総額を「2023年に約37.3兆円」とするが、これは社会人口統計体系のサイト独自指標で、一般読者が知る製造業出荷額（実額 ~330兆円規模）と桁が違う。data と矛盾はしないが、読者が「日本の製造業がたった37兆円?」と誤読しうる。冒頭で「本指標は◯◯ベース」等の1行注記を [!NOTE] で添えるとミスリードを防げる。
- [MINOR] L93「化学工業が全製造業に占める割合は全国平均で約12%前後と推定されます」「輸送用機械（約18%）」は data/*.json に裏付けがなく "推定" の語で逃げている。記事内の比率ランキング上位値（徳島40%等）と桁感が混在し読者が混乱しうる。出典を明示するか、根拠の無い概算は削るのが望ましい（evidence-based-judgment 観点）。
- [MINOR] 散布図の象限解説 (L75-81) は data と整合するが、回帰直線・相関係数の言及がなく「相関≠因果」の注意が散布図直近にない。archetype A なので必須ではないが、L59 の [!WARNING] が比率ランキング側に置かれ散布図にはかからない。散布図直下に「両軸は独立した装置産業で正の相関はない」旨を1文添えると解釈が締まる。
