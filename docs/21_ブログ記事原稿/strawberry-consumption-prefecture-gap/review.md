## 評価サマリ
「いちごの産地ほど食べない?」という逆説タイトルの問いに、本文が最後まで誠実に答えている良記事です。栃木1位という王道を先出ししたうえで、福岡34位・長崎27位・熊本39位・宮崎41位・佐賀36位という九州産地の下位集中を「発見1」で具体的に提示し、その真因を「家計調査は県庁所在地世帯の購入量で、生産県は域外出荷型ゆえ地元購入に表れにくい」という [!WARNING] と [仮説] で構造的に説明しています。下位グループも「地元に強い競合果物があるほどいちごが第一候補になりにくい」という置き換えの構図で読み解いており、単なる順位羅列に終わっていません。archetype A の必須視点「なぜ上位/下位か(地理・産業構造)」を上位・下位・産地パラドックスの三方向で満たし、3 つの callout はいずれも記事固有で読み違い防止の知識を足しています。引用数値(栃木3,636g・沖縄1,139g・3.19倍・各産地順位)は data JSON と完全一致を確認しました。
