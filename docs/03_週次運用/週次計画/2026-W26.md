## 批判的レビュー

### 1. 「技術的に楽しいだけでは？」

- AREA-PROFILE-FIX-01 は P1 SEO バグ → Must に適切。直接 Googlebot のコンテンツ取得に影響
- 未コミット変更のコミットはデプロイを詰まらせているため Should に適切
- AICONTENT-02 Could への降格は適切。機能改善だが収益直結ではない
- **懸念なし**: 今週は技術タスクが SEO/品質/収益に直結しているものだけ

### 2. 「先週と同じ失敗を繰り返してないか？」

- BLOG-WAVE 計測が Must に 5 週連続 → 「月曜朝に最初に実行」と明示して順序制約を作った。工数 S なのに未達の最大の理由は「後回し」のため
- NSM 実験が 4 週連続 Should → 今週は Must 候補にしたかったが、AREA-PROFILE-FIX-01 の方が SEO インパクトが大きいため Should のまま。ただし Should の 1 位に配置
- 計画外タスクリスク: 今週は大型技術タスク（note R2 化・SVG 標準化）が一段落。**新たな大型計画外タスクが発生しないよう、開始前に CLAUDE.md の「外科的変更」原則を確認する**

### 3. 「今週やらないと機会損失は？」

- **BLOG-WAVE effect 計測の due が 2026-06-22（月曜）** = 今日中に実行しないと期限切れ。月曜朝に強制実行
- **兵庫県知事問題への乗り方**: トレンドのピークは今週。areas/28000 への内部リンクを既存ブログ記事（税収・人口等）に追加するだけでも流入増の可能性。Should に追加したかったが今週の Should は 3 件でスロット満杯のため Could の次候補として意識
- **Organic Search の -5.3% 減**: リデザイン影響の可能性。GSC W26 snapshot を週の早い段階で取得し、特定ページの順位変動を確認すること
