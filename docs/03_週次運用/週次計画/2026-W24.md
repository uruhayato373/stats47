## 批判的レビュー

1. **「技術的に楽しいだけでは？」**: Must は 122 公開（SEO 直結）・effect 判定（検証負債）・GSC verification（実測）で、新機能開発を Must から排除。W23 の大型開発（Sankey/finance）の続きは入れていない。✓ trap なし
2. **「先週と同じ失敗を繰り返してないか？」**: ① note/SNS「5本」目標は W19/W21/W22/W23 で連続未達 → **1-2本に縮小して Should**（Must に入れない）。② AdSense OAuth は agent 実行不能 → **Must から外し「ユーザー操作」枠で明示依頼**（claude Must にしても達成不能）。③ effect 判定の慢性後回し → 今週 **Must に triage を1件昇格**。
3. **「今週やらないと機会損失？」**: ① 122 metric 410 は毎日 SEO 損失継続 → Must 最優先。② GSC W23集約 verification は 6/08 のみのタイミング。③ 令和7 離婚率/社会減は新刊データの旬（数週間）→ Should。

> 工数見積: Must 合計 L+M+S ≈ 大。122 公開(L) が重いため、Should/Could は余力次第。持ち越し（note/CLS）は意図的に Should へ降格し Must を 3 件に抑制。
