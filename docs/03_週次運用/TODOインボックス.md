# TODO インボックス

> セッション中に出た「やりたいこと・改善すべきこと」を**素早く捕捉する staging 置き場**。
> ここは SSOT ではない。整理（triage）のタイミングで適切なバックログへ振り分け、移動済みは `整理先` を埋めて `状態` を `整理済` にする。

## 運用フロー

```
セッション中に思いついた TODO
  → このインボックスの表に1行 append（種別は推定で可、空でもよい）
  → 月初の /monthly-plan（または随時）で triage:
      改善施策      → docs/02_実装計画/03_改善バックログ.md
      機能・自動化  → docs/02_実装計画/04_機能バックログ.md
      指標拡充      → docs/02_実装計画/05_指標バックログ.md
      コンテンツ    → docs/{20,22,30}_*/backlog/
      PR で閉じる改修/バグ → GitHub Issues (enhancement/bug)
  → 振り分けたら 整理先 を記入し 状態=整理済 に。実体は移動先が真実源
```

- **真実源は移動先のバックログ**。インボックスは「まだ分類していない受信箱」であり、整理済み行は履歴として残す（または定期的に下部へ畳む）。
- 種別の推定: `改善` / `機能` / `指標` / `コンテンツ` / `バグ` / `?`(不明)。
- 緊急度・サイズが分かれば備考に書く（後の優先順位付けに使う）。
