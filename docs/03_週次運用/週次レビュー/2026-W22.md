## 学び・ナレッジ

- **DBless Phase E の完了方法**: `getDrizzle` を全削除して app が R2 のみ読む形にするには、テスト基盤（schema 型ソース）と本番コードパスを分離した上でのコンパイルエラー解消が鍵。`packages/database/` を型ソースとして残しつつ本番クエリをゼロにする設計が有効。
  - `/knowledge` に記録推奨: はい（DBless 移行の最終フェーズパターン）
- **Sitemap 整理の副効果**: cities 未登録 URL を -79% 削減した施策は GSC Coverage レポートの改善に 2-4 週後に現れる見込み。P0-RANKING-INDEX 施策との相乗効果を INDEXING-DRILLDOWN-01 観測で確認すること。
- **R2 write guard の設計**: `_assert-ci-write.ts` は `CI` か `ALLOW_LOCAL_R2_WRITE` フラグのみで許可する設計が実際の運用に合っていた。ローカルからの誤 push 事故をゼロ件に抑制できる。
