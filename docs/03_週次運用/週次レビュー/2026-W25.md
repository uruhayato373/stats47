## 学び・ナレッジ

- **eslint no-duplicate-imports は --fix で自動修正不可**: 同モジュールを value import + type import の2行で書くと `no-duplicate-imports` に違反し CI がブロック。`eslint --fix` は auto-fix できない。手動で `import { Foo, type Bar } from "module"` のように inline type にマージする必要がある
  - `/knowledge` に記録推奨: はい（CI ブロックパターンとして）
- **Codex 大量リファクタ後は import/order チェックが必須**: 175ファイル削除後のバレルエクスポート再配線で import 順が変わり ESLint import/order 違反が多発。`npx eslint --fix` で大半は解消できるが duplicate は手動対応
  - `/knowledge` に記録推奨: はい
- **NSM snapshot の engagedSessions フィールドは JSON トップレベルに存在しない**: `snapshot-weekly-metrics.mjs` が出力する JSON は `ga4.channels[]` 内の `thisEngagedSessions` 合算が NSM 値。出力コンソールログと JSON フィールドが一致しない（コンソールには+51と表示されるが JSON キーは別構造）。スクリプト改修で明示フィールドを追加すべき
