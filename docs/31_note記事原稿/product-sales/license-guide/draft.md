# 都道府県データ商品のライセンス・版の違いガイド

## こんなときに
どのライセンス・データ版を選べばよいか、違いを一覧で理解したい

## この記事の内容
- 空テンプレート版：データなしのテンプレートを更新責任なしで使う
- サンプルデータ版：架空または公的サンプル付きで商品を試す
- 基準年固定データ版：調査年を明記した買い切りデータで使う
- 最新年更新版：更新時期と対象統計を限定して最新年データを使う
- 個人ライセンス：購入者本人のみが利用するライセンスで使う
- 1法人ライセンス：1法人内での利用を許可するライセンスで使う
- クライアントワーク可：成果物への組み込みを許可するライセンスで使う
- 教育機関ライセンス：授業・配布範囲を限定した教育機関向けに使う
- カスタマイズ付き：色・ロゴ・項目を変更したカスタマイズ版で使う
- サポート付き：導入説明と一定期間の質問対応を受けて使う

## 対象者
- 全商品共通

## まず無料で確認できるデータ
- 無料で見られる関連データ: [stats47.jp/](https://stats47.jp/)

## 選び方の目安
- まず「無料で試す」→「基準年固定の買い切り」→「更新版」の順で検討すると失敗しにくいです。
- クライアント納品に使う場合はクライアントワーク可ライセンスを選んでください。

## 注意
- 掲載データは e-Stat を基にした独自集計で、行政の公認・推奨ではありません。
- 相関がある指標でも、それだけで因果を示すものではありません。
