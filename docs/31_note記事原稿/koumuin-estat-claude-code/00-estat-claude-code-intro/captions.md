## Instagram — フィード投稿用キャプション (2200 字以内、改行は 2-3 行ずつ)

「県内 20 市町と人口当たり指標を比較して、明日の課内会議までに資料を出してほしい」
——自治体の企画課・統計担当・財政課・議会事務局で、突発的に降ってくるこの依頼。

多くの場合、e-Stat から Excel を 1 枚ずつダウンロードし、シートを並べ、関数を組み、グラフを貼り直す業務に半日〜1日が消えます。

本記事は、政府統計の総合窓口 e-Stat と AI コーディング環境 Claude Code を組み合わせると、その業務が「コマンド 1 本 + 5 分のレビュー」に変わる、という入口の話です。

執筆者は元自治体職員。現在は Claude Code で 47 都道府県の統計サイト stats47.jp (約 2,000 のランキングを毎日自動更新) を個人で開発・運用しています。

本マガジンの手順は、その実運用で動いているフローを公務員業務向けに切り出したもの。研究室レベルの話ではなく、現実に毎日動いている仕組みです。

Claude Code に e-Stat を任せると変わる業務は 5 つ。
1. 統計表を 1 分で「探す」
2. 47 都道府県データを 1 コマンドで「取得」
3. Excel ダウンロードを縦持ち CSV に「整形」
4. 人口当たり・前年比など「派生指標」を自動計算
5. 議会・庁内資料用の「表・グラフ」を自動生成

ターミナル経験は不要。Claude Code は日本語で頼めば必要なコマンドや設定を AI が用意してくれます。

全 12 本マガジンのうち、入口 (#00)・取得 (#03)・ベンチマーク表作成 (#08) の 3 本は無料公開。まず 3 本で効能を確かめてから有料 9 本に進むルートを推奨しています。
