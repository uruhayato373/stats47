# 都道府県コードと地域階層を扱う — SNS 拡散キャプション

## X (旧 Twitter) — 公開時投稿 (140 字以内、本文 URL 別添前提)

都道府県コードは JIS X 0401 (2 桁)・e-Stat (5 桁)・市区町村 (5 桁) と体系がバラバラ。結合キーを 5 桁文字列に統一する Claude Code 規約と、合併で廃止された旧コードの吸収パターンをまとめました。

## X — 追い投稿 (公開 1 週間後、別角度の切り口で再投稿、140 字以内)

Excel の VLOOKUP で「`01` が `1` になって結合できない」事故。CSV 読み込み時に `dtype={"pref_code": str}` を必ず指定し、`validate="1:1"` で結合キーの重複を早期検出するパターンを共有。

## Instagram — フィード投稿用キャプション (2200 字以内、改行は 2-3 行ずつ)

「e-Stat の医師数を住民基本台帳人口と結合して人口 10 万人あたり医師数を出す」——統計担当・企画課の定番依頼。

ところが結合が動かない。SQL は何も返さない。原因は ETL ロジックではなく、**コード体系の不一致** です。

e-Stat は 5 桁 (01000〜47000)、JIS X 0401 は 2 桁、市区町村は 5 桁 (上位 2 桁が県)、総務省コードは 6 桁。Excel が `01` を `1` に自動変換して、もう結合できません。

stats47.jp では 47 都道府県コードを **5 桁文字列に統一** する規約を採り、結合事故を構造的に潰しています。

記事では:

(1) 5 桁正規化の関数
(2) 市区町村コードから県コードを抽出
(3) 人口マスタとの結合 + 派生指標
(4) 平成の大合併で廃止された旧コードの変換テーブル
(5) 結合エラーを早期検出するチェックリスト

を実コードで掲載。さらに 8 地方区分への集約パターンも有料部分で公開しました。

初回構築 2 時間 → 月次運用 5 分。Claude Code に「コード変換」を任せると、Excel VLOOKUP の整備時間が消えます。
