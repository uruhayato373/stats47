## Instagram — フィード投稿用キャプション (2200 字以内、改行は 2-3 行ずつ)

「医師不足が他県と比べてどの程度深刻か、人口 10 万人当たりで示してくれ」
議会でこの質問が来たとき。

生の医師数を並べるだけでは答えにならない。
人口の多い県は医師数も多くて当たり前。
住民から見た医療アクセスを比較するには、

- 人口 10 万人当たり (単位当たり)
- 全国順位
- 全国平均との差 (偏差値)
- 5 年平均トレンド

という「派生指標」が必要になります。

統計担当が Excel で人口データと医師数を VLOOKUP で結合し、
割り算カラムを作り、RANK 関数で順位を出し、
平均と標準偏差を計算して偏差値カラムを作る。

1 指標 30 分〜1 時間。10 指標の資料なら半日が消えます。

pandas / DuckDB で書けば、1 指標 5 行。

人口 10 万人当たり: `df["doctors"] / df["population"] * 100_000`
順位: `df["per_100k"].rank(ascending=False, method="min")`
偏差値: `50 + (df["per_100k"] - mean) / std * 10`
5 年平均: `.rolling(window=5).mean()`

これだけ。

DuckDB なら SQL 1 本で `RANK() OVER` `STDDEV` `LAG` を使って書けます。
Power Query 経験者なら学習コスト最小。

本記事では:
- 派生指標の 4 大パターン (単位当たり / 順位 / 偏差 / 経年)
- pandas と DuckDB の実装比較
- e-Stat の「総数 / 男女別 / 年齢階級別」を cdCat01 で切替
- 年齢調整死亡率の計算 (基準人口で重み付け)
- 順位 vs 偏差値の使い分け

執筆者は元自治体職員。Claude Code で 47 都道府県統計サイト stats47.jp (約 2,000 のランキングを毎日自動更新) を個人で開発しています。

掲載中の人口 10 万人当たり医師数、健康寿命、介護職年収、世帯当たり年収、昼間人口比率、入港船舶総トン数 (40 県のみデータあり 124 倍格差) — すべて本記事の派生指標ロジックで計算しています。
