# 財政指標の同規模団体比較を e-Stat × Claude Code で作る — 「－」の扱いひとつで中央値が 4 倍変わる

## はじめに

「うちの市の財政は、同じくらいの規模の市と比べてどうなのか」。予算編成の説明、決算審査、議会の一般質問への答弁準備、住民向けの財政状況の公表資料。財政課や企画課では、この問いに毎年何度も答えることになります。

本記事では、e-Stat の市区町村データから財政力指数・経常収支比率・実質公債費比率・将来負担比率の 4 指標を取得し、人口規模が近い市と比べた順位表と推移表を Claude Code で作る手順を扱います。

ただし、財政指標は「取ってきて並べるだけ」だと数字を読み違えます。本記事で実データを確かめたところ、将来負担比率の「－」を欠損値として扱うか「負担なし」として扱うかで、同規模の市の中央値が **31.8% と 8.1%** のように約 4 倍も変わりました。こうした財政指標に固有の落とし穴を、実データで確かめながら進めます。

**こんな方に向けた記事です**

- 予算・決算の説明資料で「同規模団体との比較」を毎年作っている財政課・企画課の職員
- 議会答弁で「類似団体と比べてどうか」と問われたときの根拠表を短時間で用意したい方
- #08 の比較表の作り方を、財政指標に当てはめたい方（財政指標には #08 の汎用ルールが当てはまらない例外があり、本記事ではそこを扱います）

**この記事でわかること**

- e-Stat で市区町村の財政指標を一括取得する表 ID と項目コード
- 「－」表示・3 か年平均・良し悪しの向きなど、財政指標に固有の読み違いの防ぎ方
- 同規模の市との順位表・推移表を作り、AI に所見文の下書きを書かせる手順と、そのときの注意点

執筆者は元自治体職員です。現在は Claude Code で 47 都道府県の統計サイト stats47.jp（約 2,000 のランキングを毎日自動更新）を個人で開発・運用しており、財政指標のランキングも同じ e-Stat データから作っています。

e-Stat の利用は商用利用を含めて自由ですが、出典の明記が条件です（政府統計の総合窓口 e-Stat 利用規約）。資料の脚注に「政府統計の総合窓口（e-Stat）『社会・人口統計体系』より作成」と入れてください。

## 背景: なぜ財政指標の比較は間違えやすいか

財政指標の比較には、人口や面積の比較にはない約束事が 3 つあります。

1. **指標ごとに「良い方向」が違う**: 財政力指数は高いほど財政に余裕があり、経常収支比率・実質公債費比率・将来負担比率は低いほど健全です。4 指標をすべて同じ向きで並べ替えると、どちらの向きを選んでも一部の指標の順位が逆になります（降順なら 3 指標、昇順なら財政力指数）。
2. **「－」が欠損を意味するとは限らない**: 将来負担比率の「－」は「データがない」ではなく「将来の負担を、充当できる財源が上回っている」という良い状態を表します。
3. **単年度の値ではない指標がある**: 財政力指数と実質公債費比率は、過去 3 か年の平均値です（総務省「[財政状況資料集の説明](https://www.soumu.go.jp/iken/zaisei/jyoukyou_shiryou/h22/setumei.html)」「[地方財政白書 用語の説明](https://www.soumu.go.jp/menu_seisaku/hakusyo/chihou/r07data/2025data/yougo.html)」）。

Excel で作るときは、担当者がこの約束事を頭に入れているので事故は起きにくいものです。ところが AI にコードを書かせると、AI は 4 指標を同じ手順で処理しがちです。「－」を欠損として捨て、全部を降順に並べる。そうして出てきた表は、見た目は整っていても中身が間違っています。本記事の手順は、この 3 つを AI への指示に明示することを軸に組み立てています。

## 手順 1: 使う表を決める

市区町村の財政指標は、e-Stat の「社会・人口統計体系（市区町村データ）」にまとまっています。本記事で使うのは次の 2 表です。

| 用途 | statsDataId | 項目コード | 内容 |
|---|---|---|---|
| 財政指標 | `0000020204`（D 行政基盤） | `D2201` | 財政力指数 |
| | | `D2203` | 経常収支比率（%） |
| | | `D2211` | 実質公債費比率（%） |
| | | `D2212` | 将来負担比率（%） |
| 人口 | `0000020201`（A 人口・世帯） | `A1101` | 総人口（2020 年） |

2026 年 9 月 29 日に e-Stat API で取得した時点では、財政指標表は 1,913 地域を収録し、4 指標とも最新は 2022 年度でした。同じ表には基準財政収入額（`D2205`）・基準財政需要額（`D2206`）・実質赤字比率（`D2214`）なども入っています。

Claude Code には、次のように頼めば表の構造を調べてくれます。

```
Claude へ: e-Stat API の getMetaInfo で statsDataId=0000020204 のメタ情報を取得し、
cat01 のうち「市町村財政」を含む項目コードと単位、time の最新年度を一覧にしてください。
appId は環境変数 ESTAT_APP_ID から読んでください。
```

## 手順 2: 「－」を正しく処理する

2022 年度のデータで、数値ではなく「-」が入っている件数を指標ごとに数えると、次のようになりました。

| 指標 | 「-」の件数 | 内訳 |
|---|---|---|
| 財政力指数 | 195 | 政令市の区 171、東京都の特別区 23、特別区部の合計 1 |
| 経常収支比率 | 171 | 政令市の区 171 |
| 実質公債費比率 | 171 | 政令市の区 171 |
| 将来負担比率 | 1,071 | 政令市の区 171 と東京都の特別区 23 を除いても、残る 1,719 地域中 877（51%） |

財政力指数などの「-」は、政令市の区のように、その指標が算定されない地域を指します。こちらは比較対象から外して構いません。

問題は将来負担比率です。将来負担比率は「将来負担額から、充当可能な基金などの財源を差し引いた額」を分子に取る指標です（総務省「[健全化判断比率の算定](https://www.soumu.go.jp/iken/zaisei/kenzenka/index2.html)」）。充当できる財源の方が多い団体では分子がマイナスになるため、数値が出ずに「－」と表示されます。実際、このデータで数値が入っている団体に、負の値は 1 件もありませんでした。つまり「－」の団体は、将来負担の面では最も良い側の団体です。

この「－」を欠損として捨てると何が起きるかを、手順 3 で使う同規模の 117 市で確かめました。

| 「－」の扱い | 同規模 117 市の中央値 | 平均 |
|---|---|---|
| 欠損として除外（66 市で計算） | 31.8% | 40.4% |
| 負担なし＝ 0% として含める（117 市） | 8.1% | 22.8% |

![「－」の扱いで将来負担比率の同規模中央値が 31.8% と 8.1% に分かれる](./images/infographic-1-dash-handling.png)
<!-- SVG: infographic | 欠損扱い 31.8% vs 0 扱い 8.1% の棒 2 本 -->

「－」を捨てると、良い側の団体が半分近く消え、同規模の中央値が実態の約 4 倍（平均では約 1.8 倍）に悪く見えます。自団体の将来負担比率が 30% だった場合、前者なら「同規模の中央値並み」、後者なら「中央値の約 4 倍」です。議会で説明する結論が逆になります。

AI への指示には、この扱いを明記します。

```
Claude へ: 将来負担比率（D2212）の値が "-" のときは、欠損ではなく
「充当可能財源等が将来負担額を上回り、負担がない」状態なので 0 として扱ってください。
それ以外の指標の "-" は、算定対象外として NaN にしてください。
0 は集計のための値です。資料の表に印字するときは「－（負担なし）」と表示してください。
```

資料に「0.0%」と印字すると、総務省の公表値（「－」）と見た目が食い違い、問い合わせの原因になります。0 は順位と中央値を計算するためだけに使います。

なお、#08 では記号を一律に NaN として扱う方法を紹介しました。財政指標の将来負担比率は、その汎用ルールの例外です。

## 手順 3: 同規模の市を決めて順位表を作る

同規模の定義は、ここでは「2020 年の総人口が自団体の ±20% に入る市」とします。人口約 10 万人の市なら、8 万〜12 万人の市が比較対象です。町村と政令市の区は外します。

総務省の「財政状況資料集」にある類似団体は、人口と産業構造によって全国の市町村を 35 の類型に分けたものです（総務省「財政状況資料集の説明」）。本記事の簡易な定義はそれとは一致しないため、資料には「人口規模による簡易比較」と明記してください。公式の類似団体で比べたいときは、総務省が公表している類型別の団体一覧を読み込み、`peers` をその団体コードに置き換えれば同じコードが使えます。

財政状況資料集の財政比較分析表にも、類似団体の平均・最大・最小との比較は載っています。ただし、比較できるのは総務省が決めた類型の中だけです。県内の市や近隣の市など自分で決めたグループでの順位や中央値、推移の並べ比べは作れません。本記事の手順はその部分を補うものです。

以下が、手順 1〜3 をまとめたコードです。2026 年 9 月 29 日に実際に e-Stat API から取得して動作を確認しました。

```python
import os
import requests
import pandas as pd

APP_ID = os.environ["ESTAT_APP_ID"]
BASE = "https://api.e-stat.go.jp/rest/3.0/app/json"

INDICATORS = {
    "D2201": ("財政力指数", "high_is_good"),
    "D2203": ("経常収支比率", "low_is_good"),
    "D2211": ("実質公債費比率", "low_is_good"),
    "D2212": ("将来負担比率", "low_is_good"),
}


def fetch(stats_data_id, cat_codes, time_from):
    params = {
        "appId": APP_ID,
        "statsDataId": stats_data_id,
        "cdCat01": ",".join(cat_codes),
        "cdTimeFrom": time_from,
        "metaGetFlg": "N",
        "limit": 100000,
    }
    body = requests.get(f"{BASE}/getStatsData", params=params, timeout=120).json()["GET_STATS_DATA"]
    assert body["RESULT"]["STATUS"] == 0, body["RESULT"]["ERROR_MSG"]
    rows = body["STATISTICAL_DATA"]["DATA_INF"]["VALUE"]
    return pd.DataFrame(
        {
            "code": [r["@cat01"] for r in rows],
            "area": [r["@area"] for r in rows],
            "year": [int(r["@time"][:4]) for r in rows],
            "raw": [r["$"] for r in rows],
        }
    )


def area_names(stats_data_id):
    params = {"appId": APP_ID, "statsDataId": stats_data_id}
    body = requests.get(f"{BASE}/getMetaInfo", params=params, timeout=120).json()
    classes = body["GET_META_INFO"]["METADATA_INF"]["CLASS_INF"]["CLASS_OBJ"]
    area = next(c for c in classes if c["@id"] == "area")["CLASS"]
    return pd.Series({a["@code"]: a["@name"] for a in area})


def to_number(row):
    # 将来負担比率の「-」は「将来負担がない」の意味。欠損ではなく 0 として扱う
    if row["raw"] == "-" and row["code"] == "D2212":
        return 0.0
    return pd.to_numeric(row["raw"], errors="coerce")


fin = fetch("0000020204", list(INDICATORS), "2019100000")
fin["value"] = fin.apply(to_number, axis=1)

pop = fetch("0000020201", ["A1101"], "2020100000")
pop = pop[pop["year"] == 2020]  # 新しい国勢調査が追加されても 2020 年だけを使う
pop = pop.assign(population=pd.to_numeric(pop["raw"], errors="coerce")).set_index("area")["population"]

names = area_names("0000020204")
cities = names[names.str.endswith("市")].index  # 町村を含めたい場合はこの行を外す

TARGET = os.environ["TARGET_AREA"]  # 自団体の 5 桁の市区町村コード
target_pop = pop[TARGET]
peers = pop[pop.between(target_pop * 0.8, target_pop * 1.2)].index.intersection(cities)

latest = fin[fin["year"] == 2022].pivot(index="area", columns="code", values="value")
# 政令市の区は財政指標が「-」なので、財政力指数が数値の団体だけ残る
group = latest.loc[latest.index.intersection(peers)].dropna(subset=["D2201"])

rows = []
for code, (label, direction) in INDICATORS.items():
    s = group[code].dropna()
    ascending = direction == "low_is_good"
    rank = s.rank(ascending=ascending, method="min")[TARGET]
    rows.append(
        {
            "指標": label,
            "自団体": group.loc[TARGET, code],
            "同規模中央値": round(s.drop(TARGET).median(), 2),
            "順位(良い順)": f"{int(rank)} / {len(s)}",
        }
    )
print(f"同規模団体数: {len(group) - 1}")
print(pd.DataFrame(rows).to_string(index=False))
```

コードの要点は 3 つです。`INDICATORS` に指標ごとの良い方向を持たせ、順位を付けるときに昇順・降順を切り替えています。`to_number` で「－」の扱いを指標ごとに分けています。人口データにも「-」が 3 件あったため、`errors="coerce"` で数値にできない値を欠損にしています（これがないとスクリプトはエラーで止まります）。

人口約 10 万人のある市（以下「A 市」）で実行した結果が次の表です。数値は公開データそのものなので、e-Stat で調べれば団体は特定できます。本記事の目的は手順の説明であり、団体の財政運営を評価するものではないため、名前は伏せています。

```
同規模団体数: 117
     指標   自団体  同規模中央値   順位(良い順)
  財政力指数  0.52     0.71  103 / 118
 経常収支比率 91.70    91.40   62 / 118
実質公債費比率 12.40     5.10  113 / 118
 将来負担比率 94.50     8.10  113 / 118
```

A 市は、経常収支比率では同規模の真ん中にいますが、財政力指数・実質公債費比率・将来負担比率では同規模の中で低い位置にいます。ただし、1 年分の順位だけで資料を作ると一面的になります。次の手順で推移を見ます。

## 手順 4: 推移を並べる

順位は 1 年分の断面です。議会や住民への説明では「悪いのか」と同じくらい「良くなっているのか」が問われます。将来負担比率を例に、自団体と同規模中央値の推移を並べます。

```python
# --- 推移: 自団体と同規模中央値を年度ごとに並べる ---
peer_codes = group.index.drop(TARGET)
trend = fin[fin["code"] == "D2212"].pivot(index="year", columns="area", values="value")
out = pd.DataFrame(
    {
        "自団体": trend[TARGET],
        "同規模中央値": trend[peer_codes].median(axis=1),
    }
).dropna()
print(out.round(1).to_string())
```

```

year
2019  130.2    26.3
2020  119.8    24.2
2021  100.5    12.8
2022   94.5     8.1
```

A 市の将来負担比率は 3 年間で 130.2% から 94.5% へ 35.7 ポイント下がっています。同規模中央値も 26.3% から 8.1% へ 18.2 ポイント下がっており、差は 103.9 ポイントから 86.4 ポイントに縮まりました。

ただし、下がり方は「ポイント」と「率」で見え方が変わります。ポイントでは A 市の方が大きく下がっていますが、率で見ると A 市は約 27% の低下、中央値は約 69% の低下です。「差は縮まっているが、同規模の中では依然として高い」と、両方の見方を併記するのが誤解のない書き方です。これが、順位表だけでは書けない説明です。

## 手順 5: 基準との距離を添える

健全化判断比率には、法律で定められた基準があります。比較表に「基準までどのくらい余裕があるか」を添えると、同規模との比較とは別の軸で安心材料（または警戒材料）を示せます。市町村の基準は次の通りです（総務省「[早期健全化基準と財政再生基準](https://www.soumu.go.jp/iken/zaisei/kenzenka/index3.html)」）。

| 指標 | 早期健全化基準 | 財政再生基準 |
|---|---|---|
| 実質赤字比率 | 11.25〜15%（財政規模に応じる） | 20% |
| 連結実質赤字比率 | 16.25〜20%（財政規模に応じる） | 30% |
| 実質公債費比率 | 25% | 35% |
| 将来負担比率 | 350%（政令市は 400%） | 設定なし |

A 市の場合、実質公債費比率 12.4% は早期健全化基準 25% の約半分、将来負担比率 94.5% は基準 350% の約 27% です。同規模の中では低い位置にあっても、法律上の基準には大きな余裕があります。この 2 つの軸を分けて書くことで、「順位が低い＝危ない」という誤読を防げます。

参考までに、2022 年度のデータ全体で見ると、実質公債費比率が早期健全化基準の 25% 以上だった団体は 1 団体だけでした。経常収支比率が 90% 以上の地域は、数値のある 1,742 地域（政令市の区を除き、東京都の特別区と特別区部の合計を含む）のうち 790（45%）あり、経常収支比率の高さは多くの団体に共通する傾向です。

## 手順 6: 財政力指数は自分で再計算しない

財政力指数は「基準財政収入額 ÷ 基準財政需要額」ですが、公表値は **過去 3 か年の平均** です。同じ表にある `D2205`（基準財政収入額）と `D2206`（基準財政需要額）から計算して確かめたところ、次の結果になりました。

- 3 か年（2020〜2022 年度）の比率の平均は、財政力指数が数値で入っている 1,718 団体すべてで公表値と一致しました。
- 2022 年度の単年度の比率では、公表値と一致したのは 746 団体（43%）でした。0.02 以上ずれた団体が 323 団体（19%）ありました。

AI に「財政力指数を最新年度で計算し直して」と頼むと、単年度で割り算したコードが返ってくることがあります。財政力指数と実質公債費比率は公表値をそのまま使い、自分で計算し直さないよう指示に書いておきます。

## 手順 7: 所見文の下書きを AI に書かせる

表ができたら、説明資料の文章の下書きを Claude Code に頼めます。ここで一番気をつけるべきなのは、**AI に原因を推測させないこと** です。表から分かるのは「どの位置にいるか」「どう動いたか」までです。「大型の公共施設の建設が影響した」のような原因は、データのどこにも書かれていません。それを AI がもっともらしく書くと、確認されないまま議会資料に載る危険があります。

```
Claude へ: 上の順位表・推移表・基準表だけを根拠に、財政状況の説明文の下書きを
300 字程度で書いてください。条件:
- 数値は表にあるものだけを使い、各文に必ず数値を 1 つ以上含める
- 良い方向は、財政力指数は高いほど、他の 3 指標は低いほど良い
- 「同規模との比較」と「法律上の基準との距離」を分けて書く
- 原因・背景・今後の見通しは書かない。書きたい場合は【要確認】と印を付ける
- 比較対象は「人口規模が近い市（±20%）」であり、総務省の類似団体ではないと明記する
- 順位の母数は自団体を含む数で書く
- 将来負担比率が 0 の団体は「－（負担なし）」と書く
```

このプロンプトで返ってきた下書きの例です。

> 本市の 2022 年度の財政力指数は 0.52 で、人口規模が近い市（人口 ±20%。総務省の類似団体区分とは異なる）の中央値 0.71 を下回り、本市を含む 118 市中 103 番目です。将来負担比率は 94.5% で、同規模の中央値 8.1% を上回り、118 市中 113 番目の水準です。一方、2019 年度の 130.2% からは 35.7 ポイント低下し、同規模の中央値との差は 103.9 ポイントから 86.4 ポイントに縮まりました。実質公債費比率は 12.4% で、同規模の中央値 5.1% より高いものの、早期健全化基準の 25% に対しては約半分の水準です。経常収支比率は 91.7% で、同規模の中央値 91.4% とほぼ同じ水準です。【要確認】将来負担比率の低下要因

下書きの数値は、必ず元の表と 1 つずつ突き合わせてください。特に「上回る」「下回る」の向きは、指標の良い方向とセットで確認します。

## 手順 8: 毎年の作業にする

決算の数値は毎年同じ時期に更新されます。手順 1〜7 を Claude Code のスキル（#10 参照）にしておくと、翌年は自団体コードと年度を変えるだけで同じ資料が作れます。スキルの説明文には、本記事で確かめた 3 つの約束事を必ず書いておきます。

```markdown
# /fiscal-peer-table

自団体の財政 4 指標を、人口 ±20% の市と比べた順位表・推移表・基準表にする。

## 必ず守ること
- 将来負担比率の "-" は集計では 0（負担なし）として扱い、表には「－（負担なし）」と表示する。他指標の "-" は算定対象外として除外
- 良い方向: 財政力指数は高いほど良い。経常収支比率・実質公債費比率・将来負担比率は低いほど良い
- 財政力指数・実質公債費比率は 3 か年平均の公表値を使い、再計算しない
- 所見文に原因・背景を書かない。必要なら【要確認】を付ける
- 出典「政府統計の総合窓口（e-Stat）『社会・人口統計体系』」と、比較対象の定義を資料末尾に書く
```

## よくあるつまずきと回避策

- ⚠️ **将来負担比率の「－」を捨てる** → 同規模の中央値が実態より悪く見えます（本記事の例では 8.1% が 31.8% に）。集計では 0 として扱い、表示は「－（負担なし）」のままにします。
- ⚠️ **4 指標を同じ向きで並べる** → 昇順なら財政力指数、降順なら他の 3 指標の順位が逆になります。指標ごとに良い方向を持たせます。
- ⚠️ **財政力指数を単年度で計算し直す** → 本記事のデータでは 19% の団体で 0.02 以上ずれました。公表値を使います。
- ⚠️ **人口データの「-」でスクリプトが止まる** → `pd.to_numeric(..., errors="coerce")` で欠損にします。
- ⚠️ **政令市の区が比較対象に混ざる** → 区は財政指標が「-」なので、財政力指数が数値の団体だけに絞ります。
- ⚠️ **最新年度がずれている** → 市区町村データは公表まで時間がかかり、2026 年 9 月時点で最新は 2022 年度でした。より新しい年度が必要なときは、総務省が公表する決算カードや健全化判断比率の資料で補います。資料には必ず年度を書きます。
- ⚠️ **AI が原因を書く** → プロンプトで禁止し、書かれた場合は【要確認】を付けて担当課に確認します。
