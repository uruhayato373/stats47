財政力指数は単年度の割り算ではなく3か年平均。e-Stat の元データで計算し直すと、単年度で一致したのは43%の団体だけでした。AI に財政指標を扱わせるときに指示へ書いておくべき3つの約束事をまとめています。

## Instagram — フィード投稿用キャプション (2200 字以内、改行は 2-3 行ずつ)

「うちの市の財政は、同じくらいの規模の市と比べてどうなのか」
——予算・決算の説明や議会答弁のたびに求められる比較です。

本記事では、e-Stat の市区町村データから財政力指数・経常収支比率・実質公債費比率・将来負担比率を取得し、人口規模が近い市と比べる順位表と推移表を Claude Code で作る手順を扱います。

財政指標は「取ってきて並べるだけ」だと読み違えます。実データで確かめた約束事は 3 つです。

1. 将来負担比率の「－」は欠損ではなく「負担なし」。捨てると同規模 117 市の中央値が 8.1% から 31.8% に変わる
2. 財政力指数は高いほど良く、他の 3 指標は低いほど良い。同じ向きで並べると順位が逆になる
3. 財政力指数は 3 か年平均。単年度で計算し直すと 19% の団体で 0.02 以上ずれる

さらに、法定の早期健全化基準との距離を添える方法と、AI に原因を推測させずに所見文の下書きを書かせるプロンプトも掲載しています。

執筆者は元自治体職員。現在は Claude Code で 47 都道府県の統計サイト stats47.jp を個人で開発・運用しています。

出典: 政府統計の総合窓口（e-Stat）「社会・人口統計体系」
