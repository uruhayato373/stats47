## Instagram — フィード投稿用キャプション (2200 字以内、改行は 2-3 行ずつ)

「県内 X 市と比べて高いの？低いの？」「同規模自治体の中で何位？」「全国平均との乖離は？」

議会答弁で必ず問われる **3 つの比較軸**。Excel で県内市町村を縦に並べ、全国データを横に並べ、規模で並べ替えてハイライト——1 件 1〜2 時間が議会前に 5-10 件並行で来ます。

Claude Code に e-Stat の 47 県データを取らせて、同規模自治体を「人口 ±30% × 面積 ±50%」で絞り、3 軸の比較表を作る。これで 5 分。

無料記事として全文公開しました。

記事の内容:

(1) `/fetch-estat-data` で 47 県を 1 コマンド取得
(2) 同規模自治体の定義 (人口 ±30% × 面積 ±50%)
(3) 順位 / 全国平均比 / 同規模比の 3 軸計算
(4) Markdown 表 → 議会答弁原稿に貼れる形式
(5) Excel / PDF 出力 → 決裁ルートに乗せる形式
(6) `.claude/skills/benchmark-table/` でスキル化、毎月の同じ依頼を 1 コマンド化

stats47.jp ではこの仕組みで 47 県分のランキングを毎日自動更新しています。記事内で具体例 (人口当たり医師数 / 世帯当たり年収 / 介護職年収 / 昼夜間人口比率) のリンクも紹介しました。
