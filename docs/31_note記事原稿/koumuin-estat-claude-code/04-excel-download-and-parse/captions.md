## Instagram — フィード投稿用キャプション (2200 字以内、改行は 2-3 行ずつ)

「過去 10 年分の県内総生産推移を、令和換算と西暦両方で並べてくれ」
財政課からこの依頼が来たとき。

e-Stat からダウンロードした Excel を開くと、待っているのは:
- シートが 8 個 (1 枚目は注釈、2 枚目は単位の説明)
- 結合セルで分割されたコード列
- 「平成 28 年度」「令和 5 年度」が混在する年度欄
- 表の最後に紛れる「合計」「小計」「再掲」行

統計担当が Power Query でこれを処理すると、3〜4 時間が消えます。
数値検算したら合計行を本文と一緒に集計していて、最初からやり直し。よくある話です。

Claude Code に任せれば、構造把握から整形まで自然言語で指示できます。

「`data/raw/prefecture-gdp.xlsx` のシート構成と各シートの先頭 10 行を見せて」
これだけで、シート 8 個の中から「表 1 が本表」「L1-L2 がヘッダー」と特定。

「表 1 を抽出して、年度を西暦に変換した CSV を作って」
pandas で多段ヘッダー処理 + 元号 → 西暦変換 + 47 都道府県フィルタが入った
スクリプトが出来上がります。

本記事では:
- pandas (openpyxl) と DuckDB (read_xlsx) の使い分け
- 「令和 5 年 = 2023」を 4 行のマッピング関数で処理
- セル結合・合計行・小計行の除外
- 秘匿マスク (X / …) や指数表記の対処
- .xls (旧形式) と .xlsx の取り回し違い

を実装例付きで解説しています。

執筆者は元自治体職員。Claude Code で 47 都道府県統計サイト stats47.jp (約 2,000 のランキングを毎日自動更新) を個人で開発しています。製造品出荷額や県内総生産のランキングは、本記事の手順で日次更新されています。

初回 3 時間 → 月次運用 5 分。テンプレを残せば次の担当者も同じ品質で再現できる仕組みになります。
