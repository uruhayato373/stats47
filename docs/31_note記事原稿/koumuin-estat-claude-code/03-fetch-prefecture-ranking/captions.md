## Instagram — フィード投稿用キャプション (2200 字以内、改行は 2-3 行ずつ)

「全国の人口推移を他県と比較したい」
企画課からこの依頼が来たとき、統計担当が e-Stat の Web 画面から都道府県別に 47 回 CSV をダウンロードし、Excel に貴って整形する。

気付けば半日が消える。
10〜30 万人規模の自治体では、こうしたデータ収集だけで月 20〜40 時間が消えていると報告されています。

この半日が、30 秒になります。

e-Stat には API が用意されていて、statsDataId と cdCat01 という 2 つのパラメータを渡すだけで、47 都道府県分のランキングデータが 1 リクエストで返ってきます。

Claude Code を使えば、Python も JavaScript も覚える必要はありません。
「e-Stat の社会・人口統計体系から総人口の都道府県ランキングを取って」と日本語で頼むだけで、動くスクリプトを書いて実行までやってくれます。

出力される JSON はこんな形:
- areaCode (5 桁の地域コード)
- areaName (都道府県名)
- value (値)
- rank (順位)

これをそのまま Excel に貼ることも、グラフ生成スクリプトに渡すことも、議会答弁の資料に使うこともできます。

本記事の執筆者は元自治体職員。Claude Code で 47 都道府県統計サイト stats47.jp (約 2,000 のランキングを毎日自動更新) を個人で開発しています。

サイト内のすべての都道府県ランキングは、本記事で解説した手順とまったく同じ流れで毎日生成されています。実運用で動いている方法を、そのまま無料で公開しました。

「人事異動で VBA マクロが引き継がれない」「Excel のフォーマットが担当者ごとにバラバラ」という属人化、Claude Code が突破口になります。
