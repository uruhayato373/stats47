## Instagram — フィード投稿用キャプション (2200 字以内、改行は 2-3 行ずつ)

「昨年と比べてどうなったか」「ここ 5 年でどう動いたか」——議会答弁・政策評価・補助金申請で必ず問われる「直近の変化」。

e-Stat の Web 画面で年度を 1 つずつダウンロードして Excel で並べ替える作業、1 指標 30-60 分。5 指標 × 2 切り口で半日が消えます。

e-Stat API は **複数年データを 1 リクエストで取得** できます。Claude Code に整形を任せれば、その半日が 3-5 分に。

記事では:

(1) `/fetch-estat-data` で全年度を一括取得 (`cdTimeFrom` は使わない)
(2) pandas `.diff()` / `.pct_change()` で前年比較
(3) DuckDB `LAG()` SQL で同じ結果
(4) `numpy.polyfit()` で 5 年トレンドの傾き
(5) 上昇・下降・安定・揺れの 4 パターン分類
(6) 増減ランキングの Markdown 出力 (議会資料貼り付け対応)
(7) 欠損 (`-`) と秘匿 (`X`) の分離処理

を実コードで掲載。

stats47.jp ではこの仕組みで約 2,000 のランキングを毎日自動更新しています。世帯当たり年収・介護職年収・人口指標などが年度横断で並びます。

初回構築 2-3 時間 → 月次運用 3-5 分。9 月議会前の繁忙期に半日の Excel 作業を吹き飛ばす自動化テンプレです。
