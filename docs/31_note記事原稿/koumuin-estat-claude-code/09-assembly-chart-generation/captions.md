## Instagram — フィード投稿用キャプション (2200 字以内、改行は 2-3 行ずつ)

議会開会の 1 週間前。
「答弁資料用の図表 5 種類、明日まで」
この依頼で残業 3 時間、毎議会の定番です。

Excel でグラフ → スクリーンショット → PowerPoint。
1 枚 30 分、5 枚で 2.5 時間。
色も凡例も毎回ばらつき、出典フッタは入れ忘れる。

Claude Code に e-Stat を任せれば、
この作業は「データの統計表 ID と頼み方」の組み合わせで
1 枚 5 分に置き換わります。

議会・県民向け資料で使うチャートは、結局 4 種類。
順位 → 棒グラフ
変化 → 折れ線
分布 → コロプレス地図
詳細数値 → 表

質問者の発話を 1 単語に要約するだけで、自然にチャート種別が決まります。

ライブラリの選び方も 1 文で覚えられます。
議会答弁の急ぎ仕事 → matplotlib
県のパンフレット → D3
庁内ポータル → Recharts
上司に触ってもらう → Plotly

どれも Claude Code が一発で書いてくれるので、
公務員が覚えるのは「用途 → ライブラリ」のこの 1 文だけ。

頼み方のテンプレに入れておく 6 項目:
1 位の色を変える
出典フッタを右下に入れる
カラーアクセシビリティ配慮 (赤緑だけで区別しない)
PNG (300dpi) と SVG を両方出力
PowerPoint 1 枚に 4 図前提のサイズ
「政府統計の総合窓口 (e-Stat) より」を自動挿入

この 6 項目を毎回書くのは現実的ではないので、
.claude/skills/assembly-chart/SKILL.md に保存します (記事 #10 参照)。
次回からは「人口データで議会答弁用チャート作って」だけで、全部が適用されます。

stats47.jp (約 2,000 のランキングを毎日自動更新) の棒グラフ・コロプレス地図も、本記事と同じ仕組みで生成しています。
