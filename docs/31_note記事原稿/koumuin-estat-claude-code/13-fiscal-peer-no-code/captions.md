## X — 追い投稿 (公開 1 週間後、別角度の切り口で再投稿、140 字以内)

e-Stat から財政指標の CSV を落とすとき「特殊文字を 0 に置き換える」を選ぶと、政令市の区まで 0 になって区別できなくなります。Claude・ChatGPT で財政比較をする前に知っておきたい落とし穴です。

## Instagram — フィード投稿用キャプション (2200 字以内、改行は 2-3 行ずつ)

「うちの市の財政は、同じくらいの規模の市と比べてどうなのか」
——予算・決算の説明や議会答弁で毎年求められる比較を、Claude や ChatGPT で作る手順です。

プログラミングは不要です。e-Stat の画面から CSV を 2 つダウンロードし、AI にファイルとプロンプトを渡すだけです。

ただし、AI に素のまま頼むと間違えます。実際に試したところ、将来負担比率の「－」（＝負担なし）を捨ててしまい、同規模の中央値が正しい 8.1% ではなく 31.8% になりました。順位も「値が高い順」で付けられ、負担の重い市が上位に見える表が出てきました。

記事では、次のものを用意しています。

1. e-Stat の画面操作（API キー不要）
2. そのまま貼れる、財政指標の約束事入りプロンプト
3. AI の答えを 5 分で確かめる 5 つのチェック
4. 原因を推測させない説明文の下書きプロンプト

執筆者は元自治体職員。現在は AI を使って 47 都道府県の統計サイト stats47.jp を個人で開発・運用しています。
