# stats47 収益化戦略分析 — お金・健康・人間関係 (YMYL高収益3本柱)

## このレビューの目的

「お金・健康・人間関係は収益化しやすい」という一般論を stats47 に適用し、**ブログ記事 × アフィリエイトの具体戦略**へ落とし込む。既存の 8 カテゴリアフィリエイト基盤 (`affiliate-category.ts`) を、この 3 領域に**優先順位を付けて絞り込む**ことが本レビューの中心。

## 中心テーゼ（最重要・先に結論）

> **stats47 は「YMYLの助言サイト」として戦ってはいけない。「YMYL隣接のデータ供給サイト」として戦う。**

- 「お金・健康・人間関係」が収益化しやすいのは事実だが、これらは Google が **E-E-A-T を最も厳しく要求する YMYL (Your Money or Your Life) 領域**。個人運営の統計サイトが「転職のおすすめ」「サプリの効果」「婚活のコツ」で上位を取るのは**ほぼ不可能**（医療法人・大手メディアの独占領域）。
- 一方、`都道府県別 平均年収 ランキング` / `健康寿命 ランキング` / `生涯未婚率 ランキング` のような**データ系情報クエリ**は、stats47 が e-Stat 由来の一次データで**正当な権威性を持つ唯一の勝てる土俵**。
- 収益化の橋渡しは **「勝てる情報クエリ（データ記事）→ 読者の感情的気づき → 高関連アフィリエイトの CTA」** で行う。データそのものが E-E-A-T の堀になる。

この設計なら「YMYLの高CVR商材」と「勝てるSEO」を両立できる。逆に助言記事を書くと、SEOで負けて1円にもならない。

## 収益化候補（3本柱・優先順）

商材CVR/単価は A8.net 等の一般的水準に基づく推定。実測は計測ループ稼働後に上書きする（`evidence-based-judgment.md` 準拠）。

### 1. 人間関係（マッチング・婚活）— 推奨 ★★★★★ 〔最優先〕

**なぜ1位か**: 3本柱で **YMYL-SEOリスクが最も低く（婚姻データは厳格YMYLでない）、商材CVRが最も高い**（無料登録＝メール登録のみが成果地点）。最短で初成約が出る。

**データ→感情→商材ファネル**:
- データ記事: `生涯未婚率ランキング` / `都道府県別 平均初婚年齢` / `単身世帯比率` / `婚姻率・離婚率`
- 感情トリガー: 「自分の県は出会いが少ない／結婚が遅い」という自県への気づき
- 商材: マッチングアプリ（Pairs / with / ユーブライド、無料登録 1,000-4,000円/件・**CVR高**）、結婚相談所（成約 5,000-20,000円/件・高単価低CVR）

**収益レンジ（月次・3ヶ月後）**: 悲観 ¥1,000 / 標準 ¥5,000-12,000 / 楽観 ¥25,000

**実装コスト**: S。population カテゴリ記事 3-4 本投下 + 既存 Pairs リンクの記事内配置最適化。

**UX影響**: 低。データ記事末尾＋該当 H2 セクション内インライン CTA。

**リスク**:
- マッチング商材は ASP 提携審査・出稿規約あり（「煽り」表現NG等）→ A8 規約確認
- 既婚・高齢の読者には無関係 → セグメント別出し分け（未婚率の高い県の area ページで強める）

**検証**:
- Week 1-2: `生涯未婚率ランキング` 記事 1 本目を curiosity gap タイトルで投下
- Week 3-4: GSC impressions・GA4 `affiliate_click` (population) を計測
- 成功基準: 4週後に該当記事 impressions ≥ 150/週 かつ affiliate_click ≥ 5/週
- 失敗判定: click 0 が 4 週継続 → CTA 文言・配置を全面見直し

### 2. お金（転職・年収・資産形成）— 推奨 ★★★★☆

**なぜ2位か**: データ記事の検索ボリュームが3本柱で最大（「平均年収 ランキング」は鉄板クエリ）。ただし転職・証券は YMYL で大手メディアの競合が激しく、商材CVRは中程度。

**データ→感情→商材ファネル**:
- データ記事: `都道府県別 平均年収/賃金ランキング` / `世帯貯蓄額ランキング` / `消費者物価地域差指数（実質年収）`
- 感情トリガー: 「自分の県の賃金は全国下位」「物価込みの実質手取りが低い」
- 商材:
  - 転職エージェント（リクルート/doda、無料登録 1,500-4,000円/件・CVR中）← 賃金下位県の文脈
  - 証券口座（SBI/楽天、口座開設 5,000-15,000円/件・**高単価・高摩擦低CVR**）← 貯蓄文脈
  - 家計簿アプリ・クレカ・ふるさと納税（さとふる、**11-12月に季節集中**で高CVR）

**収益レンジ（月次・3ヶ月後）**: 悲観 ¥1,000 / 標準 ¥4,000-10,000 / 楽観 ¥30,000（ふるさと納税の年末ピーク込み）

**実装コスト**: M。年収・貯蓄・物価の3記事 + ふるさと納税は11月に集中投下する季節運用。

**リスク**:
- 「平均年収」クエリは competition 高 → stats47 は**都道府県粒度の網羅性**で差別化（大手は全国値止まり）
- 証券は CVR が低く、登録ハードルが高い → 転職・ふるさと納税を主軸、証券は補助

**検証**:
- Week 2-4: 年収ランキング記事を投下（既存記事があれば curiosity gap brushup）
- 成功基準: 8週後に money カテゴリ合算で affiliate_click ≥ 15/週
- ふるさと納税ゲート: 11月第1週までにさとふる導線を全 furusato 記事に配置

### 3. 健康（健康寿命・運動・医療）— 推奨 ★★★☆☆ 〔慎重運用〕

**なぜ3位か**: 検索ボリューム・商材単価は魅力的だが、**3本柱で最も YMYL-SEO リスクが高く、薬機法（旧薬事法）コンプライアンスの制約が重い**。「効果がある」「痩せる」「治る」等の表現はサプリ・健康食品アフィリエイトで**禁止**。

**データ→感情→商材ファネル**:
- データ記事: `健康寿命ランキング` / `運動習慣率` / `肥満・メタボ率` / `医療費・受診率`
- 感情トリガー: 「自県は健康寿命が短い／運動不足」
- 商材: フィットネス（chocoZAP / パーソナルジム、入会 数千円/件）、オンライン診療、健康食品（**薬機法で表現制約大**）

**収益レンジ（月次・3ヶ月後）**: 悲観 ¥500 / 標準 ¥2,000-6,000 / 楽観 ¥15,000

**実装コスト**: M。**先にカテゴリマッピングのミスマッチ修正が必須**（下記課題参照）。

**UX影響**: 中。健康データ記事に運動・ジム商材は文脈整合するが、薬機法表現レビューが要る。

**リスク（最重要）**:
- **薬機法**: 健康食品・サプリで効能効果を断定すると景表法・薬機法違反。フィットネス（役務）中心に絞るのが安全
- **YMYL E-E-A-T**: 「健康法」助言記事はGoogleが医療機関を優遇 → **データ記事のみに徹する**
- **既存ミスマッチ**: health 商材(chocoZAP)が `socialsecurity`（社会保障＝年金・福祉）カテゴリに紐付き、健康寿命データと繋がっていない（下記）

**検証**:
- まず `socialsecurity → chocoZAP` ミスマッチを是正し、健康寿命/運動データ記事に紐付け直す
- 成功基準: 12週後に health カテゴリ affiliate_click ≥ 8/週
- 失敗判定: 薬機法レビューで出稿不可商材が大半 → フィットネス役務に一本化

## 既知の課題（着手前に潰すべき技術負債）

### 課題1: health 商材のカテゴリミスマッチ（★Phase 1で修正）

`affiliate-category.ts` で `"socialsecurity": "health"` となっており、chocoZAP（フィットネス）が**社会保障（年金・生活保護・福祉）データ**に紐付いている。健康寿命・運動習慣・肥満率データ（`medical-care` / `health` タグ）と接続されていない可能性が高い。
→ `TAG_AFFILIATE_MAP` の `health` / `medical-care` → `health` マッピングが効いているか確認し、socialsecurity 由来の出し分けを健康データ側へ寄せる。

### 課題2: アフィリエイトのクリック計測が事実上ゼロ起点

現状アフィリエイト収益 ¥0（推定）、`affiliate_click` GA4 イベントは実装済だが**集計運用がない**。`02_収益化戦略.md` の `affiliate-improvement` スキル新設（Phase 1）が前提条件。本3本柱戦略は、この計測ループの上で初めて最適化できる。

### 課題3: PSI / LCP（全URLで閾値違反）

Mobile LCP 5-19秒は全収益チャネルの天井。ただし**本戦略の阻害要因としては Desktop 67% のため相対的に緩い**（Desktop LCP は一部OK）。PSI改善は別タスクで並行。3本柱の着手を待つ理由にはしない。

## 推奨アクション

1. **まず「人間関係（生涯未婚率→マッチング）」を実装**：理由は YMYL-SEO リスク最小 × 商材CVR最大で**最短で初成約の実証が取れる**から。1本目のデータ記事を curiosity gap タイトルで投下し、`affiliate_click` を計測。
2. **次に「お金（年収・ふるさと納税）」を展開**：検索ボリューム最大の年収ランキングを軸に。ふるさと納税は**11月集中の季節運用**として別途スケジュール。
3. **健康は課題1（カテゴリミスマッチ）を是正してから慎重投下**：薬機法レビューを挟み、フィットネス役務に絞る。サプリ・健康食品は当面見送り。
4. **全柱共通**：データ記事は「助言」ではなく「データ提示＋自県への気づき」に徹する。CTAは該当データのH2セクション内インライン配置（`blog-quality-standards.md` の source-link 規約に準拠）。

## やらないこと（本戦略固有）

| やらないこと | 理由 |
|---|---|
| 健康サプリ・健康食品アフィリエイト（当面） | 薬機法表現リスク。役務（ジム・診療）に限定 |
| 「転職のコツ」「婚活成功法」等の助言記事 | YMYL E-E-A-T で大手に勝てない。データ記事に徹する |
| 証券口座を主軸にする | 高摩擦・低CVR。お金柱は転職・ふるさと納税が主、証券は補助 |
| 3本柱の同時フル稼働 | リソース分散。人間関係→お金→健康の順次立ち上げ |
