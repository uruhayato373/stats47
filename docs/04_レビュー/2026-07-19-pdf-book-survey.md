# 書籍 PDF (都道府県ランキング本) → stats47 展開 調査レポート

## 結論

Google Drive「書籍等」フォルダの都道府県ランキング関連 PDF 7 冊を調査した。**最大の収穫は新規指標ではなく「論点・見せ方の型」**である。書籍が独自指標として売っている貯蓄構成比率 (定期預金比率・有価証券比率) 等は **stats47 に既に存在** (SSDS 由来) と実測確認したため、価値は「県民性ナラティブ」「相関の掛け合わせ」「実質手取りのような合成指標」という **ブログ/ai-content の論点**にある。新規 e-Stat 指標の余地は学力テスト正解率・体力運動能力・救急搬送時間・遊技店密度の 4 系統に絞られ、いずれも estat-researcher の実在検証が必要。

**著作権規律** (area-databook-standards 同型): 書籍からは指標アイデア・論点・見せ方の型のみ抽出。文言・図案・写真の複製は禁止。数値は e-Stat から取り直す (書籍の目安値・概数は使わない)。書籍由来の主張は evidence-based-judgment.md に従い「[仮説] + 実データ検証」で扱う。

**取得方式のまとめ**:
- **ライセンスがクリーン (商用可) = 救急 (PDL1.0) / 学力テスト (CC BY互換) / 金融リテラシー (出所明示で可)** → 取り込み障壁は取得コスト (PDF/xlsx パース) のみ。
- **ライセンス要確認 = 中体連 (明文規約なし) / 遊技店密度 (All rights Reserved)** → 商用公開前に発行機関へ照会。数値=事実は著作権対象外だが編集著作権の余地があり、明文許可を得るのが安全。
- **機械可読データの不在** が共通の実装コスト: 救急・中体連は PDF、学力テストは 47 分散 xlsx、遊技は HTML。いずれも e-Stat API の単一 JSON 取得と異なり、抽出・検算工程を要する。完全DBレスでは `open-data-catalog` に source 登録 (`commercialUse` 未確定は unknown で ranking 非採用) → 抽出スクリプト → git TS metric config → R2 投入、の順。
