# ココナラでの stats47 コンテンツ販売可否調査

> 2026-07-18 時点で、ココナラの公式案内、類似出品、e-Stat 利用規約、stats47 の手元資産を確認し、
> 販売可能性・商品案・価格・権利上の注意を整理した。価格・手数料・出品仕様は変更されうるため、実際の出品時に再確認する。
>
> **2026-07-18 オーナー確認:** 月間収益1万円は達成済み。収益化マスタープランがデータ販売着手条件として置く
> 月1万円ゲートは充足したものとして、本レビューではMVPの商品化検証を開始可能と判断する。

## 結論

- **販売は可能で、テストする価値がある**。ココナラにはデータ分析、可視化、調査レポートの既存市場がある。
- ただし、公開中の都道府県ランキング記事をそのまま有料化するのは弱い。公開統計そのものではなく、
  **調査時間の短縮と意思決定に使える加工済み成果物**を販売する。
- ココナラは、(1) 完成済み PDF / SVG / PNG の販売、(2) 個別依頼による分析レポート、
  (3) 高単価のダッシュボード構築、の3段階に利用できる。
- 最初の検証商品は、購入目的が明確な **「公的統計から出店候補地域を比較するレポート」**を推奨する。
- 無料の stats47 記事は、販売物そのものではなく、専門性・分析品質を示すポートフォリオ兼集客導線にする。

## 調査範囲と限界

確認したもの:

- ココナラ公式のコンテンツマーケット案内、出品ガイド、禁止事項
- ココナラ上の類似サービス（データ可視化、市場調査、ダッシュボード）
- e-Stat 本体と API の利用規約
- stats47 リポジトリの README、ブログ原稿、生成済み図版

限界:

- 検索で確認できる出品・価格・一部レビューは、ココナラ市場全体の成約件数や需要量を示さない。
- 出品ページが公開されていても、販売実績が明示されていないものは「売れている」とは断定しない。
- ココナラの価格、手数料、対応ファイル形式、審査基準は将来変わりうる。
- 法的助言ではない。第三者素材を含む商品は、出品前に個別の権利確認が必要。

## ココナラの販売方式

### コンテンツマーケット

完成済みコンテンツを、購入者との個別のやり取りなしで繰り返し販売できる。公式案内で確認できた
ファイル形式は PDF / JPG / PNG / SVG / AI / EPS / PSD。stats47 では PDF レポート、PNG / SVG 図版と相性がよい。

### 通常サービス

依頼者とトークルームで要件を確認し、個別成果物を納品する。ココナラ公式ガイドでは、通常サービスの
販売手数料は販売総額の22%。出品自体の初期費用・月会費はなく、価格はカテゴリ条件の範囲で設定する。

完成品と受注サービスを併用し、低価格商品から個別分析へ段階的に接続するのが適する。

## 追加調査: Excel / PowerPoint テンプレート販売

### 結論

**PDFレポート単体より有望で、stats47 の再利用可能な商品として優先検証に値する。** 特に PowerPoint は、
ココナラ上でテンプレートの実販売実績が確認でき、stats47 の地図・チャート・データを「資料作成の時短」に変換できる。

ただし、優先順位は次のとおり。

1. **PowerPoint 都道府県データ図表テンプレート**
2. **Excel 47都道府県コロプレス地図・チャートテンプレート**
3. **両方を組み合わせた業務用途別パック**
4. 個別カスタマイズサービス

Excel 単体を最初にしない理由は、確認できた完成済みExcelテンプレートの個別出品に販売0件が多く、
関数・管理表・ダッシュボードという競争の激しい棚に置かれるため。PowerPoint は販売実績のある市場が確認でき、
地図やチャートを「そのまま提案書に使える」という価値が伝わりやすい。

### Officeファイルの販売可否

2025-10-15 から、ココナラコンテンツマーケットで Office ファイルを直接販売できるようになっている。

- Excel: `.xlsx`, `.xls`, `.xlsm`
- PowerPoint: `.pptx`, `.ppt`, `.pptm`
- Word: `.docx`, `.doc`
- データ: `.csv`, `.tsv`, `.txt`, `.xml`
- 画像・資料: `.svg`, `.png`, `.jpg`, `.pdf` など
- ファイル販売は各500MB以内
- 「テンプレート」カテゴリが追加され、プレゼンテーション等の小カテゴリがある

前段の2025-08時点のファイル形式案内より仕様が拡張されている。出品時には最新ヘルプを正典として確認する。

- 購入者本人または1法人内での利用範囲

- Web、SNS、動画、印刷物への掲載可否

- 改変可否
- 著作権譲渡ではないこと

- 商品ページ閲覧からお気に入り・問い合わせ・購入の反応を得る。

## 商品案の網羅的インベントリ

> 「考えられる商品案を全て」の依頼に対し、現時点で合理的に想定できる候補を、購入目的・顧客・形式・販売方式で
> 網羅したアイデア台帳。文字どおり無限の組み合わせを列挙するのではなく、重複を統合した商品ファミリーとして管理する。
> **この節は全件の制作TODOではない。** 収益化マスタープランがデータ販売着手条件として置く月間収益1万円は、
> 2026-07-18 のオーナー確認により達成済み。したがって優先候補からMVPを1件選び、商品化検証へ進める状態にある。
> ただし、一覧を一括制作せず、1商品ずつ需要を実測する。

### 商品設計の基本式

商品候補は、次の5要素の組み合わせで派生する。

```
顧客 × 意思決定 × データテーマ × 納品形式 × 更新・支援レベル
```

| 軸 | 選択肢 |
|---|---|
| 顧客 | 一般個人、事業者、企画・営業、人事、コンサル、メディア、教育、自治体、公務員、研究者 |
| 意思決定 | 比較、候補抽出、現状把握、説明、報告、企画、教材、コンテンツ制作 |
| データテーマ | 人口、所得、消費、雇用、産業、住宅、医療、教育、観光、交通、財政、環境、安全 |
| 形式 | Excel、PowerPoint、CSV、SVG、PNG、PDF、動画、Webダッシュボード |
| 支援 | 空テンプレート、データ入り、年次更新、個別カスタマイズ、分析代行、研修・解説 |

同じ内容を形式違いで無秩序に出品せず、「誰が何に使うか」が異なる場合だけ別商品にする。

## 既存記事をそのまま販売しない理由

例として `overseas-travel-gap/article.md` は、無料記事・ポートフォリオには使えるが、現状のままの有料商品には適さない。

- 中心となる海外旅行行動者率が2001年で古い。
- 無料公開される記事と同内容なら購入理由が弱い。
- 読み物としては面白いが、購入後に何へ使えるかが不明確。
- 空港アクセス、産業構造、県民性など、未検証の仮説を含む。
- 海外旅行率（2001年）と県民所得（2021年度）に20年の年次差がある。

用途は、分析サンプルとして無料公開し、販売物では同一年次・最新性・再利用性・業務用途のいずれかを追加すること。

## 権利・利用条件

### e-Stat

e-Stat 利用規約では、公開コンテンツの商用利用が可能。数値データや簡単な表・グラフは著作権の対象外と説明されている。
一方、コンテンツ利用時は出典を記載し、編集・加工した場合はその旨も記載する。第三者が権利を持つ部分や、外部API連携の
コンテンツは提供元条件を個別に確認する。

表示例:

> 出典：政府統計の総合窓口（e-Stat）「○○調査」を基に stats47 作成。数値の集計・指標化・可視化を独自に行っています。

注意事項:

- e-Stat ロゴを商品の権威付けや公認表示のように使わない。
- 国、府省、自治体が作成・推奨した商品と誤認させない。
- 各調査の第三者権利、外部データベース、API提供元条件を確認する。
- データの基準日、調査年、加工方法、免責を商品内に記載する。

### stats47 と第三者素材

- リポジトリ README は MIT ライセンスを掲げているが、コードのライセンスと第三者素材の再販売権は別に確認する。
- 写真、地図素材、フォント、アイコン、ロゴ、生成AI素材は、商用利用だけでなく「素材としての再配布」が可能か確認する。
- 販売物ごとに、購入者ができること（閲覧、社内利用、記事掲載、改変）と禁止事項（再販売、素材単体の再配布）を定める。
- ココナラは知的財産権侵害、他社サービス規約違反、直接連絡につながる情報等を禁止している。

## 実行判断

現時点の判断は **小規模な販売テストを実施する価値あり**。ただし大量出品やダッシュボードの先行開発はしない。

成功条件を次のように置く:

- 1商品で、閲覧、問い合わせ、購入のどこまで反応が得られるか測定できる。
- 問い合わせ内容から、買い手の用途と必要指標を特定できる。
- 制作・修正・問い合わせ対応を含む実質時給を計算できる。
- 無料公開物との差を購入者へ一文で説明できる。
- 出典・ライセンス・調査年を商品単位で監査できる。

撤退・修正条件:

- 閲覧はあるが購入されない場合: タイトル、対象購入者、成果物サンプル、価格を見直す。
- 問い合わせが雑学用途のみの場合: 完成品の低価格販売に寄せ、受注分析を広げない。
- 個別修正が多く採算が合わない場合: 対応範囲を狭め、追加料金を明確化する。
- 最新データを安定供給できないテーマは商品化しない。
