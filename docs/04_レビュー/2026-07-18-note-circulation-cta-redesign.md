# note 既存記事の回遊・マガジン・CTA 再設計

## 結論

既存記事の末尾にリンクを追加するだけでは不十分。記事を「入口」「ハブ」「手順」「転換」の4役割に分け、各1つの主 CTA を持たせる。マガジンは全記事に同じ強度で売るのではなく、無料ハブ記事とシリーズの区切りで集中的に誘導する。

## 現状監査

- note catalog は editorial meta の git TS SSOT として整備済みだが、`stats47-note` の187記事はすべて `magazine: null`。統計系記事からマガジンへの回遊グラフがまだデータ化されていない。
- 公務員系は45記事がマガジン割当済み。36本が公開済みで、33本に共通フッターがある。一方、「他の記事はこちら」という抽象的な誘導が多く、次に読む具体的な1本の価値が弱い。
- e-Stat 系フッターはマガジン、姉妹マガジン、stats47 を同時に提示する。選択肢が競合し、どれが主 CTA かが不明。
- `note戦略.md` の旧「UTM付き5〜10本」は、実行規約の「素 URL 2〜4本」と矛盾していた。実行規約に統一した。
- 2026-07-13 の note metrics は `dobokunote` アカウントを取得しており、stats47 改善のベースラインに使えない。stats47 の最後の有効値は 2026-06-15 の24記事・904 views。ただし catalog の公開記事数と一致しないため、改修前にアカウントと取得範囲の修正が必要。

## 回遊モデル

```text
検索/レコメンド
  → 入口記事
      → 次の1本（具体的な悩みを進める）
          → 無料ハブ/マガジン
              → 有料記事または stats47 の活用ページ
```

カタログに将来追加する editorial meta は最小の3つにする。

| フィールド | 意味 |
|---|---|
| `journeyRole` | `entry / hub / step / conversion` |
| `nextBestArticle` | 読者の次の仕事に最適な1記事。未公開は指定不可 |
| `primaryCta` | `article / magazine / stats47 / purchase`。同時に1つだけ |

リンク文言やフッター本文を TS の SSOT に大量保存しない。上記 meta から決定的な雛形を生成し、「なぜ次に読むか」の1文だけを編集対象にする。

## CTA テンプレート

### 入口記事

> 次に「{reader job}」まで進めたい方は、{article title} へ。{specific outcome} まで手を動かせます。

その下にマガジンリンクを小さく置く。stats47 リンクは本文の対応データ直後に置き、記事末で競合させない。

### 無料ハブ

> いまの状況が {A/B/C} のどれかで、次の1本を選べます。全体の読書順とセット価格はマガジンにまとめました。

ハブ記事はマガジンの価値、対象読者、読まなくてよい人、無料/有料の境界を示す。単なる全記事一覧にしない。

### 手順記事

> ここまでで {completed state}。次は {next state} を行う {article title} です。

前記事へのリンクは「前提が欠ける読者」にだけ出す。全記事で前後リンクを置く必要はない。

## マガジン再編方針

1. 公務員系の既存2マガジンは維持し、各「はじめに読む無料ハブ」を1本固定する。
2. 33本シリーズは番号順よりも「導入」「安全」「文書」「データ」「組織展開」の読者別ルートをハブで示す。マガジン自体はむやみに分割しない。
3. e-Stat 12本は作業依存が強いため、`00 → 01/03 → 04/05 → 08/09 → 10/11` のジャーニーを基本にする。
4. stats47 系は187本を一括編集せず、既存レジストリの4候補（人口・労働、気候・環境、財政・自治体、働き方・賃金）に、有効ベースラインを持つ上位20記事だけを割り当てるパイロットから始める。

## 実装順序とゲート

| Phase | 作業 | 完了条件 |
|---|---|---|
| 0 | metrics の stats47 アカウント誤取得を修正し、記事URLと catalog を照合 | 公開記事数と取得対象の差分が説明できる |
| 1 | 公務員系の入口/無料記事5本だけに新 CTA | 主 CTA が各1つ、リンク切れ0、公開前差分レビュー済み |
| 2 | 2〜4週観測 | 対象の次記事 views / 購入 / stats47 参照流入を前期と比較 |
| 3 | 効果がある CTA を公務員系公開記事へ段階展開 | 機械 validator と目視サンプルレビュー通過 |
| 4 | stats47 上位20記事のマガジン割当 + CTA pilot | note → stats47 参照セッションが対照期より改善 |

プロダクションの note.com 公開記事の更新、マガジン作成・並べ替えは outward-facing のため、実行前にオーナー承認を必須とする。

## 今回行わないこと

- 187記事の一括リライトや一括更新
- マガジンの数を先に増やすこと
- クリックされない問題を CTA の色や記号だけで解決すること
- views の増加だけでマガジン購入導線の成功と判定すること
