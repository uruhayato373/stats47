# Kindle 出版 収益化評価 — 3 企画の比較

> オーナーとの対話（2026-07-14）で「Kindle 出版で収益化できるか」を、実際の Amazon 類書・
> 市場データを WebSearch で確認しながら評価した記録。結論と根拠を残す。

## 結論（先に）

- **Kindle の本命は「公務員 × Claude Code の実務活用」**。ニッチが空白・テキスト主体で Kindle 適性が高く、
  既存 note 資産（koumuin-claude-code）を再編集すれば制作コストがほぼゼロ。
- **stats47 のデータ本（県民性・都道府県ランキング）は Kindle 収益化としては弱い**。理由は (1) 直接競合
  とどランが書籍版を出版社流通で先行実施済み、(2) チャート主役のコンテンツは Kindle（リフロー型）と相性が悪い、
  (3) Web で無料公開済み。
- **人口移動フローは 3 案で最も差別化が効く**（該当書籍が存在しない空白ニッチ）。だが「動き」が魅力の動画を
  静止画に落とすと核が抜け、かつ図版主体の本は Kindle/スマホと相性が悪い。**動画のまま YouTube/SNS で
  リーチ → 課金導線に繋ぐ方が同素材でリターンが大きい。**

## 3 案の比較

| 企画 | ニッチの空き | 競合 | 媒体（Kindle）適性 | 収益見込み |
|---|---|---|---|---|
| 公務員 × Claude Code | ◎ 空白（未執筆） | ほぼ無し | ◎ テキスト主体 | funnel 込みで最有望 |
| 家計調査＝県民性雑学 | △ 成熟ジャンル | 出版社多数 | △ 要物語化 | 単体では小 |
| 都道府県ランキング | ✕ 競合が先行実施 | とどラン書籍版等 | ✕ チャート主役 | 最も弱い |
| 人口移動フロー（本） | ◎ 該当書なし | 無し | △ 固定レイアウト必須 | 動画運用に劣る |

## 根拠（実データ）

### Kindle 単体の収益構造は小さい
- KDP 印税 70%（¥250–1,250 帯）。¥500 の本で 1 冊手取り約 ¥350。
- Kindle Unlimited は既読ページ課金（1 ページ約 ¥0.5）で販売より低い。
- 個人 Kindle の相場観: 「AI活用×Kindle出版で月3万円」が書籍タイトルとして成立＝月3万円が売り文句の上限帯。
  ある実例は「2 年・50 冊超・累計 DL 1万・印税累計 100 万円」＝**1 冊あたり生涯 ~2 万円**。

### 公務員 × Claude Code
- 開発者向け「Claude Code 入門」棚は飽和（実践Claude Code入門／AI駆動開発入門／はじめての／ストーリーで覚える 等）。
  → 汎用入門書は埋もれる。
- だが「公務員向け」は書籍が存在せず空白。差別化軸として明確。
- その中身をオーナーは既に note で保有（stats47 アカウント: 稟議資料／個人情報を送らない設定／監査ログ）。
  稟議・個人情報保護条例・監査という**公務員固有の壁**が堀。
- 隣接（公務員×AI副業）は既に耕されているが「稼ぐ」話で「Claude Code で実務」ではなく棲み分け可能。
- 制約: 現職公務員なら兼業許可申請が必要（無許可は懲戒対象）。**オーナーは元職員のため不要。**

### 県民性・都道府県ランキング
- 直接競合とどラン（todo-ran.com）が `統計から読み解く 47都道府県ランキング`（久保哲朗・実業之日本社）を
  複数巻シリーズで先行出版済み。加えて木原誠太郎（文藝春秋）、岩中祥史（新潮文庫）、幻冬舎 等、
  伝統出版社が握る成熟ジャンル。個人 Kindle の後発は分が悪い。
- 家計調査「消費量日本一」型（CTR 7-17% の勝ちクラスタ）は雑学本として物語化すれば芽はあるが堀は薄い。

### 人口移動フロー
- 移動フローに特化した書籍は Amazon に無し（政府統計・RESAS・uub の可視化ツールはあるが「本」は無い）→ 空白。
- 弱点1: フローの魅力＝アニメーションの「動き」で、静止画化で核が抜ける。
  静止表現の代替: コード図／サンキー図／矢印マップ／47 県別スプレッド（転入元 TOP・転出先 TOP・矢印地図・解説）。
- 弱点2: 図版主体は固定レイアウト EPUB 必須。スマホ可読性が低く、KU 収益と相性が悪く、制作も手間。
- stats47 の差別化資産（市区町村内格差・移動フロー）は、本にするならランキングの後追いではなく
  この角度で 1 点突破（別の棚に立てる）。

## 推奨アクション

1. **最優先: 公務員 × Claude Code の Kindle 化**。価格 ¥500–1,000 + KU 登録。note 資産を再編集。
   汎用「入門」ではなく公務員固有の壁（稟議／条例・個人情報／監査ログ／前例のなさ）を前面に。
   Kindle は入口 → note 有料マガジン → 自治体向け勉強会/相談へ funnel。
2. **移動フローは Kindle でなく動画（YouTube/SNS）でリーチを作り課金導線へ**。
3. **stats47 データを本にするなら**、都道府県ランキングの後追いを避け、市区町村格差・移動フローの
   「図鑑（固定レイアウト・47 県別）」に限定。
