#### 守るべき契約

1. `fingerprint = semantic render input + renderer/font/topology/background等の依存hash + output contract` とする。
2. skip可能なのは、manifest fingerprintだけでなく全assetのSHA-256 / size / MIMEがremoteと一致するときだけ。
3. planに最終asset SHA、manifest SHA、観測時remote manifest fingerprint/SHAを固定し、2時間を超えたplanは拒否する。
4. assetをPUT/HEAD検証した後、manifestを最後にETag CASする。競合・lock owner不一致・HEAD不一致はfail closed。
5. no-change時も空planを明示生成する。plan欠落を「差分なし」と解釈しない。
6. manifestなし資産は明示keyだけをpushする。`app/blog`等の広域prefix、staging prefix、mtime判定は禁止。
7. AI背景と最終ブランド画像のhashを分離し、ブランドrenderer変更だけでGeminiを再課金しない。
8. `continue-on-error` / `|| true` / `--force`で画像不整合を隠さない。全画像writerを共通`r2-write`で直列化する。
