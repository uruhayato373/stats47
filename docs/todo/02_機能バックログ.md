### [T2-RANKING-NORM-SSG-01] ranking 正規化派生（人口10万人あたり等）の SSG 化 + SEO 対応

- **tier**: 2
- **status**: pending
- **created**: 2026-05-25
- **target_metric**: GSC clicks / impressions (normalization 派生 URL の indexing)
- **問題**: pill 切替の派生（「人口10万人あたり製造品出荷額」等）は `?norm=` query で SSG 対象外＝検索エンジン非認識。同義の e-Stat 由来派生は別 rankingKey として SSG/indexed され非対称。pill (CSR) と group toggle (別 URL) の挙動差がユーザーに不可視。`total-population` に per_population が付く意味バグも残存（→ DATA-CLEAN-01）
- **対応案**:
  - **案 A**: `?norm=` を SSG 化（`generateStaticParams` に norm 種別追加、`/ranking/{key}/{norm?}` route、canonical/alternate、sitemap 拡張）。工数 中
  - **案 B**: pill 派生を別 rankingKey に昇格（group に一本化）。metric 数 2-3 倍・snapshot 容量試算要・旧 URL 301。工数 大
  - **案 C**: pill は CSR 便利機能と割り切り `?norm=` を canonical で元 URL に吸収。工数 小
- **関連**: `packages/ranking/src/services/compute-normalization.ts` (`WELL_KNOWN_DENOMINATORS`) / `packages/ranking/src/exporters/ranking-normalized-values-snapshot.ts`
