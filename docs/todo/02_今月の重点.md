# 2026年7月の重点

残り期間は新規機能を広げず、公開中の誤りと計測不能を解消し、7月に実装した運用基盤を検証可能な状態で閉じる。

## 重点1: データ・計測・コストの正しさ

対象 ID:

- `DATA-ESTAT-FETCH-01` / `DATA-MANUAL-RESTORE-01`: 欠測・取得失敗の公開影響を解消する。
- `IND-DATA-CORRUPTION-01`: 婚姻率・離婚率の誤値を一次統計で再確認し、正値へ戻す。
- `R2-STORAGE-01`: 無料枠超過の原因と残容量を確定し、再増加を防ぐ。
- `PERF-LOCAL-NAV-01`: UIを変更せず、localhost の共通遷移遅延を依存境界から直す。

月末条件:

- 公開中の誤値と欠測について、対象、原因、修正または一時非公開の判断が確定している。
- R2 の再増加検知が機械化され、不要世代を人手判断に依存せず管理できる。
- localhost 遷移は共通ヘッダー、トップ→ランキング、ブログ、テーマで同じ計測方法を使い、変更前後を比較できる。

## 重点2: 収益・検索改善の計測ループ

対象 ID:

- `AFF-IMPRESSION-RENAME-01`: 新イベントが実測できることを確認する。
- `ASP-CONTINUITY-01`: もしも・afb の承認追跡を positive-only で閉じる。
- `SEARCH-OBSERVABILITY-RELEASE-01`: 次回 CI で検索・GA4・AdSense の live 取得を確認する。
- `SEARCH-GROWTH-CYCLE-01`: finalized 7日と rolling 28日の用途を分離した週次運用を開始する。

月末条件:

- アフィリエイト impression が 0 件ではなく、vertical 別に集計できる。
- ASP 操作は plan、journal、lock、unknown 状態を持ち、推測で承認済みにしない。
- 検索・AdSense の週次出力が期間メタデータ付きで生成される。

## 今月は行わない

- UI の見た目を伴う新規リデザイン。
- 未検証の e-Stat 候補や SNS 投稿の一括量産。
- 効果測定前の広告枠・カテゴリ写像の一括拡大。
- 明示承認のない本番デプロイ、R2 write、外部サービス設定変更。
