# 県データブック仕様 (/areas/[code] 高密度化)

## 目的

`docs/books/2021 都道府県 Data Book` (日本食糧新聞社・47 県 × 6 ページ固定テンプレ・全数値に全国順位) を
設計図に、47 県同一 6 チャートだった `/areas/[code]` を ~130 指標の高密度「県データブック」ダッシュボードへ
拡張する。全 47 県展開。

**運用正典は `.claude/rules/area-databook-standards.md`** (本 doc は背景・意思決定・Phase 記録)。

## 意思決定 (2026-07-18)

- **データ経路 = ハイブリッド 2 系統**: 順位付き KPI (~60) は exporter が R2 values.json (rank 済) から
  R2 `app/areas/<code>/databook.json` に焼き込み (ページ 1 read)。推移・構成チャートは既存 estatParams ライブ経路。
- **カタログ SSOT**: 47 県共通テンプレ `template.ts` 1 本 + 県別 `editorial/<code>.ts` (特産品・シンボル)。
  theme-catalog パターンの複製 (generator `--check` + validator + CI Area Databook Gate)。
- **ページ構成**: 1 ページ長尺 + ページ内目次 (アンカー)。`AreaChartSection` → `AreaDatabookSection` に差し替え、
  databook.json 欠損時は現行 6 チャートにフォールバック (段階展開の安全弁)。
- **特産品画像**: AI 生成イラスト (**Codex MCP セッション + OpenAI 画像 API**。2026-07-18 に Gemini から変更)。
  書籍写真は権利物のため使わない。品名・産地は事実抽出、解説は web リサーチの独自文 + 出典 URL。
  未生成の間は SpecialtyList がイニシャル代替タイルに degrade する (非ブロック)。
- **民間指標** (上場企業数・倒産件数・代表取締役出身者数): ライセンス上採用不可 (Phase 0b 調査)。
  e-Stat 経済センサス (企業等数・事業所数) で代替。社長輩出県は公的代替なしで見送り。
- **情報設計整合**: area は県軸・回遊面。47 県横並び可視化は置かない (theme の責務)。比較は rankingLink で回遊。

## アーキテクチャ

```
AREA_DATABOOK_TEMPLATE (git TS) ──generate:area-databook──▶ page-components/area/<code>.json ──▶ R2 ──▶ AreaDatabookSection (chart)
AREA_EDITORIALS (git TS) ──直 import──▶ SpecialtyList / PrefSymbolCard
area-databook-snapshot.ts ── R2 values.json (rank) ──▶ R2 app/areas/<code>/databook.json ──▶ RankedKpiGrid / GenderPairedKpiGrid
```
