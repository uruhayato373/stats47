# ココナラ商品ファクトリー実装仕様

## 目的と成功条件

レビュー文書に列挙した全商品ファミリーを、共通部品から段階的に生成する。150件前後を個別に手作業せず、
型付き商品カタログとテンプレートから PowerPoint、Excel、CSV、SVG、PNG、PDF、説明書、プレビュー、
ココナラ販売文、note記事原稿を再生成する。

月間収益1万円の着手ゲートは2026-07-18のオーナー確認により達成済み。ただし全商品を一括公開せず、
生成基盤、代表MVP、ファミリー展開、1商品ずつの出品・計測の順に進める。

成功条件:

1. 全商品案が一意のIDで型付きカタログに登録され、欠落を機械検査できる。
2. 同じ入力から複数形式を決定的に再生成できる。
3. 全成果物に版、基準年、出典、利用許諾、対応環境が入る。
4. Office実機で編集、再計算、再保存、表示崩れを検証できる。
5. 制作時間、原価、価格、販売数、問い合わせ、サポート工数を計測できる。

## 境界

含む: A〜L全商品、共通デザイン、地図、チャート、出典、ライセンス、生成、検証、販売文、リリース台帳。

含まない: ココナラへの自動ログイン・出品、購入者対応、本番Web UI変更、公開R2への商品配置、永続D1、
第三者素材の無確認利用、e-Stat公認の示唆、医療・投資・防災等の結果保証。

## SSOTと配置

新規ワークスペース `packages/product-factory/` を設ける。

```text
packages/product-factory/
├── src/
│   ├── catalog/{types,products,families,licenses}.ts
│   ├── data/{load-ranking-values,normalize-prefectures,provenance}.ts
│   ├── design/{tokens,palettes,layouts}.ts
│   ├── maps/
│   ├── charts/
│   ├── generators/{pptx,xlsx,svg,png,csv,pdf,listing-copy,manifest}.ts
│   ├── validators/
│   └── cli.ts
├── templates/{powerpoint,excel,manuals,listing}/
└── tests/
```

生成先は `.local/coconala-products/<product-id>/<version>/`。git管理しない。

```text
product.pptx|xlsx / data.csv / assets/ / manual.pdf / LICENSE-ja.txt /
SOURCES.csv / manifest.json / preview/ / listing/{coconala,note}/
```

商品定義、テンプレート、生成コードはgit TSがSSOT。観測値は既存R2がSSOT。Office等のバイナリは派生物で、
手編集を正典にしない。公開R2へ置かない。

販売チャネルは `coconala-content / coconala-skill / note-paid / note-free` として商品定義へ紐付ける。
商品IDとversionは共通化し、チャネル別の商品SSOTを作らない。

## 商品カタログ

必須型:

```ts
type ProductDefinition = {
  id: string;
  family: "asset" | "powerpoint" | "excel" | "data" | "industry" |
    "government" | "media" | "education" | "consumer" | "service" |
    "license" | "entry";
  name: string;
  audience: readonly string[];
  jobToBeDone: string;
  formats: readonly ProductFormat[];
  price: { minYen: number; maxYen: number; initialYen: number };
  dataMode: "empty" | "sample" | "fixed-year" | "updated" | "customer";
  metrics: readonly string[];
  templateIds: readonly string[];
  licenseId: string;
  supportLevel: "none" | "manual" | "limited" | "custom";
  compatibility: readonly string[];
  risk: "normal" | "high-stakes" | "rights-review";
  status: "cataloged" | "spike" | "buildable" | "generated" | "reviewed" |
    "approved" | "listed" | "paused";
};
```

レビューのA-01〜L-07を全登録する。Jは役務なので成果物雛形と販売文まで生成し、サービス自体は自動実行しない。
Kをライセンス・更新variantへ統合する場合、旧IDと新定義の対応表を残す。

## 共通仕様

- 既存stats47のデザイントークンを参照し、別ブランドを増やさない。
- 16:9、A4横、A4縦を用途別に固定する。
- 色覚多様性に配慮した3パレット以上を持つ。
- 地図は都道府県コードで結合し、名称文字列をキーにしない。
- 全図表にタイトル、単位、基準年、出典、注記領域を持たせる。
- 3Dグラフ、切断軸、過剰な色数、円グラフ乱用を禁止する。
- サンプルには年次と用途を説明しやすい指標を使い、古い海外旅行率は使わない。

データ入力の優先順位は、R2観測値、git TS metricメタ、prefecture master、架空サンプル。
`SOURCES.csv` に調査名、表名、statsDataId、URL、年、取得日、単位、加工式、注意事項を保存する。
欠損・秘匿・非該当を0にしない。異年次結合は警告または明示許可を必須にする。

## PowerPoint要件

- `.pptx`、16:9標準。テキスト、注記、標準チャートデータを編集可能にする。
- 地図は県単位で色変更可能を受入条件にする。
- SVG単体、県別SVG、Office shapeをPhase 0で比較し、Windows/Macで壊れにくい1方式を採用する。
- 埋め込みExcel値の変更でチャートが更新されることを実機確認する。
- スライドマスター、テーマ色、フォントフォールバックを定義する。

## Excel要件

- 初版はマクロなし `.xlsx`。VBAは上位版に分離する。
- 基本シートは `README / INPUT / MAP / RANKING / CHARTS / SETTINGS / SOURCES`。
- 入力、計算、保護セルを視覚的に分ける。
- 47行を差し替えると順位とチャートが更新される。
- 標準地図のMicrosoft 365・オンライン依存を明示する。
- Windows/Mac Microsoft 365で検証し、Web/Mobileの保証範囲を明記する。

## その他形式

- CSVは日本語Excelで文字化けしない形式を検証する。
- SVGはviewBox、県コード、title、アクセシビリティ情報を持つ。
- PNGは透過版と白背景版を用途別に生成する。
- PDFは説明書と固定レポート用。編集可能商品と混同しない。
- ココナラの対応形式に明記されないzipを前提にしない。

## CLIと安全性

```bash
npm run products:catalog --workspace=@stats47/product-factory -- --check
npm run products:generate --workspace=@stats47/product-factory -- --id B-01
npm run products:generate --workspace=@stats47/product-factory -- --family powerpoint
npm run products:validate --workspace=@stats47/product-factory -- --id B-01
npm run products:preview --workspace=@stats47/product-factory -- --id B-01
npm run products:report --workspace=@stats47/product-factory
```

全件は明示的な `--all` を必須とし、既定で全生成しない。既存上書きは `--force` を要求する。
出力先を固定ルート配下に制限し、秘密、ユーザー名、会社名、ローカル絶対パスをOfficeメタデータへ含めない。

## 検証

自動検証:

- ID重複、レビュー候補の欠落、参照不存在、価格逆転
- 47都道府県の件数、コード、順位、欠損
- 出典、年、単位、ライセンス、互換性表示
- PPTX/XLSXの破損、外部リンク、秘密、絶対パス、文書プロパティ
- CSV文字コード、行・列、SVG viewBox・県ID・禁止要素
- 620×620サムネイル、プレビュー枚数、販売文必須項目
- 同一入力から同一manifestを作るgolden test

実機検証:

| 環境 | 確認 |
|---|---|
| PowerPoint Windows 365 | 地図編集、色、チャート、フォント |
| PowerPoint Mac 365 | 表示、編集、再保存・再オープン |
| Excel Windows 365 | 差替え、再計算、地図、印刷 |
| Excel Mac 365 | 数式、グラフ、再保存・再オープン |

Officeがない環境では生成成功を互換性検証完了と報告しない。LibreOfficeは参考確認とし、保証対象にするときだけblocker化する。

## リリース台帳

カタログ状況は `.claude/state/products/catalog-status.json` に再生成する。販売実績は
`.claude/state/products/sales-ledger.json` に単一スクリプト経由で記録する。productId、version、生成・レビュー・出品日、
channel、価格、手数料、販売数、売上、返金、質問数、supportMinutes、入力snapshot、hashを持つ。
購入者の個人情報やメッセージ本文は保存しない。
公式APIが確認できない限り売上スクレイピングを実装せず、人間入力とする。

## Phase 記録

### Phase 0 — 技術 spike・依存判定 (2026-07-18 完了)

`/tmp/cocospike` の実 spike + 生成 .pptx/.xlsx の OOXML 検査で依存を決定した。**Office 実機
(PowerPoint / Excel) は未インストールのため、県別再着色・数式再計算の実機互換は未検証 (Phase 4 に持ち越し)。**
OOXML 構造レベルの確認のみ済み。

| 形式 | 採用 | ライセンス | 根拠 (実 spike) / 非採用理由 |
|---|---|---|---|
| PPTX | pptxgenjs 4.0.1 | MIT | pure JS・macOS/Node20 で生成確認。県別 `<a:custGeom>` shape + shape 単位 `<a:solidFill>` をネイティブ出力 (`ppt/slides/slide1.xml`)、埋め込み xlsx チャート `<c:externalData>`→`ppt/embeddings/*.xlsx` を確認。python-pptx=custGeom 補助なし+別ランタイム / raw-OOXML=高コスト |
| XLSX | exceljs 4.4.0 | MIT | pure JS。`<f>RANK(...)`/`<f>SUM(...)` を cached `<v>` 無しで出力 (`xl/worksheets/sheet1.xml`)=Excel が開封時に再計算。**チャート書き出し不可** (`worksheet.addChart` 無し)→テンプレ or raw-OOXML 注入が要る。SheetJS community も同制約 |
| PNG preview | sharp 0.33.5 (既存) | Apache-2.0 | 既存資産の再利用。playwright は静的ラスタに過剰 |
| PDF (説明書・固定レポート) | pdf-lib (**Phase 2 で追加**) | MIT | pure JS・日本語埋め込み。pdfkit=日本語埋め込みが弱い / playwright print=browser 過剰 |
| SVG 地図ソース | @stats47/svg-builder choropleth (既存) | repo | 既存 tile-grid を SVG/PNG 納品に再利用。新規は重複 |
| CSV | UTF-8 + BOM | — | JP Excel の Shift-JIS 誤判定=文字化けを BOM で回避 (一般仕様・実機未検証) |

**県別地図の採用方式**: prefecture.topojson (`apps/remotion/public/`) → d3-geo 投影 → pptxgenjs `addShape("custGeom")`
を県ごとに注入。購入者がアプリ内で県単位に再着色できる (レビュー受入条件)。単一 SVG 画像 (個別編集不可)・
県別 SVG 埋め込み (Windows 限定の shape 変換を購入者へ強いる) は却下。残リスク: 離島の shape 数肥大 /
custGeom の飛地 (穴) 描画 / チャート追従・XLSX チャート authoring は Office 未検証。

> **依存の追加時期**: pptxgenjs / exceljs / pdf-lib は Phase 0 で採用決定したが、コードが import する **Phase 2 で
> package.json に追加する** (Phase 1 は catalog + validator のみで最小構成を保つため未追加)。
