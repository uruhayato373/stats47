## 基本方針

1. **配信と計測が最優先** — 新規コンテンツ制作より、既存資産の配信と効果計測に時間を使う
2. **週次メトリクス追跡を義務化** — 毎週 GA4/GSC/SNS の数値を記録し、効果計測待ち施策を期日で判定する
3. **計画は 1 Sprint 先まで** — Sprint 完了時の実績データに基づいて次を設計する
4. **優先順位判断は [`01_収益化マスタープラン.md`](./01_収益化マスタープラン.md) の Phase 計画に従う** — 技術開発と施策投下の優先度は同マスタープランの Phase ゲートで判断する

## 週次運用リズム

スプリントタスクではなく恒常的な運用ルール。

- **日曜夜: `/weekly-review`** — その週の振り返り・記録。
- **月曜朝: `/weekly-plan`** — 翌週の計画・メトリクス取得。

記録先:
- 週次計画 / 振り返り → `docs/03_週次運用/週次{計画,レビュー}/YYYY-Www.md`
- 計測スナップショット (GSC/GA4/AdSense/PSI 等) → `.claude/state/metrics/<metric>/`（LATEST.md で 10 秒把握）+ 各 `*-improvement/reference/snapshots/`
