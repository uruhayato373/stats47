# 補助金の根拠データとAIノウハウ展開仕様

## 0. 位置づけ

2026-11-11 にオーナーと検討した内容を、次のセッションが引き継げるように残す。扱うのは 2 つ。

- **作り方のノウハウ**（e-Stat の分析、QGIS・GIS、生成 AI での統計処理）を、誰にどの形で届けるか
- **事業計画・補助金・創業融資の根拠データ**として、stats47 のデータとコンテンツをどうつなぐか

収益モデル・優先順位の正本は `docs/00_プロジェクト管理/02_収益化戦略.md`、ペルソナの正本は `docs/00_プロジェクト管理/04_ターゲットペルソナ.md`。本書はそこへ反映する前の検討の記録と調査の根拠で、**ここに書いたペルソナ・導線・判定の数値は仮説**。反映するかは `SUBSIDY-EVIDENCE-STRATEGY-01` で決める。status は、その決定で active に上げる。

調査は 2026-11-11 に Web の公開情報で行った（5 つの観点を並行で調べ、制度は公募要領の原文で確認）。聞き取りはしていない。検索ボリュームも取れていない。

## 1. 結論

**stats47 が売れるのは、データそのものではなく、計画書の式の中で無料の公的ツールが埋めない 1 項（1 世帯あたりの消費額）と、「何年のどの値を使うか」の判断。** これを、出典つきの無料ページと、作り方の買い切り記事（スクリプトと計算シートつき）で届ける。

- `ISSUE-PAYING-NEED-01` の問い「統計を仕事に使う人は、お金を払うほど困っているのか」に対して、**行政職員とは別の「仕事の読者」＝補助金・創業計画を書く事業者とその支援者**を候補として出す。行政の業務と違い、払い手（事業の経費・自腹）がはっきりしている
- 小規模事業者持続化補助金は、第 20 回から「客観的なデータを用いた市場や顧客ニーズの分析」が要件になった。申請の多い制度で、根拠データの需要が広がったと見る
- 統計局の無料講座の受講者（累計 23.1 万人）は、競合ではなく見込み客。講座で覚えた手作業を、生成 AI で短くする記事が次の段階になる
- 商圏の内側（半径数 km の世帯数）は jSTAT MAP が無料で出し、業界の市場規模は有料の書籍・データベースが持つ。そこは追わない

## 4. 集客と導線

**入口は 3 つ。雑学の流入を商品へ流す前提は置かない**（収益化戦略 §3.5 の原則のまま。導線は文脈が合う箇所だけ）。

| 入口 | 読者 | 中身 | 測るもの |
|---|---|---|---|
| ① サイトの検索（新しいページ群） | A・B | 品目 × 地域の 1 世帯あたり支出と推計市場規模（§5 の段 0）。地域名つきの長い検索語を狙う | GSC のクリックと検索語、記事への `nav_click` |
| ② note の中の検索・推薦 | C・B | 無料の入口記事「講座で Excel でやった集計を、Claude Code で 5 分にする」。講座と同じ題材（e-Stat の表）で、手作業と AI の差を見せる | 閲覧、有料記事へ流れた数 |
| ③ 制度の対応表（ハブ） | A・B | 「どの制度のどの欄に、どの統計を、どの粒度で」の表（§7 を読者向けに直したもの）。要領の版と確認日を書く | 検索語、表から推計ページ・記事への遷移 |

```text
検索「○○市 △△ 消費額」「持続化補助金 市場動向 データ」
   ↓
[無料] 推計ページ（値・出典・年次・自分の商圏の世帯数を入れる計算欄）／制度の対応表
   ↓ 「この表を自分の地域・品目で作る」
[無料] note の入口記事（手作業と AI の差）
   ↓
[有料 500〜980 円] 作り方の記事（スクリプト＋計算シート。文例は載せない）
   ↓ 3 本売れたら
[有料] マガジン
   ↓ オーナーの行政書士登録後（別の事業）
申請書の作成の相談
```

**時期**: 持続化補助金の一般型 第 20 回は 2026-12-15 締切。春は創業が多い。公募の締切の 3〜4 週前に入口が検索に載っている状態を目標にする。締切は回ごとに変わるので、ページに固定の日付を書かず、要領の版と確認日を書く。

**質問の収集**: `KNOWHOW-QA-BOARD-01` の検索語のテーマに「補助金・創業計画の市場データ」を 1 つ足すと、A の困りごとの一次証拠が同じ器で取れる（足すかはそのカードで決める）。

**姉妹サイトとの関係**: doboku-note は建設業許可・経審から施工管理の教材へ送る導線を作ると決めた（2026-11-11）。ただし建設業の申請（経営力向上計画、人材開発支援助成金）は外部の統計をほとんど使わない。stats47 から送れるのは、建設会社が新分野へ出るときの市場の説明（D）くらいで、太い線にはならない。

**段 0 の形を「市区町村の市場規模」にしない理由**: 公庫の式は「世帯数 × 1 世帯あたり消費額 × シェア」。世帯数は jSTAT MAP が無料で出し、シェアは申請者が競合を見て置く。統計サイトが担えるのは単価の項。表で完結するので、小地域のデータも、販売に申請が要る境界データ（N03・Geoshape）も要らない。既存の方針とぶつからない。

**段 0 の弱点**: 家計調査の品目別の値は 52 市（県庁所在市と政令市）にしか無い。ほかの市区町村は、県庁所在市の値を代わりに使うか按分する推計になる。ページに「推計」と方法を必ず書く。品目別の値がどの世帯区分（二人以上の世帯か総世帯か）を対象にしているかを公式で確かめ、掛ける世帯数の範囲とそろえる（未確認）。

**段 3 の論点**: 需要の証拠はいちばん強いが、3 つ決めることがある。①ココナラからは 2026-10-19 に撤退している（収益化戦略 §3.6）。②「法人向けの小地域データ・GIS は作らない」の例外になるか。③地図を納品物に入れるなら、jSTAT MAP の地図出力の利用条件。作業時間の実測も無い。

## 6. 守ること

- **改正行政書士法（2026-01-01 施行）**: 第 19 条に「他人の依頼を受けいかなる名目によるかを問わず報酬を得て」が加わった。渡すのは**値・出典・年次・計算表・調べ方**に限る。「市場動向の欄にそのまま貼れる文例」「埋めるだけのひな形」は作らない。商品の説明に「申請書の作成は申請者本人か行政書士が行う」と書く。「参考となる資料の提供にとどまる限りは作成に当たらない」とする総務省の回答（2025-10-10 付）は、行政書士の note の紹介で知っただけで、原文を確認していない。公開の前に原文を確かめる
- **推計は推計と書く**。方法・出典・年次・対象の世帯区分を、値のそばに置く
- **売り文句**: 「採択される」「通る」と書かない。収益化戦略 §8 と `KNOWHOW-PRODUCT-PILOT-01` の禁止（「稼げる」を売り文句にしない）と同じ扱い
- **1 つずつ試す**。データ集の価格の実験（判定 2026-12-30）の条件を変えない。段 1 は別の商品なので実験の変数を乱さないが、段 0 のサイトのページと段 3 は、前の判定が出てから始める
- **制度の名前・回・締切は変わる**。ページと記事には、要領の版と確認日を書く。古い回の記述を残さない
- 能動の時間は、今月の重点（収益化戦略 §5 の領域表）を侵さない

**制度の状況（2026-11 時点）**: ものづくり補助金と中小企業新事業進出補助金は公募を終え、中小機構の「新事業進出・ものづくり商業サービス補助金」に統合された。事業再構築補助金は第 13 回で公募を終えた。IT 導入補助金は「デジタル化・AI 導入補助金 2026」に名前が変わった。統合補助金の第 2 回の日程は二次情報どうしで食い違っていて未確認。

**データの出どころと、使う年の迷いどころ**:

- 令和 7 年国勢調査は人口の速報が出たばかりで、小地域の集計は令和 8 年 9 月以降に順次
- 経済センサス活動調査（令和 8 年）の速報は 2027 年 5 月の予定。商業統計は 2014 年で終わっている
- 家計調査の品目別ランキングは 52 市。全国家計構造調査（2024 年）は都道府県・県内経済圏・15 万人以上の市まで
- RESAS の画面は 2025 年 3 月に新しいシステムへ切り替わって続いている。API は 2025-03-24 に終わり、代わりに e-Stat の API が案内された
- jSTAT MAP は無料。到達圏（徒歩○分など）の中の年齢別人口・世帯数・事業所数を集計できる。保存とレポートの出力には無料の利用登録が要る

- **note**: 検索の総件数は QGIS 1,741・e-Stat 4,151・e-Stat API 348・コロプレス 191 で、ほとんど無料。有料の作り方の記事は 200〜5,000 円で散らばり、スキは 0〜4（上位 約 280 件 × 4 語の集計。stats47 自身の記事は比較の基準として別に分けた）。スキが 100 を超えた有料記事は 2 本だけで、「資料の根拠が弱い人へ。AI と公的統計で見つける 3 つの方法」（298 円・スキ 146）と、市区町村を採点した結果のデータ（500 円・スキ 121）。どちらも操作の手順ではなく、悩みか結果を売っている。都道府県 × 政府統計で最も重なる有料マガジン「データの地図帳」は 9,800 円で、購読数は分からない。note は購入数を公開していないので、スキは売上の代わりの指標でしかない
- **無料の公的講座**: 統計局の「社会人のためのデータサイエンス入門」は累計 23.1 万人で、e-Stat と jSTAT MAP を扱う。統計研究研修所は自治体職員向けに GIS・e-Stat の研修をオンラインで開いている。操作と基礎は無料でほぼ埋まっている
