### 核心診断 5 点

1. **収益化効率が極端に低い**。トラフィックは月間 GSC ~5,800 clicks で成長中だが、収益は月 ~¥500。レバーはトラフィックではなく「変換効率」にある。
2. **モバイル ranking の広告不在が最大の機械的損失**。クリックの 54% が ranking。モバイル読者は本文中広告ゼロ、最下部枠は遅延ロードで到達しない (実装: `RankingKeyPageClient.tsx:593-612`)。
3. **アフィは「枠はあるが計測も文脈もない」**。68枠あるが CTR 0.107%・CV 計測なし・収益 ¥0。
4. **検証なき deploy の恒常化**。改善施策 37 件中 effect/* 確定 0 件・overdue 23 件。何が効くか不明のまま施策を積んでいる。
5. **SNS/note/YouTube はリソース分散**。投資対効果ゼロ。SEO+blog が唯一機能しているチャネル。

## 2. 戦略の核心判断 (5 つ)

### 判断1: NSM を「PV」から「週次収益」へ転換

North Star Metric を **週次収益 (AdSense 確定額 + アフィ発生額)** に変更する。

先行指標 (leading indicators) 4 つ:

| 先行指標 | 現状 | 計測元 |
|---|---|---|
| GSC clicks / 週 | 1,349 (W23) | gsc history.csv |
| AdSense PV カバレッジ (AdSense PV ÷ GA4 PV) | ~17% | adsense / GA4 |
| RPM | ¥50 | adsense history.csv |
| affiliate_click / 週 | ~2 (28日で8) | `.claude/state/ads/ga4-affiliate-2026-06-07.json` |

### 判断2: 検証規律

- **同時 active 施策 WIP ≤ 5**。effect 未確定の系統に新施策を積まない。
- overdue 施策は週次レビューで強制的に effect 判定する (evidence-based-judgment 準拠)。
- effect 確定 0 件・overdue 23 件の現状を P0 でリセットする。

### 判断3: チャネル集中

| チャネル | 判断 |
|---|---|
| SEO + blog | **集中**。唯一機能しているチャネル |
| YouTube / TikTok | **凍結 (撤退)**。YT 登録31・実質停止、TikTok 計測データなし |
| Instagram / X | **自動化投稿のみ** (新規工数ゼロ) |
| note | 月1本のサイト誘導を基本。高単価テーマに限り SEO 衛星ページ実験を月2本まで許可。有料 note は P3 ゲート後 |

### 判断4: 広告は「枠を増やす」から「読者が見る位置に置く」へ

- モバイル本文中 in-content を主役にする。
- 低効率枠 (ranking 最下部 CTR 0%・viewability 36.6% の右サイドバー) は廃止/移設。
- CLS 予約 (`AdSenseAd.tsx:25-29`) と統一レイアウト規約 (`13_統一レイアウト設計`)、`nextjs-ssg-preservation` は遵守する。

### 判断5: アフィは文脈一致のみ

- 68 枠を厳選し、インテント一致に絞る。

| インテント | アフィ種別 | 配置先 |
|---|---|---|
| 地域 | ふるさと納税 / 引越し | `/areas/[code]` |
| 属性 (年収) | 転職 | 年収ランキング記事 |
| 属性 (教育) | 通信教育 | 教育統計記事 |

- **計測 (OAuth + GA4 custom dimension) が先、枠拡大は後**。

### `/blog/[slug]` 記事面デザイン方針

ニュースサイトの UI を複製せず、stats47 独自のデータ記事面として最適化する。方針は「本文の信頼感を上げる」「文脈一致広告を早く見せる」「関連記事で回遊を残す」の 3 点に絞る。

| 要素 | 方針 |
|---|---|
| 記事ヘッダー | `stats47 データジャーナル` / 日付 / タグ / シェアを整理し、ニュース記事として読める紙面にする |
| 本文 | 記事専用フォントスタック・行間・見出し余白を固定し、既存の Markdown / MDX / chart / ranking-table を維持する |
| モバイル | 右レールが本文下に落ちるため、文脈一致アフィリエイトを本文冒頭後に 1 枠だけ出す |
| デスクトップ | 右レールを sticky 化し、TOC・関連ランキング・関連記事・PR の順で表示する |
| 禁止 | 外部メディアのヘッダー、余白、色、ロゴ、UI パターンをそのまま複製しない |

### 2026-07-12 収益化判断（note・サイトアクセス活用）

#### 採用する二層モデル

1. **全体を薄く収益化**: ranking / blog の閲覧位置に合わせたAdSense。RPM ¥100以上を最初のゲートにする。
2. **高意図だけ深く収益化**: 年収・移住・住宅・教育の4領域に限定した文脈一致アフィリエイト。

noteは問い・物語・統計の読み方を提供し、全47都道府県データ、比較体験、広告・アフィ導線はstats47に残す。

| 領域 | noteの入口 | stats47の受け皿 | 収益接続 |
|---|---|---|---|
| 年収・仕事 | 同じ職種でも県で年収が違う | 職種別年収ranking / 賃金blog | 転職・キャリア相談 |
| 移住 | 移住前に見るべき統計 | 人口移動・住宅・医療・教育 | 引越し比較 |
| 住宅 | 年収と家賃のバランス | 家賃・地価・空き家・所得 | 不動産査定・住宅相談 |
| 教育・子育て | 子育てランキングの読み方 | 進学・教育費・医療・所得 | 通信教育・学習サービス |

#### 実行順

1. `affiliate_click`をpage type・vertical・placement別に安定計測する。
2. AdSense RPMを¥45から¥100以上へ改善する。枠数ではなく本文中のviewabilityを優先する。
3. 既存note上位記事のCTAを改善し、note→stats47→収益ページ到達を計測する。
4. 年収×転職を2記事、移住×引越しを2記事まで実験する。
5. 同一系統は4週間ごとに判定し、成果が出た文脈だけ横展開する。
6. 月¥10,000到達後に、有料note、業務テンプレート、整形済みデータパックを検討する。

#### 中長期の候補

- 行政・自治体向けの統計可視化、地域比較レポート、研修
- 出典・定義付きCSV、長期時系列、プレゼン用チャート等のデータパック
- 移住、教育、転職、地域サービスとのスポンサー企画

元の公的統計そのものではなく、整形、定義統一、更新、比較体験、業務時間短縮に対して課金する。
ランキング結果と広告・スポンサー判断は分離し、広告であることを明示する。

#### やらないこと

- 全rankingへ同じアフィリエイト広告を置く
- 47県分の薄い記事やnote記事を一括生成する
- noteとstats47へ同じ本文を複製する
- AdSenseと複数アフィ施策を同時変更して効果分離を失う
- 統計結果を商材に都合よく解釈する
- 現在の規模で会員制・有料noteを先に作る
- AdSense広告のクリックを促す表現や視覚誘導を置く

AdSenseはコンテンツ付近のviewability、レスポンシブ枠、速度を優先する。広告を主コンテンツと誤認させず、
独自分析と読みやすさを維持する。

外部根拠:

- [Google AdSense: Viewability best practices](https://support.google.com/adsense/answer/6219980)
- [Google AdSense: Program policies](https://support.google.com/adsense/answer/48182)
- [Google Search Central: Creating helpful, reliable, people-first content](https://developers.google.com/search/docs/fundamentals/creating-helpful-content)
