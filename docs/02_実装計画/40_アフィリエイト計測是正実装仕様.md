# アフィリエイト計測是正 実装仕様

> **この文書の役割**: 別 PC / 別セッションが**文脈ゼロから実行できる手順書**。
> 診断の根拠も併記してあるので、原因を再調査せずそのまま着手してよい。
> TODO の真実源は `docs/todo/01_改善バックログ.md` の `AFF-SCOUT-PIPE-01`。本書はその実装詳細。

## 1. なぜやるか

アフィリエイト広告の効果測定が**一度も機能していなかった**。2026-07-27 の実測で独立した 3 つの欠陥が確定した。

在庫（A8 提携 149 件・配信 87 件）と配線（確定 EPC による priority）は動いているが、
「どの広告が効いたか」を知る手段が無いため**開ループ**になっている。広告を増やしても学習できない。
**本作業の目的は在庫を増やすことではなく、測れる状態に戻すこと。**

### 診断の根拠（再調査不要）

**欠陥① `ad_impression` が GA4 予約イベント名と衝突**

`AdImpressionTracker.tsx` が送る `ad_impression` は GA4 の reserved event name
（[公式 Reserved event names](https://support.google.com/analytics/answer/13316687)・アクセス 2026-07-27）。

対照実験（GA4 28 日実測）:

| イベント | 機構 | 予約名 | 実測 |
|---|---|---|---|
| `home_featured_impression` | IntersectionObserver 50%×1秒 | いいえ | **1,035 件 届く** |
| `ad_impression`（自前） | 同一機構 | **はい** | **0 件** |
| `affiliate_click` | クリック | いいえ | 9 件（届く） |
| `file_download` | クリック | はい | 273 件（`ranking_key` 内訳あり・届く） |

`ad_impression` の 12,992 件は `adSourceName` が全件 `"Google AdSense account (pub-7995274743017484)"` で
**総数と完全一致**し、自前分の残余はゼロ。**CTR の分母が存在しない**。

- 同じ IO 機構で予約名でない `home_featured_impression` が 1,035 件届くので、**機構は正常**。
- 同じ予約名の `file_download` は届くので「予約名だから必ず破棄」ではない。内部機構の断定は不要
  （改名すれば衝突は解消するので打ち手が変わらない）。
- **過去に報告された「CTR 0.079%」はアフィリエイトの click を AdSense の impression で割った無意味な値。**
  参照してはならない。

**欠陥② `affiliate_vertical` にページ由来の文字列が入っている**

`events.ts` の `trackAffiliateClick` は `affiliate_vertical: params.vertical ?? params.category` だが、
`tracked-affiliate-link.tsx` が `vertical` を渡していないため `category` にフォールバックする。
その `category` に呼び出し元が入れているのは 10 軸ではない:

| 呼び出し元 | `category` / `trackingCategory` に渡している値 |
|---|---|
| `app/category/[categoryKey]/page.tsx` | `` `category-${categoryKey}` `` |
| `app/survey/[surveyKey]/page.tsx` | `` `survey-${surveyKey}` `` |
| `app/tag/[tagKey]/page.tsx` | `` `tag-${tagKey}` `` |
| `RankingPageNativeAffiliateSection.tsx` | `` `ranking-${categoryKey ?? "general"}` `` |
| `ThemePageLayout.tsx` | `` `theme-${theme.themeKey}` `` |
| `BannerAd.tsx` | 既定 `"other"` |
| `AffiliateTextAdList.tsx` | `affiliateCategory ?? "other"` |

さらに `ResolvedAffiliateBanner` 型が **`vertical` を持たない**ため、正しい軸を送ることが構造的に不可能。
実測クリック 9 件の内訳が `other` / `economy` だけだったのはこれ。**改名しても軸別分析はできない。**

**欠陥③ `NativeAffiliateRow` にインプレッション計測が無い**

`NativeAffiliateRow.tsx` は `TrackedAffiliateLink`（クリック）のみで `AdImpressionTracker` を使わない。
**category / tag / survey / theme / ranking 末尾の 5 ページ種が設計上インプレッションを送らない。**

### 過去に 3 回誤診した記録（同じ轍を踏まないため）

| 回 | 誤った断定 | 否定した証拠 |
|---|---|---|
| 1 | GA4 の custom dimension が未登録 | 画面で 2026-07-06 登録済。28 日窓に登録前が混在していただけ |
| 2 | 予約名だから GA4 が破棄している | 同じ予約名の `file_download` が 273 件届いている |
| 3 | `firedRef` を guard より前に立てる順序バグが主因 | 同機構の `home_featured_impression` が 1,035 件届いている |

**教訓**: 因果を主張する前に競合仮説を否定する対照実験を 1 つ通す。rules 等の正典への書き込みは検証後。
（`.claude/rules/evidence-based-judgment.md`）

## 4. 実装手順

### Phase 1 — イベント名を `affiliate_impression` に改名

`affiliate_click` が予約名でなく正常動作しているので `affiliate_*` 名前空間は安全。
`affiliate_impression` はリポジトリ内でイベント名として未使用。**旧名との並行送信はしない**
（AdSense 側の汚染が二重になるだけ）。

**1-a. 送信側**（`apps/web/src/features/ads/components/AdImpressionTracker.tsx`・49 行付近）

```diff
-              window.gtag("event", "ad_impression", {
+              window.gtag("event", "affiliate_impression", {
```

**1-b. 集計側**（`.claude/scripts/ads/fetch-affiliate-ga4.cjs`）

```diff
-const EVENTS = ["ad_impression", "affiliate_click"];
+const EVENTS = ["affiliate_impression", "affiliate_click"];
```
```diff
-    if (event === "ad_impression") cur.impressions += count;
+    if (event === "affiliate_impression") cur.impressions += count;
```

**1-c. 参照追従**（放置すると次のエージェントが誤認する）

```bash
grep -rn "ad_impression" --exclude-dir=node_modules --exclude-dir=.git --exclude-dir=.local .
```

対象:
- `.claude/skills/analytics/affiliate-improvement/SKILL.md`（frontmatter description / 15 / 92 / 118 行。
  **118 行の CTR 算出式 `affiliate_click / ad_impression` を必ず直す**）
- `.claude/skills/ads/manage-affiliate-experiment/reference/creative-ab-testing.md`（17 / 41 行）
- `.claude/scripts/ads/audit-affiliate-inventory.ts`（14 行・コメント）
- `.github/workflows/affiliate-ga4-weekly.yml`（3 行・コメント）
- `.claude/rules/affiliate-ads-standards.md`（112 / 243 行）
- `.claude/memory/project_ga4_setup.md`（17 行・カスタムイベント一覧）

**GA4 側の再登録は不要。** カスタムディメンションは**パラメータ単位**で登録されており
（`affiliate_vertical` 等 6 個が 2026-07-06 登録済）、イベント名を変えても新イベントで自動的に解決される。

**改名日 2026-07-XX を `analytics-event-standards.md` に記録する**（GA4 履歴の分断点。
これ以前の `ad_impression` は AdSense 由来のみで自前分と混同してはならない）。

### Phase 2 — 真の意図軸を `affiliate_vertical` に流す

既存の受け口（`trackAffiliateClick` の `vertical` パラメータ）を活かす。**新しい仕組みは作らない。**

**2-a. 型に `vertical` を追加**（`apps/web/src/features/ads/services/resolve-affiliate-ad.ts`）

```diff
 export interface ResolvedAffiliateBanner {
   id: string;
   title: string;
   href: string;
   imageUrl: string;
+  /** 広告意図軸 (10 vertical)。GA4 affiliate_vertical の正しい値 */
+  vertical: AffiliateVertical;
   trackingPixelUrl: string | null;
   width: number;
   height: number;
 }
```

マッピング（同ファイル 80 行付近の `return { id: b.id, ... }`）で `vertical: adVertical(b)` を透過させる。
`adVertical` は `apps/web/src/features/ads/constants/affiliate-category.ts` の既存ヘルパー
（`ad.vertical ?? CATEGORY_AFFILIATE_MAP[ad.categoryKey]`）を使う。**新規に写像を書かない。**
`ResolvedAffiliateAd`（テキスト広告）と `ResolvedAffiliateVariant` も同様に追加する。

**2-b. クリック側**（`apps/web/src/features/ads/components/tracked-affiliate-link.tsx`）

props に `vertical?: AffiliateVertical` を追加し、`trackAffiliateClick` へ渡す:

```diff
-        trackAffiliateClick({ category, label, position, adId, experimentId, variantId, creativeSize })
+        trackAffiliateClick({ category, label, position, vertical, adId, experimentId, variantId, creativeSize })
```

**2-c. インプレッション側**（`AdImpressionTracker.tsx`）

props に `vertical?: string` を追加し、送信を次のようにする:

```diff
                 affiliate_category: category,
-                // 広告意図軸 (10 vertical) の canonical dimension。category に vertical 値が流れる。
-                affiliate_vertical: category,
+                // 広告意図軸 (10 vertical)。category はページ文脈の文字列なので流用しない
+                // (流用すると affiliate_vertical が category-population 等で汚染される)。
+                ...(vertical ? { affiliate_vertical: vertical } : {}),
```

**`vertical ?? category` にしないこと。** 軸が無い枠は送らない方が汚染より良い。
`affiliate_category` は従来どおりページ文脈の文字列を入れる（用途が違うので分離を維持）。
`useEffect` の依存配列に `vertical` を追加する。

**2-d. 呼び出し元で `banner.vertical` を渡す**

`BannerAd.tsx` / `AffiliateAdSlot.tsx` / `AffiliateTextAdList.tsx` / `VariantAdSlot.tsx` /
`NativeAffiliateRow.tsx` / `AreaBannerAd.tsx`。**`AffiliateVertical` 型で拘束し文字列を直書きしない。**

**注意**: `events.ts` の `trackAffiliateClick` にある `params.vertical ?? params.category` の
フォールバックは、Phase 2 完了後は汚染源になる。**`params.vertical` のみを条件付きで送る形に変える**
（`AdImpressionTracker` と同じ扱いに揃える）。

### Phase 3 — ネイティブ枠に計測を追加

`NativeAffiliateRow.tsx` の各 `TrackedAffiliateLink` を `AdImpressionTracker` で囲む。
`AffiliateTextAdList.tsx`（37-81 行）が既に同じ形をしているので**それを手本にする**。

渡す値: `category={trackingCategory}` / `label={b.title}` / `position={position}` /
`adId={b.id}` / `vertical={b.vertical}`。

### Phase 5 — 検証

**5-a. デプロイ前（静的）**

```bash
npx tsc --noEmit -p apps/web/tsconfig.json
node --test .claude/scripts/ads/__tests__/
grep -rn "ad_impression" --exclude-dir=node_modules --exclude-dir=.git --exclude-dir=.local .   # 残存 0
```

**5-b. ローカル目視（要 実ブラウザ）**

```bash
npm run dev:web    # ルートの npm run dev は使わない (23 パッケージ起動で遅い)
```

dev は GA 測定 ID 未設定で `window.gtag` が **undefined**（`GoogleAnalytics.tsx` が
`NEXT_PUBLIC_GA_MEASUREMENT_ID` 無しなら null を返す）。そのため DevTools コンソールで
スパイを仕込んでから広告を画面内に入れる:

```js
window.__spy = [];
window.gtag = function(){ window.__spy.push(Array.from(arguments)); };
// 広告が 50% 以上・1 秒以上見える位置までスクロール → 2 秒待って
window.__spy.filter(a => a[1] === "affiliate_impression");
```

確認項目:
- `affiliate_impression` が **1 広告あたり 1 回だけ**（レール二重描画による二重計上が無い）
- `affiliate_vertical` が **10 軸の値**（`category-population` 等になっていない）
- `affiliate_category` はページ文脈の文字列のまま

**★Claude Code の Browser ペインでは検証できない**: ビューポートが 0×0 になり
IntersectionObserver が成立しない（2026-07-27 実測）。実ブラウザで行う。
また `https://stats47.jp` はペインのポリシーで開けない。

**5-c. デプロイ後 2〜3 日（要 GA4 鍵）**

```bash
node .claude/scripts/ads/fetch-affiliate-ga4.cjs 3
```

期待: `affiliate_vertical` が `(not set)` ではなく energy / labor 等で行が分かれ、impressions が計上される。

AdSense と分離できた確証として、`affiliate_impression × adSourceName` が `(not set)`
（= AdSense 由来でない）になることも確認する。`fetch-affiliate-ga4.cjs` は dimension 固定なので、
確認は使い捨てスクリプト（`googleapis` を使うため `NODE_PATH=<repo>/node_modules` を付ける）で行う。
