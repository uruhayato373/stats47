# 地理スコープ分離・日本統計基盤実装仕様

## 0. 文書の位置づけ

本書は、stats47の都道府県比較と日本全国の統計を分離し、将来の世界統計へ拡張できる境界を作るための
Claude Code向け実装仕様である。実装契約は本書、恒久的なページ責務は
`docs/01_技術設計/03_情報設計.md` を正典とする。

本書の対象はローカル実装、テスト、dry-run、read-only調査までである。remote R2 write、git push、PR、
本番deploy、sitemap submitは、各差分と対象キーを提示した後にオーナーが別途承認する。

## 1. ゴール

次の三つを別の主語・URL・データ契約として扱う。

1. `prefecture-set` / `prefecture`: 47都道府県の比較と個別県。既存 `/themes/*`、`/ranking/*`、`/areas/*`。
2. `japan`: 公式全国値または再現可能な全国集計。新規 `/japan`、`/japan/[themeSlug]`。
3. `world`: 同一定義の国別比較。将来の `/world`、`/world/[themeSlug]`。

利用者が次を誤認しない状態を成功とする。

- 47県の単純平均を日本全国の値として読まない。
- 都道府県固有指標を全国選択した結果、ゼロや別地域の値が表示されない。
- `/themes/*` と `/japan/*` が同じコンテンツのURL違いにならない。
- 日本統計のために既存の47県ランキングデータ契約を壊さない。

## 2. 現状の証拠

| 現状 | コード上の根拠 | 問題 |
| --- | --- | --- |
| theme未選択は `null` だが取得時に `00000` へ変換 | `ThemeMetricsDashboard.tsx`、`MetricFocusCharts.tsx` | UI状態とe-Stat全国コードが同一視される |
| 全国行が無いと47県平均へフォールバック | `aggregate-metric-timeseries.ts`、`select-national-series.ts` | 加重されない率、人口、件数を全国値にできない |
| KPI初期値は `nationalValue ?? nationalAverage` | `ThemeMetricsDashboard.tsx` | themeの主役が平均値になり、比較面の問いとずれる |
| R2 ranking/statsは全国行を保持しない | `load-theme-data.ts`、`page-data-batch.ts` | 本番表示で公式全国値を安定して再利用できない |
| `shapeForPrefecture` は5桁県コードだけを残す | `packages/data-configs/scripts/page-data-batch.ts` | 取得レスポンスに `00000` があっても保存時に消える |
| ThemeCatalogの一部chartはruntime e-Statを読む | `fetch-db-chart-data.ts` など | 全国値取得経路がchart種別ごとに分散する |
| `/japan`、`/world` routeは未実装 | `apps/web/src/app`、`url-policy.ts`、`sitemap.ts` | 日本・世界を別コンテンツとして表現する入口がない |

この基盤は `CROSS-PAGE-DATA-SSOT-01` のR2参照統一と競合させない。全国値readerは同項目の
`MetricConfig → 取得・変換 → R2 → consumer` を再利用し、web runtimeからe-Statを直接呼ぶ新経路を作らない。

## 3. 採用する用語と型

### 3.1 UI状態

Theme Dashboardの状態は、全国コードではなく明示的な判別可能unionにする。

```ts
type PrefectureView =
  | { scope: "prefecture-set" }
  | { scope: "prefecture"; prefectureCode: string; prefectureName: string };
```

- `prefecture-set` の表示名は「47都道府県」。URLはcanonical `/themes/<slug>`。
- `prefecture` は `?pref=<5桁コード>`。既存の共有URLを維持する。
- `00000` をThemePrefectureContextへ格納しない。
- `/japan/*` は別のcontext、reader、route loaderを持ち、ThemePrefectureContextへ追加しない。

### 3.2 metricの地理対応

MetricConfigに自由記述の真偽値を増やさず、全国値の由来を判別できる型付きcontractを追加する。
正確な配置は既存exportと依存方向を読んで決めるが、意味は次を満たす。

```ts
type JapanAvailability =
  | { status: "official" }
  | { status: "derived-additive"; recipeKey: string }
  | { status: "derived-ratio"; recipeKey: string }
  | { status: "unsupported"; reason: string }
  | { status: "unknown" };
```

`unknown` は移行中だけ許し、新しいactive Japan catalogへは入れない。`unsupported` は欠陥ではなく、
「県内大学進学率」のように日本全体へ同じ定義を適用できないことを表す。

## 4. 全国値の採用規則

優先順位と禁止事項を決定的にする。

1. **official**: e-Statのarea `00000`、または政府・国際機関の公表全国値を使う。
2. **derived-additive**: 母集団が全国を漏れなく覆い、意味が加算可能な実数だけを合計する。
3. **derived-ratioは別recipe**: 率、密度、1人当たり値は、全国の分子と分母が同じ年・定義で揃う場合だけ再計算する。
4. 47県の単純平均、中央値、代表県、欠測を0へ変換した値を全国値にしない。
5. 全国行と県値の年度、単位、調査定義が一致しない場合は `unknown` のまま停止する。

全国値の由来はR2 artifactへ `sourceMode` として保存し、UIが推測しない。全国行の有無を
実行時の「データが返ったか」だけで判断せず、catalogとschema validationで公開可否を決める。

## 5. R2データ契約

既存 `app/stats/<metricKey>/values.json` は47都道府県行のまま維持する。全国値を混在させず、次の
独立namespaceを追加する。

```text
app/japan/<metricKey>/series.json
```

最小schema:

```ts
type JapanSeriesArtifact = {
  schemaVersion: 1;
  metricKey: string;
  geographyScope: "japan";
  sourceMode: "official" | "derived-additive" | "derived-ratio";
  rows: Array<{ yearCode: string; yearName: string; value: number; unit: string }>;
  meta: {
    generatedAt: string;
    configHash: string;
    recipeHash: string;
    sourceId: string;
  };
};
```

- `rank`、47県配列、UI文言を保存しない。
- `yearCode` は既存 `extractYearCode` と同じ4桁正規化を使う。
- unit変換は既存unit semanticsに従い、consumer側で再変換しない。
- reader、writer、schema、shape gate、provenance、retention、監査対象を同じwork packageで追加する。
- local artifactは `.local/r2/app/japan/...`。remote R2への反映は別承認とする。

将来のworldは `app/world/<metricKey>/values.json` とし、ISO国コードとsource provenanceを持たせる。
Phase 1ではworld artifactを生成しない。

## 6. データ再取得の判断

### 結論

日本ページのpilotには選択的な再取得が必要になる可能性が高い。ただし、全metricの再取得はしない。
現在の取得処理はe-Statレスポンス内の全国行を保存しないため、既存R2だけでは公式全国値の有無を判定できない。

### 監査表

WP0でThemeCatalogが依存するmetricを列挙し、次の列を持つ機械可読inventoryを生成する。

| 列 | 内容 |
| --- | --- |
| `themeSlug` / `metricKey` | 利用元とmetric |
| `statsDataId` / recipe | 取得元 |
| `unit` / `years` | 比較条件 |
| `japanStatus` | official / derived-additive / unsupported / unknown |
| `nationalRowObserved` | read-onlyメタ・代表値で `00000` を確認したか |
| `reason` | 採否根拠または停止理由 |
| `needsRefetch` | 全国artifact生成に再取得が必要か |

inventoryは監査結果の全文をdocsへ置かず、型付きcatalogまたは `.claude/state/metrics/` の機械JSONとして扱う。
恒久判断はMetricConfig側へ反映する。

### 再取得手順

1. `collectThemeDataDependenciesWithProvenance` から対象metricを決定し、手書き一覧を作らない。
2. `education-culture` のmetric 5件とchart 5件（e-Stat系列12件）をpilotにする。
3. 各 `statsDataId` のmetaをread-onlyで確認し、area dimensionに `00000` があるか、cat/time/unitが県値と一致するかを見る。
4. 代表1metricを `--dry-run` で取得し、全国行1系列と既存47県行が両方保持されるfixtureを作る。
5. 既存 `page-data-batch.ts` のfetch・recipe・year・unit処理を共通化し、`--scope japan` または専用の薄いentrypointから再利用する。
6. pilotだけをlocal R2へ生成し、schema、値分布、ゼロ率、年次連続性、既存県artifact非変更を検証する。
7. inventoryで `needsRefetch=true` のactive Japan metricだけをbatch対象にする。
8. remote反映前に対象key、ファイル数、hash、追加・更新・削除件数をplanとして提示する。承認なしにpushしない。

e-Stat APIでは `cdArea` や `cdTimeFrom/To` を送らず、全地域・全年を取得してメモリ内で絞る既存規約を守る。
大きいtable、meta不一致、取得0件、全国値0への急変ではリトライで押し切らず停止する。

## 7. Work package

### WP0 — read-only監査と意味の固定

1. `git status --short --branch` と対象fileのdirty状態を確認する。
2. `CLAUDE.md`、本書、関連SSOT、`CROSS-PAGE-DATA-SSOT-01` の残工程を読む。
3. ThemeCatalogの依存metricを決定的に列挙し、全国対応inventoryを生成する。
4. `education-culture` の各KPI/chartについて、未選択時の表示、取得request、0/空、全国行の有無を記録する。
5. 既存の `CPI-NATIONAL-EMPTY-STATE-01`、`NATIONAL-AVG-FALLBACK-LABEL-01`、
   `HEALTH-CHECKUP-RATE-RETIRE-01` をinventoryへ紐付ける。

Gate: inventoryの全行にstatusか明示的なunknown理由があり、推測値がない。コードとR2へのwriteはまだ行わない。

### WP1 — geography contractと回帰test

1. `PrefectureView` と `JapanAvailability` を、既存依存方向を壊さない最小packageへ追加する。
2. themeのno-selectionを `prefecture-set` とし、`00000` 生成をcontextから除く。
3. 全国値resolverをpure functionにし、単純平均、率の暗黙集計、unsupported→0を拒否するtestを先に追加する。
4. legacy `null = 全国`、`areaCode = selected ?? "00000"`、`source = average` のconsumerを一覧化し、件数が増えないratchetを置く。

Gate: test fixtureで人口、率、県固有指標の三種類を区別し、誤った全国値を作れない。

### WP2 — Theme Dashboardを47都道府県比較へ修正

1. セレクタ既定値と戻る導線を「47都道府県」へ変更する。
2. 未選択時の平均KPIカードを除去し、ranking、分布、地図、または県選択案内を主役にする。
3. 県が必要なtime-series/chartは未選択時にfetchせず、画面全体で一つの簡潔な選択案内を表示する。
4. 県選択後はその県の値・順位・推移を表示し、必要な場合だけ「都道府県平均」を比較線として出す。
5. `useFlowFocusPrefecture` の代表県fallbackなど、未選択を別県の実値で埋める経路を廃止または明示的なdemoへ分離する。
6. `/themes/local-finance/cities` などbespoke routeの意味を変えない。

Gate: theme既定画面に「全国」「全国平均」「（平均）」がなく、県内大学進学率が0系列を表示しない。

### WP3 — 日本全国artifactの生成とreader

1. `JapanSeriesArtifact` のschema、parser、reader、writer、fixture、shape gateを追加する。
2. page-data-batchのfetch/shapeを共有可能なpure coreへ切り出し、県artifactのbyte出力を回帰testで固定する。
3. `--scope japan --dry-run` 相当を追加し、対象metric以外を書かない。
4. official / derived-additive / derived-ratioを別分岐にし、recipeなしのderivedを拒否する。
5. local R2のeducation pilotを生成し、公式値、年度、単位、sourceModeを一次資料と照合する。

Gate: Japan readerがlocal R2だけを読み、web runtimeからe-Statを呼ばない。既存 `app/stats` 差分は0。

### WP4 — `/japan` pilot

1. git TSにJapan catalogを追加し、active themeとmetricを明示する。最初は `education-culture` のうち
   official全国値を確認できたmetricだけを採用する。
2. `/japan` hubと `/japan/[themeSlug]` を実装する。未公開slugは404またはnoindexの既存URL policyに従う。
3. 日本ページは全国時系列、構成、出典を中心にし、47県rankingやtheme本文を複製しない。
4. page_componentsを使う場合はexport/verifyの `PAGE_TYPES` に `japan` を追加し、git sourceとR2 snapshotを同時に実装する。
5. metadata、canonical、breadcrumb、structured data、empty/error stateを追加する。

Gate: `/japan` とpilot詳細がlocalhostで表示され、公式全国値だけを描画する。値が無いmetricは非表示ではなくcatalog非採用となる。

### WP5 — URL、sitemap、ナビゲーション

1. `UrlPolicy`へknown/active Japan slugを追加し、page、middleware、sitemapが同じ集合を使う。
2. sitemap segmentは末尾追加またはstaticへのpilot追加とし、既存segment IDを変えない。
3. header/homeからの入口はpilotの内容量と公開承認後に追加する。都道府県入口の優先度を下げない。
4. `/themes/*`、`/japan/*` のtitle/description/canonicalを異なる検索意図に合わせる。
5. GA4の既存イベント規約に沿い、theme→japan、japan→themeの内部遷移を計測する。

Gate: route policy、sitemap、canonicalの対象testがgreenで、重複URLとsoft 404がない。

### WP6 — 全themeへの展開

1. pilotで確定したinventoryとgeneratorを全ThemeCatalog依存へ実行する。
2. `official` を優先してJapan catalogへ追加し、derivedはrecipe reviewを通ったものだけ採用する。
3. unsupportedを無理に埋めず、日本ページのテーマごとの最低コンテンツ基準を満たすslugだけactiveにする。
4. remote R2 write planを生成し、承認後に一度だけ反映する。
5. localとremoteの同じauditでschema、値、年、単位、hashを確認する。

Gate: active Japan metricにunknown/平均fallback/0埋めがなく、Japan catalogとR2 artifactが全件一致する。

### WP7 — world境界とrelease準備

1. `world` のroute/catalog/artifact contractを型と文書で確定するが、国際データ取得は別backlogへ分離する。
2. OECD、World Bank、UN等の出典候補は、定義・更新頻度・ライセンス・日本行の有無をread-onlyで評価する。
3. 全対象test、全package type-check、web full build、docs gate、localhost smokeを実行する。
4. commitをwork package単位に分け、R2 push、git push、PR、deployの実行計画を提示する。

Gate: world未実装がtheme/japanへfallbackせず、release差分とrollback対象が明確である。

| 層 | 必須検証 |

| config | `validate:years`、`validate:config`、ThemeCatalog validator、Japan catalog validator |

テストは現在の欠陥を再現する陰性対照を含める。

- 総人口の47県平均が日本人口として採用されない。
- 率の47県平均が全国率として採用されない。
- 県内大学進学率をJapan catalogへ登録できない。
- 未選択時に県限定actionが `00000` で呼ばれない。
- 全国artifactがないmetricを0で描画しない。
- 既存47県values artifactのshapeと値が変わらない。

## 10. Git・worktree・commit

- 現在のworking treeには本件と無関係な変更があり得る。開始時に対象pathのdirtyを確認する。
- standalone Claude Codeは同じworking treeの他writerと同時実行しない。可能なら `codex/` または適切なfeature branchの
  別worktreeを作り、現在差分を移動・削除しない。
- `git add -A` を使わず、各work packageが所有するpathだけをstageする。
- 他者の差分を `git restore`、`git checkout --`、resetで消さない。
- commitは最低でも contract、theme UI、Japan data、Japan route、SEO/releaseの境界で分ける。
- remote pushはユーザー指示がある場合だけ行う。deployは別指示まで行わない。

## 11. 停止条件

次の場合は推測・fallback・allowlist拡大をせず停止し、対象metric、一次証拠、影響、選択肢を報告する。

- 全国行の定義、年度、単位、母集団が県値と一致しない。
- 率や密度の分子・分母を再現できない。
- active Japan metricに0、空、極端な不連続、古い年しかない状態を検出する。
- source recipeを共通化すると既存県artifactのbyte出力が変わる。
- route追加が既存canonical、middleware、sitemapと不一致になる。
- 対象fileに未コミットの競合変更がある。
- remote R2 write、git push、PR、deploy、外部APIの課金を伴う操作が必要になる。

## 12. ロールバック

- themeのstate移行は互換adapterを一時的に持てるが、legacy件数をratchetで減らす。
- Japan namespaceは既存 `app/stats` と独立させ、削除で47県画面へ影響しない構成にする。
- Japan routeはcatalog `active` をfalseにすることでsitemapと公開対象から外せるようにする。
- schema変更はversionを上げ、readerとwriterを同じwork packageで変更する。
- rollbackにユーザーの既存dirty差分を巻き込まない。
