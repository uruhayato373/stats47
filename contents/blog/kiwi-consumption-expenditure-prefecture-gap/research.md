# 調査材料 (NotebookLM・背景の説明だけに使う)

日本の食料支出の地域差は、食文化・気候・産地のどの要因で説明されますか。品目の例と出典名を挙げてください
日本の食料支出に見られる地域差は、主に食文化（伝統的嗜好・習慣）、気候（気温・降雪量・保存食需要）、産地（地産地消・流通環境）の3つの要因によって説明されます。各要因における具体的な品目の例と出典名は以下の通りです。
- --
### 1. 食文化要因（歴史的な味付け・東西の嗜好差）
歴史的に培われた食習慣や、地域ごとの嗜好の違いが支出額に直接反映されます。
- 納豆
- 説明: 関東や東北で消費量が非常に高い一方、西日本（特に和歌山県や大阪府、徳島県など）では敬遠される傾向があり、典型的な東高西低の支出パターンを示します [1, 2]。
- タイとマグロ
- 説明: 鮮魚の嗜好において、東日本ではマグロの消費割合が高く、西日本ではタイ（佐賀県や長崎県、福岡県など）の購入量が多くなる地域性があります [3]。
- コーヒー・パン
- 説明: 京都市など関西の都市部では喫茶店文化や洋食文化が深く浸透しており、コーヒーやパンの年間消費量が全国トップクラスとなっています [4, 5]。
- --
### 2. 気候要因（気温・降雪・冬場の生活様式）
気温の低さや降雪量、日照時間などの自然環境が、保存食や体を温める食品の消費を促します。
- インスタントラーメン
- 説明: 青森県や秋田県、新潟県などの積雪量が多い地域では、冬場の保存食や温かい食事として愛用されており、年間降雪量と消費量に強い正の相関が見られます [6]。
- 食塩・味噌
- 説明: 東北や北日本の雪国では、冬場の保存食文化や濃い味付けが定着しているため、食塩や味噌の消費量が高くなる傾向があります [7, 8]。
- --
### 3. 産地要因（地産地消・生産地での手軽な入手）
農産物や水産物の主要産地・収穫地であるかどうか（地産地消）が、消費量やテイクアウト・家庭内での購入額に影響を与えます。
- きゅうり
- 説明: 福島県や群馬県、山形県など、きゅうりの生産量が多い東北・北関東地域において生鮮きゅうりの消費量が高く、生産量と消費量の間に高い相関が見られます [9]。
- りんご
- かき（貝）
- 緑茶
- ぎょうざ
