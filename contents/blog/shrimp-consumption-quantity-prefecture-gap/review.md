## 評価サマリ
前回の MAJOR 7件はすべて解消しました。2015〜2025年の時系列図(data/shrimp-consumption-quantity-prefecture-gap-timeseries.json)と archetype: C の宣言が加わり、題が問う「1年での入れ替わり」に実データで答えています。中位では10位1,440gから35位の東京都1,087gまでの353gに25の順位が並んでいるため、小さな値の変化でも順位が大きく動きます。本文はこの説明に加え、前年首位の熊本県が1,005g減ったことを示しています。この減り幅は47都道府県の変化の中央値141gの約7倍です。新しく加わった数値は、R2 の app/ranking/shrimp-consumption-quantity/values.json(19年分)と照合しました。首位7県、連続首位1回、前年首位が翌年に落ちた順位の最大15位、順位が10以上動いた20県、上位10県の共通3県と下位10県の共通6県、茨城県が5年連続46位、岡山県の2024年28位は、すべて一致しました。quality-gate の blockers は0件です。残る指摘は、値の幅の言い換えの誤りと、下位が動きにくい理由の説明が粗い点で、どちらも数語の修正で直せます。

## 指摘
- [MAJOR][型:value] 「下位は動きにくく…」の節で、茨城県の値を「911グラム、822グラム、741グラム、826グラム、809グラムで、毎年700グラムから900グラムの幅に収まっています」と書いています。しかし、同じ文に並ぶ2021年の911グラムが900を超えています。「741グラムから911グラムの幅」と直してください。
- [MINOR][型:causal] 同じ節の「下位の県は、値の幅が小さい分、順位も動きにくくなっています」は、本文の群馬県の例と合いません。群馬県は707g、961g、634gと年に254〜327g動いており、これは変化の中央値141gの2倍を超えます。それでも下位に残るのは、値の振れが小さいからではありません。下位の値がまばらで、次点の県から離れているためです(2025年は茨城県から175g離れています)。中位で順位が密集していることを示した前の節とも対になるので、「下位は県どうしの値の間隔が広いため、値が動いても順位が変わりにくい」と書き換えてください。
- [MINOR][型:source] 本文で使っている47都道府県分の複数年の統計(中央値141g、20県、上位10県・下位10県の共通数、首位7県、各県の過去の順位)は、記事の data/ の JSON にはありません。data/ にあるのは4県の値だけで、ほかの数値は timeseries.source.json の restore コマンドで R2 から取り直さないと確かめられません。再検証できるように、計算に使った2024年・2025年の47県の値と順位、2015年以降の各年の首位を data/ に派生 JSON として置いておくと安全です。
- [MINOR][型:chart-text] 時系列図(timeseries.svg)の直後に source-link がありません。地図の図も同様です(前回から変更なし)。ランキングページへの source-link を各図の直下に揃えてください。
- [MINOR][型:structure] TIP の「前年の5位以内から1県も残っていない一方で、値の動きは数百グラムの範囲に収まっています」は、主語が2025年の上位5県(+74〜+538g)なら正しい内容です。しかし直前で触れた2024年の上位5県には、1,005g減った熊本県が含まれます。このため、読者には「全員が数百グラム以内」と読めます。「2025年の上位5県の前年からの増加は74〜538グラムで」のように、対象を明記してください。

## 判定理由
前回の MAJOR 7件(題の約束、前年データの欠落、単年データからの因果の言い過ぎ、上位・下位の節の読み上げ、地図の節の重複、地域表記、型の必須視点)は、いずれも解消しました。新しく加わった時系列の数値と順位は R2 の values.json と全件一致し、定義の取り違え(対象世帯、年、名目と実質)もありません。BLOCK は0件です。茨城県の幅の言い換え(900g と 911g の矛盾)は事実の誤りなので、公開前に直すことを強く勧めます。ただし値そのものは正しく、記事の結論は変わりません。残りは MINOR です。読者価値の点では、上位は動きやすく下位は動きにくいという非対称を11年分のデータで示しており、参照型・C型としての約束を満たしています。以上から PASS とします。
