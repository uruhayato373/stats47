## 指摘
- [MINOR][型:structure] frontmatter は `archetype: A` に変えましたが、新しい中心は5年分の順位の安定と変動で、A 型の必須視点(地理・産業構造で上位と下位を説明する)ではありません。どちらかというと C 型(時系列推移と変化の地理的偏り。首都圏だけが動く)に近い内容です。宣言を C に寄せるか、A のままにするなら宣言と本文の主眼が少しずれていることを認識してください。公開を止める問題ではありません。
- [MINOR][型:chart-text] 5年分の順位の推移は記事の主な発見なのに、図がありません。`data/water-sewer-rank-history.json` と `.source.json` は追加されていますが、対応する SVG がなく、本文からも参照されていません。順位の推移を示す折れ線(上位・下位・首都圏の代表県)を1枚足すと、「固定と変動」が一目で伝わります。図を足さないなら、使っていない data JSON を外す判断もありえます。
- [MINOR][型:causal] 「首都圏の県の順位が大きく動くのは、県庁所在市の標本が小さく…」という[仮説]は、家計調査では東京都区部などの大都市の標本が他の県庁所在市より大きく設計されていることと噛み合わない可能性があります。仮説として明示し、検証できないことも書いているので BLOCK にはしません。ただし、標本規模を根拠にするなら家計調査の標本設計(市ごとの調査世帯数)を確かめてから書くか、「標本の世帯構成の入れ替わり」だけに絞ることを勧めます。
