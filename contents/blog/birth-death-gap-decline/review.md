## 指摘
- [MAJOR][型:title-promise] タイトル・seoTitle・description・導入の結論が本文の根拠を超えています。導入は「その答えは『結婚 → 子ども』という連鎖が大都市で機能しなくなっていることを示しています」と答えを言い切り、seoTitle と description は「少子化の真因を都道府県データで解明」と書いています。しかし東京の逆説の節では原因を [仮説] とし、「この記事のデータだけでは原因を特定できません」と自分で書いています。約束と本文が食い違うため、seoTitle・description の「真因を解明」を「東京の逆説を都道府県データで読む」程度に弱め、導入の断定も「示唆している」に直してください。「少子化の真因」という節見出しも同じ理由で「少子化の主因とされる未婚化」などへ弱める余地があります。
- [MAJOR][型:definition] 記事の核である「婚姻率トップ」は、総人口当たりの粗い婚姻率 (marriages-per-total-population、社会・人口統計体系) で、20〜30代が多い東京ではその年齢構成だけで高く出ます。同じ記事が東京の自然減の小ささを「若い世代が多いから」と説明している (しかも R2 の crude-death-rate 2023 で東京は9.74と全国最小で、この説明は裏付けられます) のに、婚姻率には同じ補正をかけていません。婚姻率の定義 (粗率・総人口分母・2022年のコロナ期の値) を一文で注記し、「トップなのに最下位」が年齢構成の差で一部説明できる可能性にも触れてください。東京の合計特殊出生率も、未婚女性の流入が分母に入る影響を受けるため、「東京で暮らす女性が1人未満しか産んでいない計算」という書き方には同じ限定が要ります。
- [MAJOR][型:definition] 未婚割合の出典が混在しています。全国の「50歳時未婚割合」は国立社会保障・人口問題研究所の値 (1980年2.6%/4.5%、2020年28.3%/17.8%)、都道府県の「45〜49歳未婚率」は社会・人口統計体系の値 (R2) です。後者は東京24.6%・大阪24.4%・沖縄25.7%と、全国値や直感より低く出ており、分母 (配偶関係不詳の扱い) が前者と同じか、この調査で確認できませんでした。本文は二つを続けて読ませ、「男性の5人に1人以上が結婚していない」と一般化しています。都道府県の数値の出典 (社会・人口統計体系、国勢調査の補完前後の別) を本文に明記し、全国値との水準の違いに一言触れてください。なお、都市の代表である東京・大阪の値を挙げずに「地方でも都市でも」と書いている点も、数値で裏付けてください。
- [MAJOR][型:source] 確かめられない全国値の出典が薄いです。(1) 合計特殊出生率の全国値1.20と置換水準2.07は NOTE に出典が無く、人口動態統計 (厚生労働省) の概況と人口問題研究所の置換水準の値を引く必要があります。(2) 婚外子2%台と欧米の3〜6割は出典が全くなく、国名と年を添えるべきです。(3) 1975年の平均初婚年齢 (夫27.0歳・妻24.7歳) は R2 の対象外 (2023年のみ) で、出典と年次の明記が要ります。(4) 「内閣府の意識調査で未婚者の多数がいずれは結婚したい」は、一般には国立社会保障・人口問題研究所の出生動向基本調査で語られる内容で、出典の取り違えの疑いがあります。調査名と年を確認してください。以上は R2 に無いため、私は値の正否を確かめられていません。全国値1.20、50歳時未婚割合、1975年の初婚年齢は、私の知る範囲では公表値と整合しますが、本文に出典が無い点が問題です。
- [MAJOR][型:chart-text] 記事の核である「婚姻率トップなのに出生率最下位」を示す図がありません。図は自然増減率と合計特殊出生率の二つだけで、婚姻率は文章で一度書かれるだけです。読者は東京が婚姻率で何位か、出生率とどう対比されるのかを図で見られません。東京の婚姻率が突出していることを示す婚姻率ランキング図、または出生率×婚姻率の散布図を足すか、少なくとも相関ページへのリンクの前に数値の対比表を置いてください (相関ページへのリンクは存在しますが、図の代わりにはなりません)。archetype A の「なぜ上位/下位か」の視点は、自然減の図と出生率の図の解釈で一応は満たされています。
- [MAJOR][型:causal] 「少子化の主因は産まないことでなく結婚しないこと」という趣旨の見出しと本文が、因果分解なしに書かれています。未婚化の影響と夫婦の出生数の低下の影響を分けたデータ (夫婦の完結出生児数など) がなく、WARNING の注記は未婚者の意識についてだけ書いています。「主因とされる」「と考えられる」の形にし、根拠となる調査を添えてください。また「ここが少子化の本質です」の直後に「東京の逆説は例外ですが」と続く箇所は、東京が本質なのか例外なのかが読み取れず、構成上も矛盾します。
- [MINOR][型:structure] 「東京の逆説」の節の「[仮説] 住居費の高さ、長時間労働、保育所の不足…」は、記事内で検証されないままです。東京の自然減が小さい理由の仮説は、crude-death-rate (東京9.74、全国最小) で検証できます。検証済みと書けば、記事の信頼度が上がります。
- [MINOR][型:value] 「約84.8万人、中核市ひとつ分を超える」は、中核市の人口は20万〜65万程度で、84.8万は政令指定都市の規模です。比喩として弱くなっているため、「政令指定都市ひとつ分に近い」などに直してください。また「東北と四国の県が並びます」の四国は高知県の1県だけなので、「東北4県と高知県」と書く方が正確です。
- [MINOR][型:structure] TIP callout (出生率が高い県は九州に集まり…) は、直前の本文の言い換えが中心です。九州が高く都市圏が低いという点は本文に既にあり、callout に独立した知識がありません。「合計特殊出生率は期間指標で、都道府県間の比較は女性の流入出の影響を受ける」といった読み違い防止の内容に差し替える余地があります。
- [MINOR][型:style] 副題・見出しの「自然増はゼロ」は、増加数がゼロ人と読める余地があります。「自然増の県はゼロ」の方が誤読を避けられます。文体はですます調で一貫しており、である調の混入はありません。
