## 評価サマリ
実数の小売店数(2021年度)と人口10万対看護師数(2020年)の相関 -0.54 が、小売店数を人口10万人当たりに直す(計算値)と +0.76 に反転する、という問いに対し、反転の理由を「横軸が県の規模から密度に変わったため」と定義に沿って説明できている。本文の値・順位・倍率(18.5倍、2.2倍、2.0倍)・相関係数(-0.5438、+0.7563、高知除外で0.738)は data/*.json と再計算で全件一致した。相関は因果と書かず、裏付けのない理由は [仮説] と明記し、確かめていない点も書いている。図1枚ごとに解釈段落があり、定義上の BLOCK は見つからなかった。残るのは、中心の説明に数値の裏付けを足せる点と、図と本文の年表記・ラベルの細部である。

## 指標定義シートとの突合
- retail-store-count は暦年だが、散布図の軸メタは「2021年度」、本文と図2は「2021年」。出典は社会・人口統計体系(R2 JSON の source)。シート上は経済センサス-活動調査で、対象・分母は config に記述なし。
- nurses-per-100k-population は 2020年、人口10万対。対象・分母は config に記述なし。
- 人口10万人当たり小売店数は retail-store-count(2021) / total-population(2021) x 100000 の計算値で、source.json にも formula と inputs が残っている。本文もこれを「小売店数を2021年の総人口で割って」と正しく説明している。

## 指摘
- [MINOR][型:causal] 記事の中心である「反転の仕組みは割り算にあります」「実数の相関は『大きな県は人口当たりの看護師が少ない』の言い換えに近い」は、本文に数値の裏付けがない。再計算では、人口(小売店数 / 人口10万人当たり小売店数から逆算)と人口10万対看護師数の相関は約 -0.59、人口と人口10万人当たり小売店数の相関は約 -0.78 で、説明を支持する。この2つを本文に1文で足すと、読者が仕組みを自分で確かめられる。ただし人口は total-population の R2 値で再確認してから書くこと。
- [MINOR][型:correlation] 「傾向は大都市圏の埼玉県、千葉県、神奈川県、東京都に強く引っ張られており」は、東京都1県を除いても相関は -0.55 で変わらず、4都県を除くと -0.42 に弱まるが逆転はしない。「強く」を「一部」に弱めるか、「4都県を除くと -0.42 に弱まる」と数値で書く。
- [MINOR][型:year] 図1の副題は「横軸 2021年度」だが、本文は「2021年」。metric の years は calendar 宣言で、軸メタだけ年度になっている。どちらが正しいかを出典の e-Stat 表で確かめて、図と本文をそろえる。
- [MINOR][型:chart-text] 図1は東京都・大阪府・神奈川県・愛知県しかラベルがなく、本文が指す高知県・鳥取県・島根県・佐賀県(左上)と北海道・福岡県(例外)が図で特定できない。図2は出典欄が「衛生行政報告例」だけで、横軸の出典(社会・人口統計体系と総人口)が欠けている。ラベルと出典欄を足すか、本文の指示を図に見える県に絞る。
- [MINOR][型:definition] 「小売店数」(事業所ベースか、調査の期日はいつか)と「看護師数」(就業者か、准看護師を含むか、就業地ベースか)の対象が本文に書かれていない。config にも記述がないため、出典の表で確認して1文足す。あわせて、[仮説] の「県境をまたいだ勤務が多い」は、看護師数が就業地ベースか居住地ベースかで向きが変わるので、確認できるまで「勤務地と居住地のずれ」程度に弱める。
- [MINOR][型:other] 「東京都は右端から43位の位置に動き」は読みにくい。「左から5番目まで動き」の方が図で追える。
