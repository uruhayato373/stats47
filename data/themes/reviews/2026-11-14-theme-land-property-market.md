# テーマ改善の提案: 不動産取引と地価 (land-property-market)

## 結論

先頭の章を、検索の表示回数が多い家賃と、いまの先頭の取引単価・公示価格 (2025 年) に固定資産税を加えた「住まいの費用」の章にし、家賃を最初のブロックに置いた。いまの 3 章のうち、指標 1 つだけだった工業地の変動率の章を、住宅地の変動率と同じ % の推移ブロックにまとめて 2 章にした (章の数は増えない)。住宅着工・空き家率・持ち家比率は、検索語は多いが living-housing や construction-industry の担当で、このテーマの主問 (地価・取引) から外れるため足していない。

THEME-PAGE-REVIEW-01 の段 4 (全 56 テーマの指標の見直し)。調査 (theme-researcher) と設計 (theme-designer) の結果を機械で検査し (実在しない指標・重複・取りこぼし・`validate:catalog`)、通った案をカタログへ適用した。

## 確かめたこと・確かめていないこと (agent の申告)

- 確認: 現カタログは metrics 6 件・章 3 つで、工業地変動率の章は指標 1 つだけだった (inventory と catalog JSON を読んだ)
- 確認: 先頭の章の先頭 2 ブロックは stat で、最新年は家賃 2024・取引単価 2025・公示価格 2025 (いずれも 2020 年以降、inventory の metricInfo と data/metrics の years)
- 確認: private-rental-housing-rent-per-3-3m2 と per-capita-fixed-asset-tax-pref-municipal は data/metrics に実在し isActive: true。sourceUrl は両定義の source.url を写した
- 確認: 先頭章の指標は円/3.3㎡・円/㎡の単価と住民1人あたり額で、総量は標本数 (件) だけ。標本数は価格の信頼度を示す補助で、総量のまま残した (登録済みの指標に割合・人口あたりの標本数は無い)
- 確認: 家賃の定義の note に、県庁所在都市を対象とする調査で都道府県全域の平均ではないと書かれている。見出しは「民営の家賃」とし、県全域とは書いていない
- 確認: 固定資産税は定義が「都道府県・市町村財政合計」の住民1人あたり額 (千円)。税率ではないので、見出しは「住民1人あたりいくら」とした
- 確認: 全 rankingKey は 1 回ずつだけ。trend の指標は 49 年の 2 件 (同じ %)
- 確認: composition は使っていない。足して全体になる組は確かめていない
- 確認: 住宅着工 (new-housing-starts) は living-housing で secondary、construction-industry で secondary。空き家比率・持ち家比率は living-housing 側 (空き家比率は primary)。なので足していない
- 未確認: 家賃の東京都の対象範囲 (区部か都全域か。定義に明記なし)
- 未確認: 固定資産税の都道府県・市町村合計が、住民1人あたりの算出で人口を何で割っているか (定義ファイルに分母の説明は無い)
- 未確認: 埋め込み章 property-prices の中身。章の配列には含めていないので、既存のカタログ設定のまま残す必要がある
- 未確認: data/themes/viewpoints/selection.json の rules は先頭 80 行までしか読んでおらず、残りの規則との整合は見ていない
- 未確認: 検索語の需要は前段調査の数字 (W45・28 日) をそのまま使っており、自分では取り直していない
- 調査の未確認: data/themes/viewpoints/selection.json は読んでいない
- 調査の未確認: 検索語の記録は W45(サイト全体 28 日)だけで、語の grep は 1 回。取りこぼしの可能性がある
- 調査の未確認: 各 ts の cdCat01 と、市町村単位の固定資産税(fixed-asset-tax-municipal、0000020204)の都道府県比較への適性は未確認で、固定資産税は候補に入れていない
- 調査の未確認: industrial-land-price・vacant-housing-rate-for-rent・fixed-asset-tax-municipal は inventory の metricInfo に無く、年数と期間が未確認
- 調査の未確認: e-Stat API へは接続しておらず、statsDataId は data/metrics の定義ファイルの記載のみ
- 調査の未確認: embedded の property-prices 章の中身は未確認(既に載っている指標と重なる可能性)
- 調査の未確認: 住宅地の地価の価格水準(単年でない系列)は登録済みの有無を ls の名前一致でしか確認していない
