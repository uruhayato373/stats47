# テーマ改善の提案: 森林と自然環境 (natural-environment)

## 結論

**いまは実装しない。** このテーマには測定中の実験 (`THEME-COPY-20261112-natural-environment` (d56 = 2027-01-07)) があり、章や指標を変えると測定に混ざる。実験の判定が出た後 (2027-01-07 以降) に、その結果を踏まえてこの案を見直してから実装する。

機械で一括に組み直す方法 (`apply-design.ts --approved`) は、このテーマには使わない。同じ日に実験のある 5 テーマへ試したところ、人が作り込んだ図・埋め込みの節・章の構成を固定するテストが落ちた (カタログの検査 1 件・テスト 6 件。変更は取り消した)。実装するときは、提案の採否を 1 項目ずつ決めて手で直す (`theme-proposal-format.md` の手順)。

設計の agent の案: 最初の章を、割合の指標があり最新年が 2024 年の自然公園の章に替えた。現行の先頭にある森林面積と森林面積割合は最新年が 2019 年で、制約 1 の先頭の章に置けないため、森林の章は 2 番目に下げた。検索需要の記録に森林・自然公園の語はほぼ無く、順序を需要で決める根拠は無い。国立・国定公園の利用者数は 1 指標だけの章になるため自然公園の章へ畳み、章は 3 から 2 に減らした。足した指標は自然公園面積割合 1 件だけで、都市公園・可住地面積割合・国立公園面積・林野面積は問いの需要が弱い、または他テーマと重なるため足さなかった。

## 確かめたこと・確かめていないこと (agent の申告)

- 確認: natural-environment.json の 6 指標と metricGroups・sections の構成を読み、2 つの章の中身がいまの章と対応することを確かめた。
- 確認: nature-park-area-ratio は data/metrics に isActive: true、years 1975-2024、単位 ％、出典 https://www.stat.go.jp/data/ssds/index.htm を読んだ。
- 確認: inventory.json の metricInfo で woodland-area と forest-area-ratio は 7 年 (1980-2019)、nature-park-area と natural-environment-conservation-area は 50 年 (1975-2024)、national-quasi-national-park-visits は 1 年 (2024) だと読んだ。trend は 2 年以上ある woodland-area と natural-environment-conservation-area だけに使った。
- 確認: 現行カタログの指標 (context の artificial-forest-area を除く) の 5 件は、すべて 1 つのブロックに 1 回ずつ入っている。
- 確認: 先頭の章の先頭 2 ブロックは stat で、最新年が 2024 年の指標 (nature-park-area-ratio・nature-park-area) を置いた。割合の指標が先頭にあり、森林の章でも割合を総量の前に置いた。
- 確認: composition は使っていない。足して全体になる組は確かめていない。
- 確認: 2020 年以降の指標だけで最初の章を組めたが、森林の章の 2 指標は最新年が 2019 年のため、現時点の値ではない。
- 未確認: nature-park-area と natural-environment-conservation-area の定義 (範囲・重なりの有無) は読んでいない。2 つを足し合わせたり内訳として扱ったりしていない。
- 未確認: forest-area-ratio の shortLabel は「林野面積割合」だが metrics の title は「森林面積割合」で、表記が食い違う。見出しは title に合わせて「森林」と書いたが、分母・算出方法は読んでいない。
- 未確認: 検索需要は 2026-W45 の 1 週だけで、森林・自然公園を直接指す語は見つかっていない。章の順序は需要で裏付けていない。
- 未確認: urban-park-area-per-person (最新 2023 年)・national-park-area・forest-area・habitable-area-ratio は定義だけを一部読み、カタログには足していない。
- 未確認: selection.json の視点の中身、e-Stat API 上の統計表の実在は確かめていない。
- 調査の未確認: selection.json の視点は grep で natural-environment に言及が無いことだけ確認し、中身は読んでいない。
- 調査の未確認: forest-area・national-park-area・urban-park-area-per-person・nature-park-area-ratio の年次の数は inventory.json に無く、metrics の years も全文は読んでいない。
- 調査の未確認: 現行カタログの forest-area-ratio は shortLabel が「林野面積割合」だが metrics の title は「森林面積割合」で、表記が食い違う。ここは確認だけで、原因は未調査。
- 調査の未確認: 検索語の記録はサイト全体の 28 日分 1 週だけ。テーマ固有語はほぼ出ておらず、需要の裏付けは弱い。
- 調査の未確認: e-Stat API や Web での統計表の実在確認は実行していない。登録済みの定義に書かれた statsDataId・cdCat01 を転記しただけ。
