# テーマ改善の提案: 貯蓄と負債 (household-assets-debt)

## 結論

章を読者の検索の問いの順に並べ直し、県別ページの最初の画面にその県の数値が 2 つ以上並ぶようにする。検索の表示回数が多い貯蓄現在高と負債現在高を、最初の章の先頭に 2 つの数値タイルとして並べ、毎年の値がある県庁所在市の二人以上世帯であることを見出しで明示した。続いて貯蓄率 (検索需要が次に大きい)、県全体の金融資産と持ち方、県全体の負債と住宅・土地の割合の順に並べた。2019 年 1 回だけの比率 4 種は、足して全体にならない (COMPOSITION_REJECTS に預貯金割合を登録済み) ので構成比にせず、1 指標ずつの stat にした。context 以外の 11 指標はすべてどれか 1 つのブロックに入れ、drop はなし。

新しい指標は今回足さない。調査で見つかった候補 5 件は下の表に残し、取り込みを別に判断する。

この提案は THEME-PAGE-REVIEW-01 の段 4 (全 56 テーマの指標の見直し) の 1 回目で、調査 (theme-researcher) と設計 (theme-designer) の結果を機械で検査してまとめた。カタログに無い指標・同じ指標の重複・取りこぼしは 0 件。agent が書いた事実の裏取りは「確かめていないこと」に挙げた範囲で未了。

## 確かめていないこと

- e-Stat ライブ API と WebFetch は呼んでいない。候補の実在はリポジトリ内の data/estat/meta/0002210008.json と kakei-ledger(取得日 2026-05-19 更新の表)による確認で、呼び元でライブ照合するのが望ましい
- 一次資料(総務省統計局 家計調査の公式ページ等)の URL は Web 閲覧していないため出典 URL は書いていない
- 『沖縄 貯蓄額 中央値』『貯蓄の中央値』を載せる指標は確認できず(家計調査の都道府県別・中央値表は調べていない)
- 全国家計構造調査(2019 年)の都道府県別の純資産・世帯主年齢階級別の貯蓄は調べていない(現状の金融資産残高・金融負債残高は 2019 年 1 回のみ)
- gini-coefficient-financial-assets(statsDataId 0003440696・cdCat01 2・2019 年 1 回・47 都道府県)は登録済みだが real-income カタログにのみ載り、このテーマには未掲載。貯蓄格差の問いに使えるが、読者需要の根拠は見つけていない
- 『都道府県 借金 ランキング』の読者が世帯の負債でなく自治体の借金を求めている可能性があり、世帯負債ページでは意図が合わない恐れがある(自治体財政は別テーマの問い)
- 公式ダッシュボード研究カタログに貯蓄・負債の記録は見当たらず、RESAS・デジタル庁等の可視化の再利用先は未確認
- 設計案の見出しは agent が書いた文で、検索語との対応は上の「読者の問い」の根拠の範囲でしか確かめていない。
- 画面での見え方 (最初の画面のタイルの数・高さ) は未計測。実装後に `measure-theme-weight.mjs` で測る。
