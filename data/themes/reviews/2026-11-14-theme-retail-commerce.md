# テーマ改善の提案: 商業と小売 (retail-commerce)

## 結論

章を読者の検索の問いの順に並べ直し、県別ページの最初の画面にその県の数値が 2 つ以上並ぶようにする。4 指標とも 2021 年の 1 時点だけ (47 地域) で、単位も事業所・m2・百万円・人とそろわないため、trend と composition は使わず全て stat にした。最初の章は GSC で需要のある「年間商品販売額」「県別の小売の規模」に答える形にし、主指標の事業所数の stat を先頭に、販売額の stat を並べて県別ページの最初の画面に数値のタイルが 2 つ出るようにした。事業所数と販売額が同じ章に入ったため「店舗数」の章は不要になり、章を 4 から 3 に減らした (retail-store-convenience は外し、ほかの 3 章の key は残してページ内リンクを保つ)。

新しい指標は今回足さない。調査で見つかった候補 5 件は下の表に残し、取り込みを別に判断する。

この提案は THEME-PAGE-REVIEW-01 の段 4 (全 56 テーマの指標の見直し) の 1 回目で、調査 (theme-researcher) と設計 (theme-designer) の結果を機械で検査してまとめた。カタログに無い指標・同じ指標の重複・取りこぼしは 0 件。agent が書いた事実の裏取りは「確かめていないこと」に挙げた範囲で未了。

最初の章についての調査の所見: 最初の章は現在の「年間商品販売額」だけでなく、需要最大のコンビニ店舗数(人口10万人あたり)と百貨店・総合スーパー数を同じ最初の画面に置き、県別ページで事業所数・販売額と合わせて2指標以上の県の数値が見えるようにする。現カタログは4指標すべてが2021年1時点のみ(inventory.json で years=1)で推移を出せないので、年数のある店舗数系列を前面に出す価値がある。

## 確かめていないこと

- e-Stat API/WebFetch は実行しておらず、H6132 の年次・都道府県粒度は未確認(要呼び元検証)
- 公式ダッシュボード研究カタログ(public-dashboards.json)には小売・商業語に該当する出力が得られず、RESAS等の既知ストーリーは確認できなかった
- コンビニ店舗数・百貨店数は登録済みでも最新年が2014年/2006年と古く、読者の「いま」の問いに足りるかは未解決。JFA等の一次資料は取得しておらず出典URLは記載しない
- ドラッグストア店舗数・ホームセンター・ネット通販(電子商取引)は需要(「ドラッグストア店舗数 都 道府県 別」1回など)が小さく、statsDataId を確認できなかったため候補に入れていない
- 「ガソリン消費量」系の需要は大きいが、別テーマ(エネルギー・交通)の可能性が高く未調査
- GSCはサイト全体28日の記録で、このテーマ宛ての順位・県別ページ別の流入までは見ていない
- GSC のこのテーマ関連語の合計表示回数を数えたが(205行・1157回)、対象語の絞り込みは広く、他テーマの語(ガソリン等)も含む
- 設計案の見出しは agent が書いた文で、検索語との対応は上の「読者の問い」の根拠の範囲でしか確かめていない。
- 画面での見え方 (最初の画面のタイルの数・高さ) は未計測。実装後に `measure-theme-weight.mjs` で測る。

## 想定実装差分と検証

- 編集するファイル: `data/themes/catalogs/retail-commerce.json` (sections・metricGroups・引き上げる指標の role と selection)。生成物は `npm run generate:catalog`。
- R2 への影響: page-components (章と図の並び)。観測値は変わらない。
- 検証: `npm run validate:catalog --workspace=@stats47/data-configs` (error 0・warning を増やさない)、`measure-theme-weight.mjs --themes retail-commerce` で品質基準 6 項目。
- 実験: 公開日に `THEME-STRUCTURE-<公開日>-retail-commerce` を `metricScope: all-routes` で登録する。
