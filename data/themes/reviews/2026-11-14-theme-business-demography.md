# テーマ改善の提案: 起業と開廃業 (business-demography)

## 結論

章の数は 3 のまま、章 key も維持した。最初の章は検索需要が最大の開業率・廃業率 (2024 年度) を stat で先頭に置き、事業所数の総量はその後ろに従えた。後ろの 2 章は企業数・従業者数の総量だけだったため、各章の先頭に登録済みの割合指標 (従業者1〜4人の事業所割合、1〜4人事業所の従業者割合) を足し、総量に割合を並べた。

THEME-PAGE-REVIEW-01 の段 4 (全 56 テーマの指標の見直し)。調査 (theme-researcher) と設計 (theme-designer) の結果を機械で検査し (実在しない指標・重複・取りこぼし・`validate:catalog`)、通った案をカタログへ適用した。

## 確かめたこと・確かめていないこと (agent の申告)

- 現行カタログの全 metrics と 3 章の構成を読んだ。context 以外の 8 指標はすべてどれかの章のブロックに入り、どの rankingKey も 2 つのブロックに重複していない。
- inventory.json の metricInfo で開業率・廃業率・事業所数 (2022〜2024、47 県) と企業系 4 指標 (2021 の 1 年のみ、47 県) の年数を確認した。trend は 2 年以上ある指標だけ (事業所数 2 指標は同じ単位「所」、割合 2 指標はそれぞれ単独ブロック)。2021 の 1 年だけの企業系 4 指標は stat にした。
- 追加 2 指標は data/metrics に実在し isActive: true、entities が prefecture、単位は %、年は 2009・2011・2014・2016・2021 の 5 時点、出典 URL は定義ファイルの https://www.stat.go.jp/data/ssds/index.htm をそのまま写した。
- 検討して外した候補: private-establishments-individual と self-employed-without-employees は entities が city だけで都道府県の比較に使えないため採らなかった。private-establishments は 2021 の企業総数と重複しうるため採らなかった (後者は 2 件とも data/metrics の定義のみ確認)。
- 追加 2 指標は ほかの全カタログ (data/themes/catalogs/*.json) に出現せず、owned-elsewhere 規則に当たらないことを確認した。
- composition は使っていない。企業総数と常用雇用者0〜4人の企業数、従業者総数と0〜4人企業の従業者数が全体を足し上げる組かは統計表で確認しておらず、stat にした。
- 総量の章 (企業数・従業者数) には割合指標を同じ章の先頭に置いた。ただし登録済みの割合指標は事業所ベースで、総量は企業ベース (経済センサス企業等集計) のため分母の単位が異なる。見出しは「事業所の割合」「企業数」と別々の語にしてある。
- 未確認: 追加 2 指標の description (定義文) は定義ファイルに無いため、図に入れる場合は検査 theme-metric-description-regression で止まる可能性がある (今回は図ではなく trend / stat のカードとして配置)。
- 未確認: 追加 2 指標の 47 県の欠測と、2009〜2021 年の系列の定義の連続性。cdCat01 (#C02206・#C03206) を e-Stat API で照合していない。
- 未確認: selection.json の冒頭 80 行までしか読んでおらず、それ以降の規則は照合していない。倒産件数・企業単位の起業件数の登録済み指標は探した範囲では見つからなかったため、倒産の問いには章を設けていない。
- 調査の未確認: selection.json は冒頭60行(採用基準と一部の規則)までしか読んでおらず、残りの規則との照合は未実施
- 調査の未確認: 候補5件の cdCat01 は未確認で、e-Stat API での実在照合も行っていない。statsDataId は data/metrics の記載に基づく
- 調査の未確認: 候補の47県の欠測と、年ごとの定義の連続性は未確認
- 調査の未確認: 検索語は 2026-W45 の1週分(クエリ表はサイト全体)で、「廃業率 ランキング」の38回以外は表示回数が小さい
- 調査の未確認: 倒産件数・企業単位の起業件数(ご依頼の「倒産」周辺の問い)に対する登録済み指標は探した範囲では見つからなかった。e-Stat 側の探索は行っていない
- 調査の未確認: 候補の指標がほかのテーマ(例 information-industry)で primary かどうかの重複確認(owned-elsewhere 規則)は未実施
- 調査の未確認: inventory.json の metricInfo に候補5件が無く、登録の実年数は data/metrics の from/to と years から読んだのみ
