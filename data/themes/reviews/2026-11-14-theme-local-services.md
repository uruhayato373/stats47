# テーマ改善の提案: 飲食・生活関連サービス (local-services)

## 結論

いまの先頭の章は飲食店数（最新2006年・8時点）とホテル（最新2017年）で、制約の2020年以降を満たさないため、人口10万人あたりで最新2023年の公衆浴場・理容美容・クリーニングを先頭の章に置き、検索需要の大きい銭湯を最初にした。最新2014年のコンビニは先頭に置けないので飲食・宿泊の章に移し、映像制作の章は人口あたりの指標が無いため娯楽の章に統合して章を4から3に減らした。飲食店数はテーマの primary のままだが最新年が古いので、章の順は2番目にしている。

THEME-PAGE-REVIEW-01 の段 4 (全 56 テーマの指標の見直し)。調査 (theme-researcher) と設計 (theme-designer) の結果を機械で検査し (実在しない指標・重複・取りこぼし・`validate:catalog`)、通った案をカタログへ適用した。

## 確かめたこと・確かめていないこと (agent の申告)

- 確認: catalogs/local-services.json の metrics の role!=context 15指標を、すべてどこかのブロックに1回ずつ入れた。context のホテル2指標も飲食・宿泊の章に入れた。rankingKey の重複なし、drop は空
- 確認: addMetrics 5件の rankingKey は data/metrics/<key>.ts が実在し isActive: true。years の from/to を定義ファイルから読んだ（公衆浴場・理美容・クリーニング 1975〜2023、コンビニ 1982〜2014、映画 2021〜2021）。出典URLは ssds の4件は定義の source.url、映画の行動者率は定義に URL が無く空文字
- 確認: 先頭の章の先頭3ブロックは stat。公衆浴場・理容美容・クリーニングはいずれも定義の最新年2023で、2015年以前の指標は先頭の章に無い
- 確認: trend ブロックは2つ。飲食店+コンビニは8時点と12時点で単位が店と所の2種、ホテルは inventory で21時点で単位は施設と室の2種。1ブロック3指標以内。1年しかない指標は trend に入れていない
- 確認: composition は使っていない。足すと全体になる組を確かめていないため
- 確認: 章は3つで元の4つより少ない。ブロックの無い章と1指標だけの章は無い
- 確認: 先頭の章は人口あたりの指標を先頭にして、総量（事業所・従業者・売上・付加価値）を同じ章の後ろに置いた。飲食・宿泊の章のホテルは総量だが同じ章に人口あたりの飲食店・コンビニがある。娯楽の章は映画の行動者率（％）を先頭にした
- 確認: 洗濯等・娯楽・映像の事業所と従業者は2021年、売上と付加価値は2020年なので、年が揃うよう別ブロックに分けた
- 未確認: R2 上の各指標の実際の年・欠測と47県の揃い（定義ファイルの years の記載と inventory だけを読んだ。候補5指標は inventory の metricInfo に載っていない）
- 未確認: 公衆浴場数が銭湯だけを数えているか（定義の title は公衆浴場数。統計表は e-Stat で照合していない）。検索語は調査結果の記載を信用し、GSC の元データは再確認していない
- 未確認: 映画の行動者率の需要。検索語の根拠は無く、率の指標を章に入れる制約のために足した。社会生活基本調査の統計表 0003456573 の実在も e-Stat では確かめていない
- 未確認: ガソリンスタンド数（道路実延長100km当たり）は分母が道路延長で需要も小さいため追加しなかった。年は定義上 2001〜2023
- 備考: 飲食店数が primary のままだが最新年が2006年と古い。公衆浴場を primary 側へ寄せる role の見直しは addMetrics の role で提案しただけで、既存指標の role は変えていない
- 備考: personal-items-service-consumption-expenditure（context・県庁所在市の家計支出）は現状どのグループにも入っておらず、章にも入れていない
- 調査の未確認: WebFetch・e-Stat API での統計表の実在確認はしていない。statsDataId と cdCat01 は data/metrics 内の記載のみで、登録済として扱った
- 調査の未確認: inventory.json の metricInfo には候補5指標の情報がなく、年数は data/metrics の years 定義から読んだ
- 調査の未確認: data/themes/viewpoints/selection.json は読んでいない
- 調査の未確認: queries.csv はサイト全体の記録で、県別ページ(/areas/<県>/local-services)に限った需要は分からない
- 調査の未確認: restaurant-count-per-1000-alt (#H06130) は存在するが isActive: false のため候補から除外した
- 調査の未確認: 検索語の集計は私が選んだ語の grep なので、語の漏れがありうる
