# テーマ改善の提案: 介護認定とサービスの需給 (long-term-care)

## 結論

いまの先頭の章は認定者数（2024年の1年分のみ・総数）と給付費総額で、人口あたりの指標が無いため、検索需要の大きい施設の問いと人口あたりの施設指標（2023年・65歳以上人口あたり）を先頭の章に置き、総量の認定者数・給付費は同じ章に割合の指標（一人暮らしの割合）を並べた章へ移した。1指標だけだった在所者の章は先頭の章にまとめ、人手と介護職の年収の問いを新しい担い手の章にした（章数は3のまま）。人口あたり・割合の認定率と1人あたり給付費は登録済みの指標が見つからなかったので、認定者数と給付費は総量のままにしている。

THEME-PAGE-REVIEW-01 の段 4 (全 56 テーマの指標の見直し)。調査 (theme-researcher) と設計 (theme-designer) の結果を機械で検査し (実在しない指標・重複・取りこぼし・`validate:catalog`)、通った案をカタログへ適用した。

## 確かめたこと・確かめていないこと (agent の申告)

- inventory.json の metricInfo と data/metrics/*.ts で、いまのカタログ5指標と追加3指標の years を確認した（認定者数は2024の1年のみ・他の施設3指標は最新2023・一人暮らし割合は1980〜2020の9年・介護職年収は2020〜2023）。先頭の章の stat 2ブロックの最新年は2023で、2020年以降。
- 追加3指標（elderly-living-alone-rate, nursing-home-staff-per-100k-65plus, care-worker-annual-income）の data/metrics/*.ts を読み、isActive: true と source.url（https）を確認した。
- 他テーマでの役割を data/themes/catalogs/*.json で確認した。elderly-living-alone-rate は aging-society の secondary、care-worker-annual-income は occupation-salary の secondary で、primary ではない（owned-elsewhere の対象外）。
- data/metrics を「認定率」「要介護」で grep したが、人口あたり・割合の認定率の指標は long-term-care-certified-persons 以外に見つからなかった（別名で登録されている可能性は残る）。そのため認定者数・給付費は総量のまま、同じ章に一人暮らしの割合を並べた。
- nursing-home-capacity-per-1000-65plus の定義文は有料老人ホームを含む4種の合計と書かれているため、paid-nursing-home-capacity-per-1000-65plus は重複として追加しなかった。ケアマネ年収も検索量が少ないため追加しなかった。
- composition は使っていない（足すと全体になる組は確かめていない）。trend は各1指標・2年以上（施設数27年・給付費24年）で制約内。同じ rankingKey は1回しか置いていない。
- 未確認: nursing-home-staff-per-100k-65plus は inventory.json の metricInfo に載っておらず、47県すべての値が R2 にあるかは確認していない（定義ファイルの years のみ）。
- 未確認: elderly-living-alone-rate の cdCat01 と、care-worker-annual-income の e-Stat 実在確認（WebFetch）は行っていない。定義ファイルの記載に依存している。
- 未確認: nursing-home-staff-per-100k-65plus の定義文・note が無く、2018年以降の標本調査の影響（施設指標の note にある注意）が同様に当てはまるかは確かめていない。
- 調査の未確認: 人口あたり・割合の要介護認定率、人口あたり・1人あたりの介護給付費の登録済み指標は、ファイル名と title の grep では見つからなかった(別名で存在する可能性は残る)。未登録なら e-Stat 介護保険事業状況報告から要新規調査で、statsDataId は未確認
- 調査の未確認: 「介護サービス施設・事業所調査」(最大需要)の事業所数・従事者の登録済み指標を個別に確認していない。home-helper-count-per-100k は years 2000-2002 で古い
- 調査の未確認: candidates の cdCat01 のうち care-worker/care-manager/elderly-living-alone-rate は定義ファイルで確認していない(空欄)
- 調査の未確認: selection.json は介護語で該当がなく、視点の適合は未確認
- 調査の未確認: e-Stat への実在確認(WebFetch)は行っていない。登録済み定義の記載のみに依存
- 調査の未確認: GSC は W45 の1週分のサイト全体の記録で、県別ページ(/areas/<県>/long-term-care)単位の流入は見ていない
