# テーマ改善の提案: 漁業（水産業） (fishery-marine)

## 結論

**いまは実装しない。** このテーマには測定中の実験 (`THEME-STRUCTURE-20261007-fishery-marine` (d56 = 2026-12-02)) があり、章や指標を変えると測定に混ざる。実験の判定が出た後 (2026-12-02 以降) に、その結果を踏まえてこの案を見直してから実装する。

機械で一括に組み直す方法 (`apply-design.ts --approved`) は、このテーマには使わない。同じ日に実験のある 5 テーマへ試したところ、人が作り込んだ図・埋め込みの節・章の構成を固定するテストが落ちた (カタログの検査 1 件・テスト 6 件。変更は取り消した)。実装するときは、提案の採否を 1 項目ずつ決めて手で直す (`theme-proposal-format.md` の手順)。

設計の agent の案: 変更は中程度。需要の大きい魚種別の漁獲量(カツオ・サバ・サンマなど)を第 2 章で 3 本ずつの推移に整理し、家計調査の登録済み指標 4 件で食べる側の問い(魚・マグロ・カツオ・うなぎ)を足した。先頭章は世帯あたりの生鮮魚介購入量を最初に置いて総量の漁獲・養殖と並べ、海面/内水面の内訳は先頭章の末尾へ、担い手の 1 指標だけの章は産出額・漁港数と同じ章にまとめて章数を 5 から 3 に減らした。漁港数(検索需要が最大)は context 役のままだが産出額の章に置いた。

## 確かめたこと・確かめていないこと (agent の申告)

- data/themes/catalogs/fishery-marine.json を読み、metrics 23 件の rankingKey・role を確認した。いまの章(sections)は 5 つ、metricGroups は 6 つ、charts は 1 つ(theme-fishery-output-trend-marine)。
- inventory.json の metricInfo で年数・最新年を確認: fish-catch 1975-2023、aquaculture 2000-2023、海面/内水面漁獲・養殖 2000 年代から 2023、marine-fishery-aquaculture-output-value 2017-2023(7 年)、fishery-workers 1975-2023(33 年)、魚種別 11 件 1956-2023(39 県)、fishing-port-count-ksj 2026(1 年のみ)。
- 追加 4 件は data/metrics/<key>.ts を読み isActive: true と years を確認: fresh-seafood-consumption-quantity・tuna-consumption-quantity・bonito-consumption-quantity は 2007-2025、grilled-eel-consumption-expenditure は 2000-2025。出典 URL は各定義の source.url(e-Stat 家計調査)を写した。
- 先頭章の先頭 2 ブロック(生鮮魚介の購入量 2025、漁獲量 2023)は stat で最新年が 2020 年以降。2015 年以前の指標は先頭章に置いていない。
- 割合・人口あたり・世帯あたり: 登録済みの水産の供給指標に割合・人口あたりの独立した指標は見つからなかった(catch 系の metrics に per_population の normalizationOptions はあるが別 rankingKey ではない)。そのため、先頭章は家計調査の 1 世帯あたり購入量を先頭に置いて漁獲・養殖の総量と並べた。魚種章は同じ魚種の世帯あたり購入量(マグロ・カツオ)と並べた。産出額・就業者数・漁港数の章は総量のままで、世帯あたり・人口あたりの指標は並べていない。
- composition は [marine-fishery-catch, inland-fishery-catch] のみ。fish-catch の description に『海面漁業と内水面漁業で採捕された水産動植物を…合計した量』とあり、2 つの合計が漁獲量全体になることを定義文で確認した。養殖(海面+内水面)は aquaculture-harvest に説明文が無く足して全体になるか確かめていないため composition にせず trend にした。
- trend は全て 1 ブロック 3 指標以内・同じ単位(トン 3 本×3 ブロック、トン 2 本、人 1 本)。同じ rankingKey を 2 ブロックに入れていない。context 以外の既存指標(fish-catch、marine/inland 漁獲、aquaculture 3 件、marine-fishery-aquaculture-output-value、fishery-workers、マグロ類・カツオ・サバ類・サンマ・イワシ類)は全てブロックに入った。
- 章は 5 から 3 に減り、増えていない。ブロックが無い章・1 指標だけの章は無い(担い手の章は産出額・就業者・漁港の 3 ブロック)。
- 未確認: 家計調査の購入量は都道府県庁所在市の二人以上世帯の値で県全体ではない(定義の note より)。ページ上でこの注意が表示されるかは確かめていない。
- 未確認: かつお購入量は鰹節ではなく生鮮のかつおの量(調査の注意)。見出しは『かつおの購入量』とし鰹節とは書いていない。
- 未確認: 魚種別漁獲量は 2019〜2022 年の都道府県値が公表されておらず(いまのカタログの章説明より)、推移は 2018 年の次が 2023 年になる。trend でこの断絶が正しく描かれるかは確かめていない。
- 未確認: 海面漁業・養殖業産出額と海面漁業産出額(marine-fishery-output-value)で対象が違う点は既存の章説明に書かれているが、新しい章構成でその説明の置き場は確認していない。海面漁業産出額と fishery-output-value 以外の context(ホタテ・コンブ・タイ類・海面漁業産出額)はブロックに入れず context のまま。fishery-output-value は 2016 年まで・基準が違う系列として drop に入れた。
- 未確認: selection.json の規則(owned-elsewhere など)は読んだが、追加指標が他テーマの primary か(例: 家計調査系が他テーマで primary か)は調べていない。
- 未確認: 漁港数の検索需要が最大(682/374/297)だが fishing-port-count-ksj は 1 年だけの指標のため stat にした。fishing-port-count-by-type は 2003 年のみで rejectedCandidates 済みのため追加していない。fishery-management-orgs(2003 年のみ)も採用していない。e-Stat API での新規指標の探索はしていない。

- 調査の未確認: fishery-management-orgs は isActive:true だが統計表名の意味と年(2003)から採用性を判断していない
- 調査の未確認: selection.json は読んでいない
