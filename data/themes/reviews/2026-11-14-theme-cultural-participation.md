# テーマ改善の提案: 文化芸術への参加 (cultural-participation)

## 結論

検索語の表示回数は図書館・博物館が圧倒的に多いので、施設の章を先頭にし、人口あたりの図書館数・博物館数 (2021年) を先頭の2ブロックに置いた。いまの施設の章は貸出冊数と博物館総数 (2015年) の総量だけだったため、人口あたりの2指標と図書館の蔵書・登録者、博物館の入館者を登録済みの指標から足し、総数は人口あたりに置き換えて drop した。鑑賞・制作の行動者率と時間の章は定義と並びがすでに条件を満たすので小さく整えるだけにし、章数は3のまま。

THEME-PAGE-REVIEW-01 の段 4 (全 56 テーマの指標の見直し)。調査 (theme-researcher) と設計 (theme-designer) の結果を機械で検査し (実在しない指標・重複・取りこぼし・`validate:catalog`)、通った案をカタログへ適用した。

## 確かめたこと・確かめていないこと (agent の申告)

- 確認済み: カタログ cultural-participation.json の全文を読み、非 context の指標10件がすべて章のブロックか drop に1回だけ入ることを突き合わせた
- 確認済み: library-books / library-registered-users / library-count-per-million / museum-count-per-million / registered-museum-visitors の data/metrics/<key>.ts を読み、いずれも isActive: true、years と出典URLを写した
- 確認済み: 先頭章の先頭2ブロックの最新年は library-count-per-million が2021年、museum-count-per-million が2021年 (年配列の末尾)。2015年以前の指標は先頭章に無い
- 確認済み: trend のブロックは library-lending-books (2007-2020・5年)・library-books (2005-2021・6年)・library-registered-users (2007-2020・5年) で、すべて2年以上、単位は冊と人の2種
- 確認済み: composition は使っていない。足すと全体になる組は確かめていないため
- 総量の扱い: 先頭章の貸出冊数・蔵書数・登録者数・入館者数は総量。同じ章に人口あたりの図書館数・博物館数を置いた。図書館・博物館の人口あたりの貸出冊数・入館者数は登録済みの指標に見つからず、総量のまま置いた (蔵書数と登録者数には人口10万人あたりの換算オプションが定義にあるが、章には使っていない)
- 総量の扱い: 貸出冊数は人口の多い県ほど大きくなる総量で、章の中の人口あたりの図書館数と並べて読む形にした
- 判断: 先頭章を変えたため、primary の美術鑑賞の行動者率が2章目になる。role は変えていない。検索需要を優先した並びで、primary を先頭に残す案との比較はしていない
- 判断: total-museum-count は最新年が2015年の総量で、museum-count-per-million (2021年・人口あたり) が同じ博物館の数を人口あたりで置き換えるため drop
- 未確認: library-count-per-million の分母 (人口100万人あたり) は定義ファイルに明記が無い。key 名と SEO 文の値 (山梨県65.8館) からの推定で、見出しは「人口に対して」としか書いていない
- 未確認: museum-count-per-million の対象範囲 (登録博物館・類似施設の区別) と、total-museum-count との定義の違い
- 未確認: library-lending-books は暦年、library-registered-users は年度と定義が違い、同じ trend に並べると x 軸の表記が揃わない可能性。年コードで突合される規則どおりだが、期間は厳密には一致しない
- 未確認: 複数キーの stat ブロックが数値タイルの格子として描かれるかは、描画側のコードを読んでいない (1 年分しかない指標を view 無しの2件以上のカードにすると validator error になる点だけ規則から把握)
- 未確認: e-Stat 側の statsDataId の実在と年次、registered-museum-visitors の2023年度の値の範囲は照合していない。映画館・読書・スポーツ・ボランティアの候補は表示回数が少なく、今回は載せていない
- 調査の未確認: カタログ JSON は150行までしか読んでおらず、後半の chapter 構成や context 指標の全体は inventory.json の要約で把握した
- 調査の未確認: selection.json の視点は未読
- 調査の未確認: 検索語CSVはサイト全体の語で、/areas/<県>/cultural-participation への流入と直接対応づけていない
- 調査の未確認: e-Stat 側 (statsDataId の実在・年次) は未照合で、登録定義の記載のみ。registered-museum-visitors の statsDataId は未確認
- 調査の未確認: 映画館映画鑑賞の行動者率 (hobby-participation-rate-cinema, 2021) や art-museum-count (2015) などの候補は表示回数が少なく5件に入れなかった。年が古い/単年のため鮮度未評価
- 調査の未確認: 人口あたりの図書館貸出冊数 (割合系) の登録済み指標は見つけられなかった
