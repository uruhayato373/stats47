# テーマ改善の提案: ごみ・リサイクル (waste-recycling)

## 結論

章を読者の検索の問いの順に並べ直し、県別ページの最初の画面にその県の数値が 2 つ以上並ぶようにする。検索語は「ごみが多い県」「リサイクル率が高い県」に集中しているため、最初の章の先頭に主指標の総排出量とリサイクル率の数値タイルを 2 つ並べた。最終処分量だけが 25 年分の系列を持つ処理段階の量なので、同じ指標を 2 つのブロックに入れない制約のもとで 2 章目に推移として置いた。1 人 1 日あたりの排出量は登録済みの都道府県の指標がなく、候補として別に記録されるため、この案には入れていない。章の key は、最初の章だけ現行の waste-disposal を引き継ぎ、2 章目は内容が変わるため final-disposal に改めた。

新しい指標は今回足さない。調査で見つかった候補 5 件は下の表に残し、取り込みを別に判断する。

この提案は THEME-PAGE-REVIEW-01 の段 4 (全 56 テーマの指標の見直し) の 1 回目で、調査 (theme-researcher) と設計 (theme-designer) の結果を機械で検査してまとめた。カタログに無い指標・同じ指標の重複・取りこぼしは 0 件。agent が書いた事実の裏取りは「確かめていないこと」に挙げた範囲で未了。

## 確かめていないこと

- e-Stat API は直接叩いておらず、0000010108 の各 cdCat01 の年次範囲と47県の欠測は未確認。候補の e-Stat 実在はリポジトリ内の週次列挙ファイルを根拠にしており、live の API 照合は呼び元で必要
- 公式ダッシュボード研究カタログに廃棄物の記録が無く、環境省などの一次資料を WebFetch で確認していない。出典 URL は新規に書いていない(現行カタログの env.go.jp URL は未再確認)
- 市区町村別の問い(「ごみ排出量 ランキング 市町村」35回)に対する県別ページ上の見せ方は未調査
- H5616/H5617 から残余年数を作る算式が公式にあるかは未確認のため、割り算指標は候補にしていない
- garbage-landfill-rate の登録 statsDataId(0000010208)が都道府県表として妥当か、H5610 と同じ0000010108表との関係は未確認
- 1ページあたりの検索語は当テーマ専用の集計がなく、サイト全体28日の語から語彙で拾っただけ(クリックはほぼ0で、需要の強さは表示回数のみ)
- 設計案の見出しは agent が書いた文で、検索語との対応は上の「読者の問い」の根拠の範囲でしか確かめていない。
- 画面での見え方 (最初の画面のタイルの数・高さ) は未計測。実装後に `measure-theme-weight.mjs` で測る。
