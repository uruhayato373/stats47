# テーマレビュー: roads（道路）

## 結論

主問は、**その都道府県にどのような道路網が整備され、道路種別・面積に対する供給と実際の交通利用がどう異なるか**とする。

読み順は次の4層に分ける。

1. **道路網の規模**: 道路実延長、高速道路、一般国道、都道府県道、市町村道
2. **地域規模で調整した供給**: 総面積当たり道路延長、人口当たり延長。分母の意味を明記
3. **整備状態**: 改良率、舗装率、橋梁・トンネル等。道路種別と舗装定義を統一
4. **利用**: 交通量、走行台キロ、渋滞。道路延長とは別の調査・観測単位として扱う

道路が長いこと、密度が高いこと、交通量が多いことは、それぞれ道路網の規模、土地面積に対する配置、利用集中を示す。いずれも単独では利便性、安全性、整備の十分さを表さない。道路延長が長い県は維持管理対象も大きく、交通量が多い県は需要の大きさと混雑の両方を含む。

## P0: 対象範囲・系列監査

実装前に次を確定する。

- 道路統計調査が道路法第3条の高速自動車国道、一般国道、都道府県道、市町村道を対象とし、林道・農道等を含まないこと
- 実延長が総延長から重用延長、未供用延長、渡船延長等をどう除いた値か
- `road-total-length-with-expressway = road-total-length + road-expressway-length` が47県で加法整合するか
- `road-total-length` が高速道路を除くことと、一般国道+主要地方道+一般都道府県道+市町村道等の内訳整合
- 現行metricsに一般都道府県道がなく、「国道・主要地方道・市町村道」だけでは道路全体の構成にならないこと
- 高速道路が高速自動車国道だけか、自動車専用道路・都市高速・一般有料道路等を含むか
- 延長6指標が現行設定では2023年1点のみで、「推移」chartを構成できないこと
- `#H06401` の公式計算式が道路実延長÷総面積であり、現行chartタイトルの「可住地面積当たり」が誤りであること
- `road-length-per-km2` のunitが `km` ではなく実質 `km/km²` と読める表示になっているか
- 総面積当たり密度が山地・離島等を含み、市街地の道路アクセスを直接表さないこと
- 主要道路舗装率の「主要道路」が一般国道+主要地方道+一般都道府県道のどの範囲か
- 舗装に簡易舗装を含むか。道路種別ごとの分子・分母を確認
- `average-road-traffic-volume` が全国道路・街路交通情勢調査のどの道路区間を対象にした平日昼間12時間平均か
- 都道府県平均交通量の加重方法、調査区間、推定区間、道路種別構成が県間で比較可能か
- 2020年表記と令和3年度一般交通量調査の実施年・延期経緯が整合するか
- 交通量調査が周期調査で、単年値を年次推移chartにしないこと
- `roadside-station-count` が2018年国土数値情報で、国土交通省の最新登録一覧より古いこと
- 道の駅の登録数を交通量、観光客数、地域経済効果の代替にしないこと
- 年度末現在・調査年度・暦年を指標ごとに区別すること

## 公式根拠

### 国土交通省「道路統計調査」

- URL: https://www.mlit.go.jp/road/road_fr4_000069.html
- 道路法に基づく高速自動車国道、一般国道、都道府県道、市町村道の延長・幅員・橋梁・トンネル等の中心出典
- 道路種別、総延長、実延長、舗装、改良の定義を表単位で確認する

### 国土交通省「道路統計年報」

- URL: https://www.mlit.go.jp/road/ir/ir-data/tokei-nen/2025/nenpo02.html
- 都道府県別実延長、道路種別、舗装・改良状況等の公式年報
- 年報名の年と現況基準日・データ年度を混同しない

### 国土交通省「道路についての定義・用語」

- URL: https://www.mlit.go.jp/road/soudan/soudan_01a_02.html
- 高速自動車国道、一般国道、都道府県道、市町村道の区分根拠
- 林道・農道等の他法道路を道路統計の総延長へ加えない

### e-Stat「社会生活統計指標 H 居住・指標計算式」

- URL: https://www.e-stat.go.jp/koumoku/sihyo_keisansiki/H
- `#H06401` が道路実延長÷総面積、`#H06406` が舗装主要道路延長÷主要道路実延長であることの公式根拠
- stats47のタイトル・unit・分母注記を計算式へ一致させる

### 国土交通省「全国道路・街路交通情勢調査 一般交通量調査」

- URL: https://www.mlit.go.jp/statistics/details/sample03_2_00044.html
- 箇所別・時間帯別交通量、道路状況等の中心出典
- URL: https://www.mlit.go.jp/report/press/road01_hh_001673.html
- 令和3年度調査の実施年、平日昼間12時間交通量等を確認する

### 国土交通省「道の駅一覧」

- URL: https://www.mlit.go.jp/road/Michi-no-Eki/list.html
- 最新の登録道の駅、登録回、登録年月、所在地の正本候補
- 2018年GIS snapshotは位置情報用contextとし、最新件数と分離する

### 追加チャート

1. **道路種別構成**: 高速自動車国道、一般国道、主要地方道、一般都道府県道、市町村道が排他的・加法可能な場合のみ。
2. **総延長と総面積当たり延長**: 別panelで規模と密度を分離。
3. **舗装率・改良率**: 同一道路scopeの系列を別panelで表示。
4. **交通量・走行台キロ**: 同じ一般交通量調査の年だけで表示し、単位を分離。
5. **最新道の駅数**: 登録基準日付きKPI。2018年GIS位置情報は別表示。
6. **道路延長・維持管理**: 橋梁・トンネル・老朽化指標が47県比較可能な場合の将来候補。

## 不採用・保留

| 候補 | 判定 | 理由 / 再検討条件 |
|---|---|---|
| 道路延長が長い=道路整備が優れている | 不採用 | 面積、集落分布、維持管理負担を反映しない |
| 道路密度が高い=アクセスが良い | 不採用 | 接続性、速度、幅員、混雑、人口分布を反映しない |
| `#H06401`を可住地面積当たりと表示 | 不採用 | 公式計算式の分母は総面積 |
| 高速込み総延長と高速道路延長を排他的に積上げ | 不採用 | 総延長が高速道路を内包する |
| 国道+主要地方道+市町村道=道路全体 | 不採用 | 一般都道府県道等が欠ける |
| 舗装率100%=道路状態が良好 | 不採用 | 劣化、幅員、耐震、除雪、維持管理を示さない |
| 平均交通量が多い=利便性が高い | 不採用 | 需要集中と混雑の双方を含む |
| 2020年交通量を通常年の構造と断定 | 不採用 | 調査実施年とコロナ禍の影響を確認する必要がある |
| 道の駅数=利用者数・観光効果 | 不採用 | 規模、利用、機能、立地を反映しない |
| 2018年道の駅数を最新値として表示 | 不採用 | 最新登録一覧との差がある |
| ICアクセス指標 | 保留 | 47県で一貫したGIS計算・人口カバー率が実装できる場合のみ |

### 禁止

- 道路延長・密度・交通量を利便性や安全性の直接指標と呼ばない
- 総面積当たりを可住地面積当たりと表示しない
- 高速込み総延長と高速道路延長を排他的に積み上げない
- 不完全な道路種別だけで全体構成を作らない

## 採用決定

**PR-0の定義・加法・調査年監査後に実装可能。総面積当たり道路延長を規模調整した主軸とし、総延長、道路種別、舗装・改良、周期交通量を別概念として構成する。現行の可住地面積表記と単年lineを修正し、2018年道の駅GISは最新行政件数から分離する。**
