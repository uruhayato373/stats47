# テーマ改善の提案: ひとり親家庭の生活 (single-parent-households)

## 結論

章を読者の検索の問いの順に並べ直し、県別ページの最初の画面にその県の数値が 2 つ以上並ぶようにする。最初の章は主指標の母の就業割合と父の就業割合を stat で 2 枚並べ、県別ページの最初の画面に 2 つの値が見えるようにした。検索語の多い「母子世帯の多さ」は率の指標が登録されていないため章にできず、世帯数は 1980〜2020 の 9 時点を活かして 2 章目の推移に置いた。生活保護の母子世帯数と児童扶養手当の受給者数は、どちらも 49 時点あるため 3 章目に推移として置き、単位が違う（世帯と人）ので率としては並べていない。所得階級の 6 指標は単年・context のままで、既存の構成比チャートが担う。

新しい指標は今回足さない。調査で見つかった候補 5 件は下の表に残し、取り込みを別に判断する。

この提案は THEME-PAGE-REVIEW-01 の段 4 (全 56 テーマの指標の見直し) の 1 回目で、調査 (theme-researcher) と設計 (theme-designer) の結果を機械で検査してまとめた。カタログに無い指標・同じ指標の重複・取りこぼしは 0 件。agent が書いた事実の裏取りは「確かめていないこと」に挙げた範囲で未了。

## 確かめていないこと

- WebFetch と WebSearch を呼んでいないため、e-Stat 上で statsDataId を直接確かめていない。候補5件は data/metrics に登録済みという repo 内の記録だけが根拠で、e-Stat API での再照合は呼び元が必要
- 新規の e-Stat 指標(ひとり親世帯の割合、養育費受領率、母子世帯の平均年間収入、全国ひとり親世帯等調査の県別値)は探せておらず、候補に入れていない
- 「シングルマザー率」「ひとり親世帯割合」に答える分母つき指標(母子世帯数÷世帯総数)は登録済みキーから見つけられていない。世帯総数との割り算で作れるか呼び元の判断が要る
- public-dashboards.json にひとり親・母子に該当する記録が grep で見つからなかった(別の書き方の可能性は未確認)。公式ダッシュボードの参照例は無い
- 候補3つの子の人数別と離婚系の年数・期間は inventory 対象外のため未確認。使うなら年数の確認が要る
- GSC の表示回数は28日分の少数(最大9回)で、検索需要は小さい。クリックはシングルマザーが多い県の1回のみ
- 設計案の見出しは agent が書いた文で、検索語との対応は上の「読者の問い」の根拠の範囲でしか確かめていない。
- 画面での見え方 (最初の画面のタイルの数・高さ) は未計測。実装後に `measure-theme-weight.mjs` で測る。
