# テーマ改善の提案: 睡眠と生活時間 (daily-time-use)

## 結論

章の数は 4 のまま、検索需要が大きい労働時間の章を家事の章より前に出し、章の題を読者の問い(睡眠は県別ランキング検索の語、労働時間と余暇は W45 の検索語)の形にした。労働時間の章には月間実労働時間(男女)と週60時間以上の雇用者割合を、余暇の章には休養・くつろぎ時間(男女)を、登録済みの指標から足した。最初の章は睡眠を維持し、先頭 2 ブロックを 2021 年の stat にしたため、男女を重ねる sex ブロックは使えなくなった(同じ指標を 2 ブロックに入れない制約のため)。

THEME-PAGE-REVIEW-01 の段 4 (全 56 テーマの指標の見直し)。調査 (theme-researcher) と設計 (theme-designer) の結果を機械で検査し (実在しない指標・重複・取りこぼし・`validate:catalog`)、通った案をカタログへ適用した。

## 確かめたこと・確かめていないこと (agent の申告)

- 確認済み: addMetrics の 5 指標は data/metrics/<key>.ts が実在し isActive: true。years と出典 URL は定義ファイルから転記した(休養は 1981-2021 の 9 年、月間実労働時間は 2020-2024、週60時間以上割合は 2022 の 1 年)
- 確認済み: いまのカタログの context を除く 8 指標(睡眠・家事・仕事・趣味娯楽の男女)はすべて 1 つのブロックに入れ、重複なし。drop は空。主指標 sleep-avg-time-female は最初の章の先頭に置いた
- 確認済み: 最初の章の先頭 2 ブロックは stat で、睡眠の最新年は inventory.json の metricInfo で 2021(2020 年以降)
- 確認済み: trend ブロックは作らず、sex ブロックは同じ単位の男女の組だけ(月間実労働時間は時間、そのほかは分)。単年の 60plus 割合は stat にした
- 確認済み: composition は使っていない。足して全体になる組かどうかは定義ファイルで確かめていない
- 注意: 登録済みの睡眠・家事・仕事・趣味・休養は一日の平均時間(1 人あたりの平均)で、率・人口あたりの指標は無い。睡眠の章に割合の指標は置けないため総量(平均時間)のままで、割合は労働時間の章の週60時間以上割合だけ
- 注意: 仕事の平均時間(有業者・分/日)、月間実労働時間(時間/月)、週60時間以上割合(就業構造基本調査・年間200日以上就業の雇用者)は対象も単位も違うため合算せず、章内でブロックを分けた
- 未確認: 月間実労働時間の cdCat01 が表す元の調査名と対象(定義ファイルの出典は社会・人口統計体系としか書かれていない)。ブロック題に調査名は書いていない
- 未確認: 休養・くつろぎ時間の対象が全員か有業者かの区別(定義ファイルの subtitle は男女のみ)。趣味・娯楽の有業者とは別ブロックにし、合算しない
- 未確認: 睡眠・家事・仕事の最新年の 2021 は inventory.json の値で、R2 の実データでの鮮度は見ていない。e-Stat の表内容は API で照合していない
- 未確認: selection.json の視点との照合は、card-chart-duplicate(カタログの charts は空)と single-year-as-trend(1 年指標は stat に限定)のみ。新規 5 指標の selection 根拠(一次資料の逐語引用)は未作成
- 調査の未確認: cdCat01 は data/metrics の定義を最後まで読んでおらず、全候補で未確認
- 調査の未確認: hobby-leisure-avg-time-unemployed-female と primary-activity-avg-time-female は inventory.json の metricInfo に無く、年数・期間を確認していない
- 調査の未確認: selection.json (指標を選ぶ視点) は読んでいない
- 調査の未確認: 割合・人口あたり・世帯あたりの指標は生活時間テーマでは時間が主軸のため、weekly-hours-60plus-rate 以外は探していない。通勤時間・ボランティア行動者率・インターネット利用時間系の登録済み指標は grep で見つからず、未調査
- 調査の未確認: e-Stat 側の実在(statsDataId の表内容)は API で照合していない。登録済みの値を data/metrics から転記しただけ
- 調査の未確認: 検索語はサイト全体の W45 1 週分の記録で、県ページ別の需要は見ていない
