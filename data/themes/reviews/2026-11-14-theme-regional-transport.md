# テーマ改善の提案: 自動車依存と移動手段 (regional-transport)

## 結論

章を読者の検索の問いの順に並べ直し、県別ページの最初の画面にその県の数値が 2 つ以上並ぶようにする。調査の助言どおり車・バス・鉄道の 3 本を最初の画面に出すため、通勤・通学の 3 指標を先頭の章に移した。ただし主指標を含む stat を先頭に置く制約があるため、自動車所有数量 (最新年が 2014 年) の stat を最初に置き、続けて車・バス・鉄道の 4 タイルを並べた。この主指標の年の古さは、タイルに年が出る前提で許容した。通勤・通学の 3 指標は 2 時点しかなく同じ単位でもあるが、タイルを 2 つ以上先頭に並べる制約を優先して stat にした。2 つ目の章は、1975〜2013 年の長期の背景であるバス事業者 (単独で trend 指定。1 指標なので実際は数値カードになる)、3 つ目の章は交通・通信支出とし、章は 4 つから 3 つに減らした。commutes-total は context のため載せていない。

新しい指標は今回足さない。調査で見つかった候補 5 件は下の表に残し、取り込みを別に判断する。

この提案は THEME-PAGE-REVIEW-01 の段 4 (全 56 テーマの指標の見直し) の 1 回目で、調査 (theme-researcher) と設計 (theme-designer) の結果を機械で検査してまとめた。カタログに無い指標・同じ指標の重複・取りこぼしは 0 件。agent が書いた事実の裏取りは「確かめていないこと」に挙げた範囲で未了。

## 確かめていないこと

- e-Stat の実 API は呼んでいない。分類コードの確認はリポジトリ内のメタ複製 (data/estat/meta) による。複製の鮮度は未確認
- 公式ダッシュボードの研究カタログは語検索で京都市交通局の記録に当たっただけで、中身も一次資料の URL も開いていない。公共交通の問いの公式ページ根拠は無し
- 乗用車の保有台数・運転免許保有者数など、自動車依存を最新年で測れる指標の statsDataId は見つけられなかったので候補に入れていない。car-ownership が 2014 年止まりなので、最新年の代替指標が最大の穴
- commute-by-car/bus/train は人数で、読者が検索する『割合』の形にはなっていない。割合化が可能か (分母 commuters-total との関係) は未検証
- bus-fare-consumption-expenditure と minicar-count、hire-taxi-operators の年数は inventory に記録が無く確認できていない (hire-taxi-operators は TS 上 1975〜2013)
- roadside-station-count (道の駅数、検索需要は大きい) は roads テーマの指標で、metric TS に statsDataId が無く e-Stat 由来か確認できないため候補に入れていない
- GSC の記録はサイト全体の 28 日分で、/themes/regional-transport や県別ページ単体の表示回数ではない
- 設計案の見出しは agent が書いた文で、検索語との対応は上の「読者の問い」の根拠の範囲でしか確かめていない。
- 画面での見え方 (最初の画面のタイルの数・高さ) は未計測。実装後に `measure-theme-weight.mjs` で測る。
