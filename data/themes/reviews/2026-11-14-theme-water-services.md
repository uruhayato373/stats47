# テーマ改善の提案: 水道の持続性 (water-services)

## 結論

検索需要のほぼすべてが下水道普及率の県比較・低い理由・推移だったため、普及の章を先頭に移し、水道管の老朽化と更新を後ろへ回しました。先頭の章には、最新年が2023年の下水道処理人口普及率と、登録済みの汚水処理人口普及率を stat で並べ、複数年ある下水道普及率の系列を trend で足しました。上水道給水人口比率は「水道がどれだけ行き渡るか」の問いに合うので、給水量・施設能力と同じ最終章へ移し、総量だけの章にならないようにしました。

THEME-PAGE-REVIEW-01 の段 4 (全 56 テーマの指標の見直し)。調査 (theme-researcher) と設計 (theme-designer) の結果を機械で検査し (実在しない指標・重複・取りこぼし・`validate:catalog`)、通った案をカタログへ適用した。

## 確かめたこと・確かめていないこと (agent の申告)

- 確認: 現在のカタログは9指標・4章で、章の数は増やしていない。全9指標が章のブロックに入り、同じ rankingKey を2つのブロックに入れていない。
- 確認: 追加2指標とも data/metrics に定義があり isActive: true。年は sewage-treatment-coverage-rate が2023のみ、sewerage-penetration-rate-2012on が2016〜2021 (定義ファイルの years)。
- 確認: 先頭の章の先頭2ブロックは stat で、最新年はいずれも2023年 (割合の指標)。2015年以前の指標は置いていない。
- 確認: trend に入れた指標はすべて2年以上ある (給水人口比率 2012〜2023、給水量 2000〜2022、施設能力 2005〜2022、下水道普及率 2016〜2021)。1ブロックは3指標・単位2種以内で、最終章の給水量と施設能力のブロックは2指標・単位2種。
- 確認: composition は使っていない (足して全体になる組を統計表で確かめていないため)。
- 確認: 追加した2指標は他のテーマのカタログに載っていない (data/themes/catalogs を grep)。
- 確認: septic-tank-flush-rate と public-sewer-housing-ratio は定義ファイルの entities が city のみのため、都道府県の章には足していない。water-sewer-consumption-expenditure は値が都道府県庁所在市のものと定義ファイルの note にあり、検索需要も弱いので足していない。
- 確認: 水道管路の章と最終章の給水量・施設能力は総量・延長の指標だが、同じ章に割合の指標 (経年化率・更新率・給水人口比率) を並べた。ただし給水量・施設能力の2指標には人口あたりの登録済み指標が無く、最終章では給水人口比率で補った。
- 未確認: sewerage-penetration-rate-2012on (SSDS #H0530401) と sewerage-coverage-rate (H5411) の定義が同じか。ブロック題は前者の指標名のまま使い、同じ系列とは書いていない。
- 未確認: 汚水処理人口普及率に浄化槽などが含まれるかどうか。定義ファイルに description が無く、章や題には含まれる内容を書いていない。
- 未確認: e-Stat API で統計表そのものを再取得して statsDataId・cdCat01 の実在を確かめてはいない。定義ファイルの記載を読んだだけ。
- 未確認: 検索語はサイト全体の記録で、/themes/water-services への流入とは結び付けていない。
- 未確認: data/themes/viewpoints/selection.json の採用基準に照らした selection の追記は今回の設計の範囲外で、追加2指標の selection は書いていない。
- 調査の未確認: data/themes/viewpoints/selection.json は読んでいない
- 調査の未確認: e-Stat API で統計表そのものを再確認していない。statsDataId・cdCat01は data/metrics の定義の記載で、実在は未検証
- 調査の未確認: public-sewer-housing-ratio と water-sewer-consumption-expenditure の年数・県別粒度は確認していない
- 調査の未確認: sewerage-penetration-rate-2012on と sewage-treatment-coverage-rate は inventory の metricInfo に無く、年数は data/metrics の years 値による
- 調査の未確認: 水道料金・水質・断水などの検索語は上位に出ず、水道料金の都道府県別の登録済み指標は探していない
- 調査の未確認: 検索語はサイト全体の記録で、/themes/water-services や /areas の特定ページに結び付けた数字ではない
- 調査の未確認: 他の候補(下水道排水区域人口など総量)は割合ではないので候補に含めていない
