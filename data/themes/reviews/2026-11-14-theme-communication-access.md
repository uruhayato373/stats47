# テーマ改善の提案: 通信環境とデジタル基盤 (communication-access)

## 結論

最初の章を検索需要が最大の携帯電話契約数 (人口千人当たり・2023年) にし、総量のブロードバンド契約数 (2024年) は同じ章に人口あたりの指標と並べた。現行の 3 章は 1 章 1 指標だったため、公衆電話と世帯の端末を 1 章、通信費を 1 章にまとめ直し、章の数は 3 のまま増やしていない。登録済みの指標のうち 4 件 (公衆電話・ネット接続料・携帯通信料・パソコン所有) を足し、古い世帯の所有数量 (最新 2014 年) は先頭の章から外した。

THEME-PAGE-REVIEW-01 の段 4 (全 56 テーマの指標の見直し)。調査 (theme-researcher) と設計 (theme-designer) の結果を機械で検査し (実在しない指標・重複・取りこぼし・`validate:catalog`)、通った案をカタログへ適用した。

## 確かめたこと・確かめていないこと (agent の申告)

- data/metrics の定義ファイルで追加 4 件と既存 3 件の isActive: true と years を確認した (公衆電話 1975〜2024、ネット接続料 2002〜2025、携帯通信料 2000〜2025、パソコン 1984〜2014、携帯契約数 2000〜2023)
- 先頭の章の 2 ブロックは stat で、携帯電話契約数 (最新 2023) とブロードバンド (最新 2024) はどちらも 2020 年以降。最新年 2014 の所有数量は第 2 章に置いた
- ブロードバンド契約数は総量のみ。登録済みに人口あたり・世帯あたりが見つからなかったため総量のまま、同じ章に人口千人当たりの携帯電話契約数を並べた (検索は grep のみで網羅は示せない)
- composition は使っていない。trend は 2 年以上の指標だけで、第 2 章の 2 つ目の trend は同じ単位 (台) の 2 指標
- 現行の指標 (context を除く) 3 件は全てブロックに入り、同じ rankingKey は 1 回だけ。internet-usage-rate-10plus と broadband-service-contract-count は context のまま触っていない
- 第 2 章に章 key を fixed-broadband-environment のまま使ったが、中身は公衆電話・端末で key 名と合わない。章 key を付け替える余地がある。第 3 章も household-mobile-ownership のままで内容は通信費
- 追加したパソコン所有数量は、役割の選択肢が primary / secondary だけのため secondary と書いた。実際の位置づけは補助 (古い 2014 年まで) で、context にするかは apply 側の判断
- 未確認: 通信費の家計調査の値は県庁所在市の二人以上世帯で県全体の値ではない (ネット接続料の定義ファイルの description を読んだ。携帯通信料側は description を読んでいない)
- 未確認: e-Stat API は呼んでおらず statsDataId と cdCat01 の実在は照合していない
- 未確認: 追加した指標の定義文 (description) が theme-metric-description-regression の検査を通るか。公衆電話・パソコン・携帯通信料の定義ファイルに description の行が見つからなかった
- 調査の未確認: e-Stat API は呼んでいない。statsDataId と cdCat01 は data/metrics の定義ファイルに書かれた値で、e-Stat 側の実在は照合していない
- 調査の未確認: public-phone-count-per-1000 の cdCat01 と、pc-ownership の最新年は確認していない
- 調査の未確認: 現行の internet-usage-rate-10plus は2001〜2006年の2時点だけで、より新しい登録済みのインターネット利用率は探し切れていない (smartphone-usage-rate-by-sex は2021年1時点で性別のため都道府県比較向きか未確認)
- 調査の未確認: GSC の表示回数は28日・サイト全体の検索語で、クリックがほぼ0のため需要は表示回数ベースの目安にとどまる
- 調査の未確認: 総量しか載っていない件 (ブロードバンド契約数) の人口あたり・世帯あたりの登録済み指標は grep では見つからなかった (broadband-service-contract-count と excluding の2件とも契約数)
- 調査の未確認: 電気通信サービスの四半期データに対応する都道府県別の指標は調べていない
