# テーマ改善の提案: 職業別年収 (occupation-salary)

## 結論

章を読者の検索の問いの順に並べ直し、県別ページの最初の画面にその県の数値が 2 つ以上並ぶようにする。検索需要が大きい医療・介護職の県値を先頭章に stat 4 枚で並べ、主指標の医師と看護師が最初の画面に入るようにした。次に需要のある教員・保育士・大学教員、大工を含む運輸・建設、IT・専門職、サービス職の順に並べ直し、章は現行の 5 つのまま key も変えていない。需要のある歯科医師・大学教授・准教授・大工は context から章に引き上げ、全職種の県平均や初任給は登録済みでもカタログに無いため今回は扱わない。

新しい指標は今回足さない。調査で見つかった候補 5 件は下の表に残し、取り込みを別に判断する。

この提案は THEME-PAGE-REVIEW-01 の段 4 (全 56 テーマの指標の見直し) の 1 回目で、調査 (theme-researcher) と設計 (theme-designer) の結果を機械で検査してまとめた。カタログに無い指標・同じ指標の重複・取りこぼしは 0 件。agent が書いた事実の裏取りは「確かめていないこと」に挙げた範囲で未了。

## 確かめていないこと

- 警察職 平均給与月額(avg-salary-police-prefecture、2012-2024の13年・47県)は検索需要が最大級(警察官年収ランキング系で計100回超の表示)だが、出典は総務省「地方公務員給与実態調査」の外部取り込み(fetcherKey local-public-employee-salary)で e-Stat の statsDataId を持たず、候補に入れなかった。同系の教育公務員・一般行政職(avg-salary-education/admin-prefecture)も同様。呼び元で出典の一次資料と取り込み状況を確認する必要がある
- e-Stat API・catalog.mjs・WebFetch は今回呼んでおらず、候補5件の statsDataId と cdCat は data/metrics の config 記載のみで確認した(e-Stat上の実在は未照合)。「登録済」はこの意味で、年次・cdCat03 の詳細(男女・学歴等)は呼び元で API 照合が必要
- 公式ダッシュボード研究カタログ(public-dashboards.json)には賃金・年収・給与に直接該当する項目が見つからなかった(語の検索のみで網羅確認はしていない)ため、政策上の問いは検索語と metricInfo から組み立てた
- 女性所定内給与(female-scheduled-earnings)・きまって支給する現金給与月額(regular-cash-salary-*)・看護師の所定内給与(nurse-salary)の statsDataId は未確認で候補に含めていない
- 一次資料の URL は WebFetch していないため、新たな出典 URL は返していない(config の既存 url のみ参照)
- GSC は全サイト合算の28日で、/areas/<県>/occupation-salary と /themes/occupation-salary への流入に絞った集計ではない。検索語も表示1〜数十回と少なく、需要の優先順位づけは弱い根拠に留まる
- 設計案の見出しは agent が書いた文で、検索語との対応は上の「読者の問い」の根拠の範囲でしか確かめていない。
- 画面での見え方 (最初の画面のタイルの数・高さ) は未計測。実装後に `measure-theme-weight.mjs` で測る。
