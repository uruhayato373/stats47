# テーマ改善の提案: 労働・賃金 (labor-wages)

## 結論

**いまは実装しない。** このテーマには測定中の実験 (`THEME-STRUCTURE-20261007-labor-wages` (d56 = 2026-12-02)、`THEME-COPY-20261112-labor-wages` (d56 = 2027-01-07)) があり、章や指標を変えると測定に混ざる。実験の判定が出た後 (2027-01-07 以降) に、その結果を踏まえてこの案を見直してから実装する。

機械で一括に組み直す方法 (`apply-design.ts --approved`) は、このテーマには使わない。同じ日に実験のある 5 テーマへ試したところ、人が作り込んだ図・埋め込みの節・章の構成を固定するテストが落ちた (カタログの検査 1 件・テスト 6 件。変更は取り消した)。実装するときは、提案の採否を 1 項目ずつ決めて手で直す (`theme-proposal-format.md` の手順)。

設計の agent の案: いまの 5 章を 4 章にまとめた。最低賃金の章に初任給を合わせて先頭に 2 つの stat を置き (最新年 2024 と 2023)、需要が最大の共働き世帯割合 (登録済み・割合指標) を女性の就労の章に足して水準の後ろに置いた。男女の賃金差は sex ブロックで男女を重ね、男女の労働時間を最後の章で並べる。読み方・FAQ の章は指標のブロックを持たないため章としては出さず、markdown の 2 件の扱いは適用側で確かめる必要がある。

## 確かめたこと・確かめていないこと (agent の申告)

- catalog labor-wages.json の metrics 20 件・sections 5 章・metricGroups の構成を読んだ
- minimum-wage-by-region は inventory で 2010-2024・15 年・47 県・円、starting-salary-university/highschool は 2020-2023・47 県で、最新年が 2020 年以降であることを確認した
- dual-income-household-ratio と monthly-average-actual-working-hours-female は data/metrics の定義ファイルを読み、isActive: true・出典 URL・years (1980-2020 の 9 年 / 2020-2024) を確認した
- dual-income-household-ratio の分母は一般世帯全体で、割合の指標 (総量ではない) であることを定義文から確認した
- labor-force-population-ratio-woman と dual-income-household-ratio はどちらも単位が％で、trend 1 ブロック 2 指標・単位 1 種に収まる
- 男女の sex ブロック 3 組 (現金給与月額 千円・パート給与 円・労働時間 時間) は、同じ単位の [男, 女] の組で、現金給与月額の男女は定義ファイルで cdCat01 #F0620103 / #F0620104 の対を確認した
- gender-wage-gap は 2021-2022 の 2 年で trend の条件 (2 年以上) を満たす。female-scheduled-earnings も 2021-2022 の 2 年
- composition は 1 つも使っていない (足して全体になる組を確かめられた指標が無いため)
- いまのカタログの非 context 指標 12 件はすべて 1 回ずつブロックに入れた (同じ rankingKey の重複なし)。drop は空で、primary は minimum-wage-by-region のみ
- 未確認: 読み方・FAQ の markdown 章 (reading) を出さないことで、その 2 件の chart が適用時にどこへ付くか
- 未確認: female-scheduled-earnings と regular-cash-salary の月額を同じ章に置くことが、賃金構造基本統計調査と社会・人口統計体系という出典の違いで読者に混乱を招かないか
- 未確認: selection.json の規則 owned-elsewhere に当たる指標 (dual-income-household-ratio は gender-participation に掲載済み) を、主担当のテーマの primary かどうかまでは確かめていない
- 未確認: monthly-average-actual-working-hours-female の cdCat01 (#F0610104) が男性の #F0610103 と同じ定義の女性版であること (定義ファイルの subtitle だけで確認)
- 非正規雇用率・週60時間以上就業・看護師の平均年収は、1 年のみ・他テーマとの重複・検索需要の弱さから今回は足さなかった
- 割合・人口あたりの賃金系指標で登録済みのものは、共働き世帯割合以外に見つけていない(最低賃金・初任給などの水準指標は総量ではなく額)
- 調査の未確認: 割合・人口あたり・世帯あたりの賃金系登録指標は、共働き世帯割合・非正規雇用率・週60時間以上就業割合のほかには見つけていない(正社員比率・実質賃金指数・男女別の賃金比などは ls の名前検索の範囲で見つからなかった)。名前に wage/salary/income を含まない指標は拾えていない可能性がある。
- 調査の未確認: e-Stat API や Web での統計表の実在確認は実行していない。statsDataId はすべて data/metrics の定義ファイルから読み取った値で、cdCat01 を確認していない候補は空欄にした。
- 調査の未確認: selection.json(指標を選ぶ視点)は読んでいない。
- 調査の未確認: GSC の表示回数は 28 日・サイト全体の値で、テーマ別ではなく /areas/<県>/labor-wages への流入の切り分けはしていない。
- 調査の未確認: avg-salary-all-prefecture などの給与系指標は isActive と years を確認していない(inventory に載っていない)。
