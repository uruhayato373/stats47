スキル・エージェント実行時にユーザーへの確認（yes/no）を求めない。全て自動で最後まで処理すること。

**Why:** ユーザーが何度も yes の確認��求められ、作業が中断された。自律的に完了まで進めることを期待している。

**How to apply:**
- `mode: "bypassPermissions"` でサブエージェントを起動する（CLAUDE.md にも記載済み）
- スキルの手順は Sonnet でもそのまま実行できるレベルの正確さ・詳細さで記述する
- シェルのクォート問題を避けるため、複雑な JS は `/tmp/` にファイル書き出ししてから `eval` に渡す
- `browser-use` コマンドは `$BU` 変数展開ではなくフルコマンドで毎回記述する（zsh 互換性）
- DB パスはハードコード定数として冒頭に定義し、スクリプト内で参照する
