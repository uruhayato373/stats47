交通網 (高速道路・鉄道・空港) と人口・産業を組み合わせる画面で、私は 2 回「表示できる主題を全部選べる画面」(レイヤーのチェックリスト・凡例の改良) を作り込み、オーナーに「表示できるものを表示するのではなく、どんな問いに対して可視化するのかという視点が抜けている」と指摘された。

**Why:** データの種類から画面を組み立てると、選択 UI を良くしても読者の問いに答えないページになり、同じ穴に戻る。表示できるものを並べるのは GIS 台帳・単体 GIS ページ・`/geo/map` などの検索対象外の道具の仕事。

**How to apply:**
- 公開する組み合わせページ (`/geo/<問い>`) は、問い → 分析の型 (開通を起点に揃える・似た地域と比べる・相関・時系列の連動・位置関係) → 見せ方 (推移のグラフが主役、地図は「どこの話か」の補助) の順で設計してから作る。
- geo は計算と並べた結果まで。因果の解釈はブログ・テーマが受け持つ。
- UI の改善案 (選択の形・凡例・ナビ) を出す前に、「この画面はどの問いに答えるか」を先に確かめる。
- 設計の続きは backlog `GEO-QUESTION-DESIGN-01`。関連 [[project_two_machine_local_footprint_2026-09]]。
