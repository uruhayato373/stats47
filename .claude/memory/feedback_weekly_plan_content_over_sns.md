週次計画（/weekly-plan）の Must は **記事公開・SEO・指標拡張**（North Star = 週間 engagedSessions の実レバー）に集約する。SNS 投稿・note 投稿は Should 以下に置く。

**Why:** 2026-W22 計画時にユーザーが「コンテンツ/SEO に集約」を選択。実数で SNS は X 累計 4,188 imp（113投稿, ≒37 imp/投稿）・TikTok 124 views（57投稿）と NSM にほぼ寄与せず、成長レバーは Organic 検索流入（GSC clicks）。賃金 SNS 投稿・note A-laborwage は 3〜5 週連続で未達 — 慢性未達タスクを毎週 Must に積むのは前週と同じ失敗の再現。W21 では「計画外」だった gis-cross 記事のほうが逃した SNS/note より North Star に近かった。

**How to apply:** /weekly-plan の Phase 3-4 で、SNS/note 投稿タスクを Must に入れない（Should 以下）。Must は記事公開・SEO 改修・トレンド連動記事など Organic 流入直結タスクに限定。慢性未達タスク（複数週 `- [ ]` のまま）は Must に再掲せず降格する。関連: [[feedback_ga4_history_unreliable_wow]]（WoW は GSC clicks で見る）, [[feedback_sns_growth_emotion_themes]]。
