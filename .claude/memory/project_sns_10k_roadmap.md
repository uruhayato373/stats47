stats47 の SNS フォロワー 10K 達成戦略 (2026-05-24 ユーザー決定)。

## 決定事項

- **目標**: Instagram 10K フォロワーを 2027-02 末までに (9 ヶ月)
- **X**: 1-2K で最低限維持。記事公開連動の自動投稿 + 月 1-2 回手動スレッド投下のみ
- **路線**: B × C (路線 B = 数字対比・意外性 / 路線 C = IG 集中)
- **禁止**: リスク・治安・心霊・差別煽り (riskmap.jp 系の領域は侵さない)
- **OK**: 数字対比 / 意外な順位 / 自分の県への接続 / 経済格差 / キャリア統計

## 9 ヶ月ロードマップ

| Phase | 期間 | follower 目標 | 主な施策 |
|---|---|---:|---|
| Phase 0: 道具整備 | 2026-05-24 - 06-07 (2 週) | baseline 計測 | Reels 生成スキル開発、フック設計テンプレ、follower 週次計測 pipeline |
| Phase 1: アルゴ評価突破 | 2026-06 - 07 (2 ヶ月) | 0→500 | Reels 週 5 本、20 本でアルゴリズム評価獲得、Reach 突破 |
| Phase 2: 量産 + リミックス | 2026-08 - 10 (3 ヶ月) | 500→3K | バズった切り口を再現テンプレ化、1 素材を 3-4 角度でリミックス |
| Phase 3: 加速 | 2026-11 - 2027-02 (4 ヶ月) | 3K→10K | コラボ (地域 PR 系)、ハッシュタグ最適化、ストーリーズ + Reels 二段 |

## Content engine (路線 B のコンテンツ設計)

- **コア素材**: 「47 都道府県差ランキング」を 1 トピック → IG Reels + X スレ + ブログ送客の 3 媒体並列
- **Reels 仕様**: 47 秒以下、最初 1.5 秒で結論、テキストオーバーレイ + 0.5 秒に 1 画面切替、縦長 1080x1920
- **フック設計**: curiosity gap (例「東京の家賃は秋田の何倍?」「自立できる県はただ一つ」)
- **品質ゲート**: 投稿前に「これは保存される / シェアされる理由が言語化できるか」を 1 行で書く。書けないなら投稿しない

## X 最低限維持の運用

- 自動投稿で 1 日 1-2 本 (Web 記事公開連動)
- 月 1-2 回手動「47 都道府県スレッド」投下
- フォロワー目標 1-2K (実質放置)
