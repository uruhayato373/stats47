**Why:** todo-ran と uub.jp/pdr の指標数は stats47 の約 3 倍。検索クエリの空白を埋め切れず、SEO 流入で根本的に劣後する状態。10 年以上の継続運用による被リンク蓄積も差を広げている。

**How to apply:**
- 指標数の中期目標を「1,500 指標」に置く（todo-ran / uub に並ぶライン）
- 「とりあえず動く 1 指標」より「1,500 指標を支える pipeline 整備」を優先
- ただし量だけでは勝てない（todo-ran は被リンクで勝つ）→ 量は守りに使い、攻めは差別化軸（市区町村×動画 / 相関分析 / public API）で勝つ
