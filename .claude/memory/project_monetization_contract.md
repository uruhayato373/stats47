## 1. AdSense は 9/20 に恒久停止 → 9/28 に再開を決定 → 2026-10-11 に手動枠で再開

- **現行 (2026-10-11)**: 新アカウント `pub-9055416085403520` の審査が通り、`ADSENSE_DISPLAY_ENABLED` を true にした
  (2026-10-11 15:43 JST に PR #1123 で本番反映済み。状況は backlog `ADSENSE-RESTART-01`)。再開時は手動枠だけ。自動広告は 2026-11-04 からオン (アンカー・全画面・ページ内バナー。2026-11-11 オーナー決定で継続。広告インテントは body の google-anno-skip が拒否する)。広告ユニットは配置ごとに
  1 個 (計 11 個) で、配置はオーナー指示「色々と試しながら計測記録改善」によりユニット別の実測で決める。
  **「AdSense は恒久停止」と答えない** (2026-10-07 に古い記述だけを見てそう答え、オーナーの決定と食い違った)。
- **アカウントの所在**: AdSense の所有者は **stats47 専用の Google アカウント** (uruhayato373 ではない)。内部ブラウザでは
  uruhayato373 が `authuser=0` で AdSense に権限が無く、stats47 アカウントは `authuser=1`。uruhayato373 は GA4 にも
  権限が無い (GA4 プロパティ 463218070 の管理者は別アカウント)。2026-10-13 に stats47 アカウントを GA4 の管理者に足し、GA4 と新 AdSense をリンクした (GA4 は作り直していない)。週次取得の API は Variable `GOOGLE_ADSENSE_ACCOUNT_ID` を 2026-10-13 に新 ID へ替えたが、refresh token も 2026-10-13 に stats47 アカウントで再発行して Secret を差し替えた。
- **改善サイクル (2026-10-13 凍結解除)**: 再開後も NSM が「恒久停止で ¥0」固定、KPI `ad-yield` 未接続、`/adsense-improvement` 凍結、
  週次計画が AdSense 候補を不採用のままだった。同日に全部戻した (backlog `ADSENSE-RESTART-01`)。`ad-yield` は AdSense 確定 7 日 × 4 週 ÷
  GA4 Japan PV 28 日 × 1,000 (`.claude/scripts/metrics/lib/adsense-revenue.mjs`)、最初の値は 2026-W45。W42〜W45 はベースラインで配置を変えない。
  **再開・停止を変えるときは、表示スイッチだけでなく NSM・KPI・skill・週次計画の前提も同じ差分で直す** (今回は 2 日ずれた)。
- **見込みの注意**: AdSense の「ページ RPM ¥37」は AdSense 自身が数えた PV (GA4 の 54〜78%) が分母。GA4 の PV で割り直すと
  停止前 W30〜W33 は 1,000 PV あたり ¥22、W31 の手動枠分だけなら ¥6.7。GA4 の PV 目標の換算に ¥37 を使わない
  (2026-10-07 に「月¥1万 = 27万PV」と誤算した。正しくは約45万 PV、手動枠だけなら約150万 PV)。KPI は `site-pageviews` と `ad-yield`。

  判断したもの。凍結記録は `data/adsense/history.csv`、本番から外したのは 2026-08-29 (PR #849)。

## 2. 収益の本線は広告ではなく行政実務向け商品

広告レーンを全部うまくやっても月 1〜2 万円が上限である (上記 1 と、アフィリエイトの 28 日実測 CTR 0.049% から)。伸びしろは
`ADMIN-STAT-PILOT-01` の行政資料商品にあり、その読者はすでに来ている
(`/blog/assembly-answer-chatgpt-5steps` は CTR 13.1%、`/blog/local-government-debt-burden` は
28 日で 425 clicks)。**広告の改善を商品検証の前提条件にしない。**

## 3. 正本に全文がある判断 (2026-11-14 に本文を参照へ縮めた)

次の判断は正本に全文がある。ここには、読み落とすと誤る 1 行と、正本に書いていない実測だけを残す。

- **NSM は週次収益で、PV ではない** → `docs/00_プロジェクト管理/02_収益化戦略.md` §1。欠測・認証切れ・古い観測は 0 円にせず
  「判定不能」と書く (2026-09 にアフィリエイトの観測が 3 週間止まったまま、週次 cron は緑だった)。
- **アフィリエイトの評価は確定収益 / 1,000 viewable impression** → `.claude/rules/affiliate-ads-standards.md` の主指標。
  在庫を増やさず表示量を減らし、意図が解決しない面では配信しない。2026-08-10〜09-06 の 28 日は CTR 0.049% で、
  デスクトップの右レールが impression の大半を消費して CTR 0.0197% (モバイル 0.137% の 7 分の 1) だった
  (`data/affiliate/affiliate-placement-baseline-2026-09-08.json`)。priority は期待収益順で、A8 の `epcYen × confirmRatePct` は
  初期値 (自サイトの確定収益が溜まったら置き換える)。
- **GA4 の `affiliate_vertical` は広告自身の vertical を送る** → `.claude/rules/affiliate-ads-standards.md` §6.1。
  是正日を境に vertical 別の時系列は連続しない。
- **雑学の情報そのものは売れない。回収は 3 経路** → 収益化戦略 §3.5。stats47 の雑学の流入を商品へ誘導する前提を置かない。
  ノウハウ商品で「稼げる」を売り文句にしない。
- **サイト (集客) も 2026-10-07 から「攻める」** → 収益化戦略 §5「領域と優先順位」。新しいページを足すより、同じ品目に
  分かれたページの表示を 1 つに集める方が先 (食の 40 品目すべてに既にランキングがあり、表示が複数ページに割れていた)。
  SNS は送客を測るまで増やさない。
- **楽天市場の商品カードと返礼品カード、日次同期は 2026-11-06 に撤去した** → `.claude/rules/affiliate-ads-standards.md`。
  楽天アフィリエイトの楽天カードと成果の記録は残す。
