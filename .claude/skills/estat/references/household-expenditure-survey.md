# 家計調査 — 取得範囲とサイト展開の参照表

実装用の分析単位の台帳 (問い × 表の軸 × 載せるページ) は `packages/data-configs/src/kakei-analysis-catalog.ts`。`npm run metrics:check` で既存指標・ページ参照との整合を検査し、`npx tsx packages/data-configs/scripts/check-kakei-analysis-catalog.ts --list` で全行を表示する。`proposed` は図・記事の完成を示さない。表メタデータの126件確認は本資料の棚卸しであり、分析単位の17件はその中の制作候補と既存入口である。

**分析の切り口 (都市比較・数量と単価・年収階級・長期推移・季節など) は調査の切り口台帳 `data/surveys/lenses/kakei-chousa.json` が正本** (担当 survey-curator、展開状況は `npm run surveys:lenses:status`)。**表と品目の採否は台帳 `data/estat/kakei-ledger/ledger.json` が正本** (全表の周期・年・地域数・分類軸と、年次品目表の品目ごとの指標の有無・採否)。e-Stat カタログ (`npm run estat:catalog:pull`) と metric config から `npm run estat:kakei-ledger:build` で作り、手で編集しない。指標を作らない・作る予定の判断は理由付きで `data/estat/kakei-ledger/decisions.json` に書く。`npm run estat:kakei-ledger:check` (PR CI) が台帳・config・判断の食い違いを止める。下の件数・表一覧は棚卸し時点の記録で、現在の件数は台帳の `summary` を読む。

報道やクイズの「○○日本一」「○○市は全国 3 位」は、総務省が公表する県庁所在市と政令指定都市の **52 市・3 年平均** の順位で、サイトの都道府県別ランキング (県庁所在市の単年値) とは集計が違う (浜松・堺などの政令市は都道府県別に入らない)。この順位を記事に使うときは `node .claude/scripts/blog/fetch-kakei-city-average.mjs --slug <slug> --name <base> --item <cdCat01>:<品目名>` で e-Stat から作る (年次値の単純平均。静岡県の公表値と一致を確認済み)。切り口台帳の「定義を読む」「都市の間で比べる」の材料。

年次値を新しい年へ更新したら、題 (title / seoTitle) に旧年の値が残る家計調査の記事を `node .claude/scripts/blog/find-kakei-stale-title-values.mjs` で一覧し、本文・図とあわせて書き直す (2026-11-02 に 2025 年へ更新した時点で 138 本)。

調査: 家計調査（総務省）。家計収支編の二人以上・総世帯・単身世帯と、貯蓄・負債編の二人以上世帯を分けて扱う。

- **収入の意味**: 貯蓄・負債編の「年間収入」（万円）と、家計収支編の「実収入」「可処分所得」（1か月平均、円）は別系列。単純に同じ年収推移として連結しない。[総務省のFAQ](https://www.stat.go.jp/library/faq/faq19/faq19a04.html)。4-3の五分位は世帯主年齢と世帯人員も大きく異なるため、支出差を収入だけの効果と書かない。

- **2025年 API の分類コード**: 上位5品目の `cat01` は納豆 `010530030`、カップ麺 `010130050`、米 `010110001`、緑茶 `011010010`、牛肉 `010310010`。`cat02=03` は農林漁家世帯を含む二人以上世帯。公式 Excel の「282」等は印刷用の品目分類番号で、API の9桁 `cat01` とは別。
- **上位5品目の接続検査 (2026-11-01)**: 旧表と2025年表の2007〜2024年を地域・年・値で比較し、各946セルで差分0。新表の2025年は各53セル（全国＋52市）を取得。配信対象の47市×2007〜2025年は各893行で dry-run 形状検査PASS。R2への反映は未実施。
- **既存品目の一括接続検査 (2026-11-01)**: `cat02=03` の旧/新DB表から2024年の全行と新表2025年の全行を取得し、品目コード・地域・値・API単位で照合。旧表の支出額36,570行、数量10,918行に対し、新表2024年は支出額36,464行、数量10,812行。登録済みactive家計調査713指標のうち、上位5件は切替済み、**697件は2024年の旧/新表が52都市で一致し2025年も52都市に実値あり**。6件は複数コードの合算で個別照合、5件は分類変更/2025年欠測（ネクタイ支出・数量、婦人ストッキング支出・数量、他の被服小物支出）で自動更新しない。697件は値の接続が確認できた候補であり、固定SEO文・既存AI解説の旧年値を是正する前に公開しない。
- **分析の順序**: ①表ID・分類コード・世帯・地域・期間・単位・欠測を確定 ②読者の問いと GSC 需要を照合 ③その軸に合う図を選ぶ ④数値と出典を確かめた説明をランキング・テーマ・ブログへ置く。参考書の `data/source-inventory/kakei-marketing/2015/analyses.json` は問いの候補であり、値・図・本文の出典にはしない。NotebookLM の回答も公式表で照合する。

## 基本構造

家計調査は**都道府県庁所在市**（＋政令指定都市）単位のデータ。
社会・人口統計体系（`lvArea=2` で都道府県取得）とは取得方法が異なる。

| パラメータ | 値 | 備考 |
|---|---|---|

## 取得時の注意点

### 1. エリアフィルタ

`lvArea=2`（都道府県レベル）では該当データがない。**フィルタなし**で全エリアを取得し、プログラム側でフィルタする。

### 2. 政令指定都市の重複

県庁所在市が政令指定都市の場合、**同一県に複数行**が返る（2023年時点で52行）。

| area code | 都市名 | 都道府県 |
|---|---|---|
| `14003` | 横浜市 | 神奈川県 |
| `14004` | 川崎市 | 神奈川県 |
| `14150` | 相模原市 | 神奈川県 |
| `22003` | 静岡市 | 静岡県 |
| `22004` | 浜松市 | 静岡県 |
| `27003` | 大阪市 | 大阪府 |
| `27004` | 堺市 | 大阪府 |
| `40003` | 北九州市 | 福岡県 |
| `40004` | 福岡市 | 福岡県 |

**対処法**: 現行 `page-data-batch.ts` の `KAKEI_CITY_TO_PREF` で県庁所在市だけを明示的に写像する。福岡市は例外コード `40004`。ファイルの並び順で「各県の最初の行」を選ぶと北九州市などを誤採用するため使わない。

### 3. 標準バッチと2025年分類

現行 `packages/data-configs/scripts/page-data-batch.ts` は `kakeiEstatSource` で既存の
`kakei-chousa` 設定を e-Stat 取得へ渡し、`remapKakeiAreas` で県庁所在市を県表示へ対応させる。
ただし、既存設定の表 ID・品目コードは2024年までの系列であり、2025年改定との対応を確認せずに
`years.to` だけ変更してはならない。R2 は `app/stats/<key>/values.json` を配信する。
