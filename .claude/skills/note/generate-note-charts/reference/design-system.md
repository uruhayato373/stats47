# note チャート デザインシステム

note 記事用 SVG チャートの共通規約。ブログ記事用（`/generate-article-charts`）の規約を踏襲し、note 向けの差分を記載。

## サイズ

| 種別 | viewBox | PNG 出力 | density |
|------|---------|----------|---------|
| ランキング本文画像 | 640×960 | 1280×1920 | 288 |
| その他チャート（散布図等） | 600×540 前後 | 2x 解像度 | 288 |
| カバー画像 | 1280×670 | 等倍 | 72 |
| CSV サンプル | 332×任意 | 2x 解像度 | 288 |

ランキング本文画像は `generateBarChartSvg(..., { layout: "mobile" })` を正とする。PC横長版は文字が縮み、
Instagram 4:5版はSNS用余白を含むため、note本文への流用を禁止する。

## フォント

```css
font-family: 'Hiragino Sans', 'Noto Sans JP', sans-serif;
```

日本語は Hiragino Sans 優先。SVG 内で `<style>` ブロックに指定する。

## ドットサイズ

| 種別 | r |
|------|---|
| ハイライトあり | 5 |
| ハイライトなし | 3.5 |
| カバー画像（キー） | 6 |
| カバー画像（通常） | 4 |

## ラベル

- ハイライトされた都道府県名: `font-size="10.5"`, `font-weight="bold"`, 色はドットと同じ
- ラベルオフセット: `dx: ±8`, `dy: -8〜14` でドットとの重なりを回避
- `text-anchor`: ドットの左側なら `"end"`、右側なら `"start"`

## 凡例

- プロット領域の左下に配置
- 背景: `white` (opacity 0.85)、角丸 `rx="4"`
- 行高: 16px
- ドット: `r="4"`, テキスト: `font-size="10"`

## カバー画像

本文チャートの規約から分離する。全カテゴリ・新規・差し替えとも `/image-prompt --use-case note-header` を使う。
方針は `data/note/cover-policies.json` の最新版。Codex built-in imagegenで文字込みの完成画像を生成する。
ClaudeのSVG作画やこのチャート規約を使ったカバー代作は禁止。元画像・確認結果・候補・採用は共通画像台帳とprivate R2で管理する。
