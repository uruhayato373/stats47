# テーマレビュー: climate（気候）

## 結論

主問は、**その都道府県の平年の気候特性は何か、直近年の天候は平年からどの程度ずれたか、県内の空間差はどこにあるか**とする。

現行テーマは2024年などの単年観測を「気候」として前面に出している。気候の基準は原則として気象庁の現行平年値である1991〜2020年の30年平均とし、単年値は「2024年の天候」として分離する。ランキング値が都道府県全域の平均ではなく代表観測地点の値である場合、その地点名と代表性の限界を常時表示する。

読み順は次の4層に分ける。

1. **平年の気候**: 1991〜2020年の気温、降水量、日照時間、雪
2. **直近年の天候**: 暦年の年平均・年合計・日数と平年差または平年比
3. **極端現象**: 真の年最高・年最低気温、猛暑日、大雨等。月平均の極値とは分離
4. **県内の空間差**: 1kmメッシュ平年値。代表地点ランキングとの差を説明

## P0: 観測地点・平年値・方式変更監査

実装前に次を確定する。

- 社会・人口統計体系B4101〜B4110の各値が、都道府県全域平均か、都道府県庁所在地等の指定観測地点か
- 47都道府県それぞれの観測地点、移転、統計切断、欠測、準正常値・資料不足値の扱い
- `yearFormat: "fiscal"`となっている現行9指標が、実際は1月〜12月の暦年値ではないか
- 2024年の年平均気温・年間降水量・年間日照時間を1991〜2020年平年値と混同しないこと
- 気象庁の平年値更新周期と、現行平年値が1991〜2020年観測に基づくこと
- 国土数値情報G02-2022が「2022年の観測」ではなく「メッシュ平年値2020」であること
- 日照GISの属性`G02_071`、0.1時間単位、欠測コード`999999`、メッシュ解像度、集計期間
- 2021年3月2日以降、アメダス日照時間が日照計から推計気象分布による推計値へ変更された影響
- 方式変更前後の日照時間を無注記で連続比較・増減率計算しないこと
- `annual-clear-days`の2020年宮崎県0日が真の0か、観測地点・目視観測縮小・欠測等による値か
- `annual-snow-days`の観測地点coverageと、雪日数0が観測対象外・欠測ではなく真の0か
- `maximum-temperature`が真の年最高気温ではなく「日最高気温の月平均の最高値」であること
- `lowest-temperature`が真の年最低気温ではなく「日最低気温の月平均の最低値」であること
- `maximum-temperature`の2023年欠落、`lowest-temperature`の2017〜2023年欠落を線で接続しないこと
- `maximum-snow-depth`が2007年1点のみであり、現在の気候・積雪状況として扱えないこと
- 気温、mm、時間、日数は人口や面積で割る量ではなく、現行`normalizationOptions`が意味を持たないこと
- 降水日数の閾値、快晴日数・雪日数の定義が全地点・全年で同一か

## 公式根拠

### 気象庁「平年値について」

- URL: https://www.jma.go.jp/jma/kishou/know/faq/faq17.html
- 平年値はその地点の気候を表す基準で、現在は1991〜2020年の観測値によることの根拠
- 単年観測を気候そのものとせず、平年差・平年比で読む

### 気象庁「平年値の更新」

- URL: https://www.jma.go.jp/jma/kishou/know/stats/dounyu_5.html
- 30年間の平均と10年ごとの更新、統計方法・新平年値の公式説明

### 気象庁「地上気象観測」

- URL: https://www.jma.go.jp/jma/kishou/know/chijyou/surf.html
- 気温、降水、日照、雪等の観測要素・観測施設を確認する中心資料
- URL: https://www.jma.go.jp/jma/kishou/know/stats/dounyu_4.html
- 統計に用いる気象要素と集計値の定義を確認する

### 気象庁「過去の気象データ検索」

- URL: https://www.data.jma.go.jp/stats/etrn/index.php
- 地点別の暦年値、平年値、資料品質、観測地点を照合する正本候補

### 気象庁「アメダスの日照時間の推計値への切替」

- URL: https://ds.data.jma.go.jp/stats/data/mdrr/man/sampling.html
- 2021年3月2日からアメダスの日照時間を日照計観測から推計気象分布による推計値へ変更したことの根拠
- URL: https://www.jma.go.jp/jma/kishou/know/suikei_kishou/kaisetsu.html
- 推計気象分布の作成方法・性質を確認し、方式変更前後の比較注記へ反映する

### 国土交通省「国土数値情報 平年値メッシュデータ G02」

- URL: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-G02-2022.html
- G02-2022の原典が「メッシュ平年値2020」であり、2022年単年観測ではないことの根拠
- 日照時間属性、単位、欠測値、メッシュ仕様をR2生成処理と照合する

### 総務省統計局「社会・人口統計体系」

- URL: https://www.stat.go.jp/data/ssds/index.html
- B41自然環境・気象指標の定義、原資料、地点、年次を確認する
- e-Stat `statsDataId=0000010102`のメタ情報と各`cdCat01`を照合する

## テーマ境界

| テーマ | 責務 |
|---|---|
| `climate` | 平年の気候、単年の天候・平年偏差、極端現象、気候の空間分布 |
| `safety` / 防災 | 災害発生、被害、警報、避難。降水量だけから災害危険度を断定しない |
| `agriculture` / `fishery-marine` | 気象条件と生産の関係。気候指標だけで生産量を説明しない |
| `living-housing` | 冷暖房、住宅性能、光熱費。気温と費用の因果を単純化しない |
| `tourism` | 観光需要・宿泊。晴天日数を観光人気の代理にしない |
| `environment` | 温室効果ガス、自然環境、汚染。単年の暑さを地域排出量の結果としない |

## 現行指標の提案

| rankingKey | 現行 role | 提案 | 理由 |
|---|---|---|---|
| `annual-sunshine-duration` | primary | **secondaryへ変更** | 2024年の単年天候。地点・方式変更を注記し、平年日照時間を主軸にする |
| `annual-clear-days` | secondary | **context / 監査後remove** | 2020年1点で0日も存在。目視観測・coverage・欠測を監査するまで比較主軸にしない |
| `average-temperature` | primary | **secondaryへ変更** | 2024年の単年値。平年値との差と組み合わせて表示する |
| `maximum-temperature` | context | **名称修正してcontext** | 真の最高気温ではない。「日最高気温の月平均の年内最高値」と明示する |
| `lowest-temperature` | context | **名称修正してcontext** | 真の最低気温ではない。「日最低気温の月平均の年内最低値」と明示する |
| `annual-precipitation` | secondary | **secondary keep** | 2024年の年合計。平年比と地点を併記する |
| `annual-precipitation-days` | context | **context keep** | 閾値と暦年を明記。降水量とは別概念 |
| `annual-snow-days` | secondary | **contextへ変更** | 2020年1点で観測地点coverageの影響が大きい |
| `maximum-snow-depth` | 未選択 | **不採用 / 最新・平年系列待ち** | 2007年1点のみで現況比較に不適切 |
| 平年年平均気温 | なし | **primary追加候補** | 地域の気候特性を示す基準。1991〜2020年・地点を明記 |
| 平年年間降水量 | なし | **primary追加候補** | 多雨・少雨の気候特性。単年値と分離 |
| 平年年間日照時間 | なし | **primary追加候補** | GISとランキングを同じ1991〜2020年基準で接続できる |
| 年平均気温平年差 | なし | **secondary追加候補** | 単年の暖かさ・寒さを絶対気温より適切に比較できる |
| 年降水量平年比 | なし | **secondary追加候補** | 地域固有の雨量水準を調整して単年の多雨・少雨を比較できる |
| 猛暑日・真冬日等 | なし | **追加候補** | 極端現象を生活実感に近い定義で比較。地点coverage監査が前提 |
| 日降水量極値・大雨日数 | なし | **追加候補** | 年合計とは異なる極端降水。ただし防災被害とは分離 |

### 全気象指標に共通する設定修正

- `yearFormat`は元表確認後、暦年値なら`calendar`へ修正する
- 気温、降水量、日照時間、日数、積雪深から人口・面積`normalizationOptions`を削除する
- `℃/10万人`、`mm/100km²`、`日/10万人`等を生成・表示しない
- 負の気温を倍率で説明しない。`-3.0倍`のようなSEO文言を禁止する
- 代表地点の場合はタイトルまたは常時表示noteに地点名を含める

## 現行表示・チャートの提案

現行`climate`は`ThemeCatalog`未移行のlegacy `IndicatorSet`で、ページコンポーネントchartはない。`sunshine-map`だけが埋め込みsectionとして登録されている。

| 表示 | 提案 | 理由 / 実装 |
|---|---|---|
| 指標カード | **平年値と単年値をsection分離** | 同じ「年間」でも30年平均と2024年合計は意味が違う |
| `sunshine-map` | **keep / 表示修正** | 「1991〜2020年平年 年間日照時間・1kmメッシュ」と明記し、2022年値と誤読させない |
| 日照map説明 | **地点ランキングとの差を追加** | GISは県内分布、rankingは代表地点である可能性があり集計単位が異なる |
| 気温推移 | **平年差を優先して追加候補** | 絶対気温は南北差が支配的。地点移転・欠測・方式を確認してgap-aware表示 |
| 降水推移 | **平年比を優先して追加候補** | 年合計の地域差と、その年の異常性を分離できる |
| 最高・最低気温 | **定義別panel** | 月平均の極値と真の観測極値を同じchartに混在させない |
| 日照推移 | **方式変更線付きで保留** | 2021年3月の方式変更を境界として表示できる場合のみ |

### 追加チャート

1. **平年値3指標**: 年平均気温、年間降水量、年間日照時間を別panelで表示。異単位を1軸に重ねない。
2. **直近年の平年差・平年比**: 気温は差、降水・日照は比を基本とし、絶対値も併記。
3. **地点別長期推移**: 観測地点の移転・統計切断・欠測を表示できる場合のみ。
4. **極端現象**: 猛暑日、真冬日、大雨日数等を定義別に表示。災害被害とは分離。
5. **日照GIS**: 1991〜2020年平年値の1kmメッシュをflagshipとして維持。

## 不採用・保留

| 候補 | 判定 | 理由 / 再検討条件 |
|---|---|---|
| 2024年単年値を地域の「気候」と断定 | 不採用 | 単年の天候と30年平年値を混同する |
| 代表観測地点の値を県全域平均と表示 | 不採用 | 山地・沿岸・島しょ等の県内差を隠す |
| G02-2022を2022年の日照時間と表示 | 不採用 | データはメッシュ平年値2020 |
| 2021年前後の日照時間を無注記で連続比較 | 不採用 | 観測から推計への方式変更がある |
| 快晴0日を真の0と即断 | 不採用 | 観測方式・coverage・欠測確認が必要 |
| `最高気温`を年内の真の最高観測値として説明 | 不採用 | 現行B4102は日最高気温の月平均の最高値 |
| `最低気温`を年内の真の最低観測値として説明 | 不採用 | 現行B4103は日最低気温の月平均の最低値 |
| 気温・降水・日照・日数の人口／面積正規化 | 不採用 | 量の意味を失い、比較解釈が成立しない |
| 負の気温の倍率比較 | 不採用 | 比率尺度ではなく、符号をまたぐ倍率に意味がない |
| 2007年最深積雪を現況ランキングへ追加 | 不採用 | 古い単年1点 |
| 全県の面積加重平年値 | 保留 | メッシュから一貫して計算し、標高・海域・欠測を監査できる場合のみ |
