# テーマレビュー: railway（鉄道）

## 結論

主問は、**その都道府県で鉄道がどの程度利用され、どのような路線・駅供給があり、旅客と貨物の地域交通をどう支えているか**とする。

読み順は次の4層に分ける。

1. **駅利用**: 駅別乗降客数の都道府県集計。延べ乗降・非公開駅・重複を明記
2. **旅客輸送**: JR・民鉄の輸送人員と旅客人キロ。人数と移動距離を分離
3. **供給・アクセス**: 駅数、営業キロ、路線密度、鉄道通勤通学。数と利便性を同一視しない
4. **貨物**: 発送量とトンキロ。旅客とは別sectionで扱う

駅乗降客数、鉄道輸送人員、国勢調査の鉄道通勤通学者数は別指標である。駅乗降客数は駅で記録された乗車・降車の延べ量、輸送人員は事業者が輸送した旅客数量、通勤通学者数は居住者の利用交通手段を表す。これらを合算したり、いずれかを「鉄道を使う実人数」と呼んだりしない。

## P0: 対象範囲・系列監査

実装前に次を確定する。

- `railway-passengers` が駅ごとの1日平均乗降客数の都道府県合計で、年間総数ではないこと
- S12の各年がデータ整備年度か原典の基準年度か。画面上の年度表示と1年ずれがないこと
- 一部非公開駅・未収録駅があり、都道府県合計が全駅を網羅しないこと
- 乗降客数が乗車+降車の延べ数で、往復、乗換、複数路線利用を含み、実人数ではないこと
- 同一駅の複数事業者・複数路線・駅コード・ジオメトリを都道府県集計時に重複計上していないか
- 都県境駅、駅所在地、路線跨境の帰属規則
- `jr-passenger-transport` と `private-railway-passenger-transport` の都道府県帰属が駅所在地、路線所在地、事業者所在地、運輸局のどれか
- 「民鉄」がJR以外を指し、公営地下鉄・軌道等を含むか。JR+民鉄が鉄・軌道合計と加法整合するか
- JR輸送人員が現行metricでは2023年1点のみで、推移chartを構成できるか
- 民鉄輸送人員の2021・2022年欠落が真の欠測か設定漏れか。線で2019/2020から2023へ接続しないこと
- 輸送人員と旅客人キロ、定期・定期外、新幹線・在来線の包含関係
- `railway-station-count` がN02の駅オブジェクト数か、名称ベースの実駅数か。乗換駅・複数路線をどうdedupeするか
- 駅数の基準日、休止駅・臨時駅・新設廃止、鉄道・軌道・索道の対象範囲
- `jr-freight-shipment` の発送地点、コンテナ/車扱、貨物駅、通過貨物の扱い
- 貨物発送量の2017〜2022年欠落が設定漏れか資料非公表か。2023へ線を接続しないこと
- 沖縄県等のJR・JR貨物0が「鉄道なし」「対象事業なし」「欠測」のどれか
- 2020〜2022年の旅客減少を恒常的な需要構造と断定しないこと

## 公式根拠

### 国土交通省「鉄道輸送統計調査」

- URL: https://www.mlit.go.jp/k-toukei/tetudouyusou.html
- 営業キロ、旅客数量、旅客人キロ、貨物数量、貨物トンキロ、列車・車両キロ、旅客収入の中心出典
- 年報は4月〜3月の年度値であり、速報・月報・年報を区別する

### 国土交通省「鉄道輸送統計調査 用語解説」

- URL: https://www.mlit.go.jp/k-toukei/tetsuyu-yougo.html
- 旅客数量と、各駅間通過人員×駅間距離である旅客人キロの定義
- 輸送人員だけで移動距離・輸送サービス量を評価しない

### e-Stat「鉄道輸送統計調査」

- URL: https://www.e-stat.go.jp/stat-search/files?kikan=00600&toukei=00600350&tstat=000001011026
- JR旅客会社、民鉄、旅客数量、旅客人キロ、貨物数量等の正本
- 現行SSDS指標の都道府県帰属と元表を確認し、全国・運輸局値を県値へ誤配分していないか監査する

### 国土交通省「国土数値情報 駅別乗降客数 S12」

- URL: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-S12-2023.html
- 全国の鉄道事業者提供資料を駅データへ付与した駅別乗降客数の出典
- 一部非公開駅があり、データ年度と更新年度を区別する

### 国土交通省「国土数値情報 鉄道 N02」

- URL: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N02-2024.html
- 鉄道路線・駅の空間データの出典候補
- 駅オブジェクトの構造を確認し、単純feature数を実駅数としない

### 総務省統計局「令和2年国勢調査 従業地・通学地による人口・就業状態等集計」

- URL: https://www.stat.go.jp/data/kokusei/2020/kekka.html
- 鉄道・電車を利用する通勤通学者の居住地/従業地・通学地側分析候補
- 駅利用や全目的の輸送人員ではなく、5年周期の通勤通学手段として扱う

### 国土交通省「都市鉄道の混雑率調査」

- URL: https://www.mlit.go.jp/report/press/tetsudo04_hh_000130.html
- 最混雑時間帯1時間の主要区間混雑率の出典
- 三大都市圏の主要区間中心で47都道府県比較にならないため、全国ランキングには使わない

## 現行指標の提案

| rankingKey | 現行 role | 提案 | 理由 |
|---|---|---|---|
| `railway-passengers` | primary | **primary keep / coverage明記** | 駅所在地ベースの利用規模に最も近い。非公開駅と延べ乗降を明記 |
| `jr-passenger-transport` | primary | **secondaryへ変更 / 地理監査** | JR利用の規模だが現状1年のみで、都道府県帰属も確認が必要 |
| `private-railway-passenger-transport` | secondary | **secondary keep / 欠測監査** | JR以外の輸送を補完。公営・軌道等の包含範囲を明記 |
| `railway-station-count` | secondary | **secondary keep / dedupe監査** | 供給基盤の指標。ただし駅feature数と実駅数を区別 |
| `jr-freight-shipment` | context | **context keep / 別section** | 貨物の発地側物流を補足。旅客KPIと分離し、欠落年を接続しない |
| 旅客人キロ | なし | **secondary追加候補** | 輸送人員では分からない移動距離を含む輸送量。県別帰属可能性を監査 |
| 営業キロ・路線密度 | なし | **secondary追加候補** | 駅数だけでなくネットワーク供給を説明。営業キロとGIS線長を区別 |
| `commute-by-train` | なし | **context追加候補** | 居住者の通勤通学手段。2020年国勢調査で駅利用とは別母集団 |
| 鉄道貨物トンキロ | なし | **context追加候補** | 発送トン数と輸送距離を補完。都道府県値が成立する場合のみ |
| 混雑率 | なし | **全国ランキング不採用** | 三大都市圏主要区間中心で47県coverageがない |

## 現行チャートの提案

| componentKey | 提案 | 理由 / 実装 |
|---|---|---|
| `railway-passenger-trend` | **P0後に再構成** | JRは現行1点、民鉄は2021・2022欠落。現状のまま「推移」として線を結べない |
| `railway-freight-trend` | **gap-awareへ変更** | 2017〜2022年が欠ける。欠測を補間せず、取得できなければ期間を分割 |

### 追加チャート

1. **駅乗降客数の推移**: 2019〜2023年度。非公開駅coverageが年ごとに同等か確認後に表示。
2. **JR・民鉄輸送人員**: 同一年・同じ地理scopeの系列だけで比較。欠測年は線を切る。
3. **輸送人員・旅客人キロ**: 別panelまたは適切な二軸chart。人数と距離を同一Y軸に置かない。
4. **駅数・営業キロ**: 供給指標として別panel。利用量との因果を断定しない。
5. **鉄道通勤通学者率**: 居住地ベースの国勢調査context。駅利用と分離。
6. **JR貨物発送量・トンキロ**: 発送量と距離を別panel。旅客sectionから分離。

## 不採用・保留

| 候補 | 判定 | 理由 / 再検討条件 |
|---|---|---|
| 駅乗降客数=鉄道利用者の実人数 | 不採用 | 乗車・降車、往復、乗換を含む延べ量 |
| S12都道府県合計=全駅の完全な合計 | 不採用 | 一部非公開駅があり、収録coverageを確認する必要がある |
| 駅feature数=実駅数 | 不採用 | 複数路線・事業者・ジオメトリによる重複可能性がある |
| JR+民鉄を全鉄道利用として無条件合算 | 保留 | 民鉄、公営、軌道、索道等の範囲と同一地理scopeを確認できる場合のみ |
| 輸送人員が多い=長距離利用が多い | 不採用 | 距離を含まず、旅客人キロが必要 |
| 鉄道利用者=観光客 | 不採用 | 通勤通学、業務、生活、帰省等を含む |
| 駅数が多い=利便性が高い | 不採用 | 頻度、路線網、接続、人口分布、所要時間を反映しない |
| 2020年の落込み=地方鉄道の恒常的縮小 | 不採用 | コロナ禍の移動・通勤変化を含む |
| 欠測年を直線補間 | 不採用 | 実測変化と誤認させる |
| 三大都市圏混雑率を47県ランキング化 | 不採用 | coverageと観測単位が都道府県比較に適さない |

5. JRの過去年が取得可能か調査し、1点しかなければline chartから除外
6. 民鉄2021・2022年、JR貨物2017〜2022年の欠落理由を確認し、欠測を線で接続しないfixtureを追加
7. N02駅数のfeature構造を確認し、事業者・路線・駅名・座標等によるdedupe方法を決定
8. 旅客人キロ、営業キロ、貨物トンキロの都道府県coverageを調べ、新規metricは指標バックログへ記録
9. 0、対象事業なし、非公開、欠測を区別する
10. 2020〜2022年へコロナ禍annotationを設定

### 禁止

- 駅乗降客数を利用者実人数・年間総数と呼ばない
- 非公開駅を0として合計し、完全coverageと説明しない
- 駅featureを無条件に実駅数として数えない
- JR・民鉄の地理scopeを確認せず合算しない
- 輸送人員と人キロを同一視しない
- 1点の系列や欠測年を連続した推移線にしない
- 鉄道利用者を観光客と呼ばない
- 貨物発送量を通過貨物や着貨物と同一視しない
- 対象事業なし・非公開・欠測を0へ丸めない
- 生成物TS/JSONを手編集しない
- R2 push / deployを行わない

## 採用決定

**PR-0の地理帰属・coverage・系列監査後に実装可能。駅乗降を主系列とし、JR/民鉄輸送人員、旅客人キロ、駅・路線供給、貨物を別概念として構成する。非公開駅、駅feature重複、1点系列、欠測年を保持し、駅所在地・事業者・居住地の地理scopeを混同しない。**
