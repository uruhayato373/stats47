### 候補1: 公務員給与・ボーナスの都道府県格差（マッチ度: ★★★ / ソース: yahoo経済 + google-news + yahoo国内 = 2〜3ヒット）

- **注目度**: Yahoo経済トピックス入り（公務員ボーナス）+ Google News国内に県別ボーナス記事 + 議員所得は毎年恒例の高関心テーマ。
- **分類カテゴリ**: administrativefinancial（行財政）／ laborwage 隣接
- **タイミング**: 6月末＝夏季賞与支給で「公務員の手当・ボーナス」が毎年バズる季節需要。stats47 に **2024年版の都道府県別データ**があり未記事化＝先行余地。
- **検出ソース**: yahoo（経済・国内）/ google-news（健康外の国内）
- **ヒットソース数**: 2 / 6（公務員報酬テーマで yahoo・google-news が独立ヒット）

1. **公務員が一番"おいしい"県はどこか**: 期末・勤勉手当（ボーナス）と平均給与月額の上位/下位を可視化。東京・大阪など大都市が上位か、それとも別の県か（curiosity gap）。
2. **国家公務員 vs 地方公務員のねじれ**: 国家公務員ボーナス73万円という全国数字に対し、都道府県別の手当はどれだけ振れるか。地方の方が高い県はあるか。

### 候補3: 農業就業人口の構造的減少（「100万人割れ」）（マッチ度: ★★☆ / ソース: hatena社会 66bm）

- **トレンド概要**: 「農業就業者、1985年以来初めて100万人を割る」（はてブ社会 66bm・47news）。担い手減少が定量フックとして強い。
- **分類カテゴリ**: agriculture（農林水産業）
- **データ**: `agricultural-employment-population`（農業就業人口・**2014と古い**）／ `agricultural-farm-count`（農家数・2019）／ `total-farm-household-income`（農家総所得）。**全国の100万人割れは2026年最新値だが、stats47 の県別データは古い**ため「構造的減少の地理」を歴史トレンドで描く形になる。
- **既存記事との差別化**: `agriculture-hokkaido-dominance` / `sixth-industry-direct-sales` / `cc-estat-13-agri-sankey` は産出額・北海道の効率がテーマ。**「担い手（就業人口）の減少」アングルは未カバー**。
- **切り口（案）**: ① 農業就業人口の減り方が激しい県・踏みとどまる県の地理 ② 農家数 vs 産出額の乖離（少人数で稼ぐ県）。
- **注意**: 県別データが2014/2019と古いため、「最新の100万人割れ」は全国の枕として使い、本文は県別の構造比較に寄せる。鮮度を前面に出しすぎない。
- **次アクション**: `fetch-ranking-data-r2.mjs`（`agricultural-employment-population` + `agricultural-farm-count`）→ アーキタイプ C/A。

### 候補4: HPVワクチン接種率の都道府県格差（マッチ度: ★★☆ / ソース: google-news健康 ×2）

- **トレンド概要**: Google News健康で「英国で HPV ワクチンが子宮頸がん死亡を減少」「男性 HPV ワクチン認知度40%にとどまる」が並走。予防医療として継続関心。
- **分類カテゴリ**: socialsecurity（社会保障・衛生）
- **データ**: `vaccination-recipients-disease`（ＨＰＶワクチン定期予防接種者数・都道府県別・**2020**）。子宮頸がん死亡率系の指標と組めると相関アングルになる。
- **既存記事との差別化**: 健康寿命系（`healthy-life-expectancy-male-female-gap`）はあるが **HPV/予防接種テーマは未カバー**。
- **切り口（案）**: ① ワクチン接種率が高い県・低い県の地理（積極勧奨停止の傷跡が残る県差）② 接種率と子宮頸がんアウトカムの相関（アーキタイプ B）。
- **注意**: データが2020と古い＋接種率は分母（対象人口）整備が要る。新規執筆前に `fetch-ranking-data-r2.mjs` で値の妥当性を確認。
- **次アクション**: データ取得 → 妥当なら アーキタイプ A/B で執筆。古ければ保留（指標バックログへ）。
