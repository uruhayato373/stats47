## 切り口選択のルール

### プライオリティ順

1. **アフィニティ ◎ の切り口 3 つ**を必ず生成する（メインセット）
2. **残り 3 切り口**はアフィニティ ○ 以上から選ぶ（サブセット）
3. `△` / `—` の切り口は生成しない（品質低下リスク）

### 同じカテゴリでも ranking_key によって微調整する

| ranking_key の特徴 | 切り口調整 |
|---|---|
| 最大/最小の格差が 2 倍以上 | 数字 ◎ を必ず入れる |
| 「通説」と逆の順位がある | 反論 ◎ を優先する |
| 生活への直接影響がある | 体験 ◎ を優先する |
| 政策的含意がある | ハウツー ◎ を入れる |
| データが複雑で「なぜ」が生じやすい | 理由 ◎ を優先する |

### 切り口の「強調バリアント」生成

アフィニティ ◎ の上位 3 切り口には、同じデータで視点を少し変えた**強調バリアント**を 1 本追加する。  
例: 数字 ◎ のメインが「1位-47位格差」なら、バリアントは「全国平均との比較」または「時系列変化」にする。

## 時間帯×切り口の最適マッチング

x-angles-scheduler が投稿スケジュールを決定する際の参照表:

| 切り口 | 最適時間帯 | 理由 |
|---|---|---|
| **数字** | 平日 7:00-9:00（通勤） | 短時間で読める・保存されやすい |
| **結論** | 平日 12:00-13:00（昼休み） | 賛否両論が起きやすい時間帯 |
| **理由** | 平日 18:00-19:30（帰宅） | 腰を据えて読む時間帯 |
| **反論** | 平日 10:00-11:30（業務中） | 議論が発展しやすい |
| **体験** | 平日 21:00-23:00（夜間） | 感情共感が起きやすい |
| **ハウツー** | 土日 9:00-11:00（週末午前） | 保存・試行率が高い |
