# 6 切り口テンプレート集

stats47 の都道府県データを 6 つの異なる切り口で X (Twitter) 投稿に変換するための文例集。
各切り口に 5 例を掲載。200 字以内（URL 除く）、ハッシュタグ 0-2 個、数値は実測値のみ。

---

## 1. 結論（Conclusion）

> **フック**: 断言から入る。「答えは〇〇です」「〇〇は△△が最強」
> **構造**: 結論先出し → 根拠 2 行 → 同意/驚き問いかけ CTA
> **目的**: 賛否両論を引き出す、引用 RT 誘発

### 文例

```
【結論】都道府県の手取り格差は「住む場所」より「何に使うか」で決まる。

1位東京の可処分所得でも、物価調整後の実質値は北海道と誤差1.2%。
格差の正体は支出構造だった。

詳細→ {{url}}
```

```
【結論】少子化の一番の原因は「出会いの機会」ではなく「住宅コスト」。

未婚率1位と家賃相関係数r=0.81。データが示す答えは経済問題だ。
あなたの県はどう感じますか？

{{url}} #少子化 #都道府県
```

```
長寿の秘訣は「長野モデル」に詰まっている。

平均寿命男性81.8歳（全国1位）、医師数は全国24位。
訪問看護件数と自主検診率が高い事実。「医療頼み」でない答えがある。

```

```

東京→鳥取で名目年収-23%、でも生活費-38%なら実質+15%になる試算。

```

```
【結論】観光立国は京都・沖縄だけではない。

人口1人当たりなら長野・山梨・沖縄の順。「小さな観光大国」がある。

{{url}} #観光 #地方

## 2. 理由（Reason）

> **フック**: 疑問提起で始める。「なぜ〇〇なのか」
> **構造**: 疑問提起 → 理由 3 層（短く） → 「詳しくは→」URL
> **目的**: 知識欲を刺激、保存率を上げる

### 文例

```
なぜ沖縄は所得が低いのに幸福度が高いのか？

理由①: 帰属意識（地域コミュニティ密度は全国1位）
理由②: 気候（真冬でも18℃）
理由③: 比較基準（外の世界を知らないという仮説は統計上否定）

データで読む「沖縄の幸福」→ {{url}}
```

```
なぜ東北・甲信越の身長が高いのか？

理由①: 農業・漁業従事者比率（屋外活動量≒成長ホルモン）
理由②: 乳製品消費量（秋田はバター消費1位）
理由③: 寒冷地適応（仮説段階）

最新データはこちら→ {{url}} #身長 #都道府県
```

```
なぜ離島県で公務員率が高いのか？

理由①: 民間企業が少ない（製造業・サービス業の立地困難）
理由②: 行政サービス維持の人件費比率が大きい
理由③: 転出した若者が残らない（就業機会の非対称）

都道府県別公務員率→ {{url}}
```

```
なぜ静岡は野菜の生産量が多いのに農業所得が低いのか？

理由①: 単価の安い葉物・茶葉が主力
理由②: 大消費地（名古屋・東京）向けの卸売構造
理由③: 6次産業化率が全国平均以下

農業所得ランキング→ {{url}} #農業
```

```
なぜ北陸は共働き率が高いのか？

理由①: 持ち家率が高く住宅ローン負担が比較的小さい（家族の経済安定）
理由②: 子育て支援の充実（石川・富山の保育所利用率は全国上位）
理由③: 気候的に農閑期の代替就業が根付いた歴史的背景

共働き率ランキング→ {{url}}
```

## 3. 体験（Experience）

> **フック**: 「もしあなたが〇〇県に住んでいたら」
> **構造**: 仮体験フック → データを感情で描写 → 「あなたの県は？」リプライ誘導
> **目的**: 個人化・感情移入、返信を誘発

### 文例

```
もし岩手県に住んでいたら、コンビニまで平均12.4kmを運転する生活。

東京では徒歩3分のコンビニが、ここでは「ちょっと買い物」が30分の往復。
インフラ格差は距離感の格差だ。

あなたの県は何分？→ {{url}}
```

```
青森県に生まれていたら、男性の平均寿命は80.0歳。
東京なら82.2歳。2.2年の差を「地元を選んだ代償」と感じるか否か。

単純な比較ではなく、何がこの差を生んでいるのかが気になる。

{{url}} #健康寿命
```

```
もし東京23区で一人暮らしをはじめたら、家賃に月収の38%が消える。

同じ給料で鳥取に住んだら家賃は16%。残った22%で何ができるか考えてみた。

あなたなら都市か地方か？引用RTで→ {{url}}
```

```
北海道の農家に生まれていたら、経営する農地は全国平均の8倍、34ha。

でも1ha当たりの農業所得は都府県平均より低い場合もある。
広さと収益は比例しない農業の実情がある。

```
大阪に住んでいたら、救急車の平均待機時間は9.5分（全国最長水準）。
長野なら4.2分。数字の差が命の差になる可能性がある。

救急医療格差、あなたの地域は？→ {{url}} #医療
```

## 4. 反論（Rebuttal）

> **フック**: 「〇〇と思いがちですが実は」「通説を覆す」
> **構造**: 通説提示 → 反証データ → 「驚いた人は保存を」CTA
> **目的**: 保存・DM 共有、知的刺激

### 文例

```
「東京は物価が高い」は正しいか？

食料費・光熱費・交通費を合算した生活費指数では、東京は全国3位。
実は鹿児島・長崎・高知の方が食費・車維持費で支出が重い。

データで通説を覆す→ {{url}} #物価
```

```
「地方は車がないと生活できない」への反論。

電車通勤率が1位のさいたま市（都市圏）より、富山市のほうが公共交通利便性が高い（コンパクトシティ指数）。
都市郊外より地方中核都市のほうが快適なケースがある。

{{url}}
```

```
「大学進学率は都市が高い」は半分正解。

京都・石川・東京の進学率は高いが、鳥取より山形のほうが低い。
地方の中でも開きがある事実。「地方＝低進学率」ではない。

{{url}} #教育 #大学
```

```
「農業県は所得が低い」への反論データ。

農業産出額1位の北海道、でも農家1戸当たりの農業所得は長野・愛知に劣る。
規模より単価・付加価値の話だとわかる。

{{url}} #農業所得
```

```
「観光客が多い県＝観光業が儲かる」は間違い。

入込客数1位は東京だが、観光業の県内GDP貢献率1位は沖縄（6.8%）。
客数よりも「1泊あたり消費額」と「滞在日数」が重要。

{{url}} #観光 #経済
```

## 6. ハウツー（How-to）

> **フック**: 「このデータを使う 3 ステップ」
> **構造**: 活用シーン → ステップ 1-2-3 → 「試してみてください」実用 CTA
> **目的**: 保存率・ブックマーク率を上げる、実用価値の訴求

### 文例

```
「移住先選び」にこのデータを使う3ステップ。

①生活費指数で絞る（目標値以下の県）
②医療施設数で絞る（医師数1000人当たり2.0以上）
③平均通勤時間で確認（30分以内）

stats47でこの3軸を同時に比較→ {{url}}
```

```
就活生の「転職前に見るべき賃金データ」3点

①都道府県別 平均月収（業種別でも絞れる）
②物価調整後の実質年収換算
③求人倍率（需給バランス）

志望地の年収が高くても物価次第で逆転する。確認は→ {{url}} #就活
```

```
「移住補助金」を調べる前に確認すべき3つの統計。

①財政力指数（支援が続くかの目安）
②人口増減率（将来の地域活力）
③可住地面積比率（土地の余裕）

移住後に後悔しないために→ {{url}}
```

```
子育て移住を考えたら見るデータ3選。

①保育所待機児童数（即入所できるか）
②教育費の公費負担率（塾代の不要な地域か）
③小学校の児童100人当たり教員数（手厚さの目安）

全都道府県で比較→ {{url}} #子育て移住
```

```
農業ビジネスの立地選びに使えるデータ3軸。

①農地1ha当たりの農業産出額（生産性）
②農業所得の都道府県中央値（稼げる環境か）
③6次産業化事業者数（販路のエコシステム）

経営判断の参考に→ {{url}} #農業 #起業
```

## 共通 NG パターン

| NG 表現 | 理由 |
|---|---|
| 「〜のはず」「おそらく」 | 実証ベース判定ルール違反 |
| 「〜と言われています」 | 一次ソースを明示できない |
| 200 字超え | X 日本語制限を超える |
| ハッシュタグ 3 個以上 | スパム判定リスク |
| URL が 2 本以上 | X の見た目が崩れる |
| 「ランキング」をタイトルに含む | Remotion のサブタイトルと重複する |
| 「R2 から取得できない数値」の使用 | 推測数値の混入防止 |
