# 公務員 note カバー 共通背景 — Codex 依頼書

公務員 note 2 シリーズ（`koumuin-claude-code` 33 本 + `koumuin-estat-claude-code` 12 本 = 計 45 本）の
**カバー画像に共通で敷くキャッチーな背景**を 1 枚作る。タイトル等の文字は後段のジェネレータ
（`.claude/scripts/note/generate-koumuin-covers.cjs`）が中央ボックスで重ねるので、**背景に文字・ロゴは入れない**。

## 成果物（唯一のアウトプット）

| 項目 | 指定 |
|---|---|
| 保存先 | `.claude/scripts/note/assets/koumuin-cover-bg.png` |
| サイズ | **2560 × 1340 px**（= 1280×670 の 2x。最終は 1280×670 に縮小して使う） |
| 形式 | PNG（不透明・RGB）。元データ（ai/psd/svg 等）は `assets/source/` に置いてよい |
| 枚数 | **1 枚**（カテゴリ別の色は後段ジェネレータが上に乗せるので、背景は 1 枚共通） |

## デザイン要件

- **テーマ**: 「公務員 × AI / Claude Code」。行政（庁舎・書類・日本地図・行政窓口の抽象）と
  デジタル/AI（ターミナル・回路・データグリッド・光の粒子・ノードの繋がり）を融合した抽象ビジュアル。
- **トーン**: **ダーク基調**（濃紺〜黒〜深いスレート）。中央に敷く半透明ボックス上の白文字が映えること。
- **彩度は抑えめ（モノトーン〜2 色デュオトーン推奨）**。後段でカテゴリ色（青/緑/赤/紫/橙/シアン/藍/琥珀…）を
  グラデで薄く乗せるため、背景自体がビビッドだと色が喧嘩する。**無彩色〜寒色の暗いベース**が理想。
- **キャッチー = 質感で魅せる**: 光のグラデ、粒子、細い格子/回路、緩い斜めフロー等。うるさすぎない範囲で。

## レイアウト制約（★重要・中央セーフゾーン）

最終カバーは **中央に半透明ボックス**を置き、その中にタイトルを載せる。よって：

```
2560×1340 キャンバス
┌───────────────────────────────────────────┐
│  ★ここに視覚の主役（左上）                   │
│        ┌─────────────────────────────┐      │
│        │  ← 中央セーフゾーン →         │      │  ← この矩形(おおよそ
│        │   x: 300–2260 / y: 240–1100  │      │     x:300-2260, y:240-1100)は
│        │   ボックスで隠れる。細かい     │      │     半透明ボックスで覆われる。
│        │   要素・被写体を置かない       │      │     重要モチーフを置かない。
│        └─────────────────────────────┘      │
│                        ★ここも主役（右下）    │
└───────────────────────────────────────────┘
```

- **中央（上記矩形）は落ち着かせる**（暗め・低コントラスト）。視覚の主役は**四隅・上下左右の余白側**へ。
- 端まで塗り切る**フルブリード**（余白の白フチを作らない）。

## やってはいけないこと

- 文字・ロゴ・数字・note/stats47 表記を入れる（全部プログラムで乗せる）
- 特定記事に依存するモチーフ（45 本共通なので普遍的に）
- 明るい/白背景（白文字ボックスが沈む）、全面ビビッド（カテゴリ色と喧嘩する）

## 完成後

`koumuin-cover-bg.png` を上記パスに置けば、`node .claude/scripts/note/generate-koumuin-covers.cjs`
が自動で全 45 カバーに合成する（ファイルが無い間はプログラム生成のダーク背景にフォールバックする）。

## 再生成 (実装済み)

背景は決定的に再生成できる。Codex が書いた生成器 `source/build-koumuin-bg.mjs`
（シード付き乱数 `mulberry32` で同一出力・sharp でラスタライズ）を実行すると
`koumuin-cover-bg.png`（2560×1340）と中間 `source/koumuin-cover-bg.svg` を再出力する:

```bash
node .claude/scripts/note/assets/source/build-koumuin-bg.mjs
```

デザインを変えたいときはこのスクリプトを編集して再実行 → `generate-koumuin-covers.cjs` で再合成する。
