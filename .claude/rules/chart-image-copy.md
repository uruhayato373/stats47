# 統計画像内のテキスト（4媒体共通）

note・サイト・X・Instagramの統計図は、[画像コピー共通契約](../scripts/media/lib/image-copy.mjs) の `CHART_IMAGE_COPY_POLICY` を適用する。2026-10-19のオーナー再指示で固定。

- **発行元（stats47・stats47.jp・ブランド行・透かし）は画像に入れない（2026-11-02 オーナー決定）。** 発行元は記事本文・投稿文で示し、画像は指標と図の印象だけで勝負する。`assertMinimalChartCopy` が `stats47` を含む可視テキストを拒否する。既存の生成経路（SNS の Remotion・quick-still・バズマップ）は共通化の移行時に外す（`IMAGE-PUBLISHER-REMOVAL-01`）。
- 画像内に残すのは指標名・年・単位・短い出典・凡例と、誤読を防ぐ必須条件だけ。母数・比較基準・抜粋範囲・統計定義は必要なものを1回だけ短く示す。
- 解説・読み方・一般的な免責・行動案内は本文や投稿文へ置く。画像内に「タイルの大きさは…」「色が濃いほど…」「帯の太さは…」「各行は…」「政令指定都市は…」などを足さない。記事のデータの説明文 (`subtitle`) を条件の行へそのまま流さない。見出しで示した範囲を末尾でも説明しない。
- 追加する文は「消すとどの数値の意味を誤るか」で採否を決める。説明を増やす前にタイトル・単位・凡例で表現する。制作条件や出典の詳細は入力・管理画面に保持し、画像から省略しても記録は削除しない。
- 新しい型も既存型の修正も生成後の可視テキストを確認する。管理画面のランキング見本は `assertMinimalChartCopy` をPNG生成前に必ず通す。実データ画像の見た目も確認し、文字列検査だけで品質合格としない。
- 棒グラフ画像は順位・県名・棒・数値を分離し、数値ラベルを直接置く。軸目盛りと目盛線は既定で表示しない。指標台帳の表示範囲は維持し、0を含まない場合は短い「範囲：最小–最大」で示す。最小値の数値と端点も残す。
- **型の文字は 30 以上 (幅 1080 の座標・2026-11-14 オーナー決定)。** ブログの本文はスマホで約 360px 幅なので型の画像は 1/3 に縮み、30 で画面上 10px になる。入らない文字は縮めず、配置を変えるか出さない (1 列のタイルは県名の頭 2 文字だけ・値は凡例と上位 3 県へ)。正本は `chart-theme.ts` の `TEMPLATE_MIN_FONT_SIZE`、検査は `svg-lint.mjs` の `findTemplateFontFloorDefects`。
- 型を変える前に公開済み原図と既存の生成処理を確認する。読みやすい配置を引き継ぎ、文字の重なりや冗長な説明は踏襲しない。管理画面には固定した公開済み原図を参考として残す。

再発原因は、個別画像から説明を削除しても共通契約と生成経路に反映せず、別の型で定型注釈を再追加したこと。会話内の記憶だけに依存しない。
